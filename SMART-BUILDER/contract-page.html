How it works — the intake

A living form, co-crafted by both sides. The user picks pieces, switches things, types answers; Naya drafts, suggests, fills in. Molded in the open until "okay, build" fires assembly.

Images upload right in chat (like ChatGPT) and ride the contract into the build — nobody uploads twice. Links typed into the builder become contract fields. Page copy comes from talking, pasting, or dropping a doc — straight into the contract. The builder proposes the page skeleton from intent; the user approves or rearranges it. The user always sees a beautiful visual of what's going on — pieces, elements, answers, all organized.

The function contract

The questionnaire captures what everything DOES — intent, vision, goal, function — not just how it looks. That's the part every other builder skips.

Division of labor: the user never says what it looks like. They pick the parts and say what it DOES. Beauty is the system's job — the pieces plus the contract handle that. The system anticipates: everything is pre-done, pre-wired, pre-beautiful — the user just fills in the intent. Tell it what you intend, pick the pieces, boom, done. So beautiful, so logical, so intelligent that once you've experienced it, you can't imagine doing it any other way.

How we build it

Compose, don't create. Builders compose pre-built elite pieces — never invent new ones, never even need to read the laws. Tweak freely (one-token changes, DNA intact). New pieces only through the full process.

Function law: pretty + useless = not done. Every element intentional, logical, actually works. The builder clicks everything — real behavior, not staged. Scorecards score the working page, never the screenshot.

Law 1

Score the experience, never the code.

The lived page is the only scorecard.

Law 2

Restraint is the excellence.

Less glow, fewer colors, generous black space.

Law 3

Every effect encodes information.

No visual is acceptable merely because it moves.

Mobile-first — the default, not a feature

Everything we build is mobile-optimized and looks like a killer mobile smart app by default. These are smart mobile apps — PWAs. Every Naya app ships with install-app built in: download it to the phone and it works like an app right away.

The intake thinks proactively: one of the intake steps is the app icon — upload the image at the right size, or better, Naya creates the image for your page. Icon, install, mobile presentation and function are common practice, handled by default, so anyone can spin up one of these mini smart apps and it's on their phone working immediately.
