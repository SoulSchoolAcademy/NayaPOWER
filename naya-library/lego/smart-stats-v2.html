Take It With You

Every visualization above is built from three primitives. Learn these and you can invent your own.

/* 1 · THE ORB — a sphere of data */
.orb{
  background:radial-gradient(circle at 35% 30%,
    rgba(255,255,255,.95) 0%, rgba(255,255,255,.22) 24%,
    var(--oc) 56%, rgba(0,0,0,.55) 88%);
  box-shadow:0 0 26px 3px var(--ocg), 0 12px 32px rgba(0,0,0,.6);
}
/* 2 · THE ORBIT — motion with meaning (inner = faster) */
.orbit-spin{ animation:spin var(--dur) linear infinite; }
@keyframes spin{ to{ transform:rotate(360deg);} }
/* 3 · THE RIVER — data that flows */
.flow{
  background:repeating-linear-gradient(100deg,
    transparent 0 18px, rgba(var(--crgb),.55) 18px 34px,
    transparent 34px 52px);
  animation:flow 2.6s linear infinite;
}
@keyframes flow{ to{ background-position:52px 0; } }
