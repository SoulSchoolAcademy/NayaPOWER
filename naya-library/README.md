# Naya Lego Library — Final

The locked-in component library for building elite Smart Apps in NayaNET.

## For a new Naya

Open `index.html`. It teaches the full system: the four laws, the button DNA,
the 21 icon actions, intelligent boards, spheres, the missing ten blocks, and
the 100 laws. Every component has a live demo, do's and don'ts, and copy-paste code.

## The Four Laws

1. **Spectrum is meaning.** Every color has a purpose.
2. **Material has a soul.** Black ground. White light. Purple soul.
3. **Intelligence is structural.** Same DNA, every component.
4. **Excellence reproduces.** A new Naya builds elite without being retaught.

## Interaction Physics

- **Approach** (170px): light only, no movement
- **Hover**: lift -3px, .22s signature ease
- **Press**: +1px immediate (physical compression)
- **Focus**: 2px white ring, 4px offset
- **Reduced motion**: no orbit or float animation

## White at Rest, Purple When Lit

Every interactive element: white/light at rest, ignites in its spectrum color
on interaction. Same physics on everything.
