# 🔱☀️ PROJECT BUILD DIRECTIVE — NAYANET E02 INTELLIGENT HUB

**Status:** CANONICAL PROJECT SCOPE  
**Parent:** NAYANET Master Build & Execution Directive  
**Design authority:** NAYANET Design System Standard  
**Target:** `NAYANET/E02-INTELLIGENT-HUB-CLOUDFLARE/`

## 1. MISSION

Build the first real seed of the NayaNET intelligent environment:

**LIVING INTELLIGENCE FRONT DOOR → INTELLIGENT HUB.**

This must establish the component, spatial, visual, interaction, and continuity language for future NayaNET pages.

Do not treat this as a landing page redesign.

Do not treat it as a SaaS dashboard.

Do not treat it as a prototype.

---

# 2. EXPERIENCE ARCHITECTURE

`PORTAL → THRESHOLD → NAYA → LIVING SUN → WORLDS → POWER PLAYER → LEARNING → INTELLIGENCE → CONNECTION → COMPOUNDING`

The user journey must feel natural:

**ARRIVE → IDENTIFY → ENTER → MEET NAYA → EXPLORE → LISTEN → DISCOVER → ACT → RETURN WITH CONTEXT.**

The first five seconds must not require explanation.

---

# 3. FRONT DOOR LAYOUT

### Top brand bar

Left aligned:

**NayaNET** + subtle intelligent-network identity.

Keep it quiet and premium. Do not over-brand the header.

### Hero

Centered composition.

Required hierarchy:

1. `INTELLIGENT INTERNET BEGINS HERE`
2. `NayaNET`
3. `Create. Connect. Grow with US.`
4. `A living intelligent network where humans and AI connect, create, and grow together.`
5. `YOUR SMART ID`
6. Name input
7. `ENTER NayaNET →`

The tagline must have breathing room beneath the brand/name.

The large portal artwork must sit behind the experience as atmosphere, not as an obstruction.

No giant orb/ring may compete with the headline or obscure the copy.

### Identity assembly

Name input and ENTER button form one coherent physical system.

The button belongs directly beneath the input assembly in the final premium treatment.

### Discovery doors

Below the primary entrance, provide five semantic miniature destination boards:

- Naya Power
- Super Brain
- Smart Identity
- Power Player
- Your Intelligence

They are discovery doors, not a conventional navigation bar.

At rest they must be black/dimensional with visible semantic edge light.

Hover/press should reveal stronger semantic color.

### Footer statement

Keep quiet and secondary:

**THE INTERNET CONNECTED INFORMATION**

**NayaNET CONNECTS INTELLIGENCE**

---

# 4. HUB LAYOUT

After entering, the front door recedes.

The user enters a living environment.

### Header

- NayaNET mark/return
- current identity
- private-intelligence status
- Ask Naya action

Keep header quiet. The environment is the primary experience.

### Center

Naya / Living Sun must be geometrically dead-center in the visual bullseye.

Idle state: **green.**

Touch/active intelligence: **purple.**

The player and Naya relationship should feel like the heartbeat of the environment.

### Nine worlds

Surround the center with nine destination objects:

1. Naya Power
2. Super Brain
3. Smart Identity
4. Intelligence
5. Naya Power Player
6. MAXESS
7. 5-Day Challenge
8. Intelligent Spaces
9. Your Network

Use semantic colors and edge light so each world has identity while the overall system remains coherent.

No world should look like a dead card.

### World entrance

Selecting a world must open a meaningful destination experience.

No tiny tooltip as the main outcome.

No generic modal as the destination.

Provide an obvious **RETURN TO NAYA** path.

Preserve context on return.

---

# 5. POWER PLAYER

The Power Player is the hub's heart and orientation mechanism.

It must be visibly more sophisticated than a basic audio bar.

Required:

- real Powercast artwork
- title
- subtitle/context
- Powercast number
- waveform
- progress timeline
- elapsed/duration
- previous
- play/pause
- next
- loading/ready/playing/paused/complete/error states
- persistent mini-player after navigation

The waveform, timeline, and playback energy should feel like one instrument.

The player should feel premium, tactile, precise, and alive.

---

# 6. POWERCAST LIBRARY

There are 18 canonical Powercasts.

Display professional artwork without replacing it with generic placeholders.

Desktop target: 4 columns where legible.

Mobile target: 3 columns where legible.

Selecting artwork changes the main player without a full page reload.

Playback must be truthful.

Do not fake audio or Naya voice activity.

---

# 7. COMPONENT IMPLEMENTATION

Apply the NayaNET Design System Standard to every:

- button
- input
- board
- world
- icon/glyph
- progress path
- player control
- Naya state
- mini-player
- navigation control

No component should be treated as complete because its default state looks good.

Verify its state transitions.

---

# 8. COLOR CORRECTION REQUIREMENTS

Do not use dominant pink/magenta as the primary visual language.

Use:

**obsidian → deep violet → purple → indigo/blue → cyan/teal → green → gold**, with magenta/pink used selectively as creation/energy accents.

Naya idle: green.

Naya active intelligence: purple.

Worlds: semantic edge colors.

Primary ENTER action: black/white dimensional core with purple intelligence response.

---

# 9. CRITICAL VISUAL CORRECTIONS

The implementation must explicitly avoid these known failures:

- dominant magenta field
- flat ENTER button
- button embedded beside input when the intended composition is stacked
- dead black/gray boards at rest
- tagline touching the NayaNET name
- pale/weak `INTELLIGENT INTERNET BEGINS HERE` treatment
- giant portal/ring artwork competing with copy
- off-center Naya/orb
- overbright central orb
- generic Power Player
- arbitrary icon styles
- dashboard-like nine-card presentation
- excessive glow
- text-heavy hero

---

# 10. CONTINUITY

Preserve:

- entered name
- selected Powercast
- playback position where technically available
- world context
- Smart Notes state
- challenge state
- existing persistence behavior

Return should feel like returning to a place, not reloading a page.

**SEE NAYANET → ENTER NAME → ENTER → MEET NAYA → DISCOVER A WORLD → PLAY A POWERCAST → RETURN.**

without reading documentation.
