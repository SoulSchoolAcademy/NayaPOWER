# Smart Note Capture Queue\n\nThis directory is an **ingestion boundary**, not the Brain and not the permanent Smart Note library.\n\nEach JSON file is a source/distillation request for the governed intelligence receiver. A successful commit creates or refines the canonical **Intelligent Block**. After independent verification, the workflow projects a human-readable Smart Note under:\n\n`.naya/memory/smart-notes/YYYY/MM/DD/category/topic/subtopic/IB-.../smart-note.md`\n\nand registers it in `.naya/memory/smart-notes/index.json`.\n\nRules:\n- one changed capture request per commit/run for V2 fail-closed simplicity;\n- arbitrary capture filenames are supported; no filename is hard-coded;\n- capture requests may reach CANDIDATE automatically, never VERIFIED/ACTIVE merely by being captured;\n- the persisted Intelligent Block is canonical; capture files and projections are representations;\n- raw source and distilled intelligence remain distinguishable.\n
