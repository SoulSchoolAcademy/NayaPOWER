# Contract 05 — Hub Consumption V1

**Owns:** consumption of canonical intelligence into human-facing Hub projections.  
**Does not own:** canonical storage, receiver identity, or an independent intelligence database.

## Canonical flow

```text
CANONICAL INTELLIGENCE
        ↓
INTELLIGENCE API / GOVERNED RETRIEVAL
        ↓
HUB ADAPTER
        ↓
SMART FEED / ROOM
        ↓
HUMAN
```

The Hub MUST consume canonical intelligence through the governed retrieval boundary.

GitHub Markdown is a human-readable projection. The Hub MUST NOT parse GitHub as a substitute canonical database.

## Requirements

The Hub MUST:

- retrieve authorized canonical intelligence;
- preserve IB identity;
- distinguish intelligence from activity;
- expose applicable truth/evidence state;
- preserve privacy and authority;
- answer the human question of the surface;
- provide real action/retrieval paths where claimed;
- never invent state absent from canonical sources.

## Reload law

After browser reload, the object MUST be re-retrieved from the governed source. UI persistence is not persistence proof.

## Projection law

Today, Feed, Reports, Library, Search, Ledger, and other surfaces are projections unless a specialized contract explicitly establishes another canonical boundary.

## Acceptance

The first vertical slice passes only when:

**Human intent → Sender → Receiver → IB → projection → governed retrieval → Hub display → reload → retrieval again**

is independently verified without the Hub creating a duplicate intelligence object.
