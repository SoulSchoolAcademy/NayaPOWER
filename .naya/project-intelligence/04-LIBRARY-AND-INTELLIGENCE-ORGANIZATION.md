# 🔱 04 — LIBRARY + INTELLIGENCE ORGANIZATION

**Purpose:** make Project Intelligence easy for a human to scan and easy for a cold Naya to retrieve.

## 1. THE LIBRARY IS AN INTERFACE

I do not want a folder full of documents that requires archaeology.

I want a navigation system that answers:

**Where do I start? What is this? What do I need next? Where is the proof? Where is the real source?**

The folder landing page is therefore part of the product.

## 3. NUMBERING LAW

**00 = master map**

**01–04 = meaning, boundaries, answers, organization**

**05–11 = requirements, architecture, intelligence, governance, execution, interoperability, build method**

**12–16 = reality, proof, acceptance, continuity, decisions**

**17 = authority routing**

**18 = machine contract**

A future Naya should infer a file's cognitive role from its number.

## 4. HUMAN READING MODES

**QUICK:** README → 00 → 01 → 02 → 03

**BUILDER:** 00 → 05 → 06 → 07 → 08 → 09 → 10 → 11

**AUDITOR:** 12 → 13 → 14 → 15 → 16 → 17 → control plane

**COLD NAYA:** START-HERE → README → 00 → 03 → 06 → 12 → 15 → 18

## 5. THREE-CLICK LAW

A material concept should be reachable within three navigation steps from README, 00 INDEX, or the canonical source map.

## 6. TIME + DATE LAW

I do not create a competing operational timeline.

Authoritative time lives in:

- Git history for source/specification changes;
- Activity for operational work;
- canonical events for occurrences;
- execution receipts for consequential actions;
- runtime timestamps for live state.

This library indexes those timelines instead of competing with them.

## 7. METADATA LAW

Durable Project Intelligence artifacts should identify, where applicable:

**title · status · scope · authority · created · updated · source · supersedes · superseded-by · proof state**

## 8. SMART RECALL

**IDENTIFY → CLASSIFY QUESTION → RESOLVE AUTHORITY OWNER → RETRIEVE NEEDED CONTEXT → RECONCILE CURRENT TRUTH → ANSWER → RECORD LEARNING IF NEEDED**

The goal is maximum useful context with minimum cognitive waste.

## 9. NO ORPHAN INTELLIGENCE

Every durable intelligence item should have a route:

**WHY IT MATTERS → WHERE IT LIVES → WHAT IT AFFECTS → WHAT PROVES IT → WHAT HAPPENS NEXT**

## 10. LIBRARY LAW

> **ONE PROJECT → ONE CANONICAL INTELLIGENCE LIBRARY → MANY AUTHORIZED VIEWS → NO COMPETING SOURCE OF TRUTH**

The library organizes truth. It does not manufacture authority.
