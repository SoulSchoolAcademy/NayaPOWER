## 1. Purpose

This scorecard measures whether NayaPOWER is becoming the system described by the new North Star.

It does **not** reward documentation volume, feature count, test count, or architectural complexity.

It measures whether the system can:

**UNDERSTAND → REMEMBER → CONNECT → RETRIEVE → APPLY → VERIFY → LEARN → COMPOUND → OPTIMIZE**

while preserving:

**AUTHORITY → TRUTH → PRIVACY → SAFETY → PROVENANCE → HUMAN AGENCY**

## 2. Scoring law

### 10.0
Independently verified, current, complete for declared scope, and no material unresolved proof gap.

### 9.5–9.9
Release-ready within declared scope with no critical unknown.

### 9.0–9.4
Strong; one or more material proof/coverage gaps remain.

### 7.0–8.9
Substantial capability exists, but important operational boundaries remain incomplete.

### 4.0–6.9
Partial capability or architecture exists, but the core outcome is not yet reliably demonstrated.

### 0.0–3.9
Mostly conceptual, unreachable, broken, or materially unproven.

### Critical-cap rule

A critical UNKNOWN, BLOCKED, unsafe authority path, competing canonical store, or unproven required system boundary prevents the whole system from being considered AAA regardless of the arithmetic average.

A score is a **measurement of readiness**, not a substitute for evidence.

## 4. The five decisive gaps

### GAP A — Semantic kernel is not yet the runtime kernel

The nine Master Nodes exist.

The next proof is:

\`\`\`

→ RESTORE
→ LOAD 9 MASTER NODES
→ SHOW NODE IDENTITIES
→ USE NODE CONTEXT
→ MAKE A DECISION
→ PROVE THAT CONTEXT MATTERED
\`\`\`

Until then, the Nodes are stored intelligence, not yet demonstrated operating intelligence.

### GAP B — Law is not yet mechanically compiled end-to-end

We have:

\`\`\`
CONTRACTS → MASTER NODES
\`\`\`

We need:

\`\`\`
CONTRACT
→ GOVERNANCE RULE
→ MASTER NODE
→ ENFORCEMENT POINT
→ TEST
→ RUNTIME
→ RECEIPT
\`\`\`

The strongest eventual proof is bidirectional traceability.

### GAP C — Relationships do not yet drive reasoning broadly

The system must graduate from:

> “Node A is related to Node B.”

to:

> “Because Node A relates to Node B in this specific way, Naya should retrieve/use B for this situation.”

That is relationship intelligence.

A learning record is not enough.

The required proof is:

→ OUTCOME A

TASK B WITH RETRIEVED LEARNING
→ BETTER OUTCOME B

CONTROL COMPARISON
→ CAUSAL CONTRIBUTION SUPPORTED
\`\`\`

and improve itself against those measurements.

## 5. AAA gate sequence

The system does not need to become “10 everywhere” at once.

It needs to close the causal chain in order:

### Gate 1 — KERNEL
Nine Master Nodes exist, are connected, and are automatically loaded.

### Gate 2 — LAW
Every critical contract rule has an identifiable deterministic enforcement point and test.

### Gate 3 — CONTEXT
Retrieval selects Nodes because they are applicable, not merely similar.

### Gate 4 — ACTION
Retrieved Nodes demonstrably change an authorized action or decision.

### Gate 5 — OUTCOME
The real outcome is observed and verified.

### Gate 6 — LEARNING
A durable lesson is created from that verified outcome.

### Gate 7 — COMPOUNDING
The lesson improves a later held-out task.

### Gate 8 — VALUE
The improvement is measured in human value, attention, effort, error, time, reuse, or related dimensions.

### Gate 9 — SELF-OPTIMIZATION
The system uses those measurements to propose safe improvements.

### Gate 10 — SELF-BUILDING
The system can implement bounded improvements, test them, verify them, and carry them forward.

### Gate 11 — SUCCESSOR
A cold Naya can reconstruct the improved system from canonical intelligence and continue.

### Gate 12 — NETWORK
The same intelligence model works across people, projects, Nayas, apps, agents, and interfaces without fragmenting authority or memory.

14. The later result improves.
15. Value is measured.
16. The system identifies a useful system improvement.
17. The improvement is tested.
18. The improvement is adopted within authority.
19. A cold Naya restores the new state.
20. The cold Naya continues without human reconstruction.

That is the real “self-building supercomputer” proof.
