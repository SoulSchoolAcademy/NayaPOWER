## Time is first-class

Preserve, where known:

- `event_at` — when the underlying event occurred;
- `created_at` — when the record was created;
- `updated_at` — when it materially changed;
- `observed_at` — when source/state was observed;
- `effective_from` / `effective_to` — applicability window;
- `supersedes` / `superseded_by` — lifecycle lineage.

Never fabricate timestamps. Physical chronology is an index; semantic meaning belongs in metadata and relationships.
