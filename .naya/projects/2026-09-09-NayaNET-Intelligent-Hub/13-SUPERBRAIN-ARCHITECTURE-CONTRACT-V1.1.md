# NAYANET SUPERBRAIN ARCHITECTURE CONTRACT
## Version 1.1 — Foundational Definition

**Status:** CANONICAL PROJECT ARCHITECTURE
**Effective:** 2026-09-09
**Governing repository:** `SoulSchoolAcademy/NayaPOWER`

## Purpose

The NayaNET Superbrain is the persistent intelligence architecture that allows a human and authorized AI systems to capture, organize, remember, retrieve, reason over, verify, and compound knowledge across tools, projects, and time.

**North Star:** **CAPTURE → DISTILL → ORGANIZE → REMEMBER → FIND → COMPOUND**

The Superbrain is not a chatbot, model, GitHub repository, Obsidian vault, or visual interface. It is the intelligence architecture connecting those mechanisms.

## Five layers

1. **Naya — Intelligence:** operating partner that interprets intent, reasons, retrieves, verifies, acts, learns, and maintains continuity.
2. **Superbrain — Intelligence Architecture:** memory, retrieval, indexing, metadata, hierarchy, relationships, relevance, context assembly, provenance, permissions, lifecycle, and compounding.
3. **Intelligent Hub — Human Intelligence Interface:** the living, searchable intelligence library/feed.
4. **GitHub Codex — Durable Source of Truth:** version-controlled substrate for canonical knowledge and durable artifacts.
5. **Authorized AI Tools:** ChatGPT, Claude, Codex, Gemini, OpenClaw, local models, and future authorized systems.

## Canonical memory object

The existing NayaPOWER Note Event remains the canonical durable memory unit. Stable identity is independent of filename, folder, title, or UI location.

Where applicable, objects/events preserve:

`event_id`, `type`, `title`, `scope`, `project`, `status`, `event_at`, `created_at`, `updated_at`, `observed_at`, `effective_at` / `effective_from` / `effective_to`, `source`, `authority`, `verification`, `confidence`, `tags`, `aliases`, `concepts`, `relationships`, `permissions`, `supersedes`, `superseded_by`, representations, summary, and actionable state.

Unknown values remain unknown. Timestamps are never fabricated.

## Time-first architecture

Canonical primary memory remains:

`.naya/memory/events/YYYY/MM/DD/HH/<event_id>.json`

Time organizes history and reconstruction. Metadata organizes meaning. Relationships organize connection. Indexes organize discovery. Permissions organize access. Relevance organizes attention. Summarization organizes context.

## Retrieval and context

Retrieval is hybrid and staged:

**INTENT → SCOPE/PERMISSION → EXACT → LEXICAL → SEMANTIC → METADATA → RELATIONSHIPS → TIME → LIFECYCLE → AUTHORITY/EVIDENCE → RANK → CONTEXT ASSEMBLY → TRACEABILITY**

The goal is the **smallest sufficient, highest-value authorized context**, not maximum context.

## Boundaries and truth

> **CONNECTED DOES NOT MEAN INTERMIXED.**

Scope and permission are resolved before context delivery. Preserve:

**SOURCE → OBSERVATION → INTERPRETATION → DECISION → ACTION → RESULT**

Current verified reality outranks stale memory, inference, or superseded material. Retrieval never grants authority.

## Lifecycle

**DOCUMENTED → ACTIVE → VERIFIED → STALE → SUPERSEDED → ARCHIVED**

Corrections preserve history. Current and historical truth remain distinguishable.

## Smart Notes / Intelligent Blocks

Smart Notes are durable intelligence events, not a second storage silo. Intelligent Blocks are user-facing representations of durable intelligence. Sharing remains governed by the existing NayaPOWER privacy model.

## Multi-tool continuity

A model/session change must not reset intelligence. Authorized tools receive only the context appropriate to task, scope, permission, and required depth.

> **CHANGE THE TOOL WITHOUT LOSING THE INTELLIGENCE.**

## Governance

This contract extends the existing NayaPOWER Context Boot Protocol, Smart Brain Operating System, Smart Notes/Event architecture, source-of-truth model, runtime gates, and NayaNET North-Star Build Law. It does not replace higher-authority governance.

## Naming correction

There is **no NayaNET system, identity, product, agent, or architecture named `9F`**. Any previous `9F` reference created during this project was an error. The canonical terminology is **Naya / NayaNET Intelligent Hub / NayaNET Superbrain**.
