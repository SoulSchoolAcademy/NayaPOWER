## 12. ENGINEERING RULES

- Prefer static HTML/CSS/JS for static blocks.
- Do not add Wrangler solely because it is convenient if the block can work without it.
- Do not add backend infrastructure before a real capability requires it.
- Keep each block independently understandable and replaceable.
- Keep assets local when possible.
- Avoid unnecessary frameworks/dependencies for a static block.
- Avoid giant monolithic bundles.
- Never hide a missing runtime behind fake UI.
- Use explicit seams for future APIs.
- Keep public/private boundaries obvious.
- Design for iframe embedding from the beginning.
- Use `postMessage` only when there is a demonstrated parent/child communication requirement; define origin validation and message contracts before implementing it.
