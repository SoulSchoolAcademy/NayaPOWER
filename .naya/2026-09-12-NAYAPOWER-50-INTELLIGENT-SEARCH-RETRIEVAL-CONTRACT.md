# NAYA POWER — INTELLIGENT SEARCH / RETRIEVAL CONTRACT V1

DATE: 2026-09-12
STATUS: CANONICAL RETRIEVAL CONTRACT V1
NUMBER: 50

## PURPOSE
Let humans find useful intelligence by meaning, not merely by exact words.

## SEARCHABLE INTELLIGENCE
Authorized search spans Smart Notes, Intelligent Blocks, Spaces, Activity, Personal Intelligence, and eligible Collective Intelligence.

## SECURITY
Search results are filtered by identity, ownership, visibility, publication state, and access before display. Private content must never leak through search snippets, ranking, autocomplete, or related results.

## RANKING
Prefer relevance + recency + verified value + user context + relationship signals. Popularity may inform ranking but must not override truth or privacy.

## SEMANTIC RETRIEVAL
Queries may match concepts, summaries, related terms, and structured fields. Results retain source identity and verification state.

## ACTIONS
Search results should lead directly to useful actions: open, save, favorite, share when authorized, add to Space, or continue relevant work.

## FAILURE
No result is different from search failure. Empty, degraded, unavailable, and unauthorized states must be distinguishable.

## ACCEPTANCE
A user can retrieve a known intelligence object using its meaning, open the canonical object, and receive only content they are authorized to see.
