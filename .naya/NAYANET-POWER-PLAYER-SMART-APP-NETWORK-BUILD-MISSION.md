# 17. BUILD METHOD

After archaeology and baseline certification:

### STEP 1 — DEFINE THE VERIFIED BASELINE

Write down what is actually working.

### STEP 2 — BUILD A FAILURE MATRIX

For every critical capability, identify expected states and current evidence.

### STEP 3 — RANK DEFICIENCIES

Prioritize:

1. broken primary journey;
2. false/fake capability;
3. media failure;
4. state/continuity failure;
5. accessibility failure;
6. mobile failure;
7. comprehension failure;
8. interaction quality;
9. visual polish;
10. micro-optimization.

### STEP 4 — MAKE THE SMALLEST COHERENT CHANGE

Do not patch symptoms independently when one underlying cause explains them.

### STEP 5 — VERIFY IMMEDIATELY

Run static checks and runtime checks after each coherent change set.

### STEP 6 — TEST THE WHOLE JOURNEY

Never certify a component while ignoring the journey around it.

### STEP 7 — ASK WHY NOT 10

Actively search for:

- confusing moments;
- dead controls;
- state ambiguity;
- visual weakness;
- continuity breaks;
- mobile compromises;
- accessibility gaps;
- fake capability;
- error-state weakness;
- unnecessary complexity.

### STEP 8 — REPAIR

Repair discovered deficiencies.

### STEP 9 — VERIFY AGAIN

A repair is not complete until regression is checked.
