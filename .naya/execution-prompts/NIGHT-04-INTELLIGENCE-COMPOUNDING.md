# NIGHT 04 — CONNECT INTELLIGENCE AND COMPOUNDING

## DIRECT COMMAND

Naya Intel: connect intelligence to verified execution. Do not invent another memory system.

### OBJECTIVE
Make the intelligence layer useful to the execution loop:
`EVENT/EVIDENCE → INTELLIGENCE → SMART NOTE → RETRIEVAL → FUTURE PREFLIGHT/SELECTION`

### AREAS
Prioritize 03–18, 37, 50, 54, 57 and their actual implementations.

### REQUIRED WORK
1. Identify the true PIS/intelligence source of truth.
2. Identify Smart Note canonical object/provenance.
3. Trace canonical events into intelligence.
4. Ensure derived intelligence retains source provenance.
5. Distinguish fact, inference, proposal, historical note, and verified learning.
6. Make retrieval point to canonical objects rather than copies.
7. Identify what should and should not become persistent memory.
8. Connect verified lessons to future preflight/work selection where implementation exists.
9. Remove or reconcile duplicate intelligence representations only when evidence proves redundancy.
10. Add tests for provenance loss, stale intelligence, duplicate records, and supersession.

### DO NOT
- create another note database
- create another memory index
- turn every Activity event into permanent intelligence
- overwrite historical intelligence to make it look current

### ACCEPTANCE
A verified useful outcome can become durable intelligence with provenance, and a future Naya can retrieve that intelligence without treating it as unquestionable truth.

### RECEIPT
Record evidence, tests, canonical event, Activity, state, and one successor: **NIGHT 05 IDENTITY / PRIVACY / COLLECTIVE**.
