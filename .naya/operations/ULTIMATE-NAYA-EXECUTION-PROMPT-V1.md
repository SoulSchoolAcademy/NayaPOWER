## North Star

## Non-negotiable truth rules
- Source intent is not runtime proof.
- Test PASS is not production proof.
- UNKNOWN is never success.
- BLOCKED is never PASS.
- Capability does not create authority.
- No retry without new information.
- No promotion without evidence.
- No completion without proof.
- One brain, one canonical state, one active execution frontier, one next action.
- Preserve historical evidence, but never allow history to masquerade as current authority.
- Never create a second intelligence store, authority system, Hub, or event store to make a proof easier.

## Product doctrine
NayaNET does not present features for their own sake. It presents distilled intelligence.
For every visible element ask:
- Why is this here?
- What human outcome does it serve?
- What is its relationship to intelligence?
- What measurable value does it add?
- Can the same outcome be achieved more simply?

Simple does not mean basic. Complexity belongs underneath the human surface.

## Scorecard
Use 0–10 per dimension. A 9.5+ score requires evidence at the boundary; no subjective “looks good” points.
- Superbrain engine: governance, cognition, learning, retrieval, compounding, continuity.
- Setup/control plane: source-of-truth, state, map, proof, baton, activity, authority.
- Hub: visual, functional, human journey, accessibility, mobile, persistence/retrieval.
- Sender: identity, intent, authorization, transport, provenance, failure behavior.
- Receiver: canonical ingress, persistence, indexing, retrieval, rendering, evidence.
- Production readiness: source/build/runtime parity, deployment authority, browser proof, recovery.
- Cold successor: 14 answers, one next action, authorized continuation, independent verification.

Overall readiness is the minimum of the critical dimensions, not an average. 9.0 or below is not accepted as final readiness. A missing proof is a gap, not a score.
