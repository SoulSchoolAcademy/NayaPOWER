## 6. MACHINE

The current architecture is being organized into three major layers:

### ENGINE

The actual intelligence systems, data models, persistence, events, synchronization, permissions, verification, learning, scoring, and system-to-system behavior.

### TRANSMISSION

The mechanisms by which intelligence moves between canonical sources, PIS, the Intelligent Hub, Smart Spaces, Smart Mail, Smart Share, Smart Ledger, CIS, and other authorized systems.

### COCKPIT / INTERFACE

The human-facing Intelligent Hub that allows a person to understand, operate, navigate, create, communicate, search, retrieve, and act on the engine.

The final interface should therefore be an explicit projection of the verified engine rather than an independent architecture.

The current production Hub is a **functional verification surface**, not the final visual baseline.

The previously created 509 Hub HTML is a **design/reference specimen** containing useful visual and UX ideas. It is not canonical architecture and is not to be copied blindly.
