## Classification vocabulary

- **CURRENT** — directly represents current authorized work.
- **ACTIVE DEPENDENCY** — current architecture/law/evidence required by current work, but not the single next action.
- **HISTORICAL INTELLIGENCE** — preserve for lessons/provenance; do not execute as current instruction.
- **SUPERSEDED** — replaced by a newer canonical record; preserve history, do not execute.
- **DUPLICATE** — same intent as another record; close only when safe and history is preserved.
- **BLOCKED** — valid current intent but cannot proceed until a named boundary changes.
- **DEFERRED** — intentionally future work, not current execution.
- **NEEDS HUMAN AUTHORITY** — cannot proceed without an explicit human/external authority decision.
