# 09 — Acceptance and Proof Ladder

## PI proof ladder

PI-01 RESTORE — cold Naya reconstructs project identity and operating context.

PI-02 RECONCILE — cold Naya distinguishes current truth, verified, failed, unknown, stale, superseded, conflicted, and open state.

PI-03 CONTINUE — cold Naya selects one authorized executable frontier.

PI-04 EXECUTE + VERIFY — Naya performs the authorized action and preserves evidence.

PI-05 SUCCESSOR — a second cold Naya retrieves changed state and continues.

PI-06 LEARN — the next cycle retrieves learning and uses it in a later decision.

PI-07 GENERALIZE — the operating model succeeds on a materially different human project.

## Final proof

A human can state a meaningful desired outcome, and NayaPOWER can construct the relevant intelligence context, distill what matters, establish the path to success, act within authority, verify reality, preserve learning, and enable a successor Naya to continue without reconstructing the project from conversation history.

## Evidence law

DOCUMENTED → IMPLEMENTED → TESTED → VERIFIED → RUNTIME-PROVEN → PRODUCTION-PROVEN

Never claim a higher rung from a lower rung.

## Human acceptance

The human can understand the project, operate the Hub, create something real, save it, reload it, find it, connect it, act on it, inspect evidence, understand what happened, see what was learned, and continue.

## Cold-Naya acceptance

WHAT / WHY / WHERE / AUTHORITY / PROTECTED / CURRENT STATE / CURRENT GAP / NEXT ACTION / PROOF / HANDOFF

without conversational archaeology.
