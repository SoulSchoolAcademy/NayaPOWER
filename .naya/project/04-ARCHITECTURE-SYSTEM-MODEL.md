## NayaPOWER

NayaPOWER is the governed Superbrain operating system for governance, continuity, intelligence, memory, execution, verification, learning, and compounding.

It is not a model, personality, standalone memory database, or self-authorizing system.

## GitHub

GitHub is the durable engineering/source context and execution record: architecture, source, contracts, control plane, evidence references, code, tests, and successor context.

## NayaNET

NayaNET is the governed network/application environment through which personal Superbrains and authorized collective intelligence can connect.

## Hub

The canonical human-facing Hub is NAYANET/HUB/index.html.

The Hub is the visual brain / human operating surface. It shows and lets humans operate the intelligence system. It is not the source of truth.
