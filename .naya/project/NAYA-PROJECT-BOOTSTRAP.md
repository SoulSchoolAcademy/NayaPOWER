## 4. Authority check

For the broken boundary determine:

- actor
- identity
- capability
- requested operation
- required authority
- actual authority

If authority is absent, **do not work around it**.

## 5. Repair rule

Repair only the first concrete boundary unless a dependency makes a larger change unavoidable.

After repair:

1. rerun the unchanged acceptance path
2. capture evidence
3. update the canonical checkpoint
4. classify the surface
5. identify the next incomplete human boundary
