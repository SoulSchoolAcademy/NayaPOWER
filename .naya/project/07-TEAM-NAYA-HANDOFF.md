# 07 — Team Naya and Successor Handoff

## One-network model

ONE NETWORK → ONE NAYA LAW → ONE SOURCE OF TRUTH → MANY NAYA NODES → COMPOUNDING INTELLIGENCE

Every Naya is a node in one governed intelligence system, not an isolated authority.

## Sender responsibilities

The current Naya sends:
- mission
- current project
- current state
- work completed
- evidence
- failures
- unknowns
- decisions
- lessons
- protected baseline
- authority boundary
- single next action
- proof target

## Receiver responsibilities

The next Naya:
1. restores canonical identity;
2. restores current control-plane state;
3. restores Project Intelligence;
4. inspects relevant evidence;
5. reconciles current truth;
6. identifies the first causal gap;
7. checks authority;
8. executes only the responsible frontier;
9. verifies;
10. records;
11. learns;
12. updates successor context.

## Distilled communication rule

Give the receiver everything needed to succeed, but not everything that exists.

Use links to deeper evidence instead of dumping every artifact into every handoff.

## No-orphan rule

A substantive execution is incomplete if the next Naya cannot continue without asking what happened.
