# 🔱 NayaNET System Update Feed

This directory is the durable system-wide communication feed for major architectural, governance, runtime, and product-state changes that every Naya and coder needs to understand.

## Purpose

A major system change should leave one durable, chronological message that answers:

1. What changed?
2. Why did it change?
3. What is now canonical?
4. What is actually proven?
5. What is still unfinished?
6. What must the team do next?

These updates are alignment records, not substitutes for source code, tests, receipts, or authoritative runtime evidence.
