# NayaNET Activity — Intelligent Block Display Contract

**Date:** 2026-09-07  
**Event:** `SN-20260907-INTELLIGENT-BLOCK-DISPLAY-ORDER`  
**Scope:** Personal intelligence architecture / Intelligent Feed UX

## What happened

Shawn clarified that the previous label **Grammar Note** was incorrect. The intended perspective is **Grandma Note**: a wise, experienced, practical human-life perspective that helps turn information into understanding and usable wisdom.

The Intelligent Block should remain **one canonical intelligence event** while presenting multiple perspectives in a deliberate order optimized for usefulness.

## Canonical display order

1. **NUTSHELL / WISDOM** — the fastest useful understanding; visually prominent.
2. **HUMAN NOTE** — what the person actually experienced, thought, learned, decided, or created. In a personalized UI this may display as **Shawn Note**, **Victoria Note**, etc., while remaining the canonical Human Note type.
3. **CHILD NOTE** — the simplest understandable explanation.
4. **GRANDMA NOTE** — the wise, experienced, practical life perspective.
5. **NAYA NOTE / AI NOTE** — Naya's synthesis, connections, interpretation, and useful intelligence.
6. **MACHINE NOTE** — structured metadata and machine-readable intelligence.
7. **LESSON + MEANING + HOW TO USE IT** — the closing actionable takeaway.

## Design principle

> **Put the most useful truth first; then progressively deepen understanding.**

The point is not to create six separate notes. It is to let a person understand one intelligence event from several useful angles without losing the original human experience or canonical identity.

## Product interpretation

This supports both fast skimming and deep learning:

**Nutshell → Human → Child → Grandma → Naya/AI → Machine → Lesson/Application**

A person can stop after the Nutshell and still get value, or continue through the perspectives for deeper understanding.

## Activity → Intelligence → Wisdom

This display contract reinforces the larger architecture:

**Activity is context. Intelligence is the asset. Wisdom is the value.**

The Intelligent Feed should therefore make the wisdom immediately visible while preserving the human source and the intelligence layers beneath it.
