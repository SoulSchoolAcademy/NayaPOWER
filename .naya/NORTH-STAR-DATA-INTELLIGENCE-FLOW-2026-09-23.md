## Canonical object
An Intelligent Event is the occurrence. An Intelligent Block is the durable human-readable intelligence projection. One object may appear as Personal Intelligence, Collective Intelligence, Activity, Today, Reports, Library, Search, or a room-specific view.

## Smart Door grammar
CAPTURE → AUTHORIZE → EVENT → PERSIST → INDEX → BLOCK → PROJECT → ACT → RECEIPT → LEARN.

## Governance
NayaPOWER is above capability. Capability does not create authority. Unknown is not success. Blocked is not pass. Verification is evidence-based.

## Compounding
Only validated intelligence and learning should improve future Superbrain behavior. Conversation may create intelligence; ending a conversation must not destroy durable intelligence.
