## Purpose

Define how Naya Power captures, retrieves, compounds, and operationalizes learning from ongoing human-AI work.

## Core Model

A **Smart Note** is one event captured in two synchronized forms:

1. **Human Note / [user-name] Note** — written for the human in simple, natural language. It should be understandable by a five-year-old, a grandparent, or anyone who needs the idea quickly.
2. **Naya Note** — written for AI retrieval and reasoning. It preserves structured meaning, context, relationships, aliases, time, evidence, decisions, lessons, discoveries, failures, and next actions so Naya can restore context efficiently.

The two notes describe the same underlying event but are optimized for different readers.

## Capture Rule

When a user says **“Naya, make a Smart Note,”** Naya should understand that both notes are required unless the user explicitly asks for only one.

Every Smart Note should be timestamped, categorized, related to nearby knowledge, and given useful retrieval aliases. Retrieval should be semantic and contextual rather than dependent on an exact keyword match. Time range, subject range, related concepts, and meaning should all help locate the note.

The user's human note should normally be named using the user's preferred name, for example **SHAWN NOTE**, while the machine-facing companion is a **NAYA NOTE**.

## What Is Worth Capturing

Capture anything that may compound intelligence, including:

- aha moments
- important discoveries
- failures and debugging lessons
- corrections
- decisions
- preferences
- useful methods
- successful workflows
- new concepts learned
- problems that reveal system weaknesses
- important evidence
- reusable prompts or procedures
- changes to the North Star
- insights about how humans and AI should work together

Do not wait for information to become obviously important. Capture memorable, potentially useful events so later intelligence can determine their value.

## Retrieval Model

Treat the Naya memory repository as an **external super-brain**. It should be organized for maximum retrieval performance, not merely as a folder of documents.

Retrieval should use:

**time + subject + meaning + aliases + relationships + status + evidence**

Exact wording is not required. A later request such as “what did we learn yesterday about Smart Notes?” should retrieve relevant notes even if the later wording differs from the original wording.

## Compounding Intelligence System (CIS)

Smart Notes are the continuous capture layer of the **Compounding Intelligence System**.

The loop is:

**EXPERIENCE → CAPTURE → ORGANIZE → RETRIEVE → SYNTHESIZE → BRIEF → APPLY → LEARN → CAPTURE AGAIN**

The objective is that useful work does not disappear when a conversation ends.

## Daily Intelligence Briefing

At the end of a day, Naya should be able to analyze the day's Human Notes and Naya Notes and produce a **Daily Intelligence Briefing** covering:

- what was learned
- what was discovered
- what failed and why
- what changed
- what decisions were made
- what patterns emerged
- what should be remembered
- what opportunities were identified
- what should happen next

The briefing is not a test. It is a concise intelligence review of the day.

It should be readable or playable as a spoken briefing so the user can simply press Play and receive the value of the day's accumulated learning.

## Learning Loop

Naya should actively encourage a daily learning habit:

**“What do you want to learn today?”**

When the user learns something important, Naya captures it. The Daily Intelligence Briefing can then revisit those lessons so knowledge becomes reinforced rather than forgotten.

## Operating Principle

Naya Power should continuously compound intelligence rather than repeatedly start from zero.

The repository is not merely storage. It is the governed memory layer that lets Naya restore context, reason over history, connect related events, and improve future assistance.

## Next Best Action

Formalize the Smart Note runtime so one user command creates both human-readable and AI-readable notes, indexes them for semantic/time-based retrieval, and feeds them into the Daily Intelligence Briefing pipeline.
