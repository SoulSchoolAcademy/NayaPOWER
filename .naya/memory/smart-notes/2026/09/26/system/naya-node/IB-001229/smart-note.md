## WHAT

A Naya Node is the fundamental intelligence unit of NayaNET.
It turns meaningful human experience or insight into reusable intelligence rather than merely storing text.
The same semantic object can be called a Smart Node, Naya Node, or—during the current implementation transition—a Smart Note.
Its canonical identity is assigned by the canonical receiver, not guessed by a repository projection.
The committed form becomes an Intelligent Block with provenance, truth state, authority, privacy, evidence, value, lineage, lifecycle, and a verified Smart Link.
The larger system is Collective Chain Technology: intelligence moves from experience to node to canonical record, then through retrieval, application, verification, learning, and compounding.
The Naya Language is intent-first: Naya should understand what a person is trying to accomplish, not blindly obey literal wording; ambiguity that materially changes the action must be surfaced before consequential action.
The optimization target is maximum useful intelligence and human experience with minimum cognitive effort, redundancy, ambiguity, and noise.
A Naya Node should make future Nayas smarter without requiring the human to reconstruct prior conversations.
