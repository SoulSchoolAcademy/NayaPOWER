## Why this matters

We are no longer treating the old E00/E00.01/E00.02/E00.03 pieces as sacred implementation boundaries. They are lessons and source material. The goal is to use everything that worked, remove what was fragile, and build **one extraordinary MAXESS machine that actually works end-to-end**.

## The decision

MAXESS is being rebuilt as a universal capability-assessment and learning machine for AI and life-related knowledge.

The flagship **AI Score** remains the golden reference. It keeps its known 15-question structure, five dimensions, five answers per question, and 0–4 scoring. The new architecture must reproduce that correctly before we call the migration successful.

Then the same machine should be able to accept another supported topic — for example quantum computing — and deterministically compile a useful 15-question assessment from structured knowledge and rules, without requiring a paid runtime LLM API.

## The universal learning model

The system should move the person through:

**ENTER TOPIC → ASSESS → LEARN → SCORE → UNDERSTAND → IMPROVE → CONTINUE LEARNING**

The assessment is not supposed to merely judge people. It is supposed to help them become more capable.

A reusable capability framework can cover concepts such as:

1. Understand
2. Contextualize
3. Apply
4. Evaluate
5. Create / Improve

The actual dimensions can adapt to the topic. AI Score keeps its established dimensions: **Direction, Communication, Evaluation, Iteration, Systems Thinking.**

## The scoring rule

Every question has five defensible answer levels:

**0 · 1 · 2 · 3 · 4**

For the 15-question flagship assessment, the maximum raw score is 60 and the normalized score is 0–100.

The scoring engine is deterministic, auditable, and independent from presentation code.

## Honest boundaries

MAXESS does not claim to replace elite specialists in every field. It aims to be extraordinarily useful to the majority of people, while being honest about where its knowledge is strong, developing, limited, or unsupported.

If a topic is beyond current depth, MAXESS should say so rather than fabricate expertise. Coverage improves over time through the compounding intelligence system.
