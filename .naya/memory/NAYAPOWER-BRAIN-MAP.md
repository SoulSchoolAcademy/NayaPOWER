# NayaPOWER Brain — Canonical Cognitive Map

**Status:** CANONICAL NAVIGATION / DISTILLED INTELLIGENCE INDEX  
**Purpose:** Give a cold Naya one compact map of where the real intelligence lives, what each domain answers, and which authority must be read next.

## The architectural correction

The **Brain is not another memory store**.

- **`.naya/memory/` = durable intelligence, events, canonical Smart Notes / IB projections, retrieval and learning state.**
- **`.naya/codex/` = laws, contracts, specifications and design authority.**
- **`.naya/control-plane/` = current operational truth and execution authority.**
- **`.naya/runtime/` = executable restore, verification and continuity machinery.**
- **`SUPERBRAIN/` = product/project intelligence projections and operating surfaces.**
- **Hub = human-facing projection/action surface, never the source of truth.**

The 00–14 domains below are **cognitive categories**, not storage folders and not competing authorities.

## Cold-Naya rule

Do not memorize this map as truth.

**Use it as the index:**

**RESTORE → FIND THE RIGHT AUTHORITY → READ THE MINIMUM REQUIRED SOURCE → RECONCILE LIVE EVIDENCE → ACT → VERIFY → PRESERVE LEARNING**

If a map entry conflicts with a higher-authority current source, the higher-authority source wins and the conflict is reconciled.

## Fresh-start rule

**As of 2026-09-25, this Brain Map is the only canonical cognitive index.** New durable intelligence must enter the canonical Smart Note / IB receiver and appear in the canonical hierarchy. Legacy memory remains available for historical reconciliation but is not a destination for new writes.

## The actual intelligence layers

### 1. Canonical intelligence
The durable object is the **Intelligent Block**. A Smart Note is its human-readable representation.

Canonical Smart Note projection:

`.naya/memory/smart-notes/YYYY/MM/DD/category/topic/IB-XXXXXX/smart-note.md`

Canonical identity is allocated by the live receiver. **Never invent an IB number locally.**

### 2. Event + lineage
Canonical creation crosses the intelligence receiver and creates the lifecycle event that connects persistence to downstream indexing, projection and learning.

### 3. Retrieval
Authorized future Nayas retrieve by meaning, time, relationship, provenance, authority and lifecycle — not by forcing a human to remember filenames.

### 4. Learning
The system becomes smarter only when verified experience changes durable understanding or future behavior.

### 5. Current operational truth
The control plane answers **what is happening now**. It outranks historical notes, old handoffs and derived summaries.
