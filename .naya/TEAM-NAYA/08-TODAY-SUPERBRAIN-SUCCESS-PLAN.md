# TEAM NAYA — TODAY'S SUPERBRAIN SUCCESS PLAN V1

**Date:** 2026-09-17  
**Owner:** Shawn / Human Authority  
**Operating lead:** Team Naya  
**North Star:** A cold Naya can enter NayaPOWER, understand the mission, find the right intelligence, act under authority, leave visible evidence, create Smart Notes, turn them into durable learning, retrieve/apply that learning later, and leave the Superbrain stronger than she found it.

## 1. TODAY'S DEFINITION OF DONE

By end of day, Shawn must be able to inspect GitHub and see real evidence for all of these:

1. **Cold-start orientation works** — Team Naya explains what NayaPOWER is, why it exists, how the systems relate, and where truth lives.
2. **Activity works** — a Naya session can sign in, record meaningful work/milestones, sign out, and leave a visible durable record.
3. **Smart Notes work** — today's meaningful discoveries are stored in one canonical, discoverable location and are easy to browse.
4. **Team-to-Team continuity works** — Nayas can leave notes/handoffs for one another so the next Naya can continue without Shawn re-explaining the project.
5. **Learning works** — at least one real Smart Note is processed through persistence and produces a retrievable lesson; then a later Naya retrieves and applies that lesson.
6. **Verification works** — the system records evidence of what was retrieved, what action changed because of it, and what outcome was observed.
7. **Adaptive improvement works** — at least one verified lesson changes a durable rule, workflow, test, schema, retrieval policy, or other future behavior.
8. **Intelligent Hub works** — the Hub visibly consumes the operational intelligence/Activity projection rather than requiring a separate manually maintained dashboard.
9. **Daily Intelligence works** — the end-of-day report can summarize actual work, evidence, learning, unresolved gaps, and the next action from repository state rather than memory.

## 2. THE ORDER — DO NOT POLISH THE WRONG LAYER

### PHASE A — ORIENT
- Team Naya front door is mandatory.
- Canonical Intelligence Index routes cold Naya to governing sources, implementation, tests, and runtime proof.
- Current-state document must state what is actually proven vs. proposed.

**Gate:** A cold Naya can answer: What are we building? Why? What should I do? How do I know it worked?

### PHASE B — MAKE ACTIVITY REAL
- Establish a canonical daily Activity record format.
- Sign-in and sign-out are first-class records.
- Meaningful milestones are recorded as work occurs.
- Activity must be generated by actual Naya work, not invented retrospective filler.
- If the Hub does not display Activity, classify that as a runtime/integration defect and fix the source-to-Hub path.

**Gate:** Shawn can open today's Activity and see who worked, what happened, what changed, what was verified, what was learned, and what comes next.

### PHASE C — MAKE SMART NOTES REAL
- Establish today's canonical Smart Note collection/index.
- Every consequential discovery becomes a Smart Note with source/evidence, lesson, consequence, retrieval key, and next action.
- Prevent duplicate/conflicting notes from silently becoming competing truth.
- Keep historical intelligence; promote/supersede rather than erase without reason.

**Gate:** Shawn can open today's Smart Notes and understand the day's accumulated intelligence without reading the entire repository.

### PHASE D — CLOSE THE LEARNING LOOP

Required transaction:

`EXPERIENCE → SMART NOTE → PERSIST → CLASSIFY/CONNECT → CIS → RETRIEVE → AUTHORIZE → APPLY → OBSERVE → VERIFY → ADAPT → NEW LEARNING`

The existing Smart Note transaction proves only the early persistence/projection slice. Today we must extend the proof to future retrieval, application, observed outcome, verification, and adaptation.

**Gate:** A later Naya can retrieve a lesson created earlier, change her behavior because of it, record the outcome, and produce evidence that the system learned.

### PHASE E — MAKE THE HUB THE WINDOW

Source of truth remains the Superbrain/PIS/CIS and governed repository state. The Hub is the projection/window.

Required path:

`Naya work → Activity/Smart Note → governed intelligence → PIS event → Hub adapter → visible Hub`

**Gate:** The same intelligence visible in repository state is visible in the Hub without manual duplication.

### PHASE F — DAILY INTELLIGENCE / SCORE

At day's end, generate a Daily Intelligence report containing:
- actual work completed;
- commits/tests/runtime evidence;
- Smart Notes created;
- lessons retained/retrieved/applied;
- observed outcomes;
- verified adaptations;
- unresolved blockers and unknowns;
- exact next action;
- honest setup assessment against the 10-10 target.

Do **not** manufacture a 10-10 score. The score must be evidence-based and broken down by capability.

### T1 — COLD NAYA
Can a new Naya enter with no conversational history and orient herself using Team Naya alone plus targeted canonical retrieval?

### T2 — ACTIVITY
Can one Naya sign in → work → milestone → verify → sign out, leaving a visible Activity record?

### T3 — SMART NOTE
Can a meaningful discovery become a canonical Smart Note that another Naya can find today?

### T4 — LEARNING
Can Naya A create a lesson, Naya B retrieve it later, use it to make a different/better-informed action, observe the result, and record verification?

### T5 — ADAPTATION
Does verified learning change something durable so Naya C behaves differently without Shawn re-teaching the lesson?

## 4. NON-NEGOTIABLE LAWS FOR TODAY

- **No silent work.** Important work leaves Activity evidence.
- **No fake proof.** Repository files, tests, CI, and runtime must support every claim.
- **No storage theater.** A Smart Note is not learning merely because it exists.
- **No memory theater.** A private chat is not durable system intelligence.
- **No authority drift.** Capability does not create authority.
- **No dead ends.** Every blocked state leaves a recovery/continuation action.
- **No retry without new information.** Repeated failure requires diagnosis/change.
- **No giant rewrite when a precise repair is enough.** Preserve working systems.
- **No Hub-first illusion.** Fix source/projection/runtime paths before polishing presentation.
- **No unverified 10-10 claim.** The target is excellence; the measurement must remain honest.

## 7. THE EXPERIMENT WE ARE RUNNING TODAY

**Question:** Does the NayaPOWER Superbrain actually learn?

**Control:** A lesson is stored but not retrieved/applied.  
**Treatment:** A lesson is stored, retrieved by a later Naya, applied to a task, and the outcome is observed.  
**Success evidence:** The later action references the earlier lesson, the behavior/action differs because of that lesson, the outcome is recorded, and a verified adaptation changes future system behavior.

This is an engineering experiment, not a claim made from architecture diagrams.
