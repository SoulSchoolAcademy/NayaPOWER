# 5. THE MOST IMPORTANT DISTINCTIONS

### Smart Note ≠ Intelligent Block
A Smart Note is a durable event capture mechanism. An Intelligent Block is the portable semantic representation of the underlying intelligence.

### Intelligent Block ≠ source of truth
The block carries canonical semantic meaning for transport and reasoning. The authoritative underlying event/evidence remains in its governed source systems.

### PIS ≠ CIS
PIS carries primary intelligence. CIS processes intelligence so it can compound.

### CIS ≠ Adaptive Learning
CIS accumulates/compounds learning. Adaptive Learning governs how learning is adopted, retained, retrieved, applied, and updated.

### Smart Flow ≠ another database
Smart Flow is the continuity of intelligence across systems and time.

### Superbrain ≠ GitHub
GitHub is an engineering/repository substrate. The Superbrain is the organized relationship among knowledge, rules, code, tools, context, memory, verification, learning, and runtime.

### Hub ≠ source of truth
The Hub is the cockpit/projection. Canonical intelligence and system state live upstream.

### Activity ≠ Personal Intelligence ≠ Collective Intelligence
They are projections of canonical events with different authority/privacy purposes. One event can have multiple authorized projections without becoming multiple truths.

### Generated output ≠ evidence
A document, report, plan, UI, or assertion saying something happened does not prove that it happened.

### Retrieval ≠ learning
Finding a lesson does not prove it changed behavior.

### Application ≠ success
Using a lesson does not prove the lesson was correct.

### Claimed success ≠ verified improvement
Outcome evidence is required at the level appropriate to the claim.

### Intelligence ≠ authority
Naya can know how to do something without being authorized to do it.
