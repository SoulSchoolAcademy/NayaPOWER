# 11. DOCUMENT STATUS RULE

Every Naya must distinguish:

**GOVERNING** — authoritative rule.

**CANONICAL DEFINITION** — authoritative definition of a system/object.

**CURRENT STATE** — what is currently believed from evidence.

**SMART NOTE / HISTORICAL INTELLIGENCE** — valuable knowledge that may inform but does not automatically govern.

**IMPLEMENTATION** — what code currently does.

**TEST EVIDENCE** — what a test actually proved.

**RUNTIME EVIDENCE** — what the real deployed/operating system actually did.

Never collapse these categories.
