**Effective:** 2026-09-23

One coherent working tree. The repository's accumulated architecture is organized so a human and a cold successor Naya can understand where truth lives, where capabilities live, how intelligence flows, and what is safe to change.

## Responsibilities
- **HUMAN:** identity, intent, vision, values, preferences, permissions, privacy, agency.
- **NAYAPOWER:** constitution, governance, authority, boundaries, safety, verification, evidence, continuity, value, execution.
- **NAYA:** understand, think, ask, explain, guide, create, act, verify, learn.
- **SUPERBRAIN:** memory, context, project intelligence, events, knowledge, relationships, lessons, decisions, evidence, activity, learning, compounding.
- **INTELLIGENT EVENT:** canonical occurrence and provenance-bearing source record.
- **INTELLIGENT BLOCK:** human-readable intelligence object derived from canonical intelligence.
- **SMART FEED:** projection of intelligence into personal, collective, and activity views.
- **HUB:** human-facing projection/action surface, never a second brain or competing source of truth.
- **SMART DOORS:** governed capability boundaries.
- **PROOF / LEDGER:** accountability, receipts, evidence, verification.
- **LEARNING / COMPOUNDING:** validated improvement returned to future Superbrain intelligence.

## Laws
1. One source of truth.
2. One canonical event model.
3. One canonical intelligence object.
4. One Hub shell and one renderer per surface.
5. Capability does not create authority.
6. Unknown is not success; blocked is not pass.
7. No duplicate product implementations.
8. No obsolete V-number variants in the active working tree.
9. Preserve proven functionality before changing it.
10. Every active file has a reason to exist and a canonical home.
11. Historical construction remains recoverable through Git history, not as competing active truth.
12. A cold Naya must locate authority, current truth, architecture, runtime, product surfaces, proof, and next action without archaeology.

READ → RESTORE → UNDERSTAND → MAP → EXECUTE → VERIFY → RECEIPT → LEARN → CONTINUE.
