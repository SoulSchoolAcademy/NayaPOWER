# Restore Checkpoints

Generated restore checkpoints belong here when created by the runtime.

A checkpoint is a recoverable intelligence snapshot, not merely a timestamp.
It records repository reality, mission state, protected elements, unknowns,
memory status, next action, and an integrity hash.

Generated artifacts should be reviewed before promotion to canonical history.
Do not treat every generated checkpoint as active context; use lifecycle states
and retrieval rules to prevent checkpoint noise.
