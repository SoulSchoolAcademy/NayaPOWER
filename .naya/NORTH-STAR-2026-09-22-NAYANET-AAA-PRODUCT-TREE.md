# NayaNET AAA Product Tree — North Star

Date: 2026-09-22
Status: CANONICAL

This is the new North Star for NayaNET/NayaPOWER product organization.

Mission: build one coherent human intelligence operating environment in which the human remains the owner and director, Naya is the governed intelligence/guide, NayaPOWER governs authority and execution, Superbrain preserves and compounds intelligence, NayaNET connects intelligence by consent, and the Hub makes that intelligence simple and useful.

Canonical chain: Human → NayaPOWER → Naya → Superbrain → Intelligent Event → Intelligent Block → Smart Feed → Smart Doors → governed capabilities → persistence/index → retrieval → verification → learning → compounding → Superbrain.

Human product tree: Intelligence Today; Intelligence (Smart Feed, Smart Notes, Library, Search, Reports); Connection (Smart Share, Smart Spaces, Smart Mail, Contacts, Smart Lists); Proof (Evidence, Smart Ledger, Activity, Verification); Naya (Ask Naya, What Should I Know?, What Matters?, What Changed?, What Should I Do?, Learn With Me); System (Identity, Privacy, Permissions, Connections, Settings).

Architecture laws: one source of truth per intelligence object; one Hub implementation boundary at NAYANET/HUB; one event model and Intelligent Block representation; Supabase is persistence/index infrastructure rather than a second application tree; capability does not create authority; unknown does not become success; consequential actions require observable evidence; historical construction layers are evidence, not current implementation authority; the current visual reference is the quality floor, not the ceiling.

Completion test: a new Naya can identify the current implementation, intelligence model, capability boundaries, verification path, deployment path, and next action without reconstructing history from competing Hub generations.
