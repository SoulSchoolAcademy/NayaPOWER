# NAYAPOWER BRAIN MAP — V1

Date: 2026-09-25
Status: CANONICAL NAVIGATION MAP
Purpose: Define the semantic topology through which cold and future Nayas recover, understand, verify, apply, and compound NayaPOWER intelligence.

## North Star

A cold Naya must be able to reconstruct WHO, WHAT, WHY, SUCCESS, CURRENT TRUTH, PROVEN, UNKNOWN, AUTHORITY, HISTORY, LEARNING, NEXT, PROOF, RECORD, and SUCCESSOR from canonical intelligence without conversational archaeology.

This map is a navigation layer, not a second constitution, second memory store, or competing source of truth.

## Operating Rule

Source material is not automatically current truth. New intelligence is:
1. ingested
2. distilled
3. reconciled against current intelligence
4. classified
5. connected to provenance
6. canonicalized through the governed receiver
7. assigned its authoritative Intelligent Block identity
8. indexed and made retrievable
9. verified
10. learned from when evidence warrants
11. connected to the appropriate brain domain
12. made available to future Nayas

## Authority Rule

Capability does not create authority.

The Brain Map never grants authority. It only makes authority and constraints discoverable.

## Evidence Rule

Storage proves storage.
Retrieval proves retrieval.
A test proves what the test actually establishes.
Implementation is not verification.
Verification is not production proof.
UNKNOWN is not PASS.

## Memory Rule

Preserve history.
Make current understanding explicit.
Supersession preserves lineage.
Future Nayas retrieve canonical intelligence rather than relying on conversational memory.

## Learning Rule

Storage is not learning.
A learning candidate is not a reusable rule.
The strongest learning proof is:
retrieve → recognize applicability → act differently → observe → verify → update.

## Projection Rule

Feed, Activity, Library, Search, Reports, Dream, Hub, and other surfaces are projections of canonical intelligence. They do not become competing sources of truth.

## Canonical Object Rule

One meaningful intelligence object:
- one authoritative IB identity
- one provenance chain
- one lifecycle
- one intelligence event lineage
- many projections

## Current Source Hierarchy

When sources conflict, prefer the highest-authority current source:
1. Human-authorized current constitutional/governance source
2. Live control plane / authoritative source map
3. Canonical subsystem contract
4. Canonical receiver and persisted runtime state
5. Verified evidence/receipts
6. Current derived synthesis
7. Historical source material
8. Conversation memory

Conflicts must be reconciled and recorded; they must not be silently averaged.
