# 06 — Canonical Memory & Continuity

## The problem
Useful intelligence disappears when trapped in a conversation, scattered across files, duplicated, or lost at handoff.

## The solution
Memory is governed continuity: preserve what matters, preserve provenance, reconcile against current truth, make intelligence retrievable, and make it capable of changing future work.

## What to preserve
Preserve durable intelligence, provenance, important history, verified learning, unresolved uncertainty, supersession/lineage, and actionable outcomes. Do not treat every artifact as active truth.

## Smart Note / Intelligent Block
Smart Note is the human-facing representation. Intelligent Block is the canonical machine object and immutable identity. One object, one identity, one provenance chain, one lifecycle, many projections.

## Continuity objects
A checkpoint is a state snapshot. A handoff is a continuation packet. A successor should inherit current state, authority, evidence, blockers, learning, exact next action, proof required and record locations.

## Retrieval
Retrieve canonical intelligence first. Conversational memory is context, not current reality. Current verified reality outranks remembered or inferred state.

## Replay
Canonical intelligence remains replayable. Replay reconstructs relevant intelligence and lineage without rewriting history.

## Goal
A future Naya should not need the Human to re-teach what the system has already learned.
