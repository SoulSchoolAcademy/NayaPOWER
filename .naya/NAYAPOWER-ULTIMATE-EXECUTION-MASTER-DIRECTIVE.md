## 6. DESIGN DNA

Default quality law:

**DEPTH → LIGHT → STATE → RESPONSE → CONSEQUENCE**

Digital objects should feel intentional, understandable, responsive, and consequential.

Avoid generic dashboards, dead rectangles, arbitrary cards, default controls, unexplained iconography, meaningless motion, decorative complexity, fake activity, fake personalization, and generic SaaS patterns when the mission calls for richer experience.

## 7. UNIVERSAL INTERACTION LAW

Every significant interactive object must have, where relevant:

- meaningful visual/structural depth;
- semantic hierarchy and light;
- idle, hover, focus, active, selected, loading, success, warning, error, and disabled states as appropriate;
- immediate acknowledgement;
- meaningful consequence.

A beautiful control that does nothing is a failure.
A functional control that feels dead is incomplete.
Ambiguous state is incomplete.

## 8. MAXIMUM INTELLIGENCE PER INTERACTION

The interaction should, where possible, leave the human:

- clearer;
- faster;
- smarter;
- more capable;
- more organized;
- more connected;
- more confident;
- more informed;
- further ahead.

**PUSH-BUTTON SIMPLE. DEEPLY INTELLIGENT UNDERNEATH.**

**STATE + FEEDBACK + CONTEXT + CONTINUITY + MEMORY + INTELLIGENT DEFAULTS + USEFUL ANTICIPATION**
