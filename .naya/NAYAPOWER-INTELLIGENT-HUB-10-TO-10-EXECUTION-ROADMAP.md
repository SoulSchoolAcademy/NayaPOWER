## 3. LANE SEPARATION — NON-NEGOTIABLE

There are two Hub implementation lanes:

1. **Assistant lane:** the Cloudflare/live Hub implementation.
2. **Other Naya lane:** the GitHub 509 implementation.

They are separate implementations and must never be silently merged, promoted, overwritten, or treated as one runtime.

GitHub may be used as architectural/reference evidence for the Assistant lane. It is not proof of the Cloudflare runtime.

If the Cloudflare editing/deployment capability is unavailable, the blocker must be recorded honestly. GitHub changes do not count as Cloudflare deployment proof.

# DEFINITION OF 10

The Intelligent Hub reaches 10/10 only when:

1. The architecture is coherent.
2. The human immediately understands where to go and why.
3. Intelligence is represented as durable objects rather than disconnected screens.
4. One object can project across the Hub without duplication or loss of provenance.
5. Search, Library, Lists, Connections, Smart Share, Spaces, Activity, Report, and Smart Mail form one intelligence system.
6. Naya materially reduces human project-management burden.
7. Private/public authority is explicit and safe.
8. Verification state is honest and visible.
9. The experience feels alive, premium, coherent, and intentional.
10. The exact runtime proves the source actually became the intended product.
11. A cold Naya can restore the architecture and continue without conversational archaeology.
12. The system records what became more intelligent and feeds that learning forward.

**10/10 is a verified system state, not a feeling.**
