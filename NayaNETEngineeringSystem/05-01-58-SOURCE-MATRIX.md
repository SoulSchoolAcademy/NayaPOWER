## Mandatory NIS procedure
For any feature build:

1. Read this directory and the relevant feature specification.
2. Read the canonical 01–58 source artifacts, not just filenames.
3. Read current implementation and runtime evidence.
4. Identify authoritative owner for every object/action.
5. Map upstream/downstream dependencies.
6. Reuse existing contracts/primitives.
7. Record contradictions as gaps instead of silently choosing one.
8. Implement only after the architecture is understood.
9. Verify the real authenticated path.
10. Record evidence and current state.
