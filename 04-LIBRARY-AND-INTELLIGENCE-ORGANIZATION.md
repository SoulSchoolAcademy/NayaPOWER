# 🔱 04 — LIBRARY + INTELLIGENCE ORGANIZATION

**Purpose:** make recall, navigation, maintenance, and successor continuity easy.

---

# 1. THE LIBRARY IS AN INTERFACE

I designed this folder as a cognitive map over canonical truth.

The user should not have to remember where the useful thing lives.

The next Naya should not have to search blindly through history.

---

# 2. THE DIRECTORY MODEL

- README = human landing page.
- 00 = master map.
- 01–04 = meaning, boundaries, creator answers, organization.
- 05–11 = construction.
- 12–16 = current reality, proof, continuity, decisions.
- 17 = source navigation.
- 18 = machine contract.

---

# 3. WHY README IS THE FRONT DOOR

GitHub presents the folder README as the folder landing page.

That makes this directory itself a usable interface.

The human enters once and sees:

- what this is;
- what to read;
- what I am building;
- the full architecture route;
- the proof route;
- the current truth boundaries.

---

# 4. NUMBERING LAW

I number by stable cognitive role, not creation time.

00 = map

01–04 = understanding

05–11 = building

12–18 = proving and continuing

---

# 5. METADATA LAW

Durable project-intelligence artifacts should identify:

- title;
- status;
- scope;
- authority;
- created date;
- updated date;
- source;
- supersedes / superseded-by;
- proof state where relevant.

---

# 6. TIME LAW

I do not create a second operational timeline merely to look organized.

Time belongs to:

- Git history for source/specification change;
- Activity for operational work;
- canonical events for occurrences;
- execution receipts for consequential actions;
- runtime timestamps for living state.

This library indexes those sources instead of competing with them.

---

# 7. SMART RECALL

I define smart recall as:

**IDENTIFY → CLASSIFY QUESTION → ROUTE TO AUTHORITY → RETRIEVE NEEDED CONTEXT → RECONCILE CURRENT TRUTH → ANSWER WITH EVIDENCE → UPDATE IF REQUIRED**

The goal is not to remember everything.

The goal is to retrieve the right intelligence at the right moment.

---

---

# 9. THREE-CLICK LAW

A material concept should be reachable in no more than three clicks from the README, master index, or canonical source map.

---

# 10. NO ORPHAN INTELLIGENCE

Every durable intelligence item should answer:

**WHY IT MATTERS → WHERE IT LIVES → WHAT IT AFFECTS → WHAT PROVES IT → WHAT HAPPENS NEXT**

---

# 11. STALENESS

If this library conflicts with higher-authority current truth:

**LIVE TRUTH → RECONCILE LIBRARY → RECORD LEARNING**

The library is a navigation and understanding layer.

It is not a competing database.
