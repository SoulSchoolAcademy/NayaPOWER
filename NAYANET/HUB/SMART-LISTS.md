# Smart Lists

**Purpose:** convert intelligence into organized, mission-aware action collections.

**List item metadata:** mission relevance, value, harm/risk, dependencies, authority, status, evidence, owner, next action.

**UI:** active lists, priority/state filters, item detail, dependency view.

**Actions:** create list, add intelligence/task, reorder/prioritize, complete/defer, open evidence, convert intelligence into next action.

**Backend mapping:** intelligence + value selection + mission state + governed action. A saved/favorite UI flag alone is not a complete Smart List.
