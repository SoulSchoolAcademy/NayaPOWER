# Your Connections

**Purpose:** make the knowledge graph navigable.

**Relationships:** person ↔ project, Smart Note ↔ event, event ↔ decision, decision ↔ authority, agent ↔ capability, intelligence ↔ intelligence, human ↔ space.

**UI:** relationship graph/list, relation-type filters, connected-object preview, provenance.

**Actions:** open relation, traverse graph, create a Smart Link only when authorized, remove/update where authorized.

**Backend mapping:** Smart Link contract + connection persistence + identity/space contracts.
