# Smart Mail

**Purpose:** treat communication as intelligent system material.

**UI:** threads, participants, project/context, decisions, commitments, actions, follow-up, captured intelligence.

**Actions:** search, open thread, extract Smart Note, link to project/person/space, create follow-up, share by choice.

**Backend mapping:** governed mail adapter. If no authorized mail provider/runtime exists, the surface must say so rather than rendering fake messages.
