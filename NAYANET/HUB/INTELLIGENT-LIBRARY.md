# Intelligent Library

**Purpose:** durable knowledge environment, not a file browser.

**Core objects:** Smart Notes, intelligence blocks, evidence, decisions, reports, links, provenance, status, freshness, supersession.

**UI:** semantic search, filters, relationship facets, freshness/status, result preview, source/provenance, related intelligence.

**Actions:** open, search, filter, connect, save, supersede where authorized, share by choice.

**Backend mapping:** Smart Note/intelligence persistence and retrieval contract; PIS adapter protects the Hub from inventing a second intelligence database.
