# 09 — Smart Ledger

**Role:** Durable record of meaningful intelligence/action state and provenance.
**Status:** DEFINED — implementation not started.

The Smart Ledger is the accountability/provenance surface for important intelligence and authorized actions, connecting value, evidence, state, and verification without replacing the Naya Power governance kernel or canonical event store.

**Connections:** Governance, Evidence, Activity, Smart Notes, Reports.

**Current boundary:** Accountability/provenance surface; governance authority remains in Naya Power.
