## What this folder is

This is the working project home for the Intelligent Hub / Superbrain. It is the place Team Naya enters to understand the whole system before working on an individual part.

The Hub is the visual brain of the Superbrain: one connected intelligence system in which human intelligence, Naya intelligence, machine evidence, activity, relationships, records, reports, communication and shared wisdom can become visible and compound over time.

## System law

- One Superbrain.
- One canonical intelligence/event model.
- One source-of-truth boundary.
- Many specialized surfaces.
- Parts may be worked independently, but no part may redefine the whole-system architecture by itself.
- Every active part has a living contract, activity record and current-state record.
- No UI implementation begins from an undefined feature.

## How Team Naya works a part

1. Enter the part folder.
2. Read its `README.md` part card.
3. For active parts, read `CONTRACT.md`, `ACTIVITY.md`, and `STATE.md`.
4. Read the parent project definition before making architectural decisions.
5. Inspect existing implementation and evidence before changing anything.
6. Perform only authorized work within the part's contract.
7. Record meaningful work in the part activity record.
8. Update current state with evidence.
9. Leave a concrete next action.
10. Reconcile the part back into the whole Superbrain before release.
