# 08 — Smart Connect

**Role:** The NayaNET participation door for connection, wisdom contribution, and privacy protection.
**Status:** DEFINED — implementation not started.

Smart Connect governs the seven connection doors. Opening a door establishes participation consent: wisdom is shared by default through governed filtering, while personal intelligence, activity, and identity remain private by default. Public publication or attribution is separate.

**Connections:** Smart Notes, Personal Feed, Collective Feed, Privacy, Smart Mail.

**Current boundary:** Participation consent is not execution authority. Capability does not create authority. Public publication is never implied.
