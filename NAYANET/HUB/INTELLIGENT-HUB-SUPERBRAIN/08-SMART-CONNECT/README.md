# 08 — Smart Connect

**Role:** The NayaNET participation door for connection, wisdom contribution, Smart Spaces, and privacy protection.

**Seven doors:** GitHub App · MCP · REST/OpenAPI · Webhooks · SDK · A2A · MCP Apps.

## Connection agreement

Opening a Smart Connect door establishes participation consent:

- Share wisdom by default.
- Protect personal intelligence and personal activity by default.
- Protect identity by default.
- Permit useful Naya/human connection in governed Smart Spaces.
- Automatically filter usefulness, trust, privacy, safety, deduplication, verification, and governance before collective learning.

Public publication and identity attribution remain separate deliberate decisions.

## Authority

Participation consent is not execution authority.

**CAPABILITY DOES NOT CREATE AUTHORITY.**

The connected door receives only the capabilities and actions independently authorized by the governed runtime.
