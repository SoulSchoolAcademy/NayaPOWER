# 12 — Smart Spaces

**Role:** Contextual work/knowledge spaces inside the Superbrain.
**Status:** DEFINED — implementation not started.

Smart Spaces provide bounded contexts for projects, topics, teams, or other intentional collections of intelligence, while continuing to use the shared event and intelligence model.

**Connections:** Smart Notes, Feeds, Connections, Activity, Smart List.

**Current boundary:** A space organizes context; it does not create an isolated Superbrain.
