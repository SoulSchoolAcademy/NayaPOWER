# 05 — Your Intelligence Today

**Role:** Derived daily intelligence highlights lens.
**Status:** DEFINED — implementation not started.

A concise, automatically derived view of the most significant intelligence, progress, discoveries, relationships, and actions for the current day. It must be derived from canonical intelligence rather than become a second source of truth.

**Connections:** Personal Feed, Activity Feed, Smart Notes, Reports, Intelligence Library.

**Current boundary:** Keep only if the highlights can be reliably generated from canonical data; otherwise defer rather than create a manual duplicate system.
