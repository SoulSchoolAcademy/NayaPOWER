# 11 — Smart Mail

**Role:** Intelligent communication surface connected to the Superbrain.
**Status:** DEFINED — implementation not started.

Smart Mail brings relevant communications into the user's intelligence context so messages can become understood, connected, actionable, and retrievable without collapsing communication into the intelligence graph itself.

**Connections:** Identity, Smart Notes, Connections, Smart Share, Activity.

**Current boundary:** Communication remains communication; derived intelligence and actions must preserve source and authorization.
