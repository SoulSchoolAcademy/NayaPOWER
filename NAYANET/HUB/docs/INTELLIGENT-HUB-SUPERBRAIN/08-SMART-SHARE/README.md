# 08 — Smart Share

**Role:** Controlled movement of intelligence between privacy boundaries.
**Status:** DEFINED — implementation not started.

Smart Share governs deliberate sharing of Smart Notes or other intelligence to people, collectives, or external destinations, with explicit consent, identity/source rules, and reversible/traceable outcomes where supported.

**Connections:** Smart Notes, Personal Feed, Collective Feed, Privacy, Smart Mail.

**Current boundary:** Sharing is an authorized action, not an automatic publication mechanism.
