# 07 — Intelligence Library

**Role:** Durable organized access to accumulated intelligence.
**Status:** DEFINED — implementation not started.

The Library provides retrieval and organization for the Superbrain's durable intelligence, including Smart Notes, reports, evidence, and connected records, while preserving source and privacy boundaries.

**Connections:** Smart Notes, Reports, Evidence, Connections, Personal Feed, Collective Feed.

**Current boundary:** Retrieval/organization surface, not a duplicate intelligence database.
