# 06 — Reports

**Role:** Persistent compounding intelligence reports.
**Status:** DEFINED — implementation not started.

Reports turn canonical intelligence and activity into durable Daily, Weekly, Monthly, and Yearly views. A requested Daily Intelligence Report reviews the prior 24 hours and persists the resulting report in the report history.

**Connections:** Smart Notes, Personal Feed, Activity Feed, Your Intelligence Today, Library.

**Current boundary:** Reports summarize canonical intelligence; they do not become an alternate event store.
