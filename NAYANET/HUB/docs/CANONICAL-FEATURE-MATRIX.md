## Smart Door contract

Every consequential room or capability must use:

1. Human intent.
2. Authority check.
3. Canonical event or action.
4. Persistence/index.
5. Human projection.
6. Receipt/evidence.
7. Learning/compounding where applicable.

A UI control is not a capability merely because a button exists. Capability does not create authority.

## Status vocabulary

- CURRENT — an implementation exists in the canonical Hub lane.
- CONSOLIDATE — capability exists but implementation still has more than one conceptual owner.
- REBUILD — current surface is insufficient for the North Star experience.
- MISSING — no canonical implementation yet.
- RETIRED — historical implementation removed from the active tree.

This matrix is the working map for reconstruction. It does not authorize creation of parallel implementations.
