# Smart Ledger

**Purpose:** durable accountability for consequential system behavior.

**Record fields:** what happened, actor, time, authority, intent, action, evidence, verification, result, value, state change, successor/next action.

**UI:** chronological event timeline, filters by actor/type/status, receipt detail, evidence detail, authority chain, verification state.

**Actions:** inspect receipt, inspect evidence, trace related intelligence, export/share where authorized.

**Backend mapping:** cross-system event contract + direct activity event architecture + execution receipts + runtime verification. Never fabricate a receipt from a UI click.
