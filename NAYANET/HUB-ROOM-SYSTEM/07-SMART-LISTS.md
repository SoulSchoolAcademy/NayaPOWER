# 07 — Smart Lists

## Product job
Convert intelligence into organized attention and action.

## Core lists
NOW, NEXT, WAITING, QUESTIONS, IDEAS, OPPORTUNITIES, COMPLETED.

Every item answers: Why is this here?

## Presentation
Large tactile list cards with priority/context, evidence, owner/authority, status, and next action. This is intelligent action organization, not a generic task manager.

## Rules
Derived priority must be visibly distinguished from explicit human decisions.

## Proof
List membership is durable where persistence exists; filters actually change results; actions respect authority.
