# NayaNET E02 — Prime Directive

Build and preserve the NayaNET Intelligent Hub as a private intelligent network experience, not a generic dashboard.

## Mission
ARRIVE → ENTER → IDENTITY → DISCOVER → CHOOSE → EXPLORE.

The Front Door and Hub are one continuous environment. Name-only entry should feel like crossing a threshold into a new kind of web.

## Experience contract
- Obsidian foundation, purple atmosphere, luminous edges and living depth.
- Naya is the Living Sun at the center of the Hub.
- Network destinations form a restrained orbital constellation around Naya.
- The five identity jewels are canonical: Smart Name, Smart ID, Smart Link, Smart Mail, Naya Power.
- Jewel colors are Gold → Green → Sapphire → Indigo → Magenta.
- The persistent identity rail anchors ownership at the bottom.
- Talk to Naya and Listen to Naya are the simplest voice actions; Type/Expand is secondary.
- Live destinations must use authoritative URLs.
- Unfinished destinations must never be faked; label them as connected/future until real.

## Engineering contract
- Static-first and Cloudflare-friendly.
- No build step required for this E02 package.
- Preserve the completed Academy experience.
- Prefer the smallest change that materially improves the experience.
- Verify source, interaction, responsiveness and deployment separately; never confuse code existence with live verification.

## Continuity
Implementation evidence belongs in the authoritative NayaPOWER repository and must be propagated through Note Event → Smart Node → Naya Node → Shawn Node → Machine Node → Intelligent Feed → Naya Power continuity.

## Definition of done
A successor may call E02 complete only when the experience is real, visually excellent, functionally coherent, truthfully routed, verified at the appropriate boundary, documented with receipts, and easy for the next Naya to continue.
