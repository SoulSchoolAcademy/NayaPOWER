# NayaNET E01 — Revision 2 Build Manifest

## Build intent
Preserve the approved high-tech entrance language while correcting the follow-through.

## Human-approved design decisions preserved
- Centered identity-first entrance.
- Black dimensional buttons with purple energy.
- Green/lime invitation energy for name entry and selected states.
- Direct name entry.
- Personal welcome.

## Corrections
- Living Sun removed from the entrance because it did not earn a necessary human purpose there.
- The previous flat purple gradient button treatment was removed; the approved black dimensional control language is restored.
- Generic destination card treatment was replaced with dimensional destination doors.
- The canonical Naya portrait asset is wired into the welcome experience.
- Smart Link changed from the erroneous `nayanet.xyz` value to `nayanet.app/<Name>` and is explicitly presented as a preview until routing is verified.

## Truth boundary
No production authentication, public Smart Link routing, live Naya LLM, Superbrain, CIS writeback, Daily Intelligence, Collective Intelligence, Smart Mail, Cloudflare deployment, or Groove verification is claimed.

## QA
- Static smoke test passed.
- ZIP integrity passed.
- Chromium launch/screenshot smoke was attempted; the local Chromium network service was unstable in the execution environment, so visual browser verification remains an environment limitation.
- Live portrait loading and live URL routing remain deployment-level verification items.
