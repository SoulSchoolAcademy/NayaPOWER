# SMART BOX LAW v1 (2026-11-03 — Shawn: "the building blocks that build endless blocks")

## What the Smart Box is
The Smart Box holds the **building blocks** — the elite parts that build **endless blocks
within the building** (Naya World, the One App). It is the citizen's Lego set.

## Two kinds of blocks (this is the law — never mix them up)

### 1. STYLE BLOCKS — portable, always alive
`smart-box.css` — the entire Naya design language as working CSS, harvested whole from
the living pages (nayanet.app/personal, /dashboard, /space — 2026-11-03).
- 2,902 style rules + 340 @keyframes/@media. 462KB. Zero inventions.
- CSS never dies when moved. Any composition that includes this file IS Naya —
  the depth equation, the crescent catch-light, the spectrum, the shapes, the type.
- **Proven alive** 2026-11-03: orbs render as glass marbles, buttons ignite, cards
  elevate — pure CSS, no page JavaScript. Screenshot: verified by Naya Nitro's eye.

### 2. LIVING BLOCKS — whole pages, never fragments
The functional components (Bugatti gauge, data orbs, feed, command bar) live ONLY as
whole working pages — the doors (see FACTORY-LAW-V5). They are pulled live, never copied.
- A gauge without its page is a picture of a gauge. We don't ship pictures.
- Living blocks are referenced by URL + PI injection, composed as doors in the One App.

## The rule
- Need the LOOK? → Smart Box CSS. Include it, use the class names, it's alive.
- Need the FUNCTION? → Living block. Open the door (whole page + PI). Never extract.
- Building something new? → Compose style blocks + living blocks. Never invent, never rebuild.
- The building (Naya World) grows endlessly because the blocks are endless — but every
  block traces to the living source. No orphans. No fakes.

## Maintenance
When Shawn upgrades a living page, re-harvest: `build-v5.py` fetches live; re-run the
CSS harvest to refresh `smart-box.css`. The Box stays in sync with the living system —
because it IS the living system, boxed.
