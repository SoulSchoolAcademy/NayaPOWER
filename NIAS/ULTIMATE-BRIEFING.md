**The 15 laws:**
1. Spectrum Flow: Purple → Blue → Green → Gold → Orange → Red → Magenta → Purple. Never double. Never random.
2. Obsidian: #050607. Not #0B0D12. Boards are black at rest. No ambient glow.
3. White at rest, color ignites (own color only, on touch)
4. Elevation everywhere (multi-layer depth, nothing flat)

8. Viewport Optimization (morph to purpose, one purpose per viewport, mobile first)
9. Text: white always, bigger is better, 20px nutshell, minimal words
10. Smart Tab (the canonical form — obsidian, white rim, top edge light, own-color icon)
11. Derive, don't invent (change shape, never language)
12. Harvest-first, never invent (every element traces to parts registry)
13. No-redesign law (edit-only: fill, wire, polish, fix — never replace)
14. No voice buttons (hidden by law)
15. 10-star or nothing (if not utterly awesome, it doesn't ship)

## The NIAS Machine — The Machine That Builds Machines

**What it is:** One universal template (DNA-locked) + PI data in → finished pages out.

**How it works:**
```
PI Data (JSON) → Generator → Finished Page (HTML)
     ↓               ↓              ↓
  vision          template      DNA-locked
  mission         + configs     10-star
  goal            + parts       ready
  name, type
```

**Input:** Fill in name, type, vision, mission, goal.
**Command:** `python3 generate-page.py input.json output.html`
**Output:** Finished page. DNA-locked. Ready to deploy.
