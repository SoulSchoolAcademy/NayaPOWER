# Network Lessons

When one team proves a lesson, it publishes a lesson card here so other teams' Compounders can attempt reproduction. That is how intelligence compounds *across* teams.

**Lesson card format:** `L-NNNN-<slug>.md`

Every card must name its **falsifier** — what would prove it wrong. A lesson without a falsifier is a claim, not a lesson.

Reproduction outcomes (`REPRODUCED` / `FAILED` / `PARTIAL`) are recorded in the reproducing team's own ledger, citing the origin card. A failed reproduction is data, not shame.

Lifecycle: PUBLISHED → ADOPTED (≥2 independent teams) / CONTESTED / WITHDRAWN / STALE.

See `BRAIN/90-OPERATIONS/INTER-LEDGER-PROTOCOL.md` §4 for the full protocol.
