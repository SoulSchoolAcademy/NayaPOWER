# Learning Contract V1

**Status:** CANONICAL BUILD CONTRACT

## Purpose
Turn verified experience into durable intelligence that measurably improves later behavior.

## Causal loop
`TASK → ACTION → OUTCOME → EVIDENCE → CAUSAL VERIFICATION → LEARNING CANDIDATE → PROMOTION → HELD-OUT RETEST`

## Laws
- Learning candidates require a verified source outcome.
- Promotion requires provenance, scope, evidence, verification, and authority.
- A learning record does not prove behavioral improvement.
- Held-out later behavior is required to claim compounding.
- Failed or contradicted learning remains visible as rejected/superseded history.

## Acceptance
A valid learning proof contains baseline behavior, learned behavior, held-out task, observed outcome, causal comparison, and promotion receipt.
