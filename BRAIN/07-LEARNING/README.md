# Learning

**Status:** PROPOSED CANONICAL — HUMAN DIRECTOR RATIFICATION REQUIRED

Owns candidate learning, verified learning, behavioral effect, reconciliation, prediction, regression protection, and compounding.

Stored information is not learned information.

## Key Principles

- Learning occurs only when an observed and appropriately verified outcome changes future behavior
- Pipeline: `OBSERVE → RECONCILE → CANDIDATE → VERIFY → ADOPT → MEASURE → COMPOUND`
- A stored note is not learning; a candidate is not verified learning
- Learning must not silently change authority
- Compounding requires measured future behavioral effect
