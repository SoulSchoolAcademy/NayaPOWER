# NayaPOWER Representation Law V1

**Status:** PROPOSED CANONICAL

One semantic object may have several representations.

```
ONE OBJECT
├── HUMAN VIEW
├── AI VIEW
├── MACHINE VIEW
├── SCHEMA
└── PROOF VIEW
```

These are views of one identity, not five independent objects.

## Human view

Optimized for understanding:
- essence
- why it matters
- what to remember
- application guidance
- uncertainty

## AI view

Optimized for reasoning:
- explicit semantics
- context
- constraints
- applicability
- relationships
- conflict handling
- authority implications

## Machine view

Optimized for deterministic processing:
- stable IDs
- enums
- references
- timestamps
- versions
- typed fields
- validation

## Proof view

Optimized for verification:
- source
- evidence
- test
- verifier
- result
- timestamp
- scope
- unresolved gaps

No representation may upgrade epistemic status merely by being machine-readable.
