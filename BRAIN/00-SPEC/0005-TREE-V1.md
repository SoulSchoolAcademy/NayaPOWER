## Domain law

- `00-SPEC` defines the brain's semantic laws.
- `03-KERNEL` defines the nine semantic responsibilities.
- `04-INTELLIGENCE` contains canonical object projections and graph relationships.
- `11-KNOWLEDGE` contains source reconciliation and population intelligence.
- `12-ENGINEERING` owns implementation truth and verification of behavior.
- `90-OPERATIONS` owns current operational state.
- `99-ARCHIVE` preserves history without current authority.

**Important:** Constitution remains a root-level canonical repository domain outside `BRAIN/`. `BRAIN/00-SPEC` is not a duplicate Constitution.

The tree is navigation. It does not, by itself, prove a living runtime brain.
