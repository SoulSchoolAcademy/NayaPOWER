# Memory

**Brain-level status:** PROPOSED pending Human-Director ratification. Individual files carry their own status declarations.

Owns durable retention, indexing, retrieval, reconciliation, freshness and continuity mechanisms.

## Canonical rule

Memory preserves useful intelligence; it does not manufacture truth or authority.

Optimize for **maximum verified future value per unit of retained complexity**.

Prefer:
- one canonical intelligence object;
- generated projections;
- provenance and applicability;
- explicit truth/learning states;
- supersession instead of silent overwrite;
- cold-retrievable lessons;
- retirement of redundant projections.

Avoid:
- duplicate Smart Note projections;
- hand-maintained file counts;
- parallel stores;
- historical snapshots presented as current law.

## Key principles

- Memory preserves identity, ownership, version, relationships, provenance, evidence, verification, learning, succession, supersession and revocation.
- Memory must not silently convert history into current truth.
- Cold continuity is the acceptance target.
- Stored data is not automatically intelligence.
- **STORED ≠ LEARNED.**
- **RETRIEVED ≠ UNDERSTOOD.**
- **APPLIED ≠ CAUSALLY IMPROVED.**

## Periodic learning

**DAILY → WEEKLY → MONTHLY → YEARLY**

Each meaningful period should distill the most valuable lessons, preserve the evidence boundary, link reusable Smart Notes and retire material that no longer earns its weight.
