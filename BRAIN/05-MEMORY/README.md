# Memory

**Status:** PROPOSED CANONICAL — HUMAN DIRECTOR RATIFICATION REQUIRED

Owns durable retention, indexing, retrieval, reconciliation, freshness, and continuity mechanisms.

Memory stores and retrieves intelligence; it does not decide truth or authority by itself.

## Key Principles

- Memory preserves identity, ownership, version, relationships, provenance, evidence, verification, learning, succession, supersession, and revocation
- Memory must not silently convert history into current truth
- Cold continuity is the acceptance target: a cold Naya can retrieve relevant intelligence without manual reconstruction
- Stored data is not automatically intelligence
