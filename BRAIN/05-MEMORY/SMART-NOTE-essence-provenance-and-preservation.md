## Essence

Nothing in the brain is deleted or rewritten on a guess. The Preservation Law is absolute: no deletion without understanding — you must know what a thing is, why it exists, and what depends on it before it may be removed, because in a compounding memory system a careless deletion destroys intelligence no one can re-derive (SN-0608). Provenance is the companion duty: a record must describe what actually happened, and there are exactly two legitimate registration patterns — (1) a real pipeline run produces real UUIDs, or (2) an explicit provenance note documents the exceptional path honestly; anything else, above all UUIDs no run ever produced, is fabrication wearing a process costume (SN-0466). And a manual registry edit owns every invariant the pipeline maintains: the registration that missed `sequence_policy.next_sequence` (361 against a corpus max of SN-408) was caught by the test suite, not by care (SN-0466). The capture lifecycle shows the failure modes by name. A direct-commit capture bypass skips the lifecycle that gives a note its checks, landing intelligence the pipeline never vetted (SN-0491). Fabricating a capture — writing provenance for an event that did not happen as described — is provenance laundering: it converts the memory system itself into a counterfeiter, and it is never a shortcut, a favor, or a repair (SN-0494).

Capture also has an identity discipline: an agent capture must present a real user JWT, and the receiver stays byte-identical — the authentication is the agent's burden to carry honestly, never the receiver's code to loosen (SN-0496). What gets captured must be findable as what it teaches: index the lesson, not just the metadata, because retrieval matches its haystack — a corpus indexed by titles and tags alone will fail to surface the very rule a cold successor needs (SN-0612). Retrieval itself is one transparent path: a single retrieval RPC whose scoring is visible, where relationships traverse but no authority is created by the act of ranking — being found is not being ratified (SN-0497).

## What this settles

- Deletion is a conclusion, not a cleanup step: understanding first, always (SN-0608).
- Provenance has exactly two honest shapes — a real pipeline run's real UUIDs, or an explicit provenance note documenting the exceptional path — and a manual registry edit must maintain every invariant the pipeline maintains, `sequence_policy.next_sequence` included; laundering is a named, forbidden act, not a gray area (SN-0466, SN-0494).
- Bypassing the capture lifecycle or loosening the receiver to accommodate a capture are both defects; the capture conforms to the system, authenticated as a real user (SN-0491, SN-0496).
- Findability is part of capture quality: the lesson text is the index, and retrieval ranking confers no authority (SN-0612, SN-0497).
