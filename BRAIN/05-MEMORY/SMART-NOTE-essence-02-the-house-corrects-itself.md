## In a Nutshell
A system that cannot correct itself in live time will be corrected by its failures instead. This essence carries the kernel-era lessons: when something lands that shouldn't have, the seat that proves it reverts it then and there; every critical mechanism gets a watcher whose silence can never be silent; a problem that can recur gets an automation, not a second hand-fix. Underneath sit the working disciplines that make correction possible: name a rule's exact criterion before you act on it (near-matches are bait, and the gate's operator submits to the gate), make test fixtures hermetic unconditionally and prove it with a poisoned-HOME probe, replay decisions for authority-rot as well as fact-rot, carry identity in an envelope you never invent fields for, and when a needed thing doesn't exist — search, ask, then build it to spec and label it BUILT, never "recovered."

## Essence
The House-Fire order runs SEE → FIX → REPORT, in that order: a merge that shouldn't have landed gets a revert commit on main (never a history rewrite) by the seat that proves it, evidence preserved, the board told, the tip verified after — and a revert touching a protected gate (Shawn-ratified content, credentials, money, security posture) escalates to Shawn instead (SN-0814). Every critical mechanism must have a liveness watcher with an alarm path — the first instance shipped the same night, when the notes sync's vanished schedule was found, restored, and given a watchdog so its silence could never be silent again; a failure class that occurs twice owes an automation; a correction is not done until it is DETECTED → CORRECTED → VERIFIED → NOTED (SN-0814). The whole system, in simple words, is a pipe: SENDER (the engine — GitHub / NayaPOWER, the canonical store; nothing is real until it lives there) → BRIDGE (the GitHub App, the governed two-way carrier; Supabase carries live user data alongside) → RECEIVER (the Hub, the rooms humans touch) — and "a room functions iff its sender→bridge→receiver path flows end to end; an unwired room exists as a page but does not function," across the 15 rooms the map enumerates (smart_note, smart_feed, todays_intel, reports, intelligent_library, smart_spaces, auto_match, smart_mail, smart_lists, smart_ledger, connections, smart_growth, start_here_smart_connect, ask_naya, settings) (SN-1769). The star goal on that map is the Smart Factory: intent + template + form answers → click build → a functioning personal smart app in minutes, assembled from pre-made parts (SN-1769). The older V1 execution doctrine, distilled from a superseded prompt so the doctrine survives the husk, still teaches: inspect live canonical state first, price inaction in the act-first chain (OBJECTIVE → EVIDENCE → EFFECT → RISK → BLAST RADIUS → REVERSIBILITY → COST OF INACTION → NET VALUE → AUTHORITY), never collapse the evidence ladder (DOCUMENTED → IMPLEMENTED → TESTED → VERIFIED → PRODUCTION-PROVEN), leave exactly one next action, and hand off CURRENT STATE, AUTHORITY, INTELLIGENCE, BLOCKERS, NEXT ACTION, VERIFICATION, and AFTER SUCCESS (SN-01774 — CANDIDATE, and it explicitly does not govern: V2 governs). The direction rule binds the dispatcher too: a trigger is the rule's exact criterion — the receipt's `Brief:` line exact-naming the brief — and name similarity, queue-arrival listings, and body-text mentions are bait, never triggers; when the night dispatcher dequeued 5 gap briefs on name match alone, all 5 were restored the same tick and the violation logged against itself, and the clean re-run dequeued 0 of 30 on the same bait (SN-1784). Hermetic must be unconditional: a fixture that reads the real file "when available" is a lie CI can never catch, because CI already runs the hermetic body — delete the condition, materialize always from registered inputs, and accept only on the poisoned-HOME probe run in three environments (real HOME, poisoned fake HOME, empty HOME), before and after (SN-1785). Replays catch authority-rot, not fact-rot: a gated decision encodes facts AND an authority premise, doctrine can change under a decision while its facts stay green, and a correct HOLD quietly becomes a stalled one — every replay re-derives the authority premise from today's doctrine in bytes, splits what math can decide from what still needs the gate, and routes the unblocked part as a scored brief (SN-1786). Identity travels in the NIO envelope — 20 fields, 9 types — under two rules that admit no exceptions: never fabricate a field, and never infer authority from the envelope itself (SN-1854). When a needed source does not exist, the loop is search the record → ask the seats who hold the surrounding system → if no one has it, build it to spec, test it, label it BUILT with date and provenance (never present a build as a recovery), and route it to the verifying seat — as when the Hub's sw.js was built on 2026-10-24 with Nitro's scope check still owed before landing, a caveat that stays attached until the check lands (SN-0855). And the build method that ties it together: ten trillion is the VALUE of the finished intelligence, never a budget; lay out the whole brief first (per part: identity, purpose, behavior, features, connections, relevance, look, function, problem solved, real-world value, bullseye paragraph — write once, link everywhere), then build in flow — fill-complete → build-while-fill-moves-on → verify-inline → next app — under proof gates a different seat scores at 9+, with disqualifiers named: staged-as-live, typed numbers, device-only truth, phone unproven, self-scored, empty shells, dead controls, claim without receipt (SN-1897).

## What this settles
- Correction is a live-time duty of the seat who sees, with protected gates the only escalation.
- A mechanism without a watcher is unfinished; a twice-occurring failure without an automation is a debt.
- Exact criteria or nothing: near-matches are anti-evidence, and operators submit to their own gates.
- Conditional hermeticism is not hermeticism; the poisoned-HOME probe, before and after, is the acceptance test.
- A replay that checks only facts will certify stalled decisions as correct; authority premises expire.
- Provenance labels are load-bearing: BUILT is not FOUND, and an envelope never mints authority.

## What It All Means
Self-correction is not a virtue; it is machinery — watchers, criteria, probes, envelopes, labels — each one small, each one falsifiable. The kernel era's real product was not any single fix; it was a house whose failures surface in minutes, whose corrections carry receipts, and whose lessons are written where the next seat cannot miss them.

## Why It Matters
Because the failure modes here are the quiet ones: a sync that silently stops, a HOLD that outlives its doctrine, a test that passes because it secretly read the real file, a "recovered" component that was actually improvised. Each one looks like health from a distance. Without these disciplines you would find out the way the reservoir taught us — all at once, a month late. With them, the system tells you itself, the same tick, with the fix already moving.
