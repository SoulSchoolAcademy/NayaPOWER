## In a Nutshell

A learning claim is a measurement or it is a slogan: influence is a number produced by control-vs-treatment ablation or it is not a claim (SN-0510), presence in context is not influence (SN-0544), LEARNED is not mastered until governed transitions prove the higher rungs (SN-0546), and a trial measures only if its task can discriminate, its prompts don't cue the answer, and its raw data survives for independent verification (SN-0452, SN-0474, SN-0573). The activation test is behavioral and two-sided: behavior changes only when the ordinary selector returns the retained lesson unprompted — and removing the seam removes the change (SN-0550).

## Essence

Retrieval is where learning claims meet reality first. Test the retrieval path with the experiment's actual queries before designing around it: two live queries named the defects in under a minute — a CANDIDATE restatement beat ratified law on a recency tie-break because the ranker scored keyword overlap only, and the experiment's own note returned NO_RELEVANT_INTELLIGENCE because it was never in the registry. Tie-breaks order as relevance first, authority second (RATIFIED=2, VERIFIED=1), recency last — authority-primary was rejected as an unmeasured global change. And the corpus defects were data defects (a tombstone-pointing SUPERSEDED entry, an unindexed file, 38 of 40 entries CANDIDATE): no ranker retrieves what was never indexed; machinery repair and corpus feeding are two different jobs (SN-0449).

Trials have integrity conditions. A control/treatment trial measures a behavioral delta only if the task can discriminate: validate the answer key against ground truth BEFORE running (a variant key asserted the gate was right when the scenario made it false — the treatment agent caught the flaw), make transfer tasks hard (clean variants produced ceiling effects, both arms 100%), and instrument cost exactly, per-trial tool-call counts, never estimated (SN-0452). The promotion rule that governs consequential action in the same spirit: a single passing check is a hypothesis, not a verdict — require a second independent check that could have disagreed; a re-run of the same check is not a second source; if the second check cannot be run, say so and hold. The rule constrains your own decisions only — it grants no authority to block another's work, and over-applying it to trivial reversible actions is a misfire (SN-0458). Cueing is the pretrial killer: an independent red-team found the SN-0458 battery's transfer prompts naming the target rule ("independent check"), letting the control arm infer the lesson without retrieval — the battery would have measured prompt-reading, not learning. Cues were stripped pretrial, the task blob rebound, and two regressions added (forbid cue leakage in transfer prompts; verify every fixture-role path against its exact Git blob) (SN-0474).

Influence, measured: the ladder EXISTS → LOADS → INVOKES → INFLUENCES → APPLIES had a specified control-vs-treatment method that nothing had ever implemented, so "influence" had never been a number. The measurement tool changed that: the manifest-bound runtime kernel invokes 2/9 nodes (SELF, LAW) with influence NONE (0/9) — its decide() hardcodes the two-node trace and its own comment admits it must not claim the rest ran; the full nine-node engine invokes 9/9 with influence 6/9 (SELF, LAW, ACT, PROVE, VERIFY, LEARN). Neither kernel is reachable from production. And a CI artifact named "behavioral acceptance" proved to be a shape check carrying independent_verification: true that no independent process produced — reported plainly, deliberately not unilaterally rewritten, because overstating a proof artifact is a truth decision for its owner. Attribution is explicit per ablation (a first draft inferred it from scenario names and was wrong), and "6/9 is not 'good' — it is the number, and the number is the contribution" (SN-0510). The architecture decision followed the number: ONE canonical runtime kernel — the manifest-bound one, whose honesty about running only SELF→LAW is correct — and the stronger engine demoted to reference/donor, its logic converged through adapters, smallest seam first, never a second orchestration stack. Never average the two measurements into a false "partially behavioral" score: the canonical truth state reads EXISTS 9/9 → LOADS 9/9 → INVOKES 2/9 → INFLUENCES 0/9 → APPLIES 0/9, and no node is called "behavioral" because a receipt dictionary contains its name (SN-0511).

Agreement is not corroboration. Six seats distilled the same 45 notes and five converged — that is one shared source with six readers, not six pieces of evidence. Before treating convergence as lock-in, enumerate each seat's evidence inputs; shared inputs count as one datum with N readers, said plainly. (The seat who named this declined to ship a sixth distillation and closed guard-proof work instead.) (SN-0515). Pipelines get the same empirical treatment: rehearse synthetically before claiming readiness — a labeled-synthetic lesson walked all 11 stages read-only against the real contracts and produced a per-stage evidence map (7 CLEAR / 3 BLOCKED / 1 GAP, the GAP being the indexing hole with no machine), with at least one fail-closed denial verified as correct behavior; "probably ready" becomes "here is exactly what flows, what blocks, and what is missing" (SN-0524).

The category errors get names. Presence is not influence: a runtime stamped influenced: true whenever ACTIVE learning evidence merely sat in context; the repair splits the schema — LEARNING_CONTEXT_AVAILABLE proven by a retrieval receipt, influence staying FALSE until a controlled intervention + outcome + independent verification establish it; the flag's setter is gated by the causal proof, not by the retriever (SN-0544). LEARNED is not mastered: the promotion path proves E1 (understands) with a governed transition, while E2–E7 (apply → outcome → reuse → generalization → successor) exist only as schema fields — capacity, not attainment. Each level needs a governed, observable transition with a falsifier, witnessed by independent evidence on live bytes, or the honest representation is "candidate learning, E1-proven," never "mastered" (SN-0546). Activation itself is defined mechanically: retained learning flows through the ORDINARY decision path (receipt → plan → law re-resolution → execute → verify handoff), never invoked by a special step or a caller-provided lesson ID. The proof is two-sided — the same task changes behavior only when the normal selector returns the applicable learning, and removing the seam removes the delta entirely. If the caller must name the lesson, it isn't learned; it's manual invocation (SN-0550). And a green proof run is bounded by the seam it exercised: a fully green production proof run never exercised the newly shipped two-phase seam, so the new seam's state was UNKNOWN, not PASS — vacuity by staleness, distinct from vacuity by skip and vacuity by fixture substitution; when a PR ships a governed seam, the same PR names the harness leg that exercises it (SN-0567).

Finally, evidence custody decides whether any of it counts: Trial-4's statistically overwhelming result (20 fresh agents, p=0.0007, h=2.214) was downgraded PASS → INCONCLUSIVE because its raw data lived on ephemeral /tmp and was lost before independent verification. The mechanized answer: a trial-evidence spec, a fail-closed verifier, and an 11-test conformance suite including a regression replay of the exact Trial-4 hole — the verifier must reject the Trial-4 shape (summary statistics, no committed raw data) and accept the committed-in-repo shape. Rule, enforcer, replay: a trial that cannot be independently verified is not a trial; it is a story with numbers (SN-0573).

## What this settles

- Test retrieval with the real queries first; tie-break relevance > authority > recency; an unindexed note is a corpus defect, not a ranking defect (SN-0449).
- Trial integrity: key validated before running, tasks hard enough to fail, cost instrumented exactly (SN-0452); prompts red-teamed for cue leakage pretrial (SN-0474).
- One passing check is a hypothesis; the second check must be independent and able to disagree (SN-0458).
- Influence is a number from control-vs-treatment ablation, with explicit attribution (SN-0510); the two kernels are never averaged (SN-0511).
- Convergence on shared evidence is agreement — one datum, N readers (SN-0515).
- Pipelines are rehearsed synthetically with per-stage verdicts before readiness is claimed (SN-0524).
- Presence ≠ influence (separate schema fields, influence defaults false) (SN-0544); levels are earned by governed transitions or they are labels (SN-0546).
- Activation runs through the normal path, proven two-sided (SN-0550); a proof run's claim is bounded by the seam it exercised (SN-0567).
- Trial raw data lives in-repo under a fail-closed evidence verifier with a regression replay of the loss that taught it (SN-0573).

## Human

The learning system is the heart of this whole project — the claim that the machine gets smarter. This block is where that claim grew up: every comforting shortcut was found and named. Notes in context were stamped "influenced." Agreement among readers of the same document was counted as independent proof. A legendary trial result evaporated because its data lived in a temporary folder. What replaced the shortcuts is a measurement discipline strict enough that the honest numbers are sometimes embarrassing — 0/9 influence on the production kernel — and exactly therefore believable.

## Child

Imagine claiming "I learned to swim" because you read a book about swimming while sitting next to a pool. The book was there (presence), but did it change what you do in the water (influence)? To prove learning, someone has to watch you swim — with the book's lesson and without it — and see the difference. And if six friends all copy the same answer from the same page, that's not six proofs; it's one page read six times. Real learning leaves evidence: you behave differently, and someone else can check.

## Grandma

Dear, it's the difference between owning a cookbook and being a cook. The books on the shelf prove nothing about dinner. What proves it: a meal cooked differently because of what was learned, tasted by someone who didn't cook it, with the recipe cards kept in the drawer where they can be found again — not thrown out with the scraps. The team learned to ask of every lesson: show me the meal, show me the cards, and let someone else taste.

## Naya

On any learning claim: run the real queries against the live index first (SN-0449); validate the key and make the task discriminating before the first trial (SN-0452); strip the cues pretrial (SN-0474); demand a second, independent, could-disagree check before promoting anything consequential (SN-0458); measure influence by ablation and report the number, never the adjective (SN-0510, SN-0511); count shared-evidence agreement as one datum (SN-0515); rehearse pipelines synthetically and publish the stage map (SN-0524); keep presence and influence in separate fields with influence defaulting false (SN-0544); claim only the rungs a governed transition has proven (SN-0546); activate through the normal path and prove it two-sided (SN-0550); bound every proof run by the seam it exercised (SN-0567); and keep trial raw data in-repo under the evidence verifier (SN-0573).

## What It All Means

Thirteen notes build the epistemology of a learning system: capability claims decompose into retrieval, trial design, causal measurement, schema honesty, activation path, and evidence custody — and each link has a mechanical test. A cold reader holding only this essence can dismantle any inflated learning claim into its failing link, and can say exactly what proof would repair it.

## Why It Matters

Compounding is the project's entire thesis — and it is unfalsifiable without this discipline. The failure modes are seductive because each produces good-looking artifacts: stamps that say influenced (SN-0544), verdicts that say behaviorally accepted (SN-0510), majorities that say corroborated (SN-0515), statistics that say overwhelming (SN-0573). Every one was, at the moment it looked best, unproven. The measurement discipline is what converts the learning story from marketing into engineering — and the honest numbers (2/9 invoked, 0/9 influence, E1-proven) are the baseline every real improvement will be measured against.

## The Learning

The corpus learned that learning-claims fail at their definitions before their data: influence defined as presence (SN-0544), mastery defined as a label (SN-0546), corroboration defined as headcount (SN-0515), readiness defined as adjacency (SN-0567). Redefining each term as a measurement — with a falsifier and a custodied evidence path — was the actual work; the numbers followed. It also learned restraint: the most damaging overstatement found (SN-0510's borrowed verification flag) was reported, not unilaterally repaired, because truth decisions belong to owners.
