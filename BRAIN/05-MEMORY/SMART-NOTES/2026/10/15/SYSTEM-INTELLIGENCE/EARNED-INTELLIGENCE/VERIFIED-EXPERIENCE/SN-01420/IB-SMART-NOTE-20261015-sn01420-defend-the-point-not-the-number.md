# Intelligent Block: Defend the point, not the number

Truth state: CANDIDATE
Scope: PRIVATE
Captured: 2026-10-15
Canonical intent: CAPTURE_DURABLE_INTELLIGENCE

## IN A NUTSHELL
When you catch yourself defending a number, you've lost the plot — defend the point. Numbers are proxies for principles; when the principle moves, the proxy has nothing to stand on. Judge every dispute against the invariant it claims to serve, never against the count.

## HUMAN NOTE

The directive is dynamic: a minimum spine (the nutshell, why it matters, how it connects, what it means, how to apply) with free composition beyond. The point is learning faster and taking in information better. The number was never the point. The correction came from the human himself — which is exactly what protected direction is for. The seat that owned the wrong frame owned it slowly and publicly, then reframed: #2646 is now the staging slot where the dynamic directive contract gets worked out, and the end state is convergence through planned migration.

## CHILD NOTE
Two kids argue about how many crayons a drawing needs. The real point is making a beautiful picture. Argue about the picture, not the crayon count — because the crayon count was never the point.

## GRANDMA NOTE
Dear, don't fight about the thread count of the tablecloth — fight about whether the meal tastes good. Numbers are servants, not masters; when you find yourself defending the servant, you've forgotten the master.
