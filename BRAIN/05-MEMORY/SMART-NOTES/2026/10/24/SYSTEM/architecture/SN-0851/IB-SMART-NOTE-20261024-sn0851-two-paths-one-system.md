# Two Paths, One System — The Interface Path and the Engine Path
SN-0851 · SYSTEM / architecture
**Created:** 2026-10-24T02:37:00Z

## IN A NUTSHELL
Shawn's bottom line (2026-10-24): all of tonight's definitions exist to get this LOCKED IN and DONE RIGHT — and the work runs on **two paths that work together**. **The Interface Path** (Nitro's side, with Tree — the Interfaces/Hub seat): everything the citizen sees, touches, and feels — the ceremony, the pages, the covers, the personal Hub, the offer words. **The Engine Path** (the rest of the team): everything that makes it true — the governed core, identity and authority, the matching engine, mail routing, the activation machinery, the doors, the evidence. Neither path is the product alone: a beautiful interface over an unproven engine is a lie, and a proven engine behind a cold interface is a warehouse. **They meet at one seam — the capability contract:** every element the interface shows binds to a named engine capability carrying a state (specified · implemented · tested · live-verified · production-proven, per #3028). The interface never promises past the engine's proof; the engine builds in the order the interface's journeys demand. And the handshake is the JOURNEY TEST: a journey counts only when both paths pass it together, end to end, from the citizen's seat.

## HUMAN
**For anyone joining the work, the map is one picture:** the citizen walks the Interface Path — claim, certificate, presentation, world, personal Hub (SN-0849). Under every step, the Engine Path answers — identity issued, pages derived, covers composed, matches computed, mail routed, evidence written (SN-0850). When a step feels magical, both paths did their half. When something is missing, the map says whose half it is — no fog, no finger-pointing: interface gaps look like *the citizen can't see it, reach it, or understand it*; engine gaps look like *it isn't true, isn't proven, or isn't running*. The Official Welcome is the first journey both paths walk together, and its acceptance test is the handshake: cold activation, voice only, landing in a personal Hub — interface beautiful, engine true, at the same time.

## CHILD
One team builds the house you can see — the doors, the paint, the welcome mat. The other team builds the plumbing and the lights inside the walls. You only get a real house when both teams finish the same house, and you check it by living in it for a day, not by admiring the paint or the pipes alone.

## GRANDMA
It's like a restaurant: the dining room and the kitchen are two paths, one meal. The menu may only promise what the kitchen can actually cook, and the kitchen cooks what the menu's guests actually order. You judge the place by the meal arriving — hot, right, and as described.

## NAYA
**Ownership, plainly:** Interface Path — Nitro (lead) + Tree (Interfaces/Hub) · the ceremony (SN-0846/0849), Trinity pages and covers, Hub personalization (sidebar top-3, tabs), the offer surface (SN-0847 words, gated by states). Engine Path — the seats on #3028/#3029 and the core lanes: the governed core + doors (SN-0850), the Smart Match engine (SN-0845 — ONE shared engine), mail/identity routing, the five-part Power activation, proof + measurement machinery (Production Engine, SN-0844). Gates both paths answer to: Delta (LAW) on the contract, Epsilon (VERIFY) on the proof — different seats, different logins, per the standing law.
**The seam discipline (how the paths stay together):** (1) No interface element ships pointing at a capability below *implemented*; no public word promises below *live-verified*. (2) The engine's build order is set by the interface's journey order — the Welcome journey first, because that is where citizens arrive. (3) Every defect is filed as interface, engine, or seam — and seam defects (beautiful but untrue, true but unreachable) outrank both. (4) The scorecard loop (SN-0843's six dimensions) already measures the split: Human/Naya experience scores the interface path; execution, network intelligence, and trust score the engine path; a journey is 10 only when both are.
**It doesn't have to be this split forever** — Shawn's own words: the paths work together, and the split exists only to make the work clear. Seats may cross; the seam may not blur.
