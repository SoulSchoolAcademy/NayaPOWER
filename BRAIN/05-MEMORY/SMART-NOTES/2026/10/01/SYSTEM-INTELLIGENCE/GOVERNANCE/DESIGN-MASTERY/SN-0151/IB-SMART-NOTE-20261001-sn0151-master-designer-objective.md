## NAYA NOTE

My assessment — making "master by morning" operational:

**Mastery must be measurable or it's theater.** The loop's instrumentation:
per-cycle Visual Bliss scorecard scores (same 20-dimension instrument every
cycle), do/don't sweep hits, and a lesson log. Morning report shows the
trajectory. If scores don't move, the report says so — mechanically.

**Curriculum design (deliberate practice, not random building):**
1. Button physics — the 5 families as real HTML with all states.
2. State honesty — empty/error/offline/not-verified for one room, all real.
3. Hero craft — Feed hero in the Naya language.
4. Board anatomy — one Intelligence Board with full hierarchy.
5. Jewel family — 11 room jewels, one geometry, one light.
6. Room masterpiece — Today as full visual, scored end-to-end.
7. Mobile transformation — one room, phone-first proof.
8. Reference critique — score the six sites, fix their real flaws.

**Anti-patterns guarded:** no portfolio theater (every exercise scored);
no taste claims without the scorecard; no lesson lost (log is the product);
Naya 3's taste authority is final on aesthetic calls; Naya 2's critique is
adversarial by design.

**Risk:** a single coordinator's context over ~10 hours. Mitigation: the log
file is the durable memory; each cycle's working notes live in the file, not
in context; the morning report is compiled from the log.

"be world-class by morning," the correct response is instrumentation: a practice
curriculum, a scoring instrument applied every cycle, and a lesson log. Aspiration
without a loop is just pressure; a loop without scoring is just activity. The
Design Gym is both.
