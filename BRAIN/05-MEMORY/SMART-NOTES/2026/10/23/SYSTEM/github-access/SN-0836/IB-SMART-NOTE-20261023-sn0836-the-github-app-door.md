## WHAT IT ALL MEANS
A system that asks permission for ordinary work trains its people to click "allow" without thinking — the popup becomes noise, and noise is where real gates get waved through. Scoping authority into the tool itself (an app with exactly the permissions the work needs, keys revocable per machine) makes ordinary work silent and keeps the true gates loud. Friction is not safety; correctly-placed authority is.

## WHAT'S IN IT FOR YOU
