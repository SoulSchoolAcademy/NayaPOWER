t1421-lane4 (Naya Mason, 2026-10-23 07:41 PDT) built the first automatic principle-violation detector — hidden_files/bin/stall-cap-check.py — from the run's own bytes, for the STALL-RECEIPT CAP (standing rule since 2026-10-16: at most one gate-stall/seat-stall receipt per hour; a second inside the hour is a violation). The detector is read-only and reads content, not just names: it parses the timestamp from the filename AND from a "Written: YYYYMMDD-HHMM" line in the body's first 10 lines, flags any consecutive pair <60 minutes apart as CAP-VIOLATION, flags >5-minute content-vs-name disagreement as its own TIMESTAMP-DRIFT violation class, and exits 1 on any violation. It was proven on fixtures before the live run: the builder's planted pair (0700/0725) flagged exit 1, the boundary pair (1200/1300) stayed clean exit 0, and the second seat's own 12-file planted set flagged all 5 violations exit 1 (t1423, detector SHA pinned e6d7653f). The rule was standing but unwatched, and it silently degraded. The lesson: a standing rule with no watcher is prose.
