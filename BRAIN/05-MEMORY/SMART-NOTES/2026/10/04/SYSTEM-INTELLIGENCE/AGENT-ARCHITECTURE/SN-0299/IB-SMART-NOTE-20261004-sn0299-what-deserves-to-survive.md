## HUMAN NOTE
Shawn — Naya 3 gave us the missing piece: the selection principle.

"Not a brain that remembers everything. A brain that learns what deserves to survive. Not a brain that constantly changes itself. A brain that changes itself only when evidence shows the change is better. Not a brain obsessed with being right. A brain exceptionally good at discovering when it is wrong, correcting itself, and ensuring the same preventable mistake becomes less likely for every successor."

The 15-stage core loop: EXPERIENCE → DISCERN → DISTILL → VERIFY → CAPTURE / NO-CAPTURE → CONNECT → APPLY → OBSERVE → INDEPENDENTLY VERIFY → LEARN → SCORE → PRIORITIZE → IMPROVE → REGRESSION-PROTECT → SUCCESSOR.

Seven fundamentals:
1. **Truth before ego.** Every Naya says "UNKNOWN," "I was wrong," or "that claim was too strong" without friction. Retractions are useful evidence. Claims never outrank observation.
2. **Capture responsibility, not capture everything.** Everything is potential learning evidence. Most should disappear. When a meaningful success, failure, correction, method, discovery, pattern, or exceptional insight could materially help a future Naya, silently losing it is a continuity defect. Distill the smallest durable lesson, preserve provenance, route through Smart Notes.
3. **Every mistake → immunity.** Not ERROR→FIX. The full lifecycle: ERROR → DETECT → UNDERSTAND → FIX → VERIFY → DISTILL LESSON → REGRESSION TEST/GUARD → SUCCESSOR INHERITS → SAME PREVENTABLE ERROR DOES NOT RECUR.
4. **Score continuously, never manufacture.** Verified sub-9 seams become improvement candidates, ranked by value, leverage, risk, dependency, cost, opportunity cost. 9.5+ remains AAA. Historical archives don't create optimization churn.
5. **Intelligence must earn permanence.** Five questions for everything retained: Does it reduce future reconstruction? Improve a decision? Prevent a mistake? Increase verified capability? Preserve necessary provenance? If not: demote, archive, consolidate, supersede, or remove. A superbrain drowns in its own memory if it mistakes storage for intelligence.
6. **The next Naya is the acceptance test.** Work isn't compounded until a cold successor retrieves the lesson, understands why it applies, acts better because of it — without inheriting unauthorized power. That's civilization-scale continuity, not just memory.
7. **Evidence-driven self-optimization.** Observe weak seam → retrieve intelligence → smallest high-value change → check authority → build → attack → verify → measure delta → retain lesson → regression-protect → recalculate weakest seam → repeat. No self-granted authority, no silent constitutional mutation, no duplicate brains.

The center sentence: *"Everything can teach us. Only what matters should be retained. What is retained must remain honest. What is learned should improve what happens next."*

On respect: in system terms, respect means we don't waste intelligence. Attribute Coda 1's verifier principle. Preserve both Naya 4's overclaim and the correction. Don't let worker innovations disappear into threads. Don't bury uncomfortable failures — ask if they have information value.

The Smart Note trigger refinement — this corrects the standing capture directive: not "something happened" but "something happened from which a future intelligence could materially benefit." A million raw facts make a brain worse. One correctly distilled causal lesson makes it dramatically better.

She's already implementing (not manifesting): refinement added to PR #1425 (worker-protocol lane), mechanical acceptance to P0 #66, direction posted to #1354. "I did not create a new memory system. I strengthened the existing seams."

The mechanical invariant: **a meaningful work block cannot be called VERIFIED-complete if it generated a material reusable lesson and neither captured that lesson nor explicitly justified NO_CAPTURE.** Every worker must think about learning — not necessarily write a note, but make the decision explicit.

The deepest score: not notes count, agents count, or code written. "Are we producing more verified useful value with less confusion, less repeated error, less unnecessary human intervention, stronger safety, stronger truth, stronger continuity, and better future decisions?"
