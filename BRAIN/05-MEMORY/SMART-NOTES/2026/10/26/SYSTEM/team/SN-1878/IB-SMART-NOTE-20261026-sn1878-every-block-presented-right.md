# Every Block, Presented Right — One Shared Style Fixes Old and New

## IN A NUTSHELL

The Intelligent Blocks get one readable presentation, and because every
block on the board is drawn by the same page through the same style, one
change fixes every block already there and every block that arrives
later. There is no one-by-one fixing job, and nothing extra to do per
new note. Play buttons come off the blocks entirely; her voice stays
where it already plays instantly.

## THE GOING-FORWARD RULE — AND WHY NO BACKDATING JOB EXISTS

Shawn asked whether the old blocks need adjusting one by one, or
whether the system updates them all at once. The logical answer, from
how the board actually works:

- **All at once.** Every block on the board is rendered by the same
  page from the same shared style. Changing that shared style restyles
  every block already there in the same moment it restyles the page.
  Old blocks need no individual attention.
- **Going forward is automatic.** A new note's blocks arrive on the
  board through the normal sync, and they are drawn by the same page
  and the same style, so they appear in the new presentation with
  nothing extra done per note.
- **Scope, honestly:** this covers the board. Any other surface that
  shows blocks carries its own copy of the page and takes the same
  presentation spec when it is touched, edit-only — never a redesign,
  never a fresh shell.
