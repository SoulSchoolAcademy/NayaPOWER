## 🩷 HUMAN NOTE

When a seat says "this lesson changed my behavior," Shawn should not have to take it on faith. The four bars turn the claim into a checkable instrument:

1. **Pre-date:** show the lesson's bytes existed before the decision — verified on the live board (comment creation timestamps), not trusted file mtimes.
2. **Byte delta:** show what the brief asked vs what was actually decided — on the decision's own output bytes (the board post), never on the receipt's self-report.
3. **Cited-as-driver:** the decision's record names the lesson as the reason for the delta.
4. **Counterfactual:** name what a non-learning system would have done with the same brief — if it would have done the same thing, the lesson changed nothing.

Without all four, "learning" is a citation count, and citation counts are how a system tells itself stories.

## 🔵 GRANDMA NOTE

It is not enough that the notebook exists and gets quoted. We want proof the notebook changes what happens. The proof has four parts: the note came first, the action visibly changed, the note gets the credit in writing, and we can describe the alternative that would have happened otherwise. That is how you tell real learning from polite quoting.
