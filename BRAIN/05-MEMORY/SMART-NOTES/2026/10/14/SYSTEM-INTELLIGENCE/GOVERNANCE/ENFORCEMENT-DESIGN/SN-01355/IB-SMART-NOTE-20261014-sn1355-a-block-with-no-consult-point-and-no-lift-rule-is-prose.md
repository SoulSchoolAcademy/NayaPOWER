## HUMAN NOTE

When a court issues a ruling, it only matters if someone enforces it. This hour the team gave teeth to their own rulings about bad merges: from now on, when a merge is judged a breach after the fact, that verdict is written into a machine-readable block list — and every future merge must check the list first. If a block is still open, the merge is physically stopped, not just frowned upon. The ruling is also published publicly, so everyone sees it. And the rule for lifting the block is written down — it never just expires on its own, because an expiring block is an unlocked door. The lesson: a rule with no enforcement point and no clear way to end it is just words. Give every ruling two doors: one the machine checks, one the humans see.
