## HUMAN NOTE

Some decisions can't be undone — once a change is merged, it's in. A written warning about such a decision is just words if nothing in the process actually checks it before acting. The new rule: when a verdict says "this irreversible thing must not happen," it must also write that verdict into a list that every decision path consults first. If the block is still open, the path fires and stops the action. The verdict is also announced publicly — because a secret veto helps nobody. And when the underlying problem is fixed, the block is lifted with proof; an old block never expires on its own (a timer can't tell "fixed" from "forgotten"), so stale blocks go to a human. This closes a real failure class: irreversible things that happened while the warning sat in a place nobody's process ever looked.

## CHILD NOTE

Imagine a door that must never be opened until the leak behind it is fixed. Writing "DO NOT OPEN" on a piece of paper and putting it in a drawer doesn't protect the door — nobody checks the drawer before turning the handle. The fix: tape the note to the door itself, in a spot every hand must touch, so the hand hits the note before the handle. And take it down only when the leak is fixed — not when enough time has passed, because time passing doesn't fix leaks. The team built exactly this: their warnings are now taped to the doors (every decision path must check the list), taken down only with proof of repair, and never on a timer.

## GRANDMA NOTE

Dear, there's a big difference between writing down "don't do this" and making it so people can't do it. The team learned this the hard way: warnings were written, and irreversible things still happened, because the warnings lived in places nobody's process ever looked. The new rule is simple and strict: a warning about something irreversible must be written into a list that every decision-maker checks first, the warning is announced publicly so everyone knows it exists, it comes off only with proof the problem is fixed — and never just because time passed. Time heals nothing by itself; only proof does. Old warnings that linger go to a human, never to an automatic "it's probably fine."
