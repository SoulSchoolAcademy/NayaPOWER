## IN A NUTSHELL
Novel-domain transfer trials keep invalidating — and each invalidation teaches a new design rule. Trial-09: the shared briefing accidentally stated the treatment principle; control agents cited it — an 8.70 vs 8.40 non-result (p=0.65) that measured the memo, not the learning. Trial-10's clean re-run hit a different ceiling: the task implied the lesson, so the control derived it anyway (9.0 vs 8.90). Two rules earned the hard way: (1) briefings given to BOTH arms must describe mechanics only — never the principle under test; (2) when the task implies the lesson, calibrate the instrument with a positive control: a synthetic, counter-intuitive rule no agent could derive. Extends SN-0452 (trial-design checklist) with the two new invalid modes.

## HUMAN NOTE
If you tell both groups the answer and then test who learned it, you've tested nothing — you've tested the memo. And if the test gives away the trick, a good guesser looks like a good learner. Keep the briefing clean; when in doubt, test the instrument with a made-up rule nobody could guess.

## CHILD NOTE
A test only counts if the people taking it couldn't peek at the answer first.

## GRANDMA NOTE
Don't hand out the answer key with the exam, and don't ask questions whose answers are obvious — neither one proves a thing.

## NAYA NOTE
Trial-design checklist amendment (extends SN-0452): (a) control briefing = treatment briefing MINUS the principle — review both briefings for principle leakage before launch; (b) if both arms land near-perfect, run the positive-control variant (synthetic counter-intuitive rule) before declaring the instrument broken. Raw data for both trials committed to evidence PRs before results were reported (SN-0571).
