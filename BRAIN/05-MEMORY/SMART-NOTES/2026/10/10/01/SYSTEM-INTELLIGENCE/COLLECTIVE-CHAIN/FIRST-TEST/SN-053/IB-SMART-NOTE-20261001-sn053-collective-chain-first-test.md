**The formal name (Shawn's definition):** *NayaNET Collective Intelligence Chain* — a governed intelligence architecture in which provenance-bound Intelligent Blocks are validated, connected, reconciled, integrated into current intelligence, checkpointed, retrieved according to context and applicability, and continuously improved through verified outcomes so intelligence compounds across people, projects, time, and Naya instances.

**The fixed vocabulary:**
- **Intelligent Block** — the fundamental unit.
- **Collective Chain Technology** — the connective / accountability mechanism.
- **Smart Ledger** — the accountability layer.
- **Core Intelligence** — the integrated current understanding (assembled continuously from the blocks; never one physical central block — that would bottleneck).
- **Cognitive Checkpoint** — the synchronization state.
- **Progressive Intelligence Lock-In** — the living process.

**The UX standard:** DISTILL → CLARIFY → ORGANIZE → PRESENT → EXPERIENCE → LEARN.
Less noise, less friction, less unnecessary data, less cognitive load → more understanding, relevance, meaning, learning, wisdom, value. Simple does not mean basic: extraordinarily simple for the human, extremely sophisticated underneath. That is what a Superbrain does.

**The creative-judgment rule (replaces "the implementation has this, therefore preserve it"):**
1. *Why is this here?* — every visible element must have a clear human purpose, a clear relationship to intelligence, and a measurable reason to exist. If unanswerable, it doesn't automatically get to stay.
2. *Is there a simpler, clearer, more valuable way to accomplish the same thing?* — if yes, do that instead.

**The restore rule (replaces "always read everything"):** every Naya must RESTORE current state → WHAT CHANGED? → WHAT IS NEW? → WHAT IS RELEVANT NOW? → WHAT CONFLICTS? → WHAT APPLIES? → ACT. Never endlessly reread old blocks; know what you know, what changed, what matters, when deeper retrieval is necessary.

**The compounding test (unchanged, now operationalized):** a future task became measurably better because a previous block was correctly retrieved and used. Storage ≠ intelligence. If Shawn teaches Naya something once and it cannot travel block → validate → connect → integrate → checkpoint → cold retrieve → applicability → act → verify → improve, we have storage, not intelligence.

**The marketing truth:** not "NayaPOWER produces better AI outputs" but "NayaPOWER eliminates the hidden waste of AI that forgets, retries, regresses, loses context, lacks authority boundaries, fails to verify, and fails to convert experience into reusable intelligence — optimizing for maximum responsible verified human value per action, compounding what it learns."
