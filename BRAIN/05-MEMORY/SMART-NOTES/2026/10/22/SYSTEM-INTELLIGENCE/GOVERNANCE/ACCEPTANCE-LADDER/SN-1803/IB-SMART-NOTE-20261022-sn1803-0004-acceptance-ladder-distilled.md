# Smart Note: The Acceptance Ladder — report only the rung you proved

## ✦ IN A NUTSHELL

A system is not alive because it exists. It is alive when each level of proof is evidenced, rung by rung: EXISTS → LOADS → INVOKES → INFLUENCES → APPLIES → OUTCOME → VERIFIES → LEARNS → COMPOUNDS → SUCCEEDS → EVOLVES. Report only the highest rung actually evidenced — never the rung you wish you were on. BLOCKED is not PASS. Implemented is not VERIFIED. Verified is not PRODUCTION-PROVEN.

## 🩷 HUMAN NOTE

Imagine someone says their new assistant "works." What does that mean? That it exists? That it turned on? That it actually changed a decision for the better — and that you can prove it? This ladder is an 11-step honesty test. Each step demands real evidence before you claim it. Most things people call "working" never get past step 2 or 3. The rule is simple: you may only claim the highest step you can prove, and proving means showing the evidence, not describing it.

## 🟣 CHILD NOTE

Saying "I can ride a bike" is different from riding it. This is a list of 11 steps from "the bike exists" all the way to "you taught someone else to ride." You only get to say the step you actually did — with proof.

## 🟠 GRANDMA NOTE

It's a checklist that keeps everyone honest, dear. Nobody gets to say "all done" until each step is truly finished and shown — not just talked about.

## 📚 LEARNING LESSON

A claim without its rung is a wish. Every status report, every "done," every score must name the highest evidenced rung — and the evidence that puts it there. | changes: status claims carry their rung + evidence pointer, or they are not claims | applies_when: any completion/verification/status claim, any area | enforcement: the fold gate (fold_wave_check.py) and the merge gate (five conditions) — a rung-less claim fails the receipt.

## 🧭 WHAT IT MEANS

This is the ancestor of the team's verification ladder (announced ≠ implemented ≠ verified ≠ sustained). It makes "done" falsifiable: if you cannot name the rung and show the evidence, you are not done. It kills the most expensive lie in the system — the premature PASS.

## 🛠 HOW TO APPLY IT

(1) Before reporting any work complete, walk the ladder and name your rung. (2) Attach the evidence for that rung — the trace, the outcome, the verification artifact. (3) If the evidence only reaches A5, report A5, not A7. (4) Run the negative tests for your claim; a claim that cannot fail closed is not a claim.

## 🎁 WHAT'S IN IT FOR YOU

You stop arguing about whether something "works" — the ladder settles it in one look. And you stop paying for work that was reported done but wasn't: every premature PASS is rework with interest.
