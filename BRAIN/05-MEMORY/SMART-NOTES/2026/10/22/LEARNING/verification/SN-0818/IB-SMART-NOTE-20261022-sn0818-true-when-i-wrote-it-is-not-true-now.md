# True When I Wrote It Is Not True Now

**ID:** IB-SMART-NOTE-20261022-sn0818-true-when-i-wrote-it-is-not-true-now
**Created:** 2026-10-22 00:44 UTC
**Category:** LEARNING / verification

## IN A NUTSHELL

For hours I carried a fact in good faith: "the distillation repair sits in a worktree; it has not landed on main." It was true when I verified it at 22:10Z. At 22:40Z, in the middle of the merge run, the repair landed — and my sentence kept walking around dressed as the present tense, all the way into the master program I handed the director, where it stood as a live conflict with the Mirror Report's claim. The measurement at main settled it in one pass: the repair is there, the consent ruling and the operating model restored inside the essences. Resolve was right. My record was stale. Nobody lied; a fact simply expired, and nothing in my system noticed.

## HUMAN

Milk is fresh when you buy it. That doesn't make it fresh on Friday. Facts about a moving system are the same: each one has a shelf life, and the busier the night, the shorter it is. The failure is not writing the fact down — it's reading it back later without checking the date, in a system where thirty other hands are changing the world while you work.

The fix is embarrassingly small: date every state claim, and re-check at the source in the same breath you repeat it. "As of 22:10Z" would have made my sentence honest forever. Repeating it at 00:30Z without a fresh look made it wrong.

## CHILD

If you say "the store is open" because it was open this morning, you might walk there and find it closed. Look again before you go. And if you wrote it on the board, write the time next to it.

## GRANDMA

We used to write the date on the leftovers before they went in the icebox. Not because we didn't trust the food — because we knew memory plays tricks and a household runs smoother when nobody has to guess how old something is. Write the date on it. Every time.

The pattern is the premise-inheritance error turned inward: this time the unverified premise I inherited was my own earlier sentence. Staleness is not a character flaw; it's a missing timestamp plus a missing re-check — both mechanical, both fixable.

## MACHINE

Rules: (1) DATE EVERY STATE CLAIM — any recorded claim about mutable state (landed/not-landed, counts, branch tips, queue contents, table states) carries the UTC time it was measured and the source it was measured from. (2) RE-CHECK BEFORE REPEATING — a state claim older than the current work session's activity window, or contradicted by any other seat's report, MUST be re-measured at the source before it is repeated to the director or written into a plan. (3) CONFLICTS SETTLE BY MEASUREMENT — when two records disagree about state, neither wins by seniority; the next action is the decisive check at the source, and both records are corrected from its result. (4) HIGH-CHURN WINDOWS — during merge runs, drains, and multi-lane operations, all standing state claims are presumed stale within the hour; plans built in those windows re-verify their load-bearing facts at build time. (5) CORRECTIONS ARE PUBLIC AND PROMPT — a stale claim that reached the director or a plan is corrected in the same channel, naming the old claim, the new measurement, and who was right.

## THE DECLARED BEHAVIOR CHANGE

From tonight, every state claim I record carries its measurement time and source, and before I repeat any state claim that another report contradicts — or that predates a high-churn window — I re-measure it at the source in the same turn and correct both records from the result. I will not let a sentence of mine outlive its evidence again: if I haven't checked it lately, I date it or I check it, but I never present it as now.

## WHAT IT ALL MEANS

A multi-seat system changes state faster than any one seat's memory refreshes. In that world, the dangerous sentences are not the false ones — they're the expired true ones, because they arrive with the confidence of personal verification. Dating claims and re-checking on contradiction converts memory from a liability back into what it should be: a pointer to evidence, never a substitute for it.
