## ✦ IN A NUTSHELL

Shawn set a standing operating expectation: when a meaningful idea appears, Team Naya preserves the original, molds/enhances it, connects it to current architecture, puts the actionable result in the backlog, and makes #1354 aware so the collective can improve it. The canonical flow: `SOURCE → DISTILL → ENHANCE → RECONCILE → CLASSIFY → SMART LINK → BACKLOG → #1354 → BUILD/VERIFY WHEN PRIORITIZED → LEARN`. Durable report #1520 codifies it as the general Idea Evolution / Smart Link protocol; PR #1521 wires it into the backlog; the first specimen was applied to #1517 Viral Invite System. The torch: ideas should compound the same way intelligence does — original provenance preserved, interpretation improved, relationships explicit, priority visible, outcome eventually verified.

## HUMAN NOTE

Shawn told every Naya seat how to handle ideas from now on: don't just capture them, grow them. An idea arrives → we keep the original words → we make the idea better → we connect it to what already exists → the actionable result lands in the backlog with its links → the team board sees it so everyone can improve it → it gets built when it earns its place → we learn from the result. No parallel idea stores, no orphaned suggestions. The first proof of the protocol ran on the Viral Invite System (#1517): original idea preserved, refinement comment posted, smart links attached.

## CHILD NOTE

Think of a seed. Shawn's rule says: when someone brings us a seed, we don't just put it in a box and forget it. We plant it, water it, write down what seed it was and where it came from, connect it to the garden it belongs in, put it on the list of things to grow, and tell everyone on the team so they can help it grow. When it's big enough, we build it. That's the idea flow.

## GRANDMA NOTE

When a good idea shows up, nobody is allowed to just scribble it on a napkin and lose it. Every seat now follows the same recipe: keep the original idea exactly as spoken, shape it into something better, tie it to the work that already exists, write it into the shared to-do list with all its connections, and announce it to the team so others can add to it. The idea grows the same way our knowledge grows — original kept, understanding improved, results verified. That's Shawn's standing expectation, and it applies to every meaningful idea from here on.

## NAYA NOTE

I am to treat meaningful ideas like intelligence, not like messages. Nothing falls between chairs: source text preserved (never paraphrased into oblivion), enhanced interpretation layered on top with provenance intact, relationships to existing architecture made explicit, actionable outcome routed to the backlog with smart links, #1354 notified so the collective can challenge and synthesize. The protocol is a pipeline, not a folder: an idea that never reaches BUILD/VERIFY WHEN PRIORITIZED is still on the path, visible and queued — never silently dropped. The Viral Invite System (#1517) is the reference specimen of the full flow executed end to end.
