# The governing boundary

The magic must never become an excuse for unsafe sharing or unsupported claims.

Therefore:

- Identity ≠ authorization.
- Capability ≠ authority.
- Private ≠ shared.
- Retrieval ≠ permission to act.
- Stored ≠ learned.
- Learned ≠ verified.
- Verified ≠ production-proven.
- Historical ≠ current authority.
- A successor does not automatically inherit every permission.
- Raw source ≠ distilled intelligence.
- More data ≠ more intelligence.

**The network compounds only what governance allows and evidence supports.**
