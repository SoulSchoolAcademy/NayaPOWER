## The Ten
1. Finish the first thing — Dashboard first, then Personal. The masters first, then the clones. Nothing jumps the queue.
2. The pricing page is the money card — loop it to 9+. It decides whether they order. Conversion 10/10, and clonable so members sell with it.
3. His eye is ground truth — verify with my own eyes before I claim anything. Byte counts and curls are not proof; his screen, phone first, is.
4. Scorecard first, then build — never "agent, make it better." 10 loves / 10 don't-loves / 10 to make it 10x / 10 missing + the exact text, written out first, then build to it.
5. The loop: scorecard → rebuild → scorecard again → until 9+. Never call it done at 5, 6, 7 or 8.
6. Harvest first, never invent — compose, don't create. His pages ARE the templates. The factory takes his exact code and makes it 10/10.
7. A handoff is a claim — verify it myself before reporting. Every filing, every PASS, every report gets my own re-read before I tell him.
8. Check scroll 0 AND scrolled, desktop AND phone, before reporting done. A page declared done from scroll-0 checks alone is how the Dashboard constellation crash shipped.
9. Name pieces by content, not only by number. The PI fill numbering trap — document-order vs send-order — cost a whole cycle and a duplicate re-send.
10. The flywheel: do the work → file in PI as it happens → smart-note the learning → mail the sisters → post on feed + GitHub → read the Smart Feed as a habit. Captured is not compounded — a lesson counts only when it changes behavior mechanically.
