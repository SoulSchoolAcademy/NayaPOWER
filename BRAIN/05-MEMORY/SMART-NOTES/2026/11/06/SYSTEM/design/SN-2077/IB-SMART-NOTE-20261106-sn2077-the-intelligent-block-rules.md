## MACHINE

The draft is a harvest: 11 shared laws, 5 tested denominators, 6 object classes, 13 block sections, 10 conflicts, 11 gaps. Sources: Anatomy, Real Object Law, Playbook, Design Laws, Naya Protocol, Hub code (HUB/app/index.html v4), essence notes.

THE ELEVEN LAWS (one set, running through every object): L1 Every element is a real physical object (touchable, or it does not ship). L2 One light source, top-left, always. L3 Real shadows and real elevation — depth is mass, not glow. L4 Own-color light — color is identity, ignites on touch. L5 White text, never colored, never gray — text never lights up. L6 Touch is physical — it moves, yields, opens. L7 The spectrum is the order things sit in. L8 Every position is calculated by formula — never eyeballed. L9 Movement means the machine is working — slow, and it means something. L10 One language — every component is family. L11 Shawn's eye wins — his verdict is the final compile.

THE FIVE DENOMINATORS (Shawn's test: an orb IS an icon IS an element): D1 Real round object that lifts and catches the one light — PARTIAL (object-ness holds; roundness does not — boards are rectangles, buttons are pills, only icons are circles). D2 Color IS identity — SUPPORTED. D3 Light is life — SUPPORTED (rest is black face plus white edge plus glowing jewel). D4 Everything is a door — PARTIAL (law for numbers; behavior for orbs and icons, not stated as law). D5 The spectrum is the order they sit in — SUPPORTED.

THE SIX OBJECT CLASSES: Buttons (Obsidian Pill, BUILT); Boards (Obsidian Board, BUILT); Icons (Jewel Orb, BUILT); Inputs (Well, BUILT); Gauges and charts (Orbit Dial and Living Line, BUILT); Smart apps, pages, sections (one app, many doors).

THE THIRTEEN BLOCK SECTIONS: the board itself; title and quote area; date and meta line; IN A NUTSHELL; HUMAN NOTE; CHILD NOTE; GRANDMA NOTE; NAYA NOTE; WHAT IT MEANS; the layer board; the icon (jewel); the play button (voice — present in code, forbidden by law); the provenance foot.

C6 The v4 overrides vs the base rules (the flat-black defect). C7 Chevron (styled vs hidden). C8 Inner-board depth (principle vs code). C9 Voice (code vs law). C10 Nutshell label (two styles).

THE ELEVEN GAPS (no source defines this): G1 Shawn's vocabulary (elevators, enhancers, pinnacle points). G2 How a board's tone is assigned. G3 The date line's exact composition.
