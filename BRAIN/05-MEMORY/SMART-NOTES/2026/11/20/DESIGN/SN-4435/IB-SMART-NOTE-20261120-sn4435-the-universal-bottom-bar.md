## The Lesson

His design, settled on call b9431e3a: the Dashboard bottom icon bar — ADD · PERSONAL · BUSINESS · WORLDS · ECOSYSTEM · CONNECT, with the plus button — becomes universal on Hub, Personal, and Dashboard alike. Network notifications show there — when anything happens in the network, it shows on that bar.

This is the alignment law applied to navigation. The pages already drifted: the Hub had its own arrangements, the Dashboard its pill cluster (already ordered out), Personal its own set. A citizen moving between worlds should never have to relearn where things are — the bar is the same set, in the same order, on every page, so the hand knows where to go before the eye has to look. And the bar is not just navigation: it is where the network speaks. A notification that lives only inside one world is a notification the citizen misses; on the universal bar, anything happening in the network shows up wherever they are.

## Why It Matters

One set of icons, the same on every page — that is the rule he has given on every page walk, and the bottom bar is where it pays off most. The bar is the citizen's home row: ADD to make, PERSONAL / BUSINESS / WORLDS to go, ECOSYSTEM and CONNECT to reach out. If it changes per page, the citizen has to think before every tap; if it never changes, the tap is thoughtless, and thoughtless is push-button simple. The notification half matters just as much: the bar is the one place that is always on screen, so it is the one place a network event can always be seen.

## How to Use It

Take the Dashboard bottom bar as the canonical set — ADD · PERSONAL · BUSINESS · WORLDS · ECOSYSTEM · CONNECT, plus button included — and carry it byte for byte to Hub and Personal. No page gets its own version, its own order, or its own extra icon. Network notifications render on the bar itself, not buried in a single world's inbox. A page walk checks the bar first: same set, same order, same destinations, on every page.
