The rhythm was right and the object was wrong, because the object was drawn fresh instead of taken. That is the whole lesson, and it is the harvest-first law with the concrete source named: the structure is already built, in the calendar's code. Take the frame. Reformat only the middle. Change the bar a little. The middle is the only thing that changes — the slides, their images, their words — because the middle is the only thing that is new. Everything else already exists, and rebuilding it is how a lookalike is born: close enough to pass a brief, wrong enough for his eye to send it back.

"Like I keep telling you" is the sting in the correction, and it is the part to hear. He has said harvest-first before — take the code byte for byte, compose never create, use the parts already on the page — and the rebuild still came back recreated. A lesson counts only when it changes behavior mechanically, so the compound runs with this note: the inventory carries the rule, the brief template carries it into the next brief, and the next builder gets the calendar's code as the starting point, not a description of the calendar's frame.

## Why It Matters

The frame is the point of the fix. The agreement's storybook only feels like the calendar if it IS the calendar's frame — the real ornate silver, the crest set into the rails — not a drawing of it. A lookalike frame breaks the spell the whole presentation depends on: the person is meant to feel they are inside the same world as the calendar, not looking at a picture of it. And the cost of recreating is paid twice: once in the build that comes back wrong, and once in the round that has to be sent back and done again. Locking in the structure pays it zero times — the frame is taken, the middle is reformatted, the bar is changed a little, and the round lands.

## How to Use It

Rebuild the storybook inside the calendar's own code: pull the calendar's HTML, keep the same frame and the same everything, reformat only the middle area for the slides, change the bar a little for the agreement's headliner. Never recreate the frame from scratch. The same rule governs every rebuild after this one: the structure is locked, the source is named, the middle is the only thing that changes. When a brief asks for a rebuild, it names the source file to harvest from — a brief that does not name it is incomplete.
