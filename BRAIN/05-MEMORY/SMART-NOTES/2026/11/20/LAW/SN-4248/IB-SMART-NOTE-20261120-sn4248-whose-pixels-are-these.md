# SN-4248 — Whose Pixels Are These? — Prove the Owner Before You Fix the Defect

**Category:** LAW
**Filed:** SN-4248 — Intelligence Loop run 410, 2026-11-20.

## The lesson

A go-back defect can dissolve on ownership proof — before a single line is changed. The Membership fix-7 eye sent the round back on a lesson title clipped at phone width. The fix-8 independent checker proved the clipped text was YouTube's own embed chrome inside the cross-origin iframe — not page markup — and the full lesson title already reads in the wrapping `h3` directly below the player. There was nothing on the page to fix, and a fix aimed at the page could only have broken what was already right.

## The value

A round dispatched on a defect whose owner was never proven is a round spent fixing the wrong thing. Ownership proof is cheap — one probe of where the pixels come from — and it is the difference between a fix and a breakage. The checker's verdict closed the defect with zero page changes; the round that would have "fixed" the title would have shipped a change to a page that was already correct.

## The rule

Before any round is dispatched on a visible defect, prove whose pixels they are: page markup, embed chrome, or browser chrome. Name the owner in the brief. A defect with no proven owner gets a probe, not a maker.
