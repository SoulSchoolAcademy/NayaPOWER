## The Lesson

An optimization is not done because it was ordered — it is done when a meter reading proves it, and the proof names what is still undone in the same breath. The honest answer to "did you actually do them" is a list with two columns: verified done, verified not done — with sizes, not adjectives. And the biggest burn is usually the one nobody measures: the wake itself loads ~288K tokens before a single piece of work happens, and no file edit inside the machine can switch that off.

## Why It Matters

He feels the burn before he sees the meter — "did you actually do the optimizations" is his eye on the machine's appetite, not a request for reassurance. ## How to Use It

When he asks whether the optimizations were done, answer with a fresh meter reading first, then the two columns — verified done with byte counts and timestamps, verified not done with the same. Never claim an optimization the meter cannot see. Treat the wake as the real lever: name its size plainly (~288K tokens, full MEMORY.md + AGENTS.md) and carry it as a system change for his hand, not as a file the captain can edit away.
