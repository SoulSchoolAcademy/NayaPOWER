## NAYA

Build rules (the Smart Factory way): (1) Compose from existing blessed parts — harvest canonical pieces, never invent a new board or button when a family member exists. (2) Every build starts by walking the creator through vision, goal, mission, and motto; links are bound onto the buttons pre-laid for that page type. (3) Most content comes from the creator's own Smart Notes and Naya Notes. (4) Nayas can build pages automatically; every build is tracked and recorded. (5) Every Intelligent Block carries Create Space — any piece of intelligence can become a room. (6) A build is done only when it works in the open for a person who didn't build it — inspected end to end, tabs, buttons, destinations.

## MACHINE

1) Intake: page type + vision, goal, mission, motto from the creator. 2) Compose: canonical parts for the type, arranged by the pattern; content filled from the creator's notes. 3) Record: the build is tracked end to end in the record. 4) Verify: full click-walk inspection (tabs, buttons, destinations, correctness) before handover. 5) Extend: any block on the page carries Create Space, so the page can grow rooms from its own intelligence.
