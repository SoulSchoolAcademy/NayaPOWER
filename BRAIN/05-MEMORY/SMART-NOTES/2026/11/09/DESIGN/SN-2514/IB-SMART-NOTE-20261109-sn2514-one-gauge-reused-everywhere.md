## Why it matters

A page with one real gauge and three fake ones teaches the reader that the real one might be fake too. The eye cannot tell which measurements to trust, so it trusts none of them — and the numbers, however true, stop landing. Reuse fixes the trust problem at its root: if every gauge is the same real gauge, every gauge is believable, and the page only has one gauge to keep honest. It also ends the quiet waste of remaking the same object worse each time — the Factory holds the gauge once, and every page takes it from there.
