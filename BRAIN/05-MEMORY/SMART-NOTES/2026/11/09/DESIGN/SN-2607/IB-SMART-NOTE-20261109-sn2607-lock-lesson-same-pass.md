## What changes now

1. **A lesson counts only when it changes behavior mechanically — lock it in the same pass, or the next seat repeats it.** Every future lesson goes through the same pass the same night: note + mail + PI + GitHub, then template + gate via the lock-in path — and the pass is not finished until the test "would this have stopped the next seat?" answers yes.
2. Every brief carries the nine steps as its spine (template §2A + the gate's checks); the brief checker fails any brief that skips done-first, harvest sources, the laws, or the anti-repeat list (SN-2463, SN-2464).
3. The gate runs on every artifact before presentation: machine clean AND human checks H1–H5 attested with evidence, or the handoff does not go out (SN-2466).
4. The daily scorecard starts: verified valuable actions, time from his word to live proof, defects caught by me/the machine versus by his eye, rework rate, lanes sitting and for how long (SN-2466, SN-2469).
5. Dashboard fix-9 is the next page to climb, built from this recipe, judged against the ten-star checklist and the ten differences, viewpoint by viewpoint, live with him (SN-2460, SN-2467).
