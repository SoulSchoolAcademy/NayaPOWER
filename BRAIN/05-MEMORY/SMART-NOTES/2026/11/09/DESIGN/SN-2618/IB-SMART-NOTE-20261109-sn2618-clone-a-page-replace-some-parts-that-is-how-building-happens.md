## Why it matters

1. A Factory nobody has built from is a shelf. The proof Naya is the difference between "the files exist" and "the system works" — the same difference as the saved-game test, which is why both proofs are defined the same way: a cold agent, the artifact alone, a live result.
2. Clone-replace-move is the only building method that compounds: every finished page becomes a template, every part becomes reusable, and the set of things still to be created shrinks instead of growing. Building from scratch every time is how the work never ends.
3. The box as the source is the moment the box stops being a copy of the system and becomes the system's memory — and the completeness gate is what makes that safe. An incomplete memory that pretends to be complete is worse than no memory at all.
4. The universal app is the end of the page sprawl: one app, one label, membership as a feature. Every seat that builds Membership as a separate page is building against the settled picture — and the settled picture is what keeps the system one system instead of twelve.
