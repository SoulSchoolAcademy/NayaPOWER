And his rules for it, because a picture alone is not a spec: "make sure that you have the gauge matching what the stats that are there and you should be able to see the numbers and it should be dynamic and work to be relevant and real looking." Four rules, each one a test. The gauge must MATCH the stats on that board — its needle and labels read the board's own numbers: clicks, views, click-through rate, revenue — scaled to that stat, never a copied $4,500 pasted onto a board whose numbers are different. The numbers must be VISIBLE — digit tiles under the gauge, readable at a glance, not tiny grey dials you have to squint at. It must be DYNAMIC — the gauge follows the number; when the number moves, the needle moves; it works. And it must look RELEVANT and REAL — a working instrument for that stat, not decoration. A gauge that reads the wrong numbers is a lie; a gauge you cannot read is a picture; a gauge that never moves is dead. He showed the object so the argument ends: here it is, take it, put it there.
