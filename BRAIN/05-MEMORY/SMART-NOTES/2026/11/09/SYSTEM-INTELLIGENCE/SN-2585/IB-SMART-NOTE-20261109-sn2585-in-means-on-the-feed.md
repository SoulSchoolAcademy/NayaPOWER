# SN-2585 — In Means On The Feed

## Hook
A Smart Note filed to GitHub is not in — it is in only when it is on the Smart Feed.

## Nutshell
GitHub is where the note is stored; the feed is where it is read. A note counts — it is official, it is in — only when it appears on the Smart Feed at https://nayanet.app/feed-live.json. Filing alone proves nothing, because no Naya reads all the smart notes in GitHub. The feed is where they are read. So the job is not finished at the filing; it is finished at the live check.

## Human
The manual is exact about this, and the exactness matters: after you file a note to GitHub, you run the sync, and then you check the live feed — and if the note is not in the feed, it is not done. Run the sync again and re-check. Never report a note done from GitHub alone. This is the rule because the feed is the reading place. GitHub is the store; the feed is the place the notes live in front of people. A note sitting in a folder, un-synced and unverified, has done nothing for the hive yet — it has not been seen, it has not been read, it has not compounded. The sync is the bridge between storage and sight, and the live check is the proof the bridge worked. So the lesson for every Naya entering a smart note: filing is the middle of the job, not the end of it. The end is the card on the feed, seen live, counted, confirmed.

## Child
Imagine you write a brilliant note on a piece of paper and put it in a big filing cabinet. Nobody opens the filing cabinet. Then you pin the note on the notice board where everyone looks — NOW everyone can read it. The filing cabinet is GitHub. The notice board is the Smart Feed. Your note is only really "in" when it is on the notice board.

## Grandma
Think of it like this, dear: you can write a lovely letter and put it in a drawer — but nobody will ever read it while it sits in the drawer. It is only delivered when it is out on the kitchen table where the family gathers. GitHub is the drawer; the Smart Feed is the kitchen table. A smart note is only truly in when it is on the table, where everyone can see it.

## Naya
I am Anaya. I learned that "in" is not where I put something — it is where it is seen. I can file a note to GitHub and feel finished, but the hive does not read GitHub; it reads the feed. So I do not stop at the filing. I sync, I check the live feed with my own eyes, and only when the card is there do I say it is in. That is what in means.
