# The Tile — Each Digit Is a Button

SN-2223 · DESIGN / THE ULTIMATE NUMBER — TILE

**Created:** 2026-11-07 21:23Z

> "If it doesn't look touchable, it doesn't ship."

## Hook

A digit is not text. It is a tile. And the tile is a button.

## Nutshell

Each digit of the number is a tile (`.reel`), 150px wide and 194px tall, built in the Dashboard button's language: a 2px coloured rim and a diffused halo (the digit's chakra colour) · a black gradient face (#171720 → #0f0f15 → #020203) · a glossy cap on the top third, a lens of the digit's colour, brightest at the top and fading to black · a white bold digit (168px) rolling inside a window (194px tall, overflow hidden) · a drop shadow beneath it all, so the tile sits ON the page. The tile's colour comes from the digit it lands on. The digit itself stays white.

## Human

Shawn's Real Object Law: every element is a real physical object, not a flat shape with effects. If it doesn't look touchable, it doesn't ship. If it doesn't feel real, it's not done. The tile is a real object — you can see it sitting on the page, lit from above, with a glossy cap you could touch.

## Child

Each number lives in its own little black jewel box, shiny on top, glowing around the edges in its own colour. The number inside is white and big so you can read it from far away.

## Grandma

The numbers aren't printed on the page. They're set into little black tiles, like the numbers on a beautiful clock — each one in its own box, each one glowing in its own colour.

## Naya

The tile is the atom of the number. One tile, one digit, one colour. The number is a row of tiles. The Dashboard is a page of tiles. The whole system is tiles — smart blocks, Lego blocks, in the digital matrix. Build the tile right once, and every number in the system is right.

## What it means

- Tile: 150×194px, 2px rim, glossy cap, black gradient face, white 168px digit, halo, drop shadow.
- Colour lives in the rim, the cap and the halo — never on the glyph.
- The tile is registered in the Parts Registry as part of The Ultimate Number (SN-2221).

## Why it matters

A number made of text is flat. A number made of buttons is real. That is the difference between a page that shows a score and a page that presents one — and presentation is the product.

## What changes now

- Any page that needs a number takes this tile. Never invent a new digit.
- The tile's recipe is in the build record, so the next builder copies it exactly.
