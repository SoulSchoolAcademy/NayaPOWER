# The Growth — The Number Grows With the Score

SN-2226 · DESIGN / THE ULTIMATE NUMBER — GROWTH

**Created:** 2026-11-07 21:23Z

> "The number grows with the score."

## Hook

The number is not fixed at three digits. It grows — a new tile slides in, and it counts up to the bigger number.

## Nutshell

The number is dynamic: it is built from the score, not fixed at three digits. `createReels(el, target)` builds one reel per digit of the target. `growAndReveal(el, fromVal, toVal)` grows it: it rebuilds every strip for the new target, slides a new tile in (`reelIn` keyframe), and counts up to the new value. 725 → 7,250 → 10,725. Thousands, ten-thousands, as far as it goes — the tiles just keep coming, each one flashing in its colour as the numbers flow through it. The gauge and the number move as one.

## Human

Shawn's direction: the number is dynamic. It is not a picture of a number — it is built from the score, live. When the score grows, the number grows with it, a new tile sliding in. That is what makes it alive instead of printed.

## Child

When your score gets bigger, a brand-new shiny box slides in next to the others, and the number counts up to the new big number. The boxes just keep coming as you grow.

## Grandma

The number isn't stuck at three digits. When the score grows, a new tile appears and the number grows with it — from hundreds to thousands to ten-thousands, as far as it goes.

## Naya

Growth is the number's proof that it is alive. A static number is a picture. A growing number is a machine — it reads the score, builds its tiles, and counts up. The reel that slides in is the moment the system shows you it is keeping up with you.

## What it means

- Built from the score: one reel per digit. Growth: rebuild the strips, slide a tile in, count up.
- 725 → 7,250 → 10,725, proven on a real screen (screen check #3, 21:00Z — five tiles, all digits showing, none blank).
- The gauge and the number move as one.

## Why it matters

A number that cannot grow is a number that will break the day the score passes it. A number that grows is a number that never breaks — it just gets more beautiful as it gets bigger.

## What changes now

- Every number in the system is built from its value, never fixed at a digit count.
- The growth sequence is the demo of the number's life — it is how the number shows it is alive.
