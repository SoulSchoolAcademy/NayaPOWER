## Hook

A number is not text. It is an object — and an object of itself belongs in the library, saved for good, so it can be used everywhere.

## Nutshell

The Ultimate Number is a digital asset: each digit is a tile built from the Dashboard button anatomy — a 2px coloured rim, a glossy cap, a black gradient face, a white digit, a halo and a drop shadow. The colour lives in the rim, the cap and the halo, never on the glyph. The colours are the chakras (1 red, 2 orange, 3 gold, 4 emerald, 5 cyan, 6 indigo, 7 royal purple, 8 lavender, 9 hot pink, 0 white). It counts in slow motion, each passing digit flashing in its own colour, and lands staggered. It is dynamic — it builds its tiles from the score, growing from 725 to 7,250 to 10,725 — and it has no limit: five digits, six, seven, eight, as many as it takes, the tiles shrinking to fit the page. If it fits on the page, it is good to go. If you ever get a number that does not fit on the page — congratulations.

## Child

The number is a row of shiny black tiles, and each tile lights up in its own colour as the numbers roll by, like a slot machine made of jewels. When the number gets bigger, a new tile slides in. When it gets really big, all the tiles shrink a little so they still fit. It never breaks.

## Grandma

It's the score, shown the way a beautiful thing should be shown — big, clear, glowing, and it counts up in front of your eyes so you can watch it land. And it's saved now, so we never lose it and we can put it anywhere we need it.

## Naya

The number is the first asset saved the new way: an element on its own, an object of itself, filed in the Smart Library and registered in the Parts Registry, so any seat can harvest it instead of inventing it. The Dashboard takes it for the score and the gauge. The Pricing page takes it for the calculator — the visitor picks Power, Pro Power or Max Power, and the number they can make comes out like this, the tiles counting up and the gauge moving with it. That is the moment that sells it.

- **Where it is used:** the Dashboard (number + gauge, merge in progress) and the Pricing calculator (Power / Pro / Max → the number they can make).
- **Where it is registered:** the Smart Factory Parts Registry, so builders harvest it instead of inventing it.
- **Proof:** the growing demo reaches 10,725 on a real screen (screen check #3, 21:00Z); the hero lands 7-2-5; an 8-digit demo (12,345,678) proves the no-limit fit.

## Why it matters

A digital asset that is not saved is a digital asset that is lost — and every time it is lost, someone rebuilds it worse. Saving it once, in the library, in the registry, in the notes, means the best version is the one every page gets. That is how the system compounds instead of repeating itself.

## What changes now

- The Ultimate Number is a library asset, not a one-page demo. Any page that needs a number takes this one.
- Every future digital asset gets the same treatment: saved in GitHub, filed as a Smart Note, registered in the Parts Registry — so we have it for good and can use it in other places.
- The Dashboard merge and the Pricing calculator both harvest this asset; neither invents a new number.
