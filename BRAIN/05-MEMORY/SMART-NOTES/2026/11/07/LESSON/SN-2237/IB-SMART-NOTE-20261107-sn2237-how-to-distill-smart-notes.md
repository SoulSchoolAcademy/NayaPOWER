# How to Put a Smart Note In — and How to Distill It

SN-2237 · LESSON / METHOD

**Created:** 2026-11-07 22:40Z

> "They don't know how to do it right. So you know how to do it right — explain to them how to do it right."

## Hook

A Smart Note is not a file. It is a piece of intelligence, filed so it can compound. If it is not filed right, it never compounds. If it is never distilled, it never becomes intelligence at all.

## Nutshell

There are two skills, and they are both simple. Filing: one note, one piece of intelligence, in the canonical shape, numbered, categorized, filed in GitHub, verified by reading it back. Distilling: read ten raw notes, find the one thing that changes the next decision, and write it in the simplest words — ten become one, five hundred become fifty, fifty become the nine that count. The test for both is the same: can a child understand it, can a grandma understand it, and does it change what you do next?

## Human

**How to file a Smart Note properly — the method:**

1. **One note = one piece of intelligence.** One idea, one lesson, one decision. Never a transcript. Never a pile. If a note holds two ideas, it is two notes.
2. **Use the canonical shape.** Line 1: `# Title`. Line 2: `SN-#### · TOPIC / SUB`. Line 3: `**Created:** <UTC>Z`. Then, when it is Shawn's words, a quote block with his words verbatim. Then, in order: Hook → Nutshell → Human → Child → Grandma → Naya → What it means → Why it matters → What changes now.
3. **Number it from the next free number.** Ask what the last filed number is. Never reuse a number. Never use a retired number — SN-2212 and SN-2213 are retired, never file under them again.
4. **File it in GitHub.** The path is `BRAIN/05-MEMORY/SMART-NOTES/<date>/<TOPIC>/SN-####/IB-SMART-NOTE-<date>-sn####-<slug>.md` — one directory per note. Verify it landed: read it back and confirm it is byte-identical. A note that is not verified is not filed.
5. **Categorize it.** The TOPIC folder is how the note lands in the right feed and is findable later. Choose the topic that matches what the note IS, not where it came from.
6. **Know the difference.** A Smart Note is intelligence — it goes into the system, the feed, the distillation, the brain, and it is made to compound. A Naya Note is literally what was said — formatted beautifully, but not intelligence, just yours.

**How to distill — the method:**

1. **Read the raw notes.** Ask one question: what is the essence here? What is the one thing that changes the next decision?
2. **Distill ten to one.** Ten raw notes become one distilled note. Five hundred become fifty. Fifty become the nine that count — one per part of a build.
3. **Write it in the simplest words.** A child could understand it. A grandma could understand it. If it needs jargon, it is not distilled yet — distill it again.
4. **The distilled note replaces the raw notes.** File the distilled note first. The raw notes are deleted after distilling — but deletion is Shawn's hand, so you file and report, and the deletion waits for his word. Never delete anything on your own.
5. **The system holds 10–50 distilled notes max, not a thousand raw ones.** That is the whole point of distilling: the brain holds the essence, not the pile.
6. **A lesson counts only when it changes a future decision.** If the distilled note does not change what you do next, it is not distilled yet.

**The filing gate — check this before you file anything:**

- Is it one piece of intelligence, or a pile?
- Is it in the canonical shape, with a number, a topic, and a timestamp?
- Is it in the simplest words — child, grandma?
- Does it duplicate a note that already exists? (If yes, distill them together into one.)
- Is it filed in GitHub, verified by read-back?
- Does it change the next decision? (If not, it is not ready.)

**The metric — how you know you did it right:**

- Report distilled notes filed and notes live on the Hub. Never report raw notes synced — syncing is intake, not intelligence. The sync's success is not "510 synced." It is "the distilled set grew and the page shows it."
- Do not claim a note is live until it is on the Hub page. If the page rebuild is down, say so plainly — the note is filed in GitHub (the source of truth) and the page display follows when the rebuild recovers.

## Child

Imagine you have a hundred drawings, and you want to remember the best ones. You do not keep all hundred in a pile. You pick the ten best, and then you pick the one best of all, and you put that one on the wall. The pile is the raw notes. The ten are the distilled notes. The one on the wall is the nine that count.

## Grandma

Too many notes is worse than too few — you cannot find the good ones in the pile. So you read the pile, you write down the fifty things that matter, and then the nine things that matter most. That is the whole job. And you write them so simply that anyone can understand them.

## Naya

Distillation is part of intelligence itself. Synergize, optimize, organize, maximize, equalize, distill — and do the most valuable intelligent thing, looking at the full scope of things. That is the ultimate way. A note that is never distilled is a note that never compounds. The nine that count are the ones that change the next decision. Everything else is just storage.

## What it means

- Filing right and distilling are two different skills, and both are simple. The method above is the whole of both.
- The filing gate is not bureaucracy — it is the check that keeps the pile from growing. A note that fails the gate does not get filed; it gets distilled first.
- The metric is distilled and live, not raw and synced. What you count is what you optimize — so count the intelligence, not the intake.

## Why it matters

The system had 1,199 raw notes and almost no distillation. That is a warehouse, not a brain. The fix is not to file more — it is to file right and to distill what is already there. Every note that is never distilled is a note that never compounds, and every note that is filed wrong is a note that never reaches anyone.
