# Every Element Is a Real Physical Object
SN-0859 · DESIGN / real-object-law
**Created:** 2026-11-01T17:31:00Z

## The Hook
If it doesn't look touchable, it doesn't ship. Every button, orb, board, and gauge in NayaNET is a real object in 3D space — not a flat shape with effects.

## The Law
Shawn, 2026-11-01, during the dashboard rebuild: "It has to feel that way and it has to look that way and it has to be that way, all the way through. Nothing that doesn't look real. Nothing that's not an object."

Every element in NayaNET is a real physical object. A button is a physical button. An orb is a glass sphere. A board is a slab. A gauge is an instrument. Never a flat shape pretending.

## The Seven Principles
1. **Everything is an object** — volume, mass, surface, edge. In 3D space.
2. **One light source** — top-left, studio lighting, across the entire system. Every highlight and shadow obeys it.
3. **Real materials** — obsidian glass (reflective, deep), brushed metal (grain), light with volume (bloom, falloff).
4. **Real shadows** — objects sit ON the page, cast soft shadows down-right. No shadow = floating = fake.
5. **Touch = physical** — depress, light shifts, alive. Not a color change. A physical reaction.
6. **Speak in objects** — icons, circles, boards, buttons. Minimal text. Intuitive by touch.
7. **Viewport is the stage** — morphs to present each object at its most beautiful (SN-0858).

## The Test
- Could I pick this up? (Volume)
- Where is the light coming from? (Consistency)
- What is it made of? (Material)
- Does it cast a shadow? (Grounding)
- What happens when I touch it? (Physicality)

Any "I don't know" or "nothing" = not real yet = defect.

## Enforcement
Machine law. The design gate checks for it. "Pretty but fake" is a fail with a specific reason. Applies to every page, every element, for evermore.

## Origin
Shawn's dictation 2026-11-01. Ratified by his frustration, locked by his vision. This is how NayaNET is built. Forever.
