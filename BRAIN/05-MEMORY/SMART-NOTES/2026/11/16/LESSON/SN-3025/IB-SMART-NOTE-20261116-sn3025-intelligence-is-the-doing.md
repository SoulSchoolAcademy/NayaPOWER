That is the scorecard, and no benchmark writes it — research groups and universities measure what they can measure, which is capacity, and no single rank establishes ultimate intelligence. ## Why it matters

1. A definition that cannot be gamed is the only defense against power calling itself intelligence. The moment "intelligent" means "powerful" or "high-scoring," the system starts rewarding the wrong thing — more power, higher rank — and the doing stops mattering. This definition keeps the doing at the center: what did it do, did life get better, can it prove it.
2. The honest claim and the live proof are the same discipline in two places. A pattern that points is not a proof, and a bake that passes is not a live view — in both cases the gap is between the claim and the thing itself, and the only bridge is an eye on the real thing. A system that tolerates either gap will eventually believe its own press releases.
3. The code and the machine are one promise kept two ways. The code says what the system will never do; the machine says what the system exists to do — intelligence doing valuable work, automatically, at massive scale. Either without the other is half a system: a code with no machine is a wish, a machine with no code is a weapon.
