## Human

An account list that only grows is a list that lies: test accounts, dead accounts, duplicates — all sitting there forever, and the citizen can't tell which one is theirs. Removal is the other half of creation: if the system can create an account every time, it must be able to remove one. And removal of something you lose for good must never be one click — the warning is the respect for the loss. The warning first, then confirm: two steps, because the loss is permanent and the tap is cheap. Duplicates being separate rows is the honesty: same name, different device key, different account — the X removes that row, not the name.
