# One System, Four Doors — Everything Lives Inside

SN-0875 · SYSTEM-ARCHITECTURE / ONE-SYSTEM

**Created:** 2026-11-04T01:12:00Z

## The Hook
We're not building dozens of apps. We're building four pages — and every feature lives inside them.

## The Architecture
**Four doors (the pages):**
- Dashboard — the stats for them all (personal cockpit, the numbers)
- Personal — the personal world
- Business — the business world
- Space — the community world
- Membership — the fifth (stats-driven, like the others)

Four of them are similar to each other (Personal, Business, Space, Membership). The Dashboard is the stats layer for all.

**Everything else is a FEATURE, not a separate app:**
- Smart Mail — works throughout
- Smart Lists — contacts, notes, naya notes organized into lists; connected to mail, messaging, projects
- Smart Meet — video/audio calls, hooked up inside the apps
- Booking — calendar/journal forward and backwards, appointments, week review (MISSING — needs building)
- Memberships — add-on to any page, private communities, can charge for access
- Smart Notes + Naya Notes — the main content, inputted in feeds, shared as understandable intelligence
- Ask Naya — ask about the system, learn how it works
- Reports — daily/weekly/monthly personal written reports
- Smart Ledger — aligned with Dashboard + Smart Stats, all one system
- Smart Factory — stores all parts
- Smart Growth — grows through the email system
- Affiliate system — integrated everywhere; anyone building pages gets an army of affiliates

**The Hub** is the central intelligence system that brings it all together — where you access everything.

**Smart bars** are the navigation — the convenience layer.

## Why This Matters
Building 4-5 pages is efficient. They're similar, so the best elements transfer. The features light up inside them. One interconnected system, not a pile of separate apps.

Front end = humans' personal worlds. Back end = systems world dashboard. One system, fully functioning, all features accessible in Personal, Business, Space, and Membership.

## The Build Order
1. The four doors first (Dashboard, Personal, Business, Space) — make them 10/10
2. Features light up inside them (Mail, Lists, Meet, Booking, Memberships)
3. Intelligence flows through everything (Smart Notes, Auto-Match, Ask Naya)
4. Growth systems connect (Factory, Growth, Affiliates, Ledger)
