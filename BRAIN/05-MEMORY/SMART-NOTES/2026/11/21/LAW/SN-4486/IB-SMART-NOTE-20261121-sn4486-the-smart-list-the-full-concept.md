## Why It Matters

Lists fail when the tools live somewhere else — a citizen writing a note should not have to go somewhere else to file it. Put the PLUS button where they input, let them tag the item to a list right there, and let the system do the organizing. And a list nobody can find is not a list: Your Worlds in the main Hub is the table of contents — one place, every list, tap and see every item. Simple access is the point, and the point is the whole feature.
