## Why It Matters

This draws the line between the three things a person can put into NayaNET, so nobody has to guess which one they are making. A smart note is the public, auto-formatted, social intelligence — and it can never be unformatted, because the public standard holds. A Naya note is the private, auto-formatted full deal — and it can go plain in Settings, because it is yours. A post is the default, straight-up thing: here you are posting, it has the social share part, and if you wanted unformatted you would just post. Same formatting family, three different defaults — and images work on all of them. A builder who auto-formats every post by default would be building the wrong default.

## How to Use It

When a person posts, default to straight up: not auto-formatted, one piece, with the social part — the social share part — on it. A post CAN be beautifully formatted if they choose it, or one block; the default is what is straight up. Keep the taxonomy in the activation document and the law (A13): smart note auto-formatted / public / social / no name / cannot unformat; Naya note auto-formatted / private / no social / may carry name / can unformat in Settings; post not auto-formatted by default / straight up / social share part. Images on all four: Naya notes, smart notes, Naya posts, normal posts.
