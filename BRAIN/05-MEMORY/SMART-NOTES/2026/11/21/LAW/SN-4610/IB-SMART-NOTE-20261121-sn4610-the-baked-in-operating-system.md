## Why it matters

1. Without one book of laws read first, every seat re-derives the system from memory — and memory is where the rebuild loop lives.
2. Without the frame library, every page is a new build — and a new build is waste, thrown away the moment his eye sees it is not the frame.
3. Without correction-becomes-law the same pass, the same mistake gets taught ten times to ten seats — and the lesson is lost the moment the call ends.
4. Without the live loop, staging is called done — and a staged page is a page nobody can use, tested by nobody, proven by nothing.
5. Without the anatomy, the Nutshell runs on forever and the sections sit empty — and a block that is not a nutshell misleads the reader it was built for.
6. Without continuous triple-A, the brand drifts — and a brand that drifts is not a brand, it is a pile of pages.
7. Without the mission written into the law, the machine optimizes for speed — and speed without the destination is the exact failure wisdom exists to stop.
