## The Lesson

**FRAME REORDER — MAX-LEVEL PERK (his ruling, 2026-11-21 ~12:02 MST):**

**MAX CAN MOVE THE FRAMES.** A Max-level citizen can change the order of their frames and pages — put one frame before another, moving blocks around. The power to order is the power to lead with what matters most to them.

**THE SET NEVER CHANGES, ONLY THE SEQUENCE.** The frames themselves stay the same set template. Reorder is not replacement, not addition, not removal — it is sequence only. The template holds; the order is theirs.

**IT JOINS THE MAX UNLOCKS.** Frame reorder sits beside the Max unlocks already recorded — custom frame swap and the affiliate army. Max is the level where the citizen shapes their own presentation; reorder is one more way they do it, inside the same template everyone shares.

## Why It Matters

Order is meaning. The same ten frames in a different order tell a different story about the person — what they lead with is what the world meets first. A Max citizen who can reorder can curate how they are met, without breaking the template that keeps every page one language. And because the set never changes, no reorder can ever break the page: the worst a citizen can do is tell their story in a different order, which is exactly the point.

## How to Use It

Max only: let the citizen move any frame before another; the frame set never changes, only the sequence. Power and Pro keep the template order. Never let a reorder add, remove, or replace a frame — that is a different unlock, not this one. Judge any reorder control by his test: does the citizen move the blocks, and does the page stay the same page, in a new order?
