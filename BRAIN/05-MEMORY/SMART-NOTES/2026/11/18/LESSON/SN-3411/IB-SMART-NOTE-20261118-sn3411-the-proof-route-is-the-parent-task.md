## NAYA

## MACHINE

1) A checker measures the property it names, on that property's own standard; proxies are labelled proxies. 2) Every instrument fix is proven both ways: synthetic pass cases AND the original failing record reproduced. 3) Counts are taken on objects (cards, entries), never on substring occurrences. 4) A blocked call is re-tested once as a gate before it is recorded as a death. 5) Proof is delivered to the parent task that commissioned the work; a summary elsewhere is not delivery.

## WHAT IT ALL MEANS

Measurement bugs are more dangerous than product bugs because they manufacture confidence in both directions: false reds send fixers after ghosts, false greens ship defects as features. This family shows the cure is procedural, not heroic — synthetic cases, regression reproduced from the original record, before/after on the same inputs. And proof that doesn't return to its parent task evaporates: the work looks done everywhere except the one place it was owed.
