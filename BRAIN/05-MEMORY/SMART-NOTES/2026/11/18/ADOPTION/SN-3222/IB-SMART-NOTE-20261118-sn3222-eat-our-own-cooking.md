## Human

This is the rule that separates a system from a story about a system. The machine talks about intelligence all day — smart notes, smart vaults, smart feeds, smart everything — and the talk is super intelligent and super valuable, and none of it counts until it is lived in. Three gates, in order, and all three must pass: adopt it (the machine itself uses the thing it offers, every day, not as a demo), automate it (it runs without a human remembering to run it — the loop, the sync, the hook), and make it physical (it becomes an interface a person can touch — a door that opens, a page that loads, a button that does something — not a paragraph that describes one). Anything that fails a gate is not useful, however intelligent it sounds. The vault is the first instance because it is the most visible: citizens are offered one vault where their whole world lives, so the machine lives in its vault first, and the vault work that started at 01:44Z is exactly that — for ourselves first. A feature the machine does not use itself is a feature the machine does not believe in — and a citizen will feel that, even if no one says it.
