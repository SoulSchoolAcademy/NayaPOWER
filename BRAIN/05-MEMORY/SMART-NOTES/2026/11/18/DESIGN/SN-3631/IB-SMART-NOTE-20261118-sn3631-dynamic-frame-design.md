## The understanding

A frame is a servant of the note, never its master. When the frame is fixed, the builder squeezes the note to fit — and a squeezed note is an incomplete note, which means the framing itself is wrong, however pretty it looks. The dynamic frame flips it: the note is written out in full first — what it means ultimately, why it matters, what's in it for you, and how — and the frame repeats its side pattern to whatever length the note needs. The board sits in the middle of the framing, lit, edges whole; the child note board sits inside the main board. Content decides the size; the frame follows.

## The law

Never squeeze a note to fit a frame. Build the frame as a repeatable side pattern that extends down to any length; fit the intelligent board in the middle, child board inside the main board, each board lighting up; present every smart note in full. If the note has to shrink to fit, the framing is wrong — grow the frame, never shrink the note.

**The note is whole first; the frame grows to match it.**
