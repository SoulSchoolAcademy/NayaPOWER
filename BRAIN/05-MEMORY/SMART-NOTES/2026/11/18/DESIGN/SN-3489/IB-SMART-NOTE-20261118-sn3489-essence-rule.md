# SN-3489 — The Essence Rule: When the Image Cannot Line Up, Make a New One That Does

## The teaching, in his words (verbatim)

If an image can't be made to line up perfectly, create a NEW image carrying the SAME ESSENCE that does line up perfectly and put it there. Perfect alignment wins; the essence is what survives, not the exact pixels.

## The understanding

Harvest-verbatim is the law — take what works byte for byte, never rebuild it. But a harvested image that cannot be made to line up is a different failure: the page is crooked, and no amount of loyalty to the original pixels fixes a crooked page. This ruling is his own exception, and it draws the line exactly: what survives is the ESSENCE — the thing the image means, what it shows, what it feels like — not the exact pixels. The maker recreates the image carrying that same essence, in a form that lines up perfectly, and puts it there. The exception is narrow by design: use it only where the original genuinely cannot be made to line up, and name it in the maker report — so a maker cannot reach for "essence" as an excuse to redesign what already aligns.

## The law

Perfect alignment wins. If an image cannot be made to line up perfectly, create a NEW image carrying the SAME ESSENCE that lines up perfectly and put it there. The essence survives, not the exact pixels — and only where the original genuinely cannot be made to line up, named in the maker report.

## Owed from this dictation

Makers apply the rule only where the original genuinely cannot be made to line up, and name every use of it in the maker report. Anything that CAN be made to line up is still harvested verbatim — this exception never becomes a reason to redesign.

**Perfect alignment wins — the essence survives, not the exact pixels.**
