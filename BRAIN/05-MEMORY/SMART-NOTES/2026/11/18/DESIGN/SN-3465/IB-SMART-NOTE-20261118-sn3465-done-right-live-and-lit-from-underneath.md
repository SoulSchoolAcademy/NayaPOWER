1. Without the fixed measure, the machine chases a percentage and calls it efficiency — starting less work to look more efficient, or cutting the checker and the eye to buy the number — and the tower gets faster and worse at the same time.

3. Without live and walked, the live domain lies about the current state and the first person to find the broken "get back in" is a citizen, not us — while a staging link and a build log can both claim a deploy that never landed.
