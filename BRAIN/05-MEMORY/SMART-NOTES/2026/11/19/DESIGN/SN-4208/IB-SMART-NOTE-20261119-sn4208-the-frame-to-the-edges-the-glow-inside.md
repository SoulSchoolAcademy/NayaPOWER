## The understanding

The frame is the presentation, not the border around it. A frame that floats inside the screen with scattered dots and icons, one thin sentence per board, and light leaking around the outside reads as mess because nothing is formed — the content was stuck into a frame instead of built as part of it. Clean is structural: the frame hugs the edges so the presentation owns its area; the glow lives inside so the light belongs to the object; each board carries enough words to be a presentation of its own, so the click earns the next frame instead of apologizing for the last one. And the concept is portable by design — the same frame discipline that fixes the walkthrough fixes About and Skills, because a frame that works is a frame that works everywhere, and the whole Personal area then feels like parts of each other.

## The law

Fit the frame to the edges, light it from the inside, and give each board enough words to be a presentation. Never stick old formatting into a new frame — start new and work with the frame until the boards feel like parts of each other. The calendar frame is an equal alternative wherever it gives more spacing. The same concept applies to the text unfold and the visual, and again in the Personal area for About and for Skills. Clean is proven by his eye at 390 and desktop, never claimed from the build.
