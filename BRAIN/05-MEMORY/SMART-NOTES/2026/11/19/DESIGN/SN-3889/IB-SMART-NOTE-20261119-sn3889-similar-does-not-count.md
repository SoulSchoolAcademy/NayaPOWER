# Similar Does Not Count

**Created:** 2026-11-20 00:17Z

**Kinds:** Honor · Multiplication · Craft · Knowledge

## Hook

He has told me this probably 100 times. Personal should look exactly like the Hub — and every round so far answered with something similar to the Hub, or part of the Hub. Similar does not count. Take the code and stick it in.

## Nutshell

The teaching landed in one voice call, ten notes deep, and it is all one ruling: copy the real thing, whole. Personal IS the Hub, literally copied — take the Hub's code and stick it into the Personal space, then only relabel the three pills to Personal / Business / World — and its only difference is the top, the feature cover with its menus, search, and the standard menu bar, while everything below mirrors the Hub exactly. About and Skills take the exact presentation code too: the unfold from the Collective Agreement and the visual presentation from the pricing page, literally, then optimized for the person and their skills — because the mechanism was built and the look was not, and "looks like crap" was the verdict on the finish, not the function — with the content filled in as him, in his voice, no placeholders. About's top row is settled: About (default, the text) / Photos / Videos / Socials; scroll down unfolds, click slideshow slideshows, Photos shows all photos, Videos shows all videos link-only — YouTube URL entry or pasted links from anywhere, NO uploads. The same copy-whole law runs through the system itself: auto-organization is universal — content, feeds, contacts, all of it, always organized and categorized, so the citizen finds anything by a search or one click on a category, never by digging — and contacts get the same shelves as the feeds, a category click showing only the contacts in that category. The colour must be true too: the colour after Skills was named magenta but read purple, and Invite is a proper purple, so the fix is a true magenta with prominent, unmistakable contrast — because a colour that reads as its neighbour is a place the citizen cannot find. Socials is icons — one click to the site — with stats shown honestly: clicks are our own tracked counts, platform notifications only if the platform sends them, never invented — and the three cover buttons are re-mappable in Settings to socials or any URL, the default staying as built. And the work itself circulates the same way: always send ALL the links together as one set, staged where staged is latest and live on the main URL where live is latest, edit while he reviews, then send the whole edited set again — one link at a time, or a set that goes stale after one pass, is not the workflow. The last law is the smallest and the sharpest: a staged link to a view inside a multi-view file carries its view hash — #memberships, and the same for every other view — verified by opening it, because a link without its hash opens the wrong door.

Across 10 notes, the thread is: copy the real thing whole — similar does not count.

## What it means

1. **SIMILAR DOES NOT COUNT:** Personal is the Hub's code, identical in behaviour, three pill labels changed only — a similar page or a partial copy is not done, and the proof is identical code and behaviour.
2. **THE ONLY DIFFERENCE IS THE TOP:** the feature cover, menus, search, and standard menu bar sit on top; everything below mirrors the Hub exactly — the seam sits at the top and nowhere else.
3. **THE LOOK RIDES WITH THE MECHANISM:** About and Skills take the exact presentation code from the agreement and the pricing page — a feature without the look is a failure, not a step — and the content is filled in as him, in his voice.
4. **FOUR BUTTONS, FOUR VIEWS:** About (default) / Photos / Videos / Socials; scroll unfolds, slideshow slideshows; Videos is link-only, never an upload — the membership media law, applied to About.
5. **WE ALWAYS ORGANIZE:** auto-organization is universal — content, feeds, contacts, all of it — so the citizen finds anything by search or one click on a category; any surface still showing everything all at once, uncategorized, is unfinished work.
6. **MAGENTA MUST READ MAGENTA:** the colour after Skills is a true magenta, Invite is a proper purple, and the contrast is prominent at a glance — a colour that reads as its neighbour is a place the citizen cannot find.
7. **SOCIALS IS A DOORWAY, A COUNT, AND A CHOICE:** icons, one click to the site; stats shown honestly, never an invented number; the three cover buttons re-mappable in Settings, defaults unchanged.
8. **THE SET CIRCULATES:** all links together as one set, each the current latest, edits landing while he reviews, the whole edited set re-sent for the next pass — a single link alone, or a stale set, is a miss.
9. **A LINK WITHOUT ITS HASH IS THE WRONG LINK:** every staged link to a view inside a multi-view file carries its hash, and it is verified by opening it — it must land on the view it names, never on the file's default.

## Why it matters

1. Without the literal copy, the next maker builds "like the Hub" for the hundred-and-first time — close enough to feel like progress, wrong enough that his eye rejects it — and the Personal mirror never lands.
2. Without the top as the only seam, the maker either copies the Hub whole and loses the Personal page entirely, or rebuilds Personal from scratch and loses the Hub — and the page is two things, not one.
3. Without the exact presentation code, About and Skills keep their mechanisms and stay plain and boring — the checker passes the parts while his eye fails the page, because a feature is not a look.
4. Without the four-button settlement, About grows a new button per round and Videos asks for an upload — breaking the membership media law and the citizen's expectation at once.
5. Without universal auto-organization, every new surface is a new pile — the citizen digs for contacts, for content, for anything — and the system stops being the system that organizes everything.
6. Without magenta reading magenta, Invite and its neighbour blur into one colour — and the colour flow, which is the map, lies about where things are.
7. Without honest stats, Socials invents notification counts to fill the space — and the first citizen who checks finds the number was never real, which breaks trust faster than any missing feature.
8. Without the circulating set, the machine serializes behind one page at a time while every other area sits untouched — and the review loop starves on single links.
9. Without the view hash, a link says membership and opens Personal home — and he catches it in one look, because the link's job is to land where it says.
