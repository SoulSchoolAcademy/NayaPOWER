## The teaching, in his words (verbatim)

This is how he works the pages from now on — always send him ALL the links together as one set: the current state of the last edits for every area that needs taking care of (staged where that is the latest, live on the main URL where that is the latest — "live can be live on the main URL"). He goes through them as fast as he can, directing edits; I edit while he is going through them; then the whole set is sent again — now edited — and he reviews again. The set circulates continuously that way so every area keeps getting done. One link at a time, or a set that goes stale after one pass, is not the workflow.

## The understanding

The workflow is the circulation, not the link. One link at a time serializes the whole machine behind a single page: he reviews it, directs edits, waits for the round, reviews again — while every other area sits untouched. The set parallelizes it: he moves through every area in one pass, directing edits everywhere, and the edits land while he is still going — so the set he gets next is already the edited one, and the next pass starts from the new state instead of the old. "Live can be live on the main URL" settles which link rides in the set: wherever live is the latest, the live link goes in; wherever staged is the latest, the staged link goes in. A set that goes stale after one pass breaks the loop at the same place a single link does — the next review would be judging yesterday's pages.

## The law

Always send ALL the links together as one set — staged where staged is latest, live on the main URL where live is latest. Edit while he reviews; then send the whole set again, edited, for the next pass. One link at a time, or a set that goes stale after one pass, is not the workflow.

## Owed from this dictation

Every review pass proves: the full link set sent together, each link the current latest (staged or live); edits landing while he reviews; the whole edited set re-sent for the next pass. A single link sent alone, or a stale set, is a miss against this law — recorded, not passed silently.

**The set circulates, or the work stalls.**
