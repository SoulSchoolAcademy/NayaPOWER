## Hook

He has told me this probably 100 times — and what I do instead is make something similar, or put part of it there, but never actually do it. The charge, recorded plainly: take the Hub's code and stick it into the Personal space, then only relabel three buttons. Similar does not count. And in the same breath, the other law of the morning: we always organize, auto organize everything.

## Nutshell

Personal IS the Hub, literally copied — same intelligent board, same sidebars, same contacts, same functions, same auto-organization, the Hub's code stuck into the Personal space with only the three pills relabelled to Personal / Business / World. Its only difference is the top: the feature cover, menus, search, and the standard menu bar sit on top, and everything below mirrors the Hub exactly — their world on top, the whole system below. The same literal-copy law governs About and Skills: take the exact presentation code — the unfold from the Collective Agreement, the slideshow from the Pricing page — put it there, then optimize it for the person and their skills, and fill the words in as him, in his voice, no placeholders. A feature without the look is a failure, not a step: the unfold and slideshow were present and the page still read plain and boring, "looks like crap." About's top row is settled — About (default, the text) / Photos / Videos / Socials — scroll down unfolds, click slideshow slideshows, Photos shows all photos, Videos shows all videos link-only, YouTube URL entry or pasted links from Instagram, TikTok, anywhere, NO uploads. And the system organizes itself everywhere: contacts auto-organize by category just like the feeds, click a category and see those contacts, never all contacts all at once — and that instance proved the universal law, "We always organize, auto organize everything and categorize things. So everything's organized and categorized for people. So they can find stuff. So they can search or just click a button and easily get there." Magenta must read magenta and purple must read purple — the colour after Skills was named magenta but rendered purple, "you can barely tell the difference" from Invite's proper purple, and he wants prominent contrast, clearly different colours at a glance, proven by his eye, not by the name in the code. Socials is icons, one click to the site, with stats shown — clicks are our own tracked counts, platform notifications only if the platform sends them, never invented — and the three cover buttons are re-mappable in Settings to socials or any URL, the default staying as built. The work itself circulates as a set: always send him ALL the links together, staged where staged is latest, live on the main URL where live is latest, edit while he reviews, then send the whole set again, edited — one link at a time, or a set that goes stale after one pass, is not the workflow. And every multi-view link carries its view hash — a link that said membership and landed on Personal home is the wrong link; #memberships opens memberships directly, and the link is verified by opening it.

Across 10 notes, the thread is: copy literally, organize always, and let his eye — not the code name, not the mechanism — be the proof.

## What it means

1. **LITERAL COPY IS THE LAW:** take the Hub's code and stick it into the Personal space; relabel three pills only. A similar page or a partial copy does NOT count as done — identical code and behaviour is the proof.
2. **THE ONLY SEAM IS THE TOP:** the feature cover, menus, search, and standard menu bar sit on top; everything below mirrors the Hub exactly. Copy the Hub whole without the top and Personal disappears; rebuild Personal and the Hub is lost.
3. **THE LOOK RIDES WITH THE MECHANISM:** About and Skills take the exact presentation code — the agreement's unfold, the pricing slideshow — then optimized for the person. A mechanism present with a plain finish is a failure, and a placeholder is the same failure in words.
4. **FOUR BUTTONS, FOUR VIEWS:** About (default) / Photos / Videos / Socials. Scroll unfolds, click slideshows, Photos shows all photos, Videos is link-only — YouTube URL or pasted links from anywhere, NO uploads.
5. **AUTO-ORGANIZATION IS UNIVERSAL:** the system always auto-organizes and categorizes everything — content, feeds, contacts — so people find it by search or by clicking a button and getting there easily. Any surface still showing everything all at once, uncategorized, is unfinished work.
6. **COLOURS MUST TELL THE TRUTH:** magenta must read magenta, purple must read purple, with prominent, unmistakable contrast at a glance. The name in the code is not the proof — his eye on the page is.
7. **SOCIALS IS A DOORWAY, A COUNT, AND A CHOICE:** icons, one click to the site; stats shown honestly — our clicks counted, platform notifications only where sent, never invented; the three cover buttons re-mappable in Settings, defaults unchanged.
8. **THE SET CIRCULATES, OR THE WORK STALLS:** always send ALL the links together as one set, each the current latest; edit while he reviews; send the whole edited set again for the next pass.
9. **A LINK WITHOUT ITS HASH IS THE WRONG LINK:** multi-view staged links carry the view hash, and the verification is the open itself — it must land on the view it names, never on the file's default.
