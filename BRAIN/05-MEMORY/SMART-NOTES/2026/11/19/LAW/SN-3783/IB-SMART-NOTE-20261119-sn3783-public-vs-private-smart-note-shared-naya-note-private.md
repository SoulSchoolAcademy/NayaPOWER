## The teaching, in his words (in substance, as recorded)

A smart note is inputted and shared intelligence with the whole network — and it is OPTIMIZED for the search engines, for the AIs and the machines, to be able to find that note. A Naya note is a PRIVATE note — NOT public, NOT optimized for the search engines. You share it with your team or whoever you share it with, or it lives in your personal notes — not everybody in the world seeing it. You CAN choose to make a Naya note a smart note — make it public — but by default a Naya note is private.

## The understanding

The difference that matters between the two notes is public vs private — and it decides everything downstream. A smart note is shared with the whole network, and it is optimized so the search engines, the AIs and the machines can find it: public by design, findable by design. A Naya note is private by default: not public, not optimized for the search engines, shared only with the team or the people the citizen chooses, or kept in personal notes — not everybody in the world seeing it. The bridge between them is a choice, never an accident: a citizen CAN choose to make a Naya note a smart note, to make it public. By default it stays private. Public is an opt-in, never a leak.

## The law

Smart notes are public and optimized for search engines, AIs and machines to find. Naya notes are private by default — not public, not search-optimized — shared only with whom the citizen chooses. A Naya note becomes a smart note only by the citizen's choice.
