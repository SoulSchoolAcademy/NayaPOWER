## What it means

1. **Harvest first, never invent.** Open the Inventory, find the piece, take it exactly as it is — never start from a blank page.
2. **Copy verbatim.** Change only the text inside. Never restyle, never rebuild "in the style of" — a look-alike fails even when it looks close.
3. **Alive or not on the page.** Every element a live living object; a dead element is removed, not decorated. No dead buttons — nothing that does nothing.
4. **One set of laws, many shapes.** The fingerprint is written down — 22 elements: nothing flat, nothing dead, nothing a picture of a thing; one light top-left; real shadows; own-color light, igniting on touch; white text always.
5. **His eye is the instrument; my score is irrelevant.** Run the five gates before every consequential action, scorecard the choices, define done before you act, and prove it with evidence — receipt before report.

## Why it matters

1. Every recreation comes back lower quality. The original was refined by his eye over a year; a builder retyping from a description cannot match it. This is a pattern, not an accident.
2. The Inventory is what makes three-minute pages possible. The parts are already proven, so the builder assembles instead of inventing — and because every builder takes the same parts, the family stays one family instead of drifting into look-alikes.
3. The block is the unit everything is built from. If the block's laws hold, the page holds; if they slip — one flat layer, one wrong jewel color, one shrunken gate list — the whole system slips with them, and the slip is invisible until his eye catches it.
4. Every rule here was paid for with a correction. The report exists so the next Naya doesn't pay for the same lesson again — and so a Naya who has never met Shawn can still build to the standard his eye already set.
