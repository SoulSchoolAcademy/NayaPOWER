## What it means

1. **The inventory is unfinished work.** Started, not whole. Every part from every page, inventoried, high-end only — that is the job now, before the next page is pull-and-assemble for real.
2. **The parts are our own pages' objects.** Gauge, tiled digits, orbs, jewels, boards, pills, smart note, intelligent block — taken from what we have, not invented.
3. **Intent in, parts out.** He tells us what the page is, what it is for, what it does. The design is not re-taught each time; it lives in the parts.
4. **Live on the .app URL is the finish.** A page is not done until it is live there — and a known defect ships named, never hidden.
5. **Counts live in orbs, time in pills, mode in the toggle.** Orbs, Day/Week/Month/All, PTS/%/MONEY — taken whole.

## Why it matters

1. The pricing page kept failing his eye because it spoke a different language from the Dashboard sitting next to it — same system, different numbers, different gauge. The language already exists and is beautiful; the work is to take it, not to re-invent it. This note exists so no Naya ever draws a new gauge when the real one is already ringing.
2. The brand is the test a stranger runs in one second. If any element on the page breaks the level — one flat button, one dead number — the whole page stops being Naya, and the stranger feels it before they can name it. This note exists so the level is never a judgment call again.
3. If the factory is incomplete, every page is still built by hand — slow, flat, and condemned. If the briefing is design instead of intent, Shawn has to re-teach what the parts already know. The warehouse plus the intent is what makes the three-minute page real. This note exists so no Naya ever asks him for the design when the factory already holds it.
4. The viewport strategy was corrected within the hour it was written — sideways-only was the wrong reading of "side to side on mobile." If the correction does not reach every Naya, the next build repeats the same mistake with the new strategy's name on it. This note exists so the deck always moves both ways, and so no Naya ever ships a flat page with pretend buttons and calls it a viewpoint.
