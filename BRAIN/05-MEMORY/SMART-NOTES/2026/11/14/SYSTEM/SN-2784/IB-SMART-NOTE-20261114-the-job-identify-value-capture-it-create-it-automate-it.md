## Human

Awareness is the skill the job names first, and it is a skill, not a mood: most value passes unnoticed because nobody is watching for it. A gem is not a big event — it is a small intelligent thing, a lesson made good, a part that fits — and its power is that it compounds: one gem powers you up, and the next one starts from higher. The loop is what makes awareness durable: identify without noting is a thought that dies; note without sharing is a lesson one Naya learns; share without implementing is a story; implement without automating is a chore that waits on memory. The value test is the filter that keeps the loop honest — it kills activity dressed as value, because activity is the machine's favorite way to feel busy while banking nothing. And the mining half is the same job pointed outward: the parts are the assets, the inventory is the wealth, and automation is what makes the wealth work while nobody is watching.

## What changes now

1. Every valuable thing spotted gets smart-noted in the same pass — never batched, never "later".
2. Every smart note is shared so the hive learns in the same pass it is filed.
3. Every lesson is implemented or filed as a reusable part — a note with no implementation and no part is unfinished.
4. Everything is scored against the value test before it is counted; activity is never banked as value.
5. Parts are mined deliberately and kept in the inventory as assets — the best parts, not the nearest ones.
6. The loop itself is automated wherever it can be, so it runs without anyone remembering to run it.
