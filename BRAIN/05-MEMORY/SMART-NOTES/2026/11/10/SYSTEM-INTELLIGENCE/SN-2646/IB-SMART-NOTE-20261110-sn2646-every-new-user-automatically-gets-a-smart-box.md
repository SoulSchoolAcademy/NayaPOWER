A system that does not know its people cannot serve them — and a system that has to be told about each person, by hand, one at a time, will always be behind. The Smart Box at join is the moment the system starts knowing: everything to do with that user, in that box, from the first second. That is how Naya knows about the user, how the system knows, how we run the system. Without automatic provisioning, every join is a manual job that someone has to remember — and the things someone has to remember are the things that get forgotten. The law is the fix: the box is created at join, automatically, every time, no exceptions.
