## Nutshell
The Master Operational Manual is written and filed — in two volumes in the one document. Volume I, BUILD THE MACHINE: the concept (what NayaNET is, and the seed growing into a tree, a forest, a living garden), the logic and the specification (the one flow, the nine nodes, the Smart Box, the Smart Ledger, the Factory, the ladders, the ambassador system), how to operate the three worlds (GitHub, Supabase, Cloudflare), the full inventory (the pricing chart's 36 rows: 18 real, 18 missing), what remains to complete the puzzle (each item with its state and whose hand), and the machine that builds the machine. Volume II, RUN THE MACHINE: how to operate every function — Smart Mail, Naya Notes, daily intelligence reports, bookings, journals, all the features; how the smart notes' nutshells become the highlights in Today's Intel; how the Smart Factory operates; how Smart Links and Smart Lists work; how it all flows together, one working off another; the expansion loop (a smart note creates a smart space, more people create more notes and more spaces, ever expanding, everybody rewarded, everybody more intelligent); the match game (anybody can connect with anyone of like mind). It extends the existing Operation Manual — never rewrites it. A fresh agent read it alone, answered all five test questions from it plus the Volume II question, and performed one operation from it alone: the live feed read.

## Human
The manual is the engineering record for NayaPOWER and NayaNET with collective team technology: how to file a note so it lands on the feed and in the Box, how to lock a Supabase table, how to deploy the Hub and prove it live from the URL, what the next missing app is (Smart Notes, the first chart row with no View app link), and what the seed, the tree, the forest, and the living garden mean. The fresh-agent test also found the gaps honestly: the note template is never shown, the lock has no SQL in the manual, the Hub deploy names no worker target, and the six-table re-prove needs a sanctioned path to the anon key. Those are the next fixes, not hidden — they are in the report.
