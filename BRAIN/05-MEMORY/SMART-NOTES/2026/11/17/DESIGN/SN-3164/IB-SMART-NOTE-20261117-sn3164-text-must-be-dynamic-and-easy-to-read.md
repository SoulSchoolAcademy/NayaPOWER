## What it means

- **THE TYPE SCALE IS LAW:** headlines 25, sub-headlines 19, smaller text 17. Hierarchy is sized, never guessed.
- **MULTIPLE COLORS:** color guides the eye — titles, names, previews, secondary lines each read differently, none of them flat grey.
- **LAYERED, NOT FLAT:** text is layered so it reads better — size, color, weight, depth, every trick that makes it easier to read and clear.
- **EVERY PAGE:** the law applies to every page, not just mail. No flat, hard-to-read text anywhere.
- **READ IT AS A READER:** the eye reads the page top to bottom as a reader and calls it broken when it doesn't present well, even if every part ticks.
