## What it means

- **THE SYSTEM, NOT THE FILE:** the laws live in GitHub TEAM-NITRO so every Naya pulls the same copy, and every seat brief names them. A law that lives in one file is a document; a law every agent must read before acting is a system.
- **READ FIRST IS A GATE, NOT A HABIT:** before ANY action, the agent reads the laws. The activation habit already said this for design work; this order extends it to every agent, every action — and makes the brief the enforcement point.
- **CHECK AFTER IS THE PROOF:** when the work is done, the agent checks the work against the laws — the §11 check in writing, the checker script run, the eye. A check that is not written down did not happen.
- **REDO UNTIL IT FOLLOWS:** if the work breaks the laws, it goes back and is done again until it follows. This is the correction compound applied to the work itself: a correction that is not enforced is a correction that repeats.
- **THE BRIEF IS THE GATE:** a brief that does not name the laws is incomplete and is not dispatched. No seat starts cold — which closes Appendix C's "fresh seats starting cold" reason at the root.
- **THE CANON RIDES WITH THEM:** the Playbook, Intelligence Report, Design Language, Naya Code, Deep Palette, Anatomy, Heart, Real Object Law — same rule, same check, same redo. The laws are written in the canon's language; the canon without the laws has no teeth, and the laws without the canon have no language.
