## What it means

- **THE OFFICIAL FORMAT:** Block 1 nutshell (headline, lit up with light, silver) → Child Note → Grandma Note → What It Means. Same format for every Smart Note, by default.
- **THE NUTSHELL IS THE HUMAN NOTE:** the human note is cut — nothing is said twice. There is no separate human note.
- **NO NAYA NOTE SECTION IN THE NETWORK:** the front display drops the Naya section. On the back end, the Machine Note does the SEO — every smart note is search-engine-optimized by the machine note.
- **WHAT IT MEANS:** what's in it for you, how it applies, how it connects — every note carries it.
- **THE COLOR FLOW:** silver → magenta → purple → indigo → cyan → emerald green → gold → orange → red → back to magenta → purple (the spectrum flow, 18:00Z). Each section changes color on the outside, themed different — it breaks attention, breaks up the text, lets you take it in.
- **NAYA NOTES ARE THE WAY NAYA WRITES:** "smart note this" or "Naya note this" — anything — outputs into these beautiful boards, 3–4 sentences at a time, a paragraph at a time, or bullet points, always in smart blocks. Anything you write gets reformatted beautifully. Save it, share it.
- **IMAGES:** 16:9 at the bottom, part of the post. Feature top OR bottom OR both (your choice at upload). Both = first image top, the rest bottom. Multiple images = one feature at the top + a grid at the bottom (3×3, 2×2, reformatted for the count), perfectly aligned underneath the message. Read the message, then the images.
- **THE UNFOLD IS A THING:** in Naya feeds and Naya pages, the unfold + the auto-formatting of intelligent communication. The unfold formats for the page — if three notes fit, three, click next; if two, two. So be it.

Without this note, every Smart Note keeps its own shape — seven sections by habit, a Naya section on the front, no SEO on the back — and a citizen reading any note has to learn its shape before they can read its knowledge. With it, the note has one official language: the nutshell lit up, the child, the grandma, what it means, each in its own color, the machine note working the back end, the unfold fitting the page. The format is the reading experience — it breaks attention, breaks up the text, lets you take it in — and a note in the official language is a note anyone can read, save, and share, in any feed, on any page.
