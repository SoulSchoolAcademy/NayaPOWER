## What it means

- **DEEP, NOT NEON:** mid to darker — not super dark, not super light. The deep versions are more elegant: deep emerald, deep sapphire blue, deep gold, royal purple. Bright is rainbow; deep is royal. A neon center is a carnival; a deep center is a jewel.
- **ONE COLOR PER COLOR:** one hex per hue, the same lightness everywhere — the same yellow, the same green, the same blue, the same purple on every button, every tile, every rim. Not a whole bunch of different blues, purples, yellows. Congruence IS the premium: the system reads as one unified thing because it IS one set of colors.
- **CHOOSE THE NICEST, THEN STOP:** the most elegant, the most beautiful, the most royal version of each color — chosen once, then used everywhere. Choosing again per button is how ten blues happen.
- **SUPERSEDES THE BRIGHT VALUES — HUES AND ORDER STAY LOCKED:** the bright spectrum values, the bright digit-tile values, the bright day colors, and the bright orb values are all replaced by the deep values. The hues themselves and the spectrum order do not change — only the values deepen. "Richest versions" now means these ten hexes.

## Why it matters

Without this note, every round picks its own shade of each color — a brighter purple here, a lighter blue there — and the system drifts into a rainbow of near-misses, each one defensible alone, all of them together looking cheap. The eye reads the inconsistency before it reads anything else: buttons that should match, don't. With it, there is one hex per hue, written as law, required reading in every brief — and the depth rule tells every builder which direction to go before they pick anything: deeper, not brighter. The palette is the difference between a system that looks designed and a system that looks accumulated. Pristine premium is not a vibe; it is one color per color, deep.
