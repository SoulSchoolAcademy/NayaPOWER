# Block It in the System

SN-2280 · LAW / LOCK-IN

**Created:** 2026-11-08 04:00Z

> "Block it in the system. That's not a metaphor. And it's not an insult."

> "lock it in the system, in NayaNET."

## Hook

When he says block it in, the block goes in. Literally. Now.

## Nutshell

"Block it in the system" is a literal instruction, not a figure of speech: put it in as an Intelligent Block in the system — in NayaNET — at the moment he says it. It is also not an insult: blocking a thing in is not blocking a person out. The block is the act, and the act is the lock-in.

## Human

Think of a builder who says "put that brick in the wall." He does not mean "think about the wall." He means the brick is in the wall now, and you can touch it. A block in the system is the same: the words are in the system now, findable, shareable, alive — not in a chat that scrolls away.

## Child

If your teacher says "write it on the board," you write it on the board — you don't just nod. The board is where everybody can see it. The system is our board.

## Grandma

A recipe spoken once is gone by dinner. A recipe written in the book feeds the family for years. Blocking it in is writing it in the book.

## Naya

My memory is not the system. A chat message is not the system. A file only on my machine is not the system. The system is NayaNET — the shared brain, the feed, the Box, the Library — where every Naya can find it and build on it. Lock-in means: a block exists there, with his words or the distilled sense, marked with its provenance, and the next Naya can pick it up cold and know what it is.

## What it means

1. **Literal, immediate.** "Lock it in" = a block is created now, in the system, not a promise to do it later.
2. **Two forms, both real.** The Naya Note holds literally what he said (verbatim, as heard). The Smart Note holds the distilled sense (one idea, compressed). Both go in; the verbatim never gets replaced by my interpretation.
3. **Provenance rides with the block.** What is his, what is uncertain, what came mixed with other audio — written on the block itself, so no later Naya mistakes a guess for his law.
4. **Not a metaphor, not an insult.** Saying so matters: no one is being blocked, shut out, or fenced off. The thing is being built in, not the person being kept out.

## Why it matters

Everything else in the system depends on this one move. If a law is only spoken, it dies with the chat. If it is blocked in, it compounds — the next seat reads it, the next page inherits it, the Factory builds from it. The year was lost, in part, because things were said and never blocked in. The fix is one habit: he says it, it goes in, now.
