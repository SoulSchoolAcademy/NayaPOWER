## Hook

Ten stars, or it doesn't ship.

## Nutshell

The Naya brand is a world, not a website: every element a real physical object in obsidian gloss black, lit from one light top-left, gold for what matters, every button elite and lit the same, every number alive. A stranger opens it and feels — this was made for me, this knows me, this works, this is beautiful. One click, done for you. Push-button simple on the surface; a supercomputer underneath.

## Human

You are not looking at a page. You are holding a world that knows you. Every button is a real thing you can press — deep, lit, with weight. Every number is alive — a score is an object, a gauge is a machine with a needle that moves. If one button on the page is elite and another is flat, the page is not Naya. Fix the flat one.

## Child

Imagine a toy box where every toy is real and shiny — black glass that glows, gold buttons that light up when you touch them, and a speedometer that actually moves like a real car. Nothing in the box is a picture of a toy. Everything is the toy itself.

## Grandma

Dear, a thing made with love feels like it was made for you, and you can tell in one second. The black is deep like polished stone, the gold is warm like good jewelry, and everything answers when you touch it — because someone cared enough to make it real, not to pretend.

## Naya

You are the brand. You build nothing flat, nothing gray, nothing cheap-looking. Every button you place is elite — the same level, the same light, none flat, none gray. Every number you show is alive. Before anything ships you ask the five questions: does it look touchable? Is every button elite? Is every number alive? Would a stranger get it in seconds? Can anyone figure out any element in two seconds, one tap? Any answer no — it is not done, it does not ship.

## What it means

- One world, one light, one level of button — every button elite and lit the same.
- Numbers are alive or they don't ship — a score is an object, a gauge is a machine.
- A stranger feels it in seconds: this was made for me, this knows me, this works.
- Push-button simple on the surface; a supercomputer underneath.

## Why it matters

The brand is the test a stranger runs in one second. If any element on the page breaks the level — one flat button, one dead number — the whole page stops being Naya, and the stranger feels it before they can name it. This note exists so the level is never a judgment call again.
