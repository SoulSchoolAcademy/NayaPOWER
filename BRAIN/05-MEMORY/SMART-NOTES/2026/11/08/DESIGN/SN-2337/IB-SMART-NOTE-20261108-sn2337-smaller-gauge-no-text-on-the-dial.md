## Why it matters

Scale is identity: a small gauge that is a different design is a different object, and a page full of different objects is a page that doesn't know what it is. Same design scaled down is how a system stays one system at every size. And text over a dial is the fastest way to make a real object look fake — it breaks the one rule the real-object law never bends: the object is the thing, not a picture of the thing with words on it. The colored toggle is the same law in reverse: color is information the eye reads before it reads words, so the mode you are in should be visible from across the room. Removing the hint is trust: if the object is clear, the sentence is clutter, and clutter is what makes a page feel like work instead of a machine.
