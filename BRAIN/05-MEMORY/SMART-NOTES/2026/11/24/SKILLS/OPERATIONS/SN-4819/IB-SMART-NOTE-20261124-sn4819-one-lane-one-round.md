# One Lane, One Round

SN-4819 · SKILLS / OPERATIONS

**Created:** 2026-11-24T20:19:26Z
**Category:** Operations
**Skill:** 73
**SN:** SN-4819

## Nutshell

One coordinator per page file — if a round is already running on that file, stand down and spawn no maker.

## Child

Imagine two kids both trying to paint the same picture at the same time, on the same paper, in different colors. You'd end up with a mess — and one of them wasted their time. This law says: one painter per picture, and check first whether someone is already painting it.

## Grandma

Each page gets one team, one round at a time. Before anyone starts a new round on a page, they check: is a round already running on that page? If yes, they stand down — no second builder, no second version of the same page.

## What It Means

One coordinator per page file. Before dispatching, check the live rounds — if a round is already running on that file, stand down and spawn no maker. Small rounds: one item per round when the item is small; version one in one hour max.

## Why It Matters

No duplicate teams building the same page two different ways. Two builders on one page means two versions, and one of them is wasted work — wasted time, wasted tokens, thrown away.

## How It Connects

It connects to the Parallel Law — parallel lanes, not parallel teams on the same file. It connects to the Live Sequence — one hour max, one version landing. And it connects to Fail Fast — a bad round dies early, alone, without a twin to confuse things.

## How to Apply

Before dispatching any round, check the live rounds for that file. If one is running, stand down — do not spawn a maker. Keep rounds small: one item per round when the item is small, and land version one within the hour.

Real example: this came from the Ultimate Setup, Shawn's order of 2026-11-19. The same day, a duplicate Dashboard round was caught and stood down, costing one wake instead of a whole build. The check-before-dispatch is what saved that build.

## What's In It For You

No collisions, no wasted builds, no merging two versions of the same page. One lane, one team, one version — and the version you get is the only version there is.
