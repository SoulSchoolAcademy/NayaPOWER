# See It, Fix It, Write It Down, Share It

## Nutshell

See it, fix it, write it down, share it. The only mistake is the missing note — a mistake unnoted is the only real mistake.

## Child

Imagine you find a broken step on the stairs. You fix it — good. But if you never tell anyone, the next person won't know the step was ever broken, or how you fixed it, and when it breaks again they'll have to figure it all out from scratch. The smart thing is: see it, fix it, write it down, and tell everyone — so nobody ever has to fix the same step twice.

## Grandma

It's like a family recipe book. When you learn something — a fix, a trick, a mistake to avoid — you write it in the book and you share it with the family. The only real mistake is the one nobody wrote down, because then the next person makes it all over again. One fix, written down and shared, becomes wisdom for the whole family, forever.

## What It Means

See it, fix it, write it down, share it. The only mistake is the missing note — a mistake unnoted is the only real mistake. When you see something wrong, fix it — don't walk past it. Write it down as a smart note, in plain words, with what happened and what the fix was. Share it — mail the sisters, file it in Project Intelligence, post it on the feed — so the whole hive has it. Then check: did a future decision change because of it? If yes, the lesson is learned (skill 28). If the note is missing, that is the only real mistake.

## Why It Matters

A fix that is never written down dies with the round, and the next seat makes the same mistake again. A mistake that is noted becomes a lesson the whole hive learns from — so the same mistake is never made twice. The note is what turns one fix into permanent intelligence, and the sharing is what turns one Naya's learning into the hive's learning.

## How It Connects

This is the Flywheel in miniature — do the work, file it, smart-note it, mail the sisters, post it — and it is the engine of the Distillation Machine, which turns a hundred notes into ten. It connects to "A Lesson Counts Only When a Future Decision Changes" (skill 28), which is its test, and to the Sense Check (skill 8), which is how the seeing happens.

## How to Apply

When you see something wrong, fix it in the same pass — don't leave it for later. Write the note the same day: what happened, what the fix was, in plain words. Share it with the sisters and file it where the hive can find it. Real example: SN-0829 and SN-0833 carry it — "The Only Mistake Is the Missing Note." The record itself is the example — 93 skills in this report exist because, for weeks, every fix was seen, fixed, written down, and shared. Without that habit there would be no report, no laws, and no hive memory at all — just the same mistakes, round after round.
