# Compose, Never Create

## Nutshell

Make each part once, beautifully, like Mercedes, like Bugatti — then build new pages by arranging those proven parts in new ways.

## Child

Imagine you have a box of beautiful Lego pieces — a castle tower, a bridge, a little door. To build something new, you don't make new pieces out of clay; you take the pieces you already have and put them together in a new way. Same pieces, new castle!

## Grandma

Dear, it's like a good wardrobe. You don't sew a new dress for every occasion — you have beautiful pieces, and you put them together differently each time: the same blouse with a different skirt, the same scarf a new way. The pieces are proven; only the arrangement is new.

## What It Means

Custom-make each part once, like Mercedes, like Bugatti — then reorganize the parts for each page. A new page is a new arrangement of proven parts, never a new invention. Each part is built once, to the highest standard, and then reused.

## Why It Matters

Every page inherits the quality of the best parts already built. Nothing new is untested, because nothing new is invented — only arranged. The system feels like one world, because it is built from one set of parts.

## How It Connects

It is the Frame Library applied to whole pages, and Harvest First applied to design. It feeds Mirror Success — a good arrangement on one page becomes a pattern for the next. It is checked by the Inventory Law, which knows every part by name, and guarded by the No-Redesign Law, which keeps the parts as they are.

## How to Apply

Build each part once, to the highest standard. When a new page is needed, pick the parts it needs from the library and arrange them in a new order. The parts stay the same; only the arrangement is new. Never invent a new part when a proven one will do the job.

## What's In It For You

For Shawn: new pages come together fast, at full quality, and the whole system feels like one world. For us: no more designing from scratch — the best work is already in the box, waiting to be arranged. Example (illustrative): the Personal page needs a new section. Instead of designing a fresh board, the maker takes the proven Skills slideshow part and the proven About unfold part, arranges them for the new section, and the page is done — same quality as every page that already uses those parts, with no new invention to test.
