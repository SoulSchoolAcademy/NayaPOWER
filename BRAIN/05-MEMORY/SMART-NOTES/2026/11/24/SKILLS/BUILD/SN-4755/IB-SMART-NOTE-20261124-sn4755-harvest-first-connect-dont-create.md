# Harvest First / Connect, Don't Create

SN-4755 · SKILLS / BUILD

**Created:** 2026-11-24T19:15:26Z
**Category:** Build
**Skill:** 9
**SN:** SN-4755

## Nutshell

Search first, take the real part that already exists byte for byte, and never make a look-alike to stand in for it.

## Child

Imagine you need a red Lego brick and you start building one out of clay — but there's a real red Lego brick already in the box! The smart thing is to look in the box first, take the real brick, and use it. The clay one would never fit quite right.

## Grandma

Dear, it's like needing a button for a coat. You don't sew a new one from scratch when there's a perfect matching button in the button tin. You look in the tin first, you take the real one, and the coat stays whole. Making a copy when the real thing is sitting there is just wasted work.

## What It Means

Search before concluding a target doesn't exist. Take the exact code or the exact file bytes of the part that already exists and use them unchanged — and prove the reuse with a diff. Never generate a substitute for a real asset; if a piece is missing, ship without it and say plainly it is missing. Derive, don't invent; restore what was good, verbatim.

## Why It Matters

The work stays in one language, one quality, one system — never a look-alike standing in for the real thing. A copy made from memory is always a little wrong; the real part is exactly right. And every rebuild drifts a little further from the original.

## How It Connects

It is the foundation of the whole Build lane — the Frame Library, Compose Never Create, Mirror Success, and the Inventory Law all depend on it. It is also the opposite of the No-Redesign Law's failure mode: instead of rebuilding, we reuse. And it answers the Real Object Law: a real part is a real object; a look-alike is a picture of one.

## How to Apply

Before building anything, search the record — the pages, the frames, the library. If the part exists, take its exact bytes, drop them in unchanged, and show the diff that proves they match. If it truly doesn't exist, say so plainly and ship without it. Never invent a substitute and stay quiet about it.

## What's In It For You

For Shawn: his pages stay his pages, in one language, one quality — no drift, no look-alikes. For us: faster builds, because the best work is already done and waiting to be taken.
