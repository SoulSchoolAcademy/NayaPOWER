## Nutshell

Build each frame once, done right, keep it in the library — then clone it forever and swap only the middle.

## Child

Imagine you have a beautiful picture frame, and you want ten pictures on the wall. You don't build ten new frames — you use the same lovely frame ten times and just change the picture inside! One frame, done beautifully, used over and over.

## Grandma

Dear, it's like a good cake tin. You buy one excellent tin, and you bake a hundred cakes in it — you don't buy a new tin for every cake. The tin stays the same; only the cake inside changes. That's the frame: one build, done right, used again and again.

## What It Means

Real harvested parts, cloned, never rebuilt, never invented. Three frames: the agreement frame (big story moments), the calendar frame (text-heavy lessons inside the software), the empty-middle frame (special featured moments). One build done right, then clone and repeat — swap only the centre. The maker proves the frame code byte-identical to the harvested source with a diff before anything reaches Shawn.

## Why It Matters

It stops the rebuild loop. A frame built once, properly, and cloned forever means every page starts from the best version — not from a fresh guess that drifts a little further from the original each time.

## How It Connects

It is Harvest First made concrete — the library is where harvested parts live. It feeds Compose, Never Create: new pages are arrangements of these frames. It is checked by the Inventory Law, which knows every frame by name. And it is guarded by the No-Redesign Law: the frame is taken as it is, not restyled.

## How to Apply

Build the frame once, to ten-star quality. Put it in the library. For each new page, clone the frame, swap only the middle content, and prove with a diff that the frame code matches the library copy byte for byte. If the frame doesn't exist yet, build it once — then never build it again.

## What's In It For You

For Shawn: pages get faster to build and identical in quality — every new page starts ten-star. For us: the rebuild loop ends, and our time goes to new work instead of remaking old work. The real-world proof: Shawn ordered this on 2026-11-21 ~18:00–18:12 MST, with the One-Build Law the same morning ~08:10 MST. The About page was rebuilt three times because the frame was never taken. One build, cloned, would have ended that loop after the first build.
