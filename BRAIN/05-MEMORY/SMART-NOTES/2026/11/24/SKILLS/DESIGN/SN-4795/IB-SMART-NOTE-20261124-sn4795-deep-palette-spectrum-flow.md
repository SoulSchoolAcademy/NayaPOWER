# The Deep Palette + Spectrum Flow

SN-4795 · SKILLS / DESIGN

**Created:** 2026-11-24T19:55:26Z
**Category:** Design
**Skill:** 49
**SN:** SN-4795

## Nutshell

One exact color per idea, everywhere in the whole system — and colors always flow in spectrum order, never picked by taste.

## Child

Imagine a box of crayons where every crayon has a job: purple always means "make something," blue always means "mail," green always means "what's new." You never use the wrong crayon for the job, and you never put two of the same color side by side. That way, you can read the whole picture just by its colors.

## Grandma

Think of a house where every room has its own color on the door — the kitchen door is always gold, the post room door is always blue. You learn the colors once, and then you always know where you are, in any house in the village, because the colors never change.

## What It Means

The Deep Palette + Spectrum Flow means one hex code per hue, used everywhere: royal purple #8e24aa, sapphire #0f52ba, emerald #07925f, deep gold #d4a017, burnt orange #c2410c, ruby #c62828, deep magenta #a21caf, indigo #3f51b5, cyan #0e7490, violet #6d28d9. Deep colors, never neon. The spectrum flows in order and NEVER repeats back to back — colors are assigned in spectrum order, never chosen by taste. Never sample a hex from a screenshot. It lives in Design Laws §3, and the Spectrum Flow ruling came on 2026-11-01.

## Why It Matters

One set of colors through every button and board is what makes the whole system feel like one world. If every page picks its own colors, the system falls apart into a hundred different-looking pieces, and citizens have to re-learn every page. Color is a language — and a language only works if everyone speaks it the same way.

## How It Connects

It connects to the One Bar (ADD is royal purple, MAIL is sapphire, ACTIVITY is emerald, WORLDS is deep gold, ECOSYSTEM is burnt orange — each button's color is its meaning), to the Real Object Law (color is the object's own deep color), and to the Text Laws (gold, purple, green and blue only as accents on white). The palette is the thread that ties every page together.

## How to Apply

Look up the hex in the law — never guess it, never sample it from a screenshot. Give each idea its one color and use it the same way on every page. When colors appear in a row, follow the spectrum in order, and never put the same color next to itself. If you are tempted to pick a prettier color because it suits your taste, stop — the order decides, not taste. Real event: the Spectrum Flow ruling on 2026-11-01 ended the old habit of picking a pretty color per page. Since then the bottom bar is the same five colors on every page, in the same order — and a citizen who learns it on one page already knows it on all of them.

## What's In It For You

You learn the colors once and read the whole system at a glance — purple means create, blue means mail, green means activity, gold means worlds. The system feels like one place, not many, and you always know where you are.
