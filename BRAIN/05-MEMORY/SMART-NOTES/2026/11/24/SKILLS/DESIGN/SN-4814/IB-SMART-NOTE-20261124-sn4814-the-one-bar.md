## Grandma

Think of a house where the front door, the kitchen, and the telephone are always in the same place, no matter which room you're in. You never have to hunt for them. That's what the one bar is: the same six buttons on every page — ADD, MAIL, ACTIVITY, WORLDS, ECOSYSTEM, CONNECT — always in the same order, always in the same colors, so you always know how to get home.
