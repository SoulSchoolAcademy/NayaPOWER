# The Object Anatomy + The Catalog

## Nutshell

Every object is built the same way — black inside, white as a real object in the middle, light and shadow outside — from a catalog of eight, with every position worked out, never guessed.

## Child

Imagine building with toy bricks. Every house you build has the same parts: a floor, walls, a roof — and every brick snaps into place on a grid, never just stuck wherever. Our buttons and boards are like that: same parts, same grid, every time.

## Grandma

Think of a good dressmaker's pattern: the collar is always cut the same way, the sleeve is always cut the same way, and every measurement is written down, never guessed. Our objects have a pattern like that — inside, middle, outside — and every maker follows the same pattern.

## What It Means

The Object Anatomy + The Catalog is the construction spec for how every object is built. Inside: board black, with no glow inside ever. Middle: the white as a real object, with depth, sitting ON the black. Outside: the light and the lift — a thin bright rim in the object's OWN color, an outside halo, underglow, and a real shadow down and to the right. One light, top-left, every gradient at 135°. Eight objects, one construction each: board, pill button, tile, icon, digit tile, chip/tab, face circle, gauge/dial. Three reference objects to measure against: the top-left +, the Smart Note board, the X button. Spacing in multiples of 8px; every position calculated, never eyeballed. It lives in Design Laws §4.

## Why It Matters

It is the construction spec behind "real" — the reason an object feels touchable instead of drawn. Without it, every maker builds objects a different way, and the system stops feeling like one world. With it, any maker can build any object and have it come out looking like it belongs.

## How It Connects

It connects to the Real Object Law (the anatomy is *how* the law is built), to the Deep Palette (the rim takes the object's own deep color), to the Glow Law (glow sits outside, never inside), and to the Emblem (the quality bar every object is measured against). The anatomy is the recipe; the other laws are the ingredients and the taste test.

## How to Apply

Build every object in three layers — black inside, white as a real object in the middle, light and shadow outside — with the light always top-left and the rim always in the object's own color. Pick the object's type from the catalog of eight and follow its one construction. Measure new work against the three reference objects. Space everything in steps of 8px, with every position worked out, never guessed. Example (illustrative) — a maker building a new pill button does not invent its look: she takes the pill button's one construction from the catalog, checks it against the Smart Note board and the X button, and spaces it in multiples of 8px. The button lands on the page already matching everything around it, because the spec — written into Design Laws §4 — did the deciding before she started.

## What's In It For You

Objects that always feel like they belong together — same light, same depth, same spacing — so the whole system holds together no matter how many hands build it, and every page feels like one world made by one maker.
