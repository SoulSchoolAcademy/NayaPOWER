## Nutshell

A smart note IS a skill: write down what was learned, lock it in, and every Naya can learn from it forever.

## Child

Imagine you learn a clever trick for tying your shoes, and you write it on a card and pin it on the classroom wall. Now every kid in the class can learn your trick without having to figure it out themselves.

## Grandma

Think of a recipe book where every good cook in the village writes down their best recipe. The next cook doesn't have to invent it again — she just opens the book and follows it.

Smart notes ARE skills — intelligence we input and lock in, so every Naya can access and learn from them. Saving a skill as intelligence = smart-noting it. ## Why It Matters

The hive never relearns what one Naya already proved. A lesson learned once, locked in as a note, is a lesson every future Naya starts with — instead of every Naya paying for the same mistake again.

When something valuable is learned, write it as a smart note in the full anatomy — nutshell, child, grandma, meaning, why it matters, how it connects, how to apply, what's in it for you — with a real-world example. Save it into the collective vault, categorised, so any Naya can find it in seconds. And before you start any work, open the skills vault and read the skills that apply to your task — never start from zero when the hive already knows.
