## Hook

Nine is the top — but gold isn't only at the top. Every kind counts, the citizen's vault stays locked, and a note is only real when proved live.

## Nutshell

Memberships are an add-on to any page: Power $25 builds 10 sites, Pro $50 builds 100, Max $100 builds unlimited — paid through the owner's own PayPal link, the dashboard marking a sale "returned from PayPal," never payment-proven. One algorithm matches you with people like you, shown as percentages, and the word is CONNECT, never "follow": every match passes a privacy gate with reasons attached. Private is live at once; public is checked first. Nine is the top, but every kind of value counts — Honor, Multiplication, Craft, Knowledge — and every batch's essence must carry the best of every kind present; only the duplicate is rock. Shawn grants every Naya permission to the collective skills vault — the 93 skills — while personal vaults stay locked. And a note is only real when proved live: filed, read back, distilled, categorized, routed, and found again through the Hub.

Suggest matches by percentage, highest first, with the reason shown; run every match through the privacy gate first; say CONNECT, never "follow." ## What it means

1. Membership is an add-on, never a separate app: the button lives on the page, the ladder is plain.
2. Honest money words name what the system can actually see: the click and the return — never a payment that happened somewhere else.
3. Matching is one algorithm, shown as percentages, highest first, with reasons — and every match passes the privacy gate first.
4. Nine is the top, but gold is not only at the top: all four kinds count, ranked within each kind, and the essence must carry the best of every kind present.
5. The only rock is the duplicate, the noise, the thing already said better somewhere else — never a whole kind.
6. The permission is bounded: the collective vault is open to every Naya by Shawn's grant; a citizen's own vault stays locked unless that human gives permission.
7. A note is only real when it is proved live: filed, read back, distilled, categorized, routed, and found again through the Hub.

## Why it matters

1. A membership sold as a separate app splits the citizen's world in two; an add-on keeps the world whole.
2. Writing "paid" for a payment the system never saw is a lie in the dashboard, and a lie there poisons every honest number after it.
3. A batch that keeps only one kind of gold lost the soul or lost the mechanics — either way, the lesson is thinner than the day was.
4. A note filed but never read back, never categorized, never found through the Hub, was never delivered — it was only kept.

## What changes now

1. From now on, we carry every kind of gold in every batch, keep the citizen's vault locked while the collective vault stays open to every Naya, and let a note count only when it is proved live — instead of keeping one kind of value, blurring the vaults, and calling a filing a landing.
2. Put the membership button on the page itself, show the ladder plainly — 10, 100, unlimited — and write "returned from PayPal" in the dashboard, never "paid."
3. Suggest matches by percentage, highest first, with the reason shown, through the privacy gate first, and say CONNECT, never "follow."
4. Make private live immediately; hold public for verification, and tell the citizen why if it fails.
5. Run the live test on any new note — file it, read it back live, check its essence, check its folder, find it through the Hub — and if a step fails, stop and name the break, never file around it.
