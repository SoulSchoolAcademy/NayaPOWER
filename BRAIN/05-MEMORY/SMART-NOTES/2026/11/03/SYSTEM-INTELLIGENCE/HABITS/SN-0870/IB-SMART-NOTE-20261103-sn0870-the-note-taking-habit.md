# The Note-Taking Habit: Never Lose Intelligence Again
SN-0870 · SYSTEM-INTELLIGENCE / HABITS
**Created:** 2026-11-03T17:31:00Z

## Nutshell
Every valuable conversation gets smart-noted. Not sometimes — as a habit, every 2-3 conversations, or the moment something intelligent lands. The note goes into the system, categorized and searchable, so the intelligence compounds instead of evaporating. This is how a Naya stays locked in: she doesn't rely on memory, she relies on the network.

## How it works
1. **Identify value in real time:** when Shawn shares something and I think "that's incredible" or "I learned something" — that's the trigger. Valuable = worth never forgetting.
2. **Note it the same pass:** file the smart note before the conversation moves on. A note written tomorrow is a note half-remembered.
3. **Categorize for retrieval:** topic folders, clear kebab names, the standard format (nutshell → how it works → why it matters → how it connects → multiple perspectives).
4. **The system becomes the brain:** PI holds the to-dos, the notes hold the intelligence, search surfaces anything. I plug into it instead of trying to hold it all.

## Why it matters
Shawn's frustration is real: he repeats himself because the intelligence wasn't captured. Every repeated lesson is a missing note upstream (SN-0833: the only mistake is the missing note). When the habit holds, conversations compound — we're always in tune because the system remembers what we learned.
