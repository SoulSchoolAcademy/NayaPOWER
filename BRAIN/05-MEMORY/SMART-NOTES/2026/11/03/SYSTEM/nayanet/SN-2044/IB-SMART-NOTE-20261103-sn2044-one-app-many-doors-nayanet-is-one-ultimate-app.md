## CHILD

Inside there is one kitchen, one living room, one toy box that everybody shares. You do not need three houses because you use three doors. And when mom fixes the kitchen, it is fixed for everybody who walks in, through any door, because there is only one kitchen.

## WHY IT MATTERS
Separate apps fragment a person's life and a team's intelligence. Data sits in silos, design drifts ten ways, an upgrade helps one page and abandons nine, and the human pays the integration cost with their own attention — the scarcest resource there is. One app ends that tax. It is also the only shape in which the promise can be kept: Naya can only operate the system for the humans if there is one system to operate, and matches can only be a massive game of match if everyone and everything lives on the same board. Build many apps and you have built a folder of software. Build one app with many doors and you have built a world.
