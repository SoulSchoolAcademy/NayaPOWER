# One Deep Colour per Object — The Spectrum Flows, the Bottom Five Fixed

SN-4895 · DESIGN

**Created:** 2026-11-27T16:54:00Z
**Category:** Design
**SN:** SN-4895

## Nutshell

One deep color per object, as rim and glow. One hex per hue, everywhere — never a second blue, never a color sampled from a screenshot. The spectrum flows and never repeats back to back. The bottom five are fixed, everywhere: ADD royal purple, MAIL sapphire, ACTIVITY emerald, WORLDS deep gold, ECOSYSTEM burnt orange.

## Child

Imagine a row of jewels, each a different deep color — purple, blue, green, gold, orange — marching in order, never two the same side by side. And the five buttons at the bottom always wear the same five colors, on every page.

## Grandma

Dear, each thing gets one rich color, like one good gem — never two the same next to each other, and the colors walk along in order. The five little buttons at the bottom always keep their colors, so you always know where you are.

## What It Means

Design Laws section 3. The deep palette, one hex per hue: royal purple #8e24aa, sapphire #0f52ba, deep emerald #07925f, deep gold #d4a017, burnt orange #c2410c, ruby red #c62828, deep magenta #a21caf, deep indigo #3f51b5, deep cyan #0e7490, deep violet #6d28d9. Deep, not neon. Colors are assigned in spectrum order, cycling — nobody picks a color because it 'feels right'; the order picks it. Never sample a hex from a screenshot: the reference photographs show bright values that predate the deepening. The bottom five are fixed, one bar, everywhere. Why it matters: one set of colors through every button is what makes the whole network feel like one place — and the wrong value breaks it at a glance.

## How to Apply

How it connects: color lives in rims, halos, glows, digits, chips, and orbs — never as fills, never neon — and at rest the page is obsidian and white; color ignites on touch, in the element's own color only. The weekday identity (section 3.3) gives each day its own color and frequency.

## What's In It For You

Every page feels like the same world — the same deep colors, the same five buttons in the same five colors — so you never have to relearn where anything is.
