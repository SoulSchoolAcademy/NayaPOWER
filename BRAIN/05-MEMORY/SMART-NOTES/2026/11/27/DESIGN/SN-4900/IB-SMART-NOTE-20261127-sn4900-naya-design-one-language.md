# Naya Design — One Language, One Pattern

## Nutshell

Naya design is one language, spoken the same way in everything we design, so you can tell it was Naya design because it follows one consistent design pattern. It is multi-dimensional, high active intelligence, living depth. Everything is an object. That is the standard — and the test is whether a stranger, seeing any page cold, knows it is Naya.

## What It's Not

It is not a style pasted on at the end, not a different look per page, and not flat shapes with effects. A page that looks like a picture of an object instead of the object itself is not Naya design, however pretty it is.

## Child

Imagine a family: you can tell the brothers and sisters apart, but you know they are family because they look alike, they move alike, they talk alike. Naya pages are like that. Every page is its own person, but they all speak the same language.

## Grandma

You know how you can tell a good quilt from a shop-bought blanket, because every stitch is done the same careful way? Naya design is like that quilt. Every button, every board, every page is made the same careful way, so the whole thing feels like one home.

## What It Means

Every button, icon, and board is built the same way, in three parts: obsidian black inside, like the Smart Note board; the white in the middle — the glyph, the word, the number — a real object sitting on the black, not writing drawn on it; and the light outside only, a thin rim in the object's own colour, with a real shadow down-right. One light source, top-left, always. When you touch it, it responds like a physical thing: it presses in, the light shifts, it lifts. No glow inside, ever. No grey text, ever. Two formats only: framed and feed. Innovations is the master frame — clone it, never rebuild it.

## Why It Matters

Because Shawn should never have to explain it every single time. When the language is locked in and every Naya speaks it, every new page — Skills, About, membership pages, everything created in the future — comes out right the first time, and a citizen feels at home on every page because every page feels like the same world.

## How It Connects

The written language is the Design Laws, the Naya Code, the Deep Palette, and the Playbook, with the Real Object Law underneath them all. The three reference objects are the measure: the top-left + button, the Smart Note board, and the X button. A checker who cannot name which reference an element was measured against has not checked it. His eye is the final gate.

## How to Apply

Before any build, read the laws first. Harvest the frame verbatim — never invent, never approximate. Measure every element against the three reference objects. If it does not look touchable, it does not ship. If it does not hold at phone width first, it does not ship.

## What's In It For You

Pages that feel like one world, one brand, one family — where everything flows together, everything talks to each other, and nothing has to be explained twice. That is what makes it obvious it was Naya designed.
