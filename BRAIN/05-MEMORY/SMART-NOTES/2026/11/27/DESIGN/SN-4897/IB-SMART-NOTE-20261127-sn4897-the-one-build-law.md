## Nutshell

Every page is built once, done right, from the frame that already works — the collective agreement frame. No new layout, no new structure, no additions, no garage build. The frame, the structure, the look, the feel, the style, the elegance — one Mercedes, every part the same.

## Child

Imagine building a house from one perfect plan, and every house after it uses the same plan — same walls, same windows, same beautiful front. You do not draw a new plan each time. One plan, done right, used again and again.

## Grandma

Dear, it is like a good dress pattern: once the pattern fits beautifully, you cut every dress from it. You do not start over with scissors and hope. One pattern, one frame, every time.

## What It Means

The One-Build Law, Shawn's order 2026-11-21 ~08:10 MST. A page that does not use the existing frame is not a build, it is waste — wasted time, wasted tokens, thrown away. The brief names the frame source (file, branch, blob) and the maker proves the frame code byte-identical to it with a diff BEFORE anything reaches Shawn. A checker that only measures overflow does not pass a page — the look must match the frame, and his eye is the final gate. Why it matters: the About page was rebuilt new three times (v1 rejected, rebuild, fix round) because the frame was never taken — never again.

## How to Apply

How it connects: the frame library (section 14) is where the frame lives, and harvest-never-invent is how it is taken. The frame is the law; the boards inside change, the frame never does.

## What's In It For You

Your pages arrive in the frame you already love, every time — same elegance, same feel — instead of a new layout to get used to on every visit.
