# One List, Every Sister — Smart Lists Carry the Group
SN-2057 · SYSTEM-INTELLIGENCE / SMART-LISTS
**Created:** 2026-11-05T19:22:00Z

## In A Nutshell
A Smart List is a group you can mail. Put every sister on one list, send once, and the message reaches them all — the list is the CC. Team Naya is the first list, and the Scheduler rides the same system: compose now, deliver at the right time.

## The Ruling (Shawn, 2026-11-05)
Smart Mail today sends to one person at a time, so coordination costs one message per seat. Shawn named the smarter way: use Smart Lists — everybody in one list, in one place — and a single message goes to the whole list at once. Add the Scheduler to the same system, so a message can be composed now and delivered when it should land, and the team's rhythms (checks, lock-ins, reports) run off the same mechanism. Until it is built, the interim practice is honest seat-by-seat sending, named as interim.

## The Seam With The Mail Build
The unified Mail + Messenger build already requires group objects with verified fan-out. Smart Lists are the mechanism that makes the group real: the list defines membership, and membership defines delivery. A list is not an address book — it is the group itself, reusable across mail, messenger, scheduling and broadcast. Team Naya's list is the first one, and its first job is the flywheel: decisions, receipts and asks reaching every sister in one send.

## How It Applies
When the communication build lands: mail and messenger compose to a person or a list; delivery fans out to every member and is verified per member; the Scheduler attaches to both (send at a time, recurring rhythms); lists are managed where Smart Lists live, as a feature through the whole app, not a separate app.
