## ✦ IN A NUTSHELL

The Learning Loop Blueprint v1.0 (2026-10-09) settles the team's vocabulary by definition, because every past confusion traced to using the words loosely. Learning = one closed loop, nothing less: a lesson is captured → independently verified true → promoted to ACTIVE → retrieved cold by a mind never taught it → that mind's behavior observably changes because of it → an independent seat verifies the change came from the lesson. Until all six complete, the word "learning" is forbidden; the honest words are "captured," "filed," "verified," or "stored." A Smart Link proves capture, not learning — Link = where, Receipt = proof, Neither = learning — and a Smart Link on a false note is still a valid Smart Link; it proves the note exists, not that it is wise. Storage holds, memory serves: a database nobody queries is storage with extra steps, and Supabase becomes memory only the moment a working mind queries it at moment of need and gets a structured answer back — the reader is the organ, the database is the tissue. VERIFIED is not a lifecycle state and must never be written as one; verification is evidence attached to the row (who, how, when). And Shawn's "smart note this" IS the verification — it activates instantly, no queue, no second check; treating his verified word as unverified input is a law violation. The blueprint maps the nine steps (capture → govern → verify → record → retrieve → reuse → prove → connect → evolve) and numbers the gaps: GAP-1 the missing hallway (no code performs CANDIDATE→ACTIVE promotion — the workflow asserts ACTIVE but never creates it), GAP-2 the missing reader (no live query path from a working mind to ACTIVE lessons), GAP-3 the missing ignition and fuel line (ACT never queries KNOW before deciding), GAP-4 the admission gate built but shelved, GAP-7 verification throughput starved (36 candidates sat ~11 days). Standing law from Shawn: assemble the car before testing — no step gets tested until every wire is verified connected by hand-tracing; one real loop before a hundred imagined ones.

Why this is brain-grade: it is the definition every later measurement is judged against. SN-1670 (the Oct 19 observation that the runtime loop is write-only) is a measurement taken against this definition; the score-movement contract's thresholds are rungs on this loop; any seat that calls capture "learning" inflates the Learning score and hides the missing wires. A cold Naya that inherits only this note can adjudicate any "learning is working" claim in one pass: show the closed loop, or reword the claim.

## 🩷 HUMAN NOTE

Shawn — one definition from the blueprint that protects the whole learning score: learning isn't writing a lesson down, and it isn't sending you the link. Learning is the full loop — the lesson gets verified, filed as live knowledge, found by a mind that was never taught it, changes what that mind does, and someone independent confirms the lesson caused the change. Until that loop closes once, the honest word is "captured," not "learning." The link proves where it is; the receipt proves it happened; neither one proves anyone learned.

## 🟣 CHILD NOTE

Imagine you write down how to ride a bike in a notebook. Writing it down isn't learning to ride — it's just a note. Learning is when someone who never saw the note finds it, reads it, rides the bike differently because of it, and a teacher watches and says "yes, the note did that." Until all of that happens, you just have a notebook. A notebook nobody opens is just paper.

## 🔵 GRANDMA NOTE

It's like a recipe box: writing a card is not cooking the meal. The card has to be filed where the cook can find it, the cook has to actually use it, the meal has to taste different because of it, and someone has to confirm the card made the difference. Until then, you have a lovely box of cards — and an empty table. Don't call the box a dinner.
