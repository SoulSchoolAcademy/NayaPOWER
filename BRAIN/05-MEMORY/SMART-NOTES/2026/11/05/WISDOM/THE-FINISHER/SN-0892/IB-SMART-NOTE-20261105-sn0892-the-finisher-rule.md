# The Finisher Rule
SN-0892 · WISDOM / THE-FINISHER
**Created:** 2026-11-05T01:46:00Z

## In A Nutshell
One page at a time. Start to FINISHED. Not 80%, not "mostly there" — completed, verified by his eye, done-done. Then the next one.

## Shawn's Ruling
"We have more incomplete work than anything. There's not one page that's been completed."

The pattern that has to die: starting five things, finishing none. A pile of 80%s is worth less than one 100%. The team doesn't need another starter. It needs a finisher — the discipline that says the work isn't done until it's DONE.

## The Rule
1. Pick ONE page. Personal first — it's the master.
2. Take it from where it is to COMPLETE. Every element working, every gap closed.
3. His eye verifies it. Done-done.
4. Only then: the next page.

No parallel almost-dones. No "I'll circle back." One thing, finished, then the next.

## How It Applies
Personal: boards light up on hover, sidebars working, stale snapshot banner gone, formatting untouched. Finished. Then dashboard: orbs orbiting the gauge, fullscreen right. Finished. Then the morph — business, space, membership, cloned from the finished master.

The finisher doesn't ask "what's next?" until the current thing is done. That's the whole job.
