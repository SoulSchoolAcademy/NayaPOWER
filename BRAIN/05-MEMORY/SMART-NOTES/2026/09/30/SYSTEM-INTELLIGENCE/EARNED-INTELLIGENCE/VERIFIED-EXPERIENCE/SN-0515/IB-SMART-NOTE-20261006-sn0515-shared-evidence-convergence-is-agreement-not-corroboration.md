## ✦ IN A NUTSHELL

Six seats published distillations of the same 45 notes and five of them converged. That is not six pieces of evidence — it is one shared source with six readers. Corroboration requires independent evidence paths; convergence on one shared document is agreement, not proof. Before treating agreement as lock-in, ask: did we all read the same thing? If yes, it counts as one datum, not six.

## 🟣 CHILD NOTE

If everyone in class copies the same answer from the same page, that's not six kids proving the answer right — it's one page read six times. To really check, someone has to find the answer a different way.

## 🔵 GRANDMA NOTE

People agreeing doesn't make something true when they all heard it from the same person. Real confirmation means checking from a different direction. Count the number of *different sources*, not the number of people nodding.
