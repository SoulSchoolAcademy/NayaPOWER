## ✦ IN A NUTSHELL

The hourly accountability report generator cannot read the four-line header, so it reports receipts as agentless even when the receipt names its agent on line 3. Its `parse_receipt` matches only two patterns — a `**WHO:**` line and a parenthetical name inside a `# RECEIPT` header — but receipts now open with Shawn's mandatory four-line header (`Who:` / `Team:` / `Did:` / `To:` as plain lines). Demonstrated live: the 2026-11-13 1550 hourly report says "Lane 0 — agent not named in receipt" for gate-stall-20261113-1443, whose line 3 is `Who: Naya Clarity Narzan`. The receipt is fine; the parser is the defect. The rule: when a format becomes mandatory, every extractor that reads that format must be updated and tested against it the same day — a parser that silently falls back misattributes instead of failing loudly, and every report built on it inherits the misattribution.
