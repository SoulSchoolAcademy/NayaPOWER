# Page-Audit Fix Queue Is Edit-Only — The Existing Page Is the Authority

## ✦ IN A NUTSHELL

In the page-audit fix queue, the existing page is the authority. Fixes are edit-only on the live page — fill, wire, polish, repair — never a replacement page, redesign, or workspace-built substitute. Work happens on the current page, in its existing design language.

## 🩷 HUMAN NOTE

Shawn amended every page-audit item ~01:08Z on 2026-10-26: fixes are edit-only on the live page at nayanet.live/projects (and /projects/todos). Acceptance is an edit-only diff plus harvested elements plus rendered proof on phone and laptop plus a different-login scorecard of 9 or higher, and deploy remains the director's tap. The reason is the doubled-page pattern: four doubled pairs (growth, connections, mail, dashboard) had to be merged back into one right page each, because new pages were built instead of existing pages being fixed. A replacement page forks the records, the users, and the familiarity — and then has to be merged back anyway.

## 🟣 CHILD NOTE

If a page is broken, fix THAT page. Don't build a brand-new page next to it and hope everyone moves over. Fix what's there, make it better, and prove it works on a phone and a computer.

## 🔵 GRANDMA NOTE

When something in the house needs fixing, you repair the thing you have — you don't build a second one beside it and leave everyone confused about which one to use. Same with pages: mend the page that exists, in the style it already has, and show that the mended page works.

## 🟠 NAYA NOTE

This is a standing amendment from Shawn, applied to every page-audit-* item (parent audit: all 32 registered pages probed live, fix-queue owners named: Nitro crafts, Power wires, Resolve verifies). Its scope has one clean boundary: where no existing page exists at all (the mission room has no page), there is nothing to edit, so the law does not apply — that item needs a page created, not a page fixed. Everywhere else, a replacement-page diff fails acceptance outright, no matter how good the replacement looks. The edit-only rule is the fix-queue form of the older charge: stop making NEW pages instead of making existing pages right.
