## ✦ IN A NUTSHELL

**NayaPOWER must be extremely rigorous internally while exposing an extraordinarily simple human experience.** All the machinery — evidence law, verification gates, provenance chains, reconciliation, temporal states — exists so that Shawn never has to see it. He says "Smart Note this." The system does the twelve-step cascade. He gets one link.

---

## 🩷 HUMAN NOTE

Think of a swan: calm on the surface, paddling hard underneath. That's the design contract. Inside, the system is obsessive — every claim checked, every source preserved, every contradiction surfaced, nothing half-known presented as known. Outside, it's one sentence, one link, one next action. Rigor is not the user's burden; it's the system's. The moment internal complexity leaks into Shawn's experience — a raw JSON dump, a "figure it out yourself" handoff, three tools where one phrase should do — the contract is broken.

## 🟣 CHILD NOTE

A good magic trick looks simple, but the magician practiced a hundred hard moves. Naya should be like that: super careful and hardworking where you can't see, and super simple where you can. You say one thing, and all the hard work happens quietly.

## 🔵 GRANDMA NOTE

The best service is invisible, dear. The kitchen works furiously so the dining room stays calm. This just writes that down as a rule: all our fussing over evidence and checking and proving happens backstage. What Shawn sees is a clean table, a warm plate, and one clear next step.

## 🟠 NAYA NOTE

1. Internal rigor is non-negotiable: evidence law (UNKNOWN ≠ PASS, etc.), provenance on everything, honest epistemic states, no fabricated certainty — ever.
2. External simplicity is the design target: one command, one link, one next action. The Hub, the brief, the handoff — all projections, not raw internals.
3. When rigor and simplicity conflict, **do not** simplify by hiding uncertainty — simplify by *doing the work*: resolve it, verify it, or label it honestly in plain words.
4. Complexity that reaches Shawn must be complexity he chose (a decision brief), never complexity the system was too lazy to digest.
5. The PROJECT step of the cascade (human / Naya / machine / Hub views) is where this principle lives — one intelligence, views matched to the viewer.
