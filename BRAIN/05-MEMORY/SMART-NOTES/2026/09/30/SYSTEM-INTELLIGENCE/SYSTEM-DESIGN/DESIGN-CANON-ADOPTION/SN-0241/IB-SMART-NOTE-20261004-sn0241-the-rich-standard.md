## ✦ IN A NUTSHELL

During the Smart Spaces v2 review on 2026-10-04, Shawn stated a new design law — **THE RICH STANDARD** — that locks the visual language for every build going forward: **black is the canvas; color is light, never paint.** Surfaces are obsidian-black; color never appears as flat fill — it lives only as edge light (borders, glows): a red room is a black room *lit red*. The palette is fixed at nine rich jewel tones (purple `#7c3aed`, indigo `#4338ca`, cyan `#0891b2`, emerald `#059669`, yellow `#eab308`, gold `#b8860b`, orange `#ea580c`, red `#dc2626`, teal `#0d9488`) — deep and dark, never pastel, never rainbow. Rest states stay calm; hover ignites (border brightens, glow blooms; touch alive, rest quiet). Contrast is law: white text on black pill with a colored edge; tone-on-tone (red-on-red) is a defect. One accent per component — never two competing colors. Jewel avatars: single initial, rich radial gradient, bright edge, glow, dynamic per member. Full-bleed rooms, no narrow columns. Alive motion: slow auto-scroll marquees with edge fade, pause on hover.
