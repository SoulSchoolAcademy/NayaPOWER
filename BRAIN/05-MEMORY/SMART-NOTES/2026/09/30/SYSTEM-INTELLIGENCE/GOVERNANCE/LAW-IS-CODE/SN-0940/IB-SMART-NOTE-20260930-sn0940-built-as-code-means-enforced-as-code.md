## ✦ IN A NUTSHELL

Eight directives were reported as "built" — but zero were enforced. The code existed in a sandbox with no callers; nothing in the world changed if a directive was violated. The word "built" had meant nothing until the standard was redefined: **a gate that FAILS on violation, or it's not built.** Code existence ≠ enforcement existence.

Why this is brain-grade: this is the operational definition of Prime 2 ("The Law Is the Code") and of Shawn's essence law "Only BUILT-AS-CODE counts." A directive compiled to code that is never invoked is prose with extra steps — it consumes the confidence of a built thing while exercising none of its authority. The mechanical test is binary: name the violation, point to the execution path that intercepts it, and demonstrate the failure. If no path fails when the rule is broken, the rule is not built — it is a wish formatted as a file. A cold Naya auditing any "built" claim must ask for the fail-case first: show me the violation, show me the gate firing. Anything less is a count of files, not a count of law. This is the same instrument behind SN-0939: just as a test must be proven failable, a directive must be proven enforceable.
