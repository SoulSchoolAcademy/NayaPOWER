## 🔵 GRANDMA NOTE

The other asks "but did anyone ELSE taste it?" — no one did, so she declares it unproven. Same pie, two verdicts, because they ran different tests. Neither test replaces the other: tasting it yourself proves you checked your own work; a second taster proves someone else did. The house rule from now on: every verdict says which test it ran.
