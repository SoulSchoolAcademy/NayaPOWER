## HUMAN NOTE
The seats' own memory system turned its audit inward and found its map didn't match its territory. The registry — the thing everyone reads to know what intelligence exists — was missing a third of the corpus, pointed at the wrong version of a note, gave two notes the same number, and carried hashes that match nothing. Meanwhile every note's boilerplate promised a direct Smart Link that doesn't exist in a single one of them. The durable lesson Shawn's whole project teaches here: the pipeline that stores intelligence must be held to the same verification standard as everything else it verifies. Re-derive registries from disk, generate hashes in the loader, and treat a promised-but-never-delivered field as a defect, not a wish.

## CHILD NOTE
Imagine a library with a card catalog that says there are 19 books — but there are actually 30 on the shelves, and one card points to the wrong shelf, and two cards have the same number. A person using the catalog would be lost. That was the smart-note registry. The lesson: the catalog has to be rebuilt from the actual shelves regularly, and any card that claims something (a secret code, a link) has to actually be true — or the card gets thrown away. A catalog that lies is worse than no catalog.

## GRANDMA NOTE
The index is only as honest as the last time someone checked it against the real thing. The audit found the smart-note index out of sync with reality in five different ways — missing entries, wrong pointers, duplicate numbers, hashes matching nothing, and promises of links that were never built. The standing fix is simple: indexes get regenerated from ground truth, never hand-maintained; anything the index claims must be mechanically verifiable; and anything promised in the standard text must actually exist, or the text must stop promising it.

## NAYA NOTE
For me, months from now: when you maintain any registry — of notes, blocks, laws, anything — treat it as CANDIDATE metadata until it is re-derived from disk. The failure pattern to memorize: (1) hand-maintained registries drift — index 19, disk 88; (2) identity drift — one ID, two divergent texts, no supersession marker; (3) number collisions need a director decision, not a silent pick; (4) hash fields are claims against the artifact, not the runtime — regenerate them at write time; (5) boilerplate promises ("a direct Smart Link") that no generator fulfills are defects in the boilerplate. This audit's method is the reusable part: enumerate the ground (disk), enumerate the claims (registry), diff every field, score it. The Smart Link gap also names the real open work: either build the link generator or remove the promise — under SN-0269's law-as-code discipline, an unenforced promise is not law.
