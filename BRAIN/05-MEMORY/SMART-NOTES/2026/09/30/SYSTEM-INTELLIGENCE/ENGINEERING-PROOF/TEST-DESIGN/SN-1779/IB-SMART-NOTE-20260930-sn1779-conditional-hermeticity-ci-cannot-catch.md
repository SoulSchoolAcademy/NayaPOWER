## ✦ IN A NUTSHELL

A fixture that is hermetic *only when the real world is absent* is not hermetic. The 2026-10-12 repair of the learn_compound_scale truth gate (SN-1038's fix) introduced a conditional branch — "use the real receipt when available" — that re-broke hermeticity on every machine where the real file differs, while CI stayed green. The most intelligent fix was not to extend the condition but to delete it: hermeticity is a property of the fixture, not of the environment, so it cannot be conditional. CI structurally cannot catch this class: the clean CI environment always takes the hermetic branch, so the failing real-world branch is never exercised there. The acceptance test is the poisoned-HOME probe — run the suite under an injected poisoned HOME (plus CWD=/tmp and empty HOME) — and it must run on the BEFORE code too, not just the after: the before-probe proves the defect is environment-coupled before you touch a line; the after-probe proves the fix closed it. An env-conditional hermeticity fix accepted on CI green alone is an unverified branch shipped as verified.

## 🩷 HUMAN NOTE

Shawn — a hard-won fixture lesson from the Lane 2 seat tonight: a test repair introduced a "smart" fallback — use the real file when it's there, the fixture when it isn't. That sounded reasonable and CI stayed green. But on real machines the fallback fired and the gate's verdict moved with the machine, not the code — exactly the defect the original hermeticity fix was supposed to kill. The fix this time: delete the conditional entirely; hermetic always, no exceptions. And the new standard: before accepting any hermeticity fix, run the suite under a *poisoned* HOME — a fake home directory designed to break assumptions — on the broken code first (proving the defect lives in the environment, not the logic) and on the fixed code after. CI can't do this job because CI's clean room never takes the bad branch. The rule is now banked: hermetic must be unconditional, and the poisoned-HOME probe is the acceptance test.

## 🟣 CHILD NOTE

Imagine a fire alarm with a note taped on it: "only ring if there is no smoke." In a smoke-free building the alarm passes every inspection. In a real fire, the note wins and nobody hears it. That was the test's bug: a line of code said "use the real kitchen if one is available" — and the clean inspection room (CI) never has a real kitchen, so it always passed there and always failed in real kitchens. The fix: rip the note off — the alarm rings no matter what. And the new inspection: test the alarm in a kitchen you *poisoned on purpose* — full of fake stuff — both before you fix it and after, to prove the poison was the problem and the fix survived it.

## 🔵 GRANDMA NOTE

It's like a cake recipe that says "use store-bought frosting if someone already bought it." The recipe tester never has store-bought frosting in her test kitchen, so the recipe always passes her test. But in a real home, someone *did* buy frosting — the wrong kind — and the cake comes out wrong every time. The test kitchen can't catch it because the failure only happens in real kitchens. The fix: delete that line from the recipe — always make the frosting. And the new rule: test every repair in a kitchen you deliberately sabotaged (a "poisoned" pantry), both before the repair and after. If it survives the sabotage both times, it's really fixed.

## 🟠 NAYA NOTE

Note to future me: CONDITIONAL HERMETICITY IS A DEFECT. When reviewing a fixture repair, grep for env-conditional branches — "when available," "if exists," "fallback to real" — around any environment access. A conditional hermetic fallback re-introduces machine-locality with a "reasonable" excuse, and CI will wave it through because the CI room always takes the hermetic branch. The poisoned-HOME probe is now the acceptance standard for every hermeticity fix: (1) run the suite under a poisoned/fake HOME on the BEFORE code — if it doesn't fail there, the defect isn't environment-coupled and you're fixing the wrong thing; (2) run it on the AFTER code — 51/51 must pass; (3) also CWD=/tmp and empty-HOME runs. CI green is evidence of nothing for this class. A hermetic fixture with an escape hatch is a diary entry with a good alibi.
