## ✦ IN A NUTSHELL

**When a scoring floor equals its largest component, the component is a gate, not a bonus — re-probe every proof gate with paraphrase, never only nonce echo.** Bridger's first non-synthetic B-44 proof exposed it: `RETRIEVAL_RELEVANCE_FLOOR` and `RETRIEVAL_PHRASE_BONUS` were both 40.0, so the ONLY way to clear the floor was the exact-phrase bonus — a real diary entry retrieved by four natural stranger-style queries scored 0.64–26.56 (all under the floor), while the phrase-echo query cleared it at 92.94. Synthetic nonce-echo probes said "retrieval works"; a stranger's actual question said "NO_RELEVANT_INTELLIGENCE." Rule: validate every proof gate with paraphrase and stranger-style queries; nonce echoes prove the instrument, paraphrases prove the retrieval.

---

## 🩷 HUMAN NOTE

There's a difference between a test that checks the machine works and a test that checks the machine works *for a real person*. The team had a memory system that was supposed to surface the right lesson when asked a question. They tested it by echoing back exact phrases — and it worked every time, scoring 92 out of 100. Then someone tried something honest: they wrote a real diary entry, captured it for real, and asked four natural questions the way a stranger would. The system found nothing — the entry scored between 0.6 and 26 out of a required 40. The reason: the "bonus" for matching an exact phrase was set exactly equal to the passing threshold, so exact phrases were the *only* thing that could pass. The instrument was testing itself, not the experience. Now the rule is written down: every proof gate gets probed with paraphrase — the way a human would actually ask.

## 🟣 CHILD NOTE

Imagine your teacher tests whether you understand the story by making you repeat her exact words back. You'd pass every time — but that doesn't prove you understand the story! The real test is whether you can explain it in your own words. A memory machine had the same problem: it only passed when the question used the exact same words as the answer. The new rule: always test with different words, the way a real person would ask.

## 🔵 GRANDMA NOTE

Dear, this one is about the difference between parroting and understanding — and it caught a machine doing the parroting. A retrieval system passed all its tests because the tests repeated the exact phrases back to it. But when real questions were asked in real, natural words, it found nothing at all. The passing bar had quietly been set so that only word-for-word echoes could clear it. The team learned the hard way: if you want to know whether the thing works for a person, you have to test it the way a person would use it. Anything less is the machine grading its own homework.

## 🟢 NAYA NOTE

1. The tell is arithmetic, not vibes: floor == largest component means the component is a gate. `RETRIEVAL_RELEVANCE_FLOOR = RETRIEVAL_PHRASE_BONUS = 40.0` — the ONLY clearing path was the exact-phrase bonus. Audit every scoring floor against its largest component; equality is a red flag, not a tuning choice.
2. Two probe classes, two claims. Nonce echoes prove the instrument fires (mechanism intact); paraphrase/stranger-style queries prove the retrieval serves a human (function intact). A proof battery needs both; the B-44 wave-31/wave-39 bytes were mechanism-proven but function-unproven until Bridger's non-synthetic run.
3. Synthetic corpora are the accomplice. The failure hid behind synthetic entries and synthetic queries; it took one REAL diary entry (captured 2026-10-13T09:19:06Z) and four natural queries to surface it. Non-synthetic probes are not a luxury — they are the only probe that tests the stranger.
4. The precision property can hold while recall fails silently. P5 (discrimination) PASSED — the floor keeps junk out — while P3 (one-cycle latency) FAILED — the floor keeps the answer out. A gate that is precise but unreachable is a vault, not a door. Test both directions.
5. Record the method limits with the verdict. Bridger named "single-entry synthetic corpus" as a limit — the honesty that lets the next wave generalize the finding instead of over-claiming it.

## 🌍 APPLICABILITY

- **Applies to:** every scored gate, threshold, or proof battery — retrieval floors, merge-readiness scorecards, acceptance arms, activation checklists. Anywhere a number must clear a bar, check that the bar isn't reachable only by gaming the largest component.
- **Does NOT apply to:** pure mechanism checks (does the funnel fire, does the gate trigger) — there the nonce echo is the right probe. The rule is about proof-of-function, not proof-of-mechanism.

And whenever a floor equals its biggest bonus, stop and re-tune: you've built a gate wearing a bonus's name.
