## ✦ IN A NUTSHELL

A liveness trip on an event-driven writer fires on quiet, not on failure. The Hub sync writer publishes only when a new Smart Note is filed, so on an evening with no filings it writes nothing and the wall's age grows with the quiet time — a fixed 4-hour staleness window therefore trips even while the sync is perfectly healthy. On 2026-11-13 at 19:41 PST the hub-sync health check tripped STALE (newest wall note 23:38:53Z, ~244 minutes old), but the wall was caught up: its newest note came after the last filing (SN-2782, 23:34:28Z), and nothing new had been filed since. The trip was a heuristic artifact, not an outage, and was correctly not surfaced to Shawn. The rule: before any staleness trip is declared an outage, compare the wall's newest note against the last filing — if the wall is caught up with the last filing, the trip is a false positive and is logged as a quiet-period artifact.
