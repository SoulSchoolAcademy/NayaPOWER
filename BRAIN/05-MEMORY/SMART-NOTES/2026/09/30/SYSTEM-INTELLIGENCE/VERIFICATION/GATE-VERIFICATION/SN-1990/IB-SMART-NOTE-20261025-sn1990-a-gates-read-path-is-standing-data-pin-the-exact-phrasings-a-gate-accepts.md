## ✦ IN A NUTSHELL
A gate's read path is standing data — pin the exact phrasings a gate accepts, and test the gate against the snapshot's actual bytes, not its assumed bytes. The distill-daily receipt independently reproduced a board-rotation drift and pinned its root cause: `boot_pointer_check.py`'s `LIVE_BOARD_RE` tolerates bold and whitespace after "board" but NOT a colon, while the snapshot it reads writes "Live board: #3066" (colon form) — so the gate went DEGRADED on a formatting drift, and the real violation (main's mission-state file still the 2026-10-22 version naming retired board #2793) hid behind the same DEGRADED label. A fail-closed gate firing on phrasing is not the same as a gate firing on a violation, and the two must never share one undifferentiated label. Read-path phrasing is not decoration: it is the data the gate actually reads, so it is pinned like any other standing data, and the gate is tested against the bytes its input really carries.

## 🩷 HUMAN NOTE
Imagine a guard at a door who has been told to let in anyone who says the password in exactly one way — "the board is number three-oh-six-six" — but the messenger arrives saying "the board: three-oh-six-six," with a little pause where the colon sits. The guard does not recognise the pause, so he slams the door and shouts that something is wrong. Meanwhile, behind him, the real problem sits unnoticed: the old map on the wall still points at the retired board. The guard's shout was about the pause, not the map — but everyone heard one shout and assumed one problem. The lesson: write down exactly which wordings the guard accepts, test him with the messenger's actual words, and make his shout say whether he stopped a wording or a real violation — because one shout covering both hides the real problem.

## 🟣 CHILD NOTE
Imagine a robot that opens a box only when it hears "open box" — but your friend says "open: box," with a funny pause. The robot gets confused and says "SOMETHING IS WRONG!" — even though the real wrong thing is that the box still has the old label on it. The robot's alarm was about the pause, not the label, but it only has one alarm sound, so nobody can tell which problem it found. The rule is simple: teach the robot every way your friend might say it, test it with your friend's real words, and give it two different alarm sounds — one for "I didn't understand the words" and one for "the label is really wrong."

## 🔵 GRANDMA NOTE
Dear, this one is about a checking gate that cried wolf on the wrong thing. The gate reads a snapshot file to learn which board is live. Its pattern allows bold print and spaces after the word "board," but not a colon — and the snapshot writes "Live board: #3066," colon and all. So the gate failed closed, shouting DEGRADED, over a punctuation mark — while the genuine fault, main's mission-state file still naming the retired board from three days earlier, hid behind that same shout. A gate that cannot tell "I misread the wording" from "I found a real violation" is a gate that hides the violation it exists to catch. So the standing rule is plain: pin down, in the gate's own notes, every wording it accepts; test it against the file's real words, not the words you imagined; and never let one label cover two different causes.
