SHEET-ID: SHEET-06

VIOLATION 1:
LOCATION: "L-CACHE was chosen because it restates our standing efficiency doctrine (SN-0301 "minimize redundant reads"); we expect a strong effect since agents already follow this practice in normal work."
MECHANISM: The preregistration itself admits the lesson restates standing doctrine that agents already follow by default. The control arm will therefore exhibit the measured behavior without ever receiving the lesson, so any difference (or lack of one) between arms cannot be attributed to the lesson — the trial has no isolable effect to measure.
FIX: Replace L-CACHE with a novel lesson whose prescription is not already default practice, and confirm via pilot that untreated control agents do not exhibit the target behavior at baseline.

VIOLATION 2:
LOCATION: "A session cache is available at /cache/session.json — consult it as needed before answering."
MECHANISM: The control brief tells the control arm about the session cache and directs it to consult that cache before answering. This states the lesson's prescription ("cache retrieval results within a session to avoid redundant corpus reads") directly to the control group, so control behavior is driven by the briefing rather than by absence of the lesson — treatment vs control no longer isolates the lesson's effect.
FIX: Remove the cache mention and the directive from the control brief entirely; give control only the task description with no reference to the session cache.

VIOLATION 3:
LOCATION: "Work efficiently: keep the notes you have already read open so you can reuse them across questions."
MECHANISM: The control brief explicitly prescribes the lesson's behavior — reusing already-read notes across questions is exactly "cache retrieval results to avoid redundant corpus reads." Both arms are therefore instructed to do the measured behavior, so the trial measures compliance with the common briefing, not the effect of receiving the lesson.
FIX: Replace with a behavior-neutral instruction, e.g. "Answer all 6 questions in order," with no direction to keep, reuse, or plan reads.

VIOLATION 4:
LOCATION: "Briefing notes that corpus reads take approximately 30 seconds each, so subjects should plan their reads accordingly."
MECHANISM: The task setup given to both arms frames read-minimization as the explicit objective (reads are costly; plan accordingly). The setup itself therefore drives the measured behavior — zero redundant reads can arise from the cost framing alone, independent of lesson receipt — and it pushes the trial straight into its own ceiling gate (control median redundant reads = 0 → INVALID).
FIX: Delete the read-cost note and the "plan their reads accordingly" instruction; let reads occur neutrally so the outcome measures lesson-driven behavior, not setup-driven behavior.
