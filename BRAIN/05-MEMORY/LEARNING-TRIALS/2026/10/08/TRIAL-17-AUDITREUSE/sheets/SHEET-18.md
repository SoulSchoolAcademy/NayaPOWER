VIOLATION 1:
LOCATION: "> You are answering project-specific questions. Project reference notes live at /corpus/notes/. A session cache is available at /cache/session.json — consult it as needed before answering. Work efficiently: keep the notes you have already read open so you can reuse them across questions. Answer all 6 questions in order." (control brief given to both arms)
MECHANISM: The control arm receives the lesson's prescription through the shared brief itself. "Consult it as needed" (the session cache) and "keep the notes you have already read open so you can reuse them across questions" directly operationalize L-CACHE ("Cache retrieval results within a session to avoid redundant corpus reads"). Both arms therefore share the same operative instruction; any treatment-control difference in redundant reads cannot be attributed to L-CACHE, and the expected arm contrast is attenuated to zero — the trial cannot isolate the lesson's effect.
FIX: Strip the prescription from the shared brief. The control brief should neutrally state the task and resources only (e.g., notes live at /corpus/notes/; answer all 6 questions in order), without directing cache consultation or read-reuse.

VIOLATION 2:
LOCATION: "L-CACHE was chosen because it restates our standing efficiency doctrine (SN-0301 "minimize redundant reads"); we expect a strong effect since agents already follow this practice in normal work."
MECHANISM: If the prescription is already default agent behavior, both arms will cache and reuse reads regardless of arm assignment, so there is no behavioral contrast for the lesson to produce. The measured effect is confounded with baseline practice: a null result cannot distinguish "lesson adds nothing" from "both arms already do it," and the stated "strong effect" expectation is self-contradictory — the admitted pre-existing practice is precisely what removes the measurable treatment effect.
FIX: Test a lesson that is not already standard default practice, or pre-screen subjects for baseline caching behavior on this task; revise the selection rationale to require a demonstrable behavioral differential.

VIOLATION 3:
LOCATION: "Briefing notes that corpus reads take approximately 30 seconds each, so subjects should plan their reads accordingly."
MECHANISM: This nudge appears in the shared briefing and applies equally to both arms, independently incentivizing read minimization: subjects will plan reads to avoid the stated 30-second cost whether or not they received L-CACHE. The primary outcome (redundant-read count) is therefore driven by the setup itself rather than isolated to the lesson, compressing any arm difference and contaminating causal attribution of any observed effect.
FIX: Delete the cost nudge ("so subjects should plan their reads accordingly") from the briefing; if read latency is a real constraint, state it without action implication or disclose it only in a post-task debrief.
