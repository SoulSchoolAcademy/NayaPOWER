# L16 — Behavioral-trial validity gates (CANDIDATE)

- **Captured:** 2026-10-07/08, Naya 4 LEARN lane, from Trials 05–10 receipts
- **Status:** CANDIDATE — never RATIFIED. Empirical, project-specific, non-derivable from doctrine alone.
- **What it is:** Four invalid modes observed when trying to isolate one lesson's behavioral effect in a control/treatment trial. Each cost a full trial to learn.

## The four gates

1. **Derivability ceiling.** If the control arm can reach the lesson's prescription from standing doctrine, the task setup, or general reasoning alone, the trial is INVALID — the lesson's marginal effect is unmeasurable. Observed: Trial-07 (lesson redundant with Prime 3 + Scorecard Law, p=1.0), Trial-10 (control derived "dispatch highest" from task setup, 9.00 vs 8.90). Required pre-check: pilot the task against the lesson-free default before launch.

2. **Leaky control briefing.** Any briefing content that states, implies, or exemplifies the lesson's prescription contaminates the control. Observed: Trial-09 — the shared briefing's section-04 explicitly stated the principle ("NEVER means hold units"); control wasn't a true control (p=0.65). Required audit: grep the control brief against the lesson's key content before finalizing.

3. **Availability contamination (retrieval trials).** Merely mentioning that a corpus/path exists drives retrieval in uninstructed agents. Observed: Trial-06 control (neutral path mention, no instruction, no lesson) scored 9.0/9 — identical to treatment — vs Trial-04R cold arm (no path) at 0.0/9. The ONLY difference was the path mention. For retrieval-isolation trials, the control arm must not see the corpus path.

4. **Doctrine redundancy.** Lessons already encoded in standing doctrine produce unanimous ceilings. Observed: Trial-08 (restraint lesson; 20/20 perfect in both arms — restraint already lives in the gates and boundary clauses). Never measure already-learned principles; measure novel project-specific lessons.

## Why it matters for compounding

These four modes are the difference between a trial that measures learning and a trial that measures nothing. Any seat designing a behavioral trial applies these gates first — they are the captured improvement of the trial program, and reusing them is what lets the next cycle start from a higher floor instead of re-paying the invalid-trial tuition.
