# Decision Protocol (Shawn, 2026-10-01)

When a decision is needed: (1) frame options honestly; (2) run gates first — protected boundaries (merges, production deploys, ratification, destructive, privacy/consent/security/authority) are never inferred away; (3) score with the V2.1 Decision Value Calculus; (4) decisive winner → decide, act, report; (5) close scores or ranking-flipping unknown → investigate cheaply or escalate. Every decision reported with scores, rationale, reversibility, and an open invitation for challenge.
