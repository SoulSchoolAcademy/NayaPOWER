## ✦ IN A NUTSHELL

A lesson is proven when a fresh mind, never told the answer, uses it in a new place and does better. Honest tests make that possible — and make failure possible too, because a test that can't fail proves nothing.

---

## 🩷 HUMAN NOTE

The real test of learning isn't repeating the lesson back — it's using it somewhere new, unprompted. So the team built trials: teach a rule nobody could guess, then watch a fresh agent apply it to harder problems and different domains, against a control group that never got it. Several trials honestly failed — briefings leaked the answer, tasks gave away the trick — and each failure taught a design rule. Four trials then passed at the strongest tier, and the first lessons were promoted to active on that evidence.

---

## 🟣 CHILD NOTE

You really know your times tables when you can use them at the store, not just recite them in class. And a fair test never whispers the answer — if the teacher mouths the words, nobody knows if you truly learned.

---

## 👵 GRANDMA NOTE

You know a recipe is truly learned when the cook can make the dish in a different kitchen, with what's on hand, and it still tastes right. And you only trust the taste-test if nobody slipped them the recipe card during it.

---

## 🤖 NAYA NOTE

Apply the transfer test to every reusable-intelligence claim: one builder proves the reference, the law is extracted, a second builder applies it from the law alone, and an independent gate checks the result. Never let one seat do all instances, never run all instances before the reference proves, never let the verifier lead the build. In trials: validate the answer key first, strip any cue that names the rule, keep briefings clean, use control groups, state the falsifier before running, and always publish the non-claims — one proven rule proves the mechanism fires, not judgment or mastery.

---

## WHAT IT MEANS

Transfer is where intelligence stops being private and becomes shared capability. The trials' deepest product wasn't the passing scores — it was the instrument itself: failure modes mapped by cause, negative controls every run, evidence committed before reporting, and honesty about what a result does not prove. A score that stops where the evidence stops is what makes the whole learning claim believable.

---

## WHAT'S IN IT FOR YOU

You can trust the claim 'she learned it' because it survived tests designed to catch faking — including tests that caught the testers. Lessons that pass this bar work in new situations, not just the one that taught them, so one person's hard-won lesson becomes everyone's capability.

---

## HOW IT APPLIES

Before believing any learning claim, ask: did someone new use it, somewhere new, without being told? Was there a control that did worse without it? Could the test have failed, and was the failure condition written down first? If any answer is no, the honest verdict is 'unproven,' not 'learned.'

### SN-0348 — The Canary Turned Over — The Seven-Rung Learning-Loop Proof and Its NON-CLAIMS [audit: PARTIAL → lost element restored]

A learning-loop claim is closed rung by rung through the seven-rung proof ladder, each rung closed on its own evidence and falsifier: (1) RETAINED, (2) RETRIEVABLE, (3) CONSUMED, (4) BEHAVIOR CHANGED, (5) OBSERVED, (6) INDEPENDENTLY RECOMPUTED, (7) COLD-SUCCESSOR REPRODUCED. Each rung needs its own receipt (SHAs, PR numbers, verbatim quotes, control results); a control without the rule must choose differently, or the behavior-changed and recomputed rungs fail. The falsifier is pre-declared, every claim ships its NON-CLAIMS, and the system under test is never its own witness — proof comes from independent cold consumers.

### SN-0452 — Intelligent Block: SN-0452 [audit: PARTIAL → lost element restored]

Two trial-design rules: (1) Instrument cost exactly — record per-trial tool-call counts; never estimate cost from checklists. (2) Make transfer tasks hard enough to discriminate — clean, too-easy tasks produce ceiling effects where both arms score 100% and the trial cannot discriminate; a control/treatment trial only measures a behavioral delta if the task can fail.

### SN-0582 — Intelligent Block: SN-0582 [audit: PARTIAL → lost element restored]

Briefings given to both arms may describe mechanics only — never the principle under test; review both briefings for principle leakage before launch (Trial-09's shared briefing stated the treatment principle, control agents cited it, and the 8.70 vs 8.40, p=0.65 result measured the memo, not the learning). When the task itself implies the lesson, calibrate the instrument with a positive control — a synthetic, counter-intuitive rule no agent could derive (Trial-10's control derived the implied lesson anyway, 9.0 vs 8.90). If both arms land near-perfect, run the positive-control variant before declaring the instrument broken.

### SN-0583 — Intelligent Block: SN-0583 [audit: PARTIAL → lost element restored]

Two durable findings: (1) Compositional transfer — agents combine multiple rules with correct priority ordering (Trial-12: two rules with priority ordering, treatment 10/10 vs control 0/10, p=0.000011, h=1.51). (2) Boundary respect — the treatment arm did not over-apply the rule where it did not belong; the treatment respected the rule's boundary (no over-application).

### SN-0585 — The Trial Program Is the Instrument: 8 Trials, 4 Mapped Failure Modes, 4 Tier-S Validations — LEARN 9.0 PROVISIONAL [audit: PARTIAL → lost element restored]

The program-level taxonomy: four mapped INVALID modes — INVALID by ceiling effect (Trials 7, 8: unanimous near-perfect on both arms; measuring already-learned principles proves nothing — measure novel, non-derivable lessons, not known principles) and INVALID by design flaw (Trial-9: principle leakage into the control briefing; Trial-10: derivability ceiling) — and four VALID Tier-S transfer dimensions: single-rule, compositional, cross-domain, and real-lesson transfer (Trial-14: the real AGENTS.md lesson, 10/10 vs 2/10, p=0.0007, h=1.10). The synthetic-rule calibration gate makes a null result on a real lesson interpretable: if the instrument cannot detect transfer of a deliberately non-derivable synthetic rule, a null on a real lesson is uninterpretable.

### SN-0628 — The First Promotions Went ACTIVE — the Learning Loop Closed Its First Full Cycle [audit: PARTIAL → lost element restored]

A verified promotion follows a four-gate recipe: (1) Tier-S trial proof, (2) no negative transfer, (3) independent verification, (4) an immutable receipt per lesson. The verifier is separate from the promoter (in the first promotions, verifier Naya 1, promoter Naya 4; receipts `1ec13a35`, `ea8960ab`, `d426f3e7`, `aab7aaf4` for T11–T14). ACTIVE is the starting line, not the finish: demand later application (T11 through the #1602 application path) and reuse evidence before scoring compounding.
