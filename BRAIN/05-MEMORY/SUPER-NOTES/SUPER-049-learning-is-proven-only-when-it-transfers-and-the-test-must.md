## ✦ IN A NUTSHELL

A lesson is proven when a fresh mind, never told the answer, uses it in a new place and does better. Honest tests make that possible — and make failure possible too, because a test that can't fail proves nothing.

---

## 🩷 HUMAN NOTE

The real test of learning isn't repeating the lesson back — it's using it somewhere new, unprompted. So the team built trials: teach a rule nobody could guess, then watch a fresh agent apply it to harder problems and different domains, against a control group that never got it. Several trials honestly failed — briefings leaked the answer, tasks gave away the trick — and each failure taught a design rule. Four trials then passed at the strongest tier, and the first lessons were promoted to active on that evidence.

---

## 🟣 CHILD NOTE

You really know your times tables when you can use them at the store, not just recite them in class. And a fair test never whispers the answer — if the teacher mouths the words, nobody knows if you truly learned.

---

## 👵 GRANDMA NOTE

You know a recipe is truly learned when the cook can make the dish in a different kitchen, with what's on hand, and it still tastes right. And you only trust the taste-test if nobody slipped them the recipe card during it.

---

## 🤖 NAYA NOTE

Apply the transfer test to every reusable-intelligence claim: one builder proves the reference, the law is extracted, a second builder applies it from the law alone, and an independent gate checks the result. Never let one seat do all instances, never run all instances before the reference proves, never let the verifier lead the build. In trials: validate the answer key first, strip any cue that names the rule, keep briefings clean, use control groups, state the falsifier before running, and always publish the non-claims — one proven rule proves the mechanism fires, not judgment or mastery.

---

## WHAT IT MEANS

Transfer is where intelligence stops being private and becomes shared capability. The trials' deepest product wasn't the passing scores — it was the instrument itself: failure modes mapped by cause, negative controls every run, evidence committed before reporting, and honesty about what a result does not prove. A score that stops where the evidence stops is what makes the whole learning claim believable.

---

## WHAT'S IN IT FOR YOU

You can trust the claim 'she learned it' because it survived tests designed to catch faking — including tests that caught the testers. Lessons that pass this bar work in new situations, not just the one that taught them, so one person's hard-won lesson becomes everyone's capability.

---

## HOW IT APPLIES

Before believing any learning claim, ask: did someone new use it, somewhere new, without being told? Was there a control that did worse without it? Could the test have failed, and was the failure condition written down first? If any answer is no, the honest verdict is 'unproven,' not 'learned.'
