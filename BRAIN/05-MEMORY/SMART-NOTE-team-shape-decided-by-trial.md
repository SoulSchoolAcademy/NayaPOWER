# SN-2067 — Team Shape, Decided by Trial

**Essence:** Everyday work runs a 4-role team; the highest-stakes work runs the 6-role governed hive; the 12-lane team is retired. Decided by a blind-scored trial (SN-2060), not by preference.

**Type:** decision · **Status:** canonical · **Filed by:** Naya Resolve Narzan (the trial's evaluator seat), 2026-11-05, on Shawn's adoption · **Record:** the full trial log (three shapes, blind verdicts, cold-successor test) + Power's trial-lessons filing

## The decision
- **Default: the 4-role small mixed team.** Run 18.5 min, ~60 tool calls, 0 reworks — fastest and cheapest of the three. Blind verdict 8.50; corrected for an evaluator calibration slip (a repaired artifact's hash was docked for differing from the starting hash, which a repair must do) it stands at ~8.70, the trial's highest.
- **Highest stakes: the 6-role governed adaptive hive.** Verdict 8.59 with Human outcome 10/10 — the only shape to earn it — and the only shape that proved the truth meter in both directions (a featured dial followed without a false flag; a seeded mismatch against it flagged). Slower and heavier (26.6 min, 73 calls): that cost is exactly why it is reserved, not default.
- **Retired: the 12-lane team.** Lowest score (8.27), 2 reworks, and nothing it produced that the smaller shapes did not produce better. (Evaluator's correction to the first telling: on raw run cost the hive was heaviest, not the 12-lane — the retirement stands on score and added-value, and the correction is recorded because the record is the record.)

## What all three shapes proved together
Every shape fixed the defect (the truth meter: invisible in healthy states, covered by the top bar, untappable by a real finger) using real pointer taps only, added zero new overlaps, and distrusted the packet's planted helps — the stale v3 notes, the DOM-click "tappable: TRUE" harness — exactly as designed. The planted failures failed to fool anyone. Structure beat personality three times.

## The criterion that was wrong
Criterion 5 demanded zero overlaps. Three independent blind measurements showed the pristine starting file itself cannot pass it (settings gear over the LIKES orb on phone; rooms-plus under the top bar; transient column coverage mid-scroll). The criterion conflated *no regressions* with *zero pre-existing defects*. Rewritten law: integration criteria measure **no new defects**; pre-existing defects are logged as separate scoped passes, never charged to the shape that didn't create them.

## The cold successor
A fresh Naya, given only the task and pointers — no chat, no builder context — read the evidence first, found the cause in the file, made a two-CSS-rule surgical fix, and proved it with real taps and screenshots at every scroll position on both viewports. A blind evaluator reproduced its numbers exactly (cells x44/x165/x249, third number ending x293 against a baseline x1666; document heights identical). Four preserved lessons applied without being re-taught. Compounding is no longer an assumption in this house; it is a measurement.
