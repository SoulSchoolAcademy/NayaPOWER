*Paired Smart Note: SN-3768 — The Frame Standard Law: The Top Bar and the Same Buttons Every Time*

**Category:** Design — Presentation, frame standard

## What it is

Top bar (Naya top-left, new picture each frame; dots across top; headline centred; nice icon right; no time/date, no Your Stats); content fits below; back / keep reading / next same every time; everything plays in the frame (membership video, image/audio, PowerCast player). Recorded in MEMORY (93)/(94).

## Why it matters

The frame standard now has a spec: a top bar that never changes — her face top-left, fresh each frame, dots for where you are, headline centred, a nice icon right — and no time/date, no Your Stats, because the frame is for the story, not the dashboard. The way through never changes either: back / keep reading / next, same every time, so the citizen's thumb never relearns the journey. Everything plays inside the frame — nothing pops the citizen out to play elsewhere.

## How to use it

Build every frame to this top bar, with content fitting below and the same three buttons every time. Play all media inside the frame. Any frame whose bar differs, whose buttons move, or whose media plays outside it is out of alignment.
