*Paired Smart Note: SN-3749 — The Link Set Circulates*

**Category:** System — Workflow, review

## What it is

The standing circulation workflow, as he works the pages from now on: always send him ALL the links together as one set — the current state of the last edits for every area that needs taking care of (staged where that is the latest, live on the main URL where that is the latest — "live can be live on the main URL"). He goes through them as fast as he can, directing edits; I edit while he is going through them; then the whole set is sent again — now edited — and he reviews again. The set circulates continuously that way so every area keeps getting done. One link at a time, or a set that goes stale after one pass, is not the workflow.

## Why it matters

One link at a time makes him wait on the machine, and the machine wait on him — each page reviewed alone, each edit round-tripped alone, the other areas sitting untouched while one moves. The set keeps everything moving at once: he reviews every area, directs edits across all of them, and the edits land while he is still reviewing — so the next set he gets is already the edited one. The circulation is the work: a set that goes stale after one pass breaks the loop, because the next review would be judging yesterday's pages. Live links ride in the set too, wherever live is the latest — the set is the current state of everything, not just the staged things.

## How to use it

Every review sends ALL the links together as one set: staged where staged is latest, live on the main URL where live is latest. Edit while he reviews. Then send the whole set again, edited, for the next pass. Never one link at a time; never a set that goes stale after one pass.
