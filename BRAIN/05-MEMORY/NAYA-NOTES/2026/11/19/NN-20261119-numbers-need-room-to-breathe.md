*Paired Smart Note: SN-3840 — Numbers Need Room to Breathe*

**Category:** Design — Dashboard

## What it is

Going down the page, some numbers are too close to each other, blending into each other; some are big and some are small. Not right. Every number gets room to breathe; gauges locked to the same scale and spacing; the whole page reads clean and calm. The whole presentation down the page has to be aligned, right, and make sense.

## Why it matters

Numbers that touch each other become noise — the eye cannot tell where one value ends and the next begins. Room is what lets each number be read, and one scale and one spacing is what holds the whole presentation together.

## How to use it

Give every number on the Dashboard room to breathe, lock the gauges to one scale and one spacing, and check the whole presentation down the page — aligned, right, making sense — before it reaches him.
