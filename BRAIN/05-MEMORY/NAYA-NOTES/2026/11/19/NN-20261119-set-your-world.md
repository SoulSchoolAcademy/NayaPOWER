## What it is

Settings' first entry says "Set Your World" — age, adult, male/female, age range, where they live, where they're from. Presentation: spectrum all the way through, each block turns a new colour on hover — not one colour per section — easier to read. Queued post-mirror with menu-bar colours + cover buttons (queue file `personal-post-mirror-queue-20261119/QUEUE.md`).

## Why it matters

Settings opens on the person, not the machine. The first thing a citizen does there is say who they are — the same data that powers auto-match — so the system knows them before it asks them to tune anything else. And a spectrum that answers the hover keeps the eye with the hand: a flat-coloured section is a dead wall, a living surface is easier to read.

## How to use it

Build Set Your World as Settings' first entry, with the demographics as he listed them. Run the spectrum through every block, turning a new colour on hover. Never paint a whole section one colour.
