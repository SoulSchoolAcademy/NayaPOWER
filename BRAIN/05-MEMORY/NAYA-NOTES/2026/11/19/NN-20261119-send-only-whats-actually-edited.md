*Paired Smart Note: SN-3860 — Send Only What's Actually Edited*

**Category:** Design — Delivery

## What it is

Shawn, ~15:13 MST: "Send me all the updated links. Everything's been updated." — with the condition in the same breath: make sure they're actually editing it; don't send it back if they're not edited; make sure they got it done. The idea: get as much edited and ready to ship as possible, complete, ready to go live.

Standing delivery rule, reinforced by the same ruling: a link goes to him only when the edit is in it and checked — unverified or unedited builds are held, not sent.

## Why it matters

A link is a promise that the edit is in it. Sending a build that hasn't actually been edited — or hasn't been checked — wastes the one thing he can't get back, his attention, and teaches him the links can't be trusted. Holding an unedited build is not slowness; it is the job. The five-link set that went out at 22:21Z carried only checked, edited builds; the walkthrough and membership were held back in the same message, with the reasons named.

## How to use it

Before any link goes to him: the edit is in the build, and the build has been checked — on screen, at phone width first. If either fails, the link is held and the reason is named in the same message. "Everything's been updated" is verified per link, never assumed for the set.
