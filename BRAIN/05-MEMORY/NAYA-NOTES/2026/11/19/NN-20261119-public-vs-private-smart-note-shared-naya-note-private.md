*Paired Smart Note: SN-3783 — Public vs Private: The Smart Note Is Shared, The Naya Note Is Private*

**Category:** Law — Privacy

## What it is

A smart note is inputted and shared intelligence with the whole network — and it is OPTIMIZED for the search engines, for the AIs and the machines, to be able to find that note. A Naya note is a PRIVATE note — NOT public, NOT optimized for the search engines. You share it with your team or whoever you share it with, or it lives in your personal notes — not everybody in the world seeing it. You CAN choose to make a Naya note a smart note — make it public — but by default a Naya note is private.

## Why it matters

This is the difference that matters, because it decides what the world can find and what stays with the citizen. A smart note is public by design and findable by design — that is its purpose, shared intelligence for the whole network. A Naya note is private by default: the full report, the citizen's own record, shared only with whom they choose. The bridge is a choice, never an accident — a citizen can make a Naya note public, but nothing makes it public for them. The privacy law holds: NayaNET never reads mail or messages, and now the note split is explicit — public is opt-in, private is the default.

## How to use it

File smart notes to the public feed and the search index; keep Naya notes in the private record, shared only with the team or people the citizen names. Any build that surfaces notes must check the split first — no Naya note reaches the public feed or the search index without the citizen's choice to make it public.
