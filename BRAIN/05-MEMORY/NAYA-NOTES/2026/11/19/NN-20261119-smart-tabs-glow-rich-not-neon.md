*Paired Smart Note: SN-3717 — The Smart Tabs Glow Rich, Not Neon*

**Category:** Design — Hub smart bars / smart tabs

## What it is

On the smart bars' look, live on the call: "but what I notice is the color like that glows. Looks like almost like too neon rainbow bright. They're not rich enough. Like where the say the collective the personal and the activity you know how it has much more rich bright colors. So I would make the collective, the personal activity, those buttons need to be the smart tab buttons as well just smaller, right? And then glow like that. So they're aligned. So it's the same type of glow and look and richness. Does that make sense?"

## Why it matters

The tabs glow neon rainbow — bright, but not rich. The Collective, Personal and Activity buttons already carry the rich bright colours the system is known for. The smart tabs should be those same buttons, just smaller, with the same glow, the same look, the same richness — one family, aligned, not a second language on the same page.

## How to use it

The Hub round that owns the smart bars rebuilds the tabs as the Collective / Personal / Activity buttons at smaller size, with their rich glow — never the neon rainbow wash. Proven on the page at 390 and 1920.
