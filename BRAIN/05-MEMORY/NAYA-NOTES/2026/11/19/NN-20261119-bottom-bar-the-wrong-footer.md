*Paired Smart Note: SN-3847 — Bottom Bar: The Wrong Footer*

**Category:** Design — Personal

## What it is

On the live Personal walk, coming to the bottom of the page should show the SET icon bar — the Dashboard's set icon bar, Set 3, the standard six. Instead it shows "Together we grow" / Naya — beautiful, but not how it's supposed to be.

## Why it matters

The bottom bar is the way home on every page — one set, the same on every page, never different per page. A sign-off where the standard bar belongs breaks the one-system promise: the person reaches the bottom and finds a poster instead of their controls.

## How to use it

Rides the next Personal round with the keyword-bar fix. The eye proves the bottom carries the SET icon bar — Set 3, the standard six — the same as the Dashboard.
