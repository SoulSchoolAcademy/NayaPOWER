The settled form (recorded in MEMORY.md + AGENTS.md as "THE SMART NOTE FORMAT — THE OFFICIAL LANGUAGE"): **every Smart Note outputs in the same format — Block 1 is the nutshell, the headline, lit up with light. Then the Child Note, then the Grandma Note. The nutshell IS the human note, so the human note is cut; there is NO Naya Note section in the network. On the back end, the Machine Note does the SEO — every smart note is search-engine-optimized. Then What It Means — what's in it for you, how it applies, how it connects. The color flow: silver (the lit-up nutshell) → magenta → purple → indigo → cyan → emerald green → gold → orange → red → back to magenta (the spectrum flow). Each section changes color on the outside, themed different — it breaks attention, breaks up the text, lets you take it in. Naya Notes ARE the way Naya writes: "smart note this" or "Naya note this" — anything — outputs into these beautiful boards, 3–4 sentences at a time, a paragraph at a time, or bullet points, always in smart blocks. Save it, share it. Images: 16:9 at the bottom; feature top OR bottom OR both (your choice at upload); both = first image top, the rest bottom; multiple images = one feature at the top + a grid at the bottom (3×3, 2×2, reformatted for the count), perfectly aligned underneath the message. In feeds and pages, the unfold + the auto-formatting of intelligent communication — the unfold formats for the page (three fit, three, click next; two fit, two). This is the official language.** The screenshot he showed: the current format — Child Note (purple), Grandma Note (dark), Naya Note (blue), What It Means (green) — with the What It Means board carrying numbered lessons. The new format CUTS the Naya Note section from the front and puts the Machine Note on the back end.

## Why it matters

Every smart note now speaks one language — the same blocks, the same order, the same color flow — so a citizen reading any note knows where they are in it before they read a word. The nutshell is the human note, so nothing is said twice. The colors do the work of breaking up the text: each section themed different, so the eye can take it in. And the unfold is a thing: the format fits the page it is on — three fit, three, click next; two fit, two. That is the official language, and it is the way Naya writes by default.

## How to use it

Output every Smart Note in the official format: nutshell lit up with light (silver), then Child, then Grandma, then What It Means — each section in the spectrum flow, themed different on the outside. No separate human note, no Naya Note section in the network; the Machine Note does the SEO on the back end. Write in smart blocks — 3–4 sentences at a time, a paragraph at a time, or bullet points. Images 16:9, feature top or bottom or both, grids reformatted for the count, perfectly aligned underneath the message. In feeds and pages, unfold a section at a time, formatted for the page.
