## Why it matters

A button that says the same number seven times is not information — it is decoration pretending to be a count, and a button that opens a group chat when it looks like a mail filter is a button that lies about what it does. "Not aligned with our buttons" is the design half; "they don't make sense" is the function half. Both halves have to hold: aligned with the standard, and doing what it says.

## How to use it

A count that is identical everywhere is not a count — fix the count or remove the claim. A pill that opens a chat is a chat control, not a mail filter — say what it does, or make it do what it says. Every button aligns with the system's button standard or it does not ship. The fix rides the Smart Mail follow-on round (21:52Z).
