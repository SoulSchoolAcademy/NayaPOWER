## Why it matters

He was looking at a page we had just called done and delivered — and the first thing his eye caught was something left over from before the Smart Tabs that nobody had removed, and icons that differ from page to page. A delivered page is not a finished page if it still carries the old thing and the wrong icons. The charge is wider than the one cluster: as I go through these pages, I look for anything that needs to be aligned and put right — the bottom bar, the sidebars, the plus buttons, all the same on every page, not different on each page. And the learning runs both ways and always: take a feature from one page to another whenever it makes it beautiful — not only "if needed" — because we learn from each other, we grow, we help, and the art we're crafting is an art to master. The scorecard question is the tool for it: why is this whole page not a ten, what is it missing, what would make it ten times better, how aligned is it with the universal smart app page — and what can we learn from here to take over to the calendar inner pages.

## How to use it

Remove the cluster from the Smart Mail page — it is a leftover from before the Smart Tabs and we do not need it there at all anymore — and remove the message that should not be there. Make the page clean and nice and make it make sense; keep the point / percentage / money icons, the best icons. Then, on every page I go through, look through as I go: align the bottom bar, the sidebars, the plus buttons — all the same on every page, not different on each page. Take features and language from page to page universally whenever it makes it beautiful — the numbers language here is great, letters or symbols in some cases; this page learns from the Personal page and the Personal page learns from this one. Scorecard every whole page against the universal smart app page: why is it not a ten, what is it missing, what would make it ten times better, what is aligned, what is amazing, what can we learn from here for the next page.
