*Paired Smart Note: SN-3501 — Never Re-Send an Unchanged Link as If It Were New*

**Category:** Law — Process

## What it is

Shawn, ~22:45Z — he caught that the Dashboard link sent to him was the SAME staged doors-out page, not a new version — the fixes were not built yet. His words: "I don't see any update yet so I don't know why you sent it back." Own it plainly when it happens: never re-send an unchanged staged link as if it were new; say which version it is.

## Why it matters

A link sent is a claim that something is new to see. He opens a link expecting the new work, finds the old page, and has to spend his own time telling us nothing changed. Naming the version costs nothing; sending the old page as the new one costs his trust and his time. The follow-on round carries the real list, and the doors-out link must not be presented to him again as if updated.

## How to use it

Every future handoff names its version — the link, the commit or blob, what changed since the last link he saw. If nothing is new, say so; never send the old page as the new one.
