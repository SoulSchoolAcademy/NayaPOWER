*Paired Smart Note: SN-3489 — The Essence Rule: When the Image Cannot Line Up, Make a New One That Does*

**Category:** Design — Images

## What it is

Shawn, voice call, ~22:18Z — his exception to harvest-verbatim, for images that cannot align: if an image can't be made to line up perfectly, create a NEW image carrying the SAME ESSENCE that does line up perfectly and put it there. Perfect alignment wins; the essence is what survives, not the exact pixels.

## Why it matters

A harvested image that cannot line up leaves the page crooked, and loyalty to the original pixels cannot fix a crooked page. What the image means — its essence — is what matters; remaking it in a form that lines up keeps the meaning and fixes the page.

## How to use it

Use it only where the original genuinely cannot be made to line up, and name every use in the maker report. Anything that CAN be made to line up is still harvested verbatim — this is never a reason to redesign.
