## Why it matters

Counts are comforting because they are countable — but distinctness is a string comparison, and a frame with a swapped word is distinct by string and identical by reading. The citizen does not count, they read. A world that repeats itself is not a world, it is a recording — and the first thing a citizen learns about NayaNET would be that its writing is fake.

## How to use it

Every batch of written boards is proved by the READ — three or four boards aloud as a stranger — before any count is cited. Any repeated sentence fails the round, whatever the counts say. Rubrics forbid frames-with-slots by name, with the killed frames listed as examples. No question bank or frame bank is adopted as a fix for repetition — composition from each story's own facts is the only fix.
