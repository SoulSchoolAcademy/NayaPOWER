## Why it matters

There is a special cruelty in a control that never answers — worse than an error, because an error at least ends the uncertainty. "Sending…" forever is a door that never opens and never says it's locked. An honest failure tells the citizen the truth about what happened instead of leaving them to guess, and it returns their agency instead of holding it hostage. The same discipline shows in the record: five finish FAILs grounded-not-fixed, named, not hidden — because a record that names what it didn't fix is a record you can trust about what it did.

## How to use it

Give every promise that can hang a deadline — at the deadline it fails in plain words, with the control back and a way to try again. "Sending…" forever is a defect, not a state. Re-prove fixes with real clicks at phone and desktop widths. Name unfixed failures in the record, grounded — never hidden, never patched into passing.
