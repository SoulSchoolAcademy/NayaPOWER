## Why it matters

Every other calendar is a forward-looking tool — a place to put things you have not done yet. This one is a memory that stays alive: any day, any world, what happened, in one click. That is a different product, and it is the product a wisdom system would build — because wisdom is what you learn from the days behind you, and a system that cannot show you yesterday cannot teach you anything.
