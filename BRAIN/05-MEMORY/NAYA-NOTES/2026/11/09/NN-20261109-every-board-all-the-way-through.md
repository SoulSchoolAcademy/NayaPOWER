## Why it matters

A dashboard where some boards have speedometers and others don't is a dashboard that looks unfinished — the eye trips on the gap before it reads anything. His ruling makes consistency the requirement, not the decoration: every board carries these speedometers, all the way through, the same speedometer, the same presentation, no board without them. And every board's buttons link to the place the board is about — the board is not a picture, it is a door. The inconsistency itself is the defect: not a missing speedometer on one board, but the fact that the boards disagree with each other. One presentation, everywhere, all the way through.
