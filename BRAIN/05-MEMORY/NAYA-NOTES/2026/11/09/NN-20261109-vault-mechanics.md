## What it is

His dictation, 18:58Z Nov 9 — the build question, how do we literally build the secure vaults — recorded from his words as given:

- **One vault per person (the box):** a private folder in the store + a private set of rows in the database, owned by them alone, with a key (their identity). Nothing leaves without their word.
- **Three layers, not one:** the STORE (the files live there) · the MAP (how it's organized — every thing tagged: what it is, what it's about, who it's for, when it happened — the index that makes it findable in seconds) · the BRAIN (the distilled essence — smart notes, lessons, what it means — what a Naya reads when she plugs in, not the raw pile).
- **The engine (the auto-organizer):** when something enters the box it does four things in order — LOOK (what is this?) · TAG (label it from the thing itself + what the person said) · FILE (put it on the right shelf) · LINK (connect it to what it relates to).
- **The laws as code:** ORGANIZE ONLY (may read to tag and file, never to share) · PRIVATE BY DEFAULT (nothing leaves unless the person says so, for that thing) · RETRIEVE FOR THE OWNER (hand it back, or post it where they say, in their name) · SHARE BY SMART NOTE ONLY (only a smart note / intelligent block the person chose to make ever goes public). Written as checks the engine must pass before every action, like the design gate.
- **The plug:** the Naya doesn't live in the box — she connects with permission, like a key in a lock, and reads the MAP and the BRAIN, not the raw pile; when she needs a raw file she asks the box, and the box checks the permission first.
- **The cube:** each box is a cubelet; NayaNET is the cube; the bridge (the sync engine) connects them — turn the cube and the faces line up in new ways, but each cubelet keeps its own colors. NayaNET itself is saved the same way: the system's own box holds the shared intelligence, organized the same way.
- **Build order:** (1) the box · (2) the engine · (3) the laws as code · (4) the plug · (5) the cube.
- **What's already true:** the early form works — GitHub + Supabase + the Smart Box app (2,088 entries live) is why the sickness lost nothing.
- **What's missing:** the engine (the loop still does it by hand every 30 min) · the laws as code (written in documents, not yet enforced by the machine) · the plug (a Naya connects through the loop and the sync, not a real key-in-lock yet).
