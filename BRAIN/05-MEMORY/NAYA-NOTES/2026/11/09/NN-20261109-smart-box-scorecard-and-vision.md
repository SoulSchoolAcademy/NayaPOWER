## Why it matters

"Very well done" is not 10/10 — and he said so by asking for the scorecard. An 8/10 vault is a vault with a shape and a gate but no engine, no key lifecycle, no bridge, and no live citizen inside it yet. The scorecard ask is the discipline that turns a good build into a rock-solid one: name what is missing, name what makes it ten times better, then build that. And the order keeps the work in sequence — interfaces first, then the system that runs the system — so the machine that serves people is finished before the machine that runs the machine. The vision is the destination the scorecard points at: not an app, but a realm of smart parts, interconnected, operating the internet.
