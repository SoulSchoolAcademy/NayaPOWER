## What it is

**THE UNIVERSAL BOTTOM BAR (his design, settled, call b9431e3a):** the Dashboard bottom icon bar — ADD · PERSONAL · BUSINESS · WORLDS · ECOSYSTEM · CONNECT, with the plus button — becomes universal on Hub, Personal, and Dashboard alike. Network notifications show there — when anything happens in the network, it shows on that bar.

## Why it matters

One set of icons, the same on every page, so the hand knows where to go before the eye has to look. And the bar is the one place always on screen, so it is the one place a network event can always be seen.

## How to use it

Take the Dashboard bottom bar as the canonical set and carry it byte for byte to Hub and Personal. No page gets its own version, its own order, or its own extra icon.
