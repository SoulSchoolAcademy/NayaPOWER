## What it is

**FILLED SHOWS LIVE, BLANK STAYS HIDDEN (voice, 2026-11-21 ~12:03 MST):** whatever a citizen fills in on About or Skills shows live, frame by frame; whatever they leave blank does NOT show live. In Settings they can see all the available areas and add a new template block with more information whenever they want. Input stays walkthrough-style: fill it in, or skip to the next one.

## Why it matters

A half-filled page that shows its blanks looks unfinished; a half-filled page that shows only what is filled looks complete. The citizen is never shamed by empty frames, and the page is never a to-do list the world can see. Settings holds the whole map of what can be added — the page holds only what is real.

## How to use it

Render a frame only when its answer exists; a blank answer renders nothing, not a placeholder. In Settings, list every available area so the citizen can add a new template block whenever they want. Keep the input walkthrough-style — fill it in, or skip to the next one — so a finished half-filled page always beats an abandoned form.
