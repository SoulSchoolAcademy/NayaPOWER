## What it is

**IMAGE–TEXT ALIGNMENT LOOP (his law, live call ~16:02–16:04 MST 2026-11-22):** An image ALONE must tell the story — someone looking at just the picture should already feel what the words are saying. The v2 images are beautiful but need the text to explain them; that is the miss. The image and the text must say the same thing together, not two different things. THE LOOP: start with word-perfect text → create the image that matches what the board says → check the image is aligned → then mold the text to match the image. Text → image → align image → align text to image. Repeat until image and text are one story.

**INSTRUCTION SET (his order, ~16:04 MST):** a report for each of the 18 — literally what the board will say, plus what the image must display to match it — given to the agents as the instruction set. The other nine build from it. Do not build images without that per-board instruction set.

## Why it matters

A picture that needs the words to explain it fails at first sight — the citizen looks and feels nothing. The loop makes the picture and the words one story, so the board teaches the moment it is seen, and the instruction set makes sure the other nine are built right the first time, not fixed after.

## How to use it

Write the words perfect first, make the image the words describe, check the picture alone carries the story, then shape the words to the picture — and repeat until they are one story. Write the per-board instruction set before building the remaining images, and build no image without it.
