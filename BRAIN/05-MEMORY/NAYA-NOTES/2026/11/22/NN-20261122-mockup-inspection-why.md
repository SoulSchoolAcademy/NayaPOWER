**336. MOCKUP INSPECTION 058fcf20 — THE WHY (~15:36 MST):** builder made NO new images — reused the old Naya Code slide and vault picture, squeezed into two tall 9:16 boards. No forward button — only tap-to-enlarge on phones, so on laptop nothing to click. Sizing math narrowed the boards, left a big empty gap. The idea wasn't the problem; the build was.

## Why it matters

A failed mockup that is really a failed build looks exactly like a failed idea from the outside. Without inspecting the build first, a good idea gets thrown away for a bad build's sins — and the next build repeats the same sins on a new idea.

## How to use it

When a mockup fails, inspect the build before judging the idea: what was actually made, what controls exist on each device, what the sizing actually did. Reused assets are named as reuse, never passed off as new work. Tap-to-enlarge is not navigation — every mockup needs a forward control on laptop as well as phone.
