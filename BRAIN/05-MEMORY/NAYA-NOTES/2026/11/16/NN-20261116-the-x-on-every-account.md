## Why it matters

An account list that only grows is a list that lies: test accounts, dead accounts, duplicates — all sitting there forever, and the citizen can't tell which one is theirs. Removal is the other half of creation: if the system can create an account every time, it must be able to remove one. And removal of something you lose for good must never be one click — the warning is the respect for the loss.

## How to use it

Every account row on the entrance dial carries its own X. Tap → warning (you will lose this account for good) → confirm to remove. Never one-click. Duplicates of one name are separate rows; the X removes that one row only. A test account can go, and the list stops growing forever.
