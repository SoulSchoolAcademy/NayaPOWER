## Why it matters

The seats built flat. They knew the Real Object Law — every element a real physical object — but they did not know how to make one. The clone trick is the how: take the whole thing, clone it once, put the clone behind, move it right or left just a tad. The clone becomes the glow, the edge, the underglow; the original stays the solid body in front. One clone does it — triples too much, quadruples way too much. A law without a method is a wish; this is the method.

## How to use it

Every brief carries the clone trick — inputs, buttons, names, everything that must feel real. One clone, behind, nudged a tad. Round 5's ⓘ button and inputs are the first application after the name. A flat build is now a named miss, not a style.
