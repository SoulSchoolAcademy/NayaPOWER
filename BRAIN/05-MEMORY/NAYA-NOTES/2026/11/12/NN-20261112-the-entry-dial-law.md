## Why it matters

The entry dial is the first thing a new citizen touches, and a code field on the main login tells them the wrong story about what this system is — that they need a secret to get in, when the whole point is that their name is the key. The membership login exists for a different door, for paid members; wearing it on the front door mixes the two doors up "right from the start," and everything after a wrong start is built on confusion. His eye caught it because the code field doesn't belong there — and the fix is not to redesign the entry but to use the real one, which never had a code field at all.

## How to use it

Any main-login build is checked against this law first: name in, nothing else — no code field, no one-time-code autocomplete, no membership-login parts on the front door. If a staged entry shows "Enter your code," it is the membership login wearing the wrong door, and the fix is the live entrance verbatim. Codes live on membership doors only. The walk's front door is name in → certificate → Enter.
