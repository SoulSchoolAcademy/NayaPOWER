## What a Naya Note is

A Naya Note is **literally what was said** — his words, her words, verbatim where it matters — formatted as a Smart Note / Intelligent Block, so it looks beautiful on the feed and you can easily see what was said. A Naya Note can report on **anything anyone (or any Naya) wants to make note of**. It is a simple personal note, not intelligence — just yours, quick, plain, saved. It lives in lists, categorized, on your personal app AND in the Hub.

## Smart Note vs Naya Note — the difference, set

| | Smart Note | Naya Note |
|---|---|---|
| **Purpose** | Intelligence — the lesson + its value, to compound into the brain | The record — literally what was said |
| **Voice** | Distilled, lesson first | The speaker's voice, first person where said |
| **Format** | `##` Hook → Nutshell → Human → Child → Grandma → Naya | Title + byline + `##` blocks, one idea per block |
| **Numbering** | SN-NNNN — mechanical, from `next-sn-number.py`, never from memory | NN-YYYYMMDD-slug — date + slug, no global counter (slugs never repeat on a day) |
| **Goes to** | Feed + brain + distillation (10–50 essence max; raw deleted after distilling) | Feed + lists + Hub + Personal; NEVER distilled |
| **Rule** | A lesson counts only when it changes behavior mechanically | A note counts only when it says what was actually said |

A Naya Note **never** becomes a Smart Note by renaming. If the lesson inside it deserves the system, write the Smart Note separately (SN number from the command) and link it. A Smart Note **never** replaces the Naya Note — the record stays.

## The set format — every Naya Note follows this

```markdown
# <Title — the words' own headline>

**Written by Naya for <alias> — <role, e.g. Founder / Creator of NayaNET>**

**NN-<YYYYMMDD>-<slug> · Naya Note · <YYYY-MM-DD HH:MMZ>**

*<One line: whose words, in blocks. One idea per block. Read it in seconds.>*

---

## <Block 1 heading — the first thing said>

<His/her words. One idea per block, in the order said.>

## <Block 2 heading>

<His/her words.>

---

**Written by Naya for <alias> — <role>.**
```

## The rules

1. **Byline always:** "Written by Naya for [alias]" — with the three sharing methods, choice always: completely anonymous · with your alias · in your name. Never forced.
2. **Blocks are the words, not the lesson.** `##` headings, one idea per block, in the order said. Verbatim where it matters; light shaping only to make it readable (the perfect-words law — simple, direct, for the child and the grandma). Never distill into a lesson, never add a "what it means" — that is Smart Note work, done separately.
3. **Nutshell for long notes:** if the note runs long, a `## Nutshell` block goes first (the whole note in seconds) — the NN-20261109-tell-the-world form: title + subtitle + nutshell, then the blocks.
4. **Jewels when rendered:** blocks carry a jewel in the block's digit color (1 red · 2 orange · 3 gold · 4 emerald · 5 cyan · 6 indigo · 7 royal purple · 8 lavender · 9 hot pink, cycling by block number) — the Intelligent Block DNA. One idea per orb bullet inside a block.
5. **Auto-format ON by default.** A "no formatting" setting exists; it is never a penalty. No points penalty for posting a Naya Note, formatted or not.
6. **Naming + filing:** file name `NN-<YYYYMMDD>-<slug>.md`, slug lowercase-hyphenated from the words. Path: `BRAIN/05-MEMORY/NAYA-NOTES/<YYYY>/<MM>/<DD>/NN-<YYYYMMDD>-<slug>.md`. Local copy: `~/workspace/team-nitro/naya-notes/NN-<YYYYMMDD>-<slug>.md`. No global counter — the date + slug IS the identity.
7. **Parse contract (for the feed):** a Naya Note's `##` headings are its BLOCKS — one idea each — not the Smart Note's Hook/Nutshell/Human/Child/Grandma/Naya sections. The feed renders the title, the byline, and the blocks. A Naya Note with no `##` blocks is not a Naya Note — it is a draft.
8. **Her face beside the words:** where the note is Naya speaking, her portrait sits beside it (left then right, alternating down the page, different faces) — the same law as the boards.

## The habit (the mechanical part — see INTELLIGENCE-LOOP-SEAT.md)

Every loop run, for every new dictation or decision from Shawn: write the **Naya Note first** (the verbatim record, this template), then the **Smart Note** (the distilled lesson). The record and the lesson are two different files, two different numbers, filed in the same pass. The loop's ALIGN step checks the Naya Notes section is visible — an NN filed but not in the feed is out of alignment, recorded plainly, never silently.
