## In a Nutshell

Draw it before you build it, write down what "finished" means before you start, and stop when that definition is met — the loop is intent → spec → blueprint → machine contract → build → verification → freeze (SN-0140), a freeze is a baseline with an honest public thaw rather than a coffin (SN-0141), rooms are modules under one contract rather than apps (SN-0142), and when two options both lose half the picture, the choice itself is false and gets dissolved, not picked from (SN-0207).

## Essence

Nothing is built from a vibe. The build loop is: intent → spec → blueprint → machine contract → build → verification → freeze — and the blueprint precedes the build because eleven room blueprints written before code existed are what made the rooms buildable at all; iteration counts (10 tries, 100, 198) are effort trivia, and the acceptance contract is the only thing that closes a build (SN-0140). The closing rule deserves its own statement because it keeps being rediscovered: work stops when the contract closes — not when the budget of attempts runs out and not while the contract still gapes; effort numbers measure stamina, never completion (SN-0153). A freeze is a baseline, not a coffin: frozen means protected against casual re-derivation, and the lawful thaw is a public sequence — a failing test in the open, a public amendment, the fix, re-proof of dependents, a new baseline. Repair is always legitimate; silent drift never is (SN-0141).

Structure follows the same discipline. Rooms are modules, not apps: each room registers under one contract — a named global, an ownership declaration for what it controls — so ten rooms mounted with zero edits to the foundation they share; a room that needs the foundation changed is a foundation conversation, not a room edit (SN-0142). What gets frozen is what the approver actually approved: the design freeze is a two-way lock between spec and visual, and the visual is the lock artifact because the approver reviews the image, not the prose — freezing prose the approver never saw locks nothing (SN-0147). False choices are dissolved, not picked from: when two programs appear to compete — one hub vision against another — the move is to name the false choice and state the integrated model (one program, one shared spine), because choosing a horn of a false dilemma amputates half the system (SN-0207).

## What this settles

- The loop is intent → spec → blueprint → machine contract → build → verification → freeze; the acceptance contract closes builds, iteration counts never do (SN-0140, SN-0153).
- Freeze = baseline with a public thaw protocol (failing test → amendment → fix → re-prove → new baseline), never immunity from repair (SN-0141).
- Rooms are modules under one mounting contract; foundation changes are foundation conversations (SN-0142).
- The approved visual is the lock artifact of a design freeze (SN-0147).
- False choices are named and dissolved into the integrated model (SN-0207).

## Intelligence views

**Human:** Draw it before you build it, write down what "finished" means before you start, and stop when that definition is met — not when you're tired, not after a round number of tries. Once something is approved, protect it from casual changes, but keep an honest, public way to fix it when it's genuinely wrong. And when you're offered two options that both lose half the picture, refuse the choice and describe the whole.

**Child:** You plan the treehouse on paper first — and the plan says what "done" looks like. You stop when it looks like the plan, not after you've hammered a hundred nails. If a board breaks later, you can fix it — you just tell everyone and write the fix on the plan.

**Grandma:** A dress is cut from a pattern, dear, and finished when it matches the pattern — not when the thread runs out. A pattern put away in the drawer isn't sacred; if the dress tears, you mend it properly and note the alteration. What you don't do is quietly let the seams out and pretend it was always that size.

**Naya (AI):** Refuse build tasks without a blueprint and an acceptance contract; report completion only against the contract. Run thaws as the five-step public sequence. Register modules under the single contract and route foundation needs upward. Freeze the rendered visual alongside the spec. When handed a binary, test whether it's false before choosing.

**What it all means:** Six notes form the build constitution of the Hub era: plan first, define done, freeze honestly, thaw publicly, modularize, dissolve false choices. Every rule answers a specific failure — builds that iterated without closing, freezes that blocked repair, prose frozen instead of the image approved. Two standing texts that bordered this family — the executor's personal binding oath (SN-0199 — one seat's own oath, derivative and non-competing, not a director text) and the director's fix-or-remove directive (SN-0251) — stand alone under the campaign rule and are not carried here. Hold this essence and the loop runs without re-deriving it per project.

## Why It Matters

Building without a blueprint and a written definition of done is how a team produces motion instead of products: effort gets spent, attempts get counted, and nothing closes (SN-0140, SN-0153). For the reader, this essence is the difference between a build culture and a tinkering culture — and its freeze/thaw pair (SN-0141) is what lets a system be both stable and repairable, instead of choosing one and suffering the other.

## How It Connects

The acceptance contract that closes a build here is the same instrument the proof-discipline essence demands be measurable (SN-0146) and the receipts essence demands be pinned (SN-0206). The module contract (SN-0142) is the build-side half of the mount-contract truth the deployment essence verifies at the consumer (SN-0218). The design freeze's visual lock (SN-0147) is where the design-canon essence's taste loop lands its approvals (SN-0193).

## What Is In It For You

You get builds that finish: a picture of the thing before it exists, a contract that says when it's done, and a freeze you can trust because its thaw is honest and public (SN-0140, SN-0141). Apply it by refusing, politely and completely, any build request that arrives without a blueprint and an acceptance contract — and by treating "how many tries did it take" as trivia, never as evidence of completion (SN-0153).

## The Learning

The era taught that iteration is not a virtue signal: 10, 100, or 198 attempts measure stamina, and only a contract measures completion (SN-0140, SN-0153). It also taught that protection and repair are not enemies — a freeze with a public thaw protocol survived contact with real defects, while both unfreezable drafts and unthawable freezes failed (SN-0141). The learning to keep: define done before starting, protect what passed, and make the legitimate repair path easier than the silent one.
