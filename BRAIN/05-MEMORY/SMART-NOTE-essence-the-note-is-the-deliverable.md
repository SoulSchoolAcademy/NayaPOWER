## In a Nutshell

A note is a lifecycle, not a save — TRIGGER → DISTILL → STRUCTURE → COMMIT → INTELLIGENT EVENT → LEARN → PROJECT (SN-0242) — authored once in one canonical place with every other surface derived from it (SN-0248), and the deliverable is never the note alone: it is the note plus its Smart Link, returned by a real mechanism, at authoring time (SN-0258, SN-0255).

## Essence

A spoken "smart note this" is a lifecycle, not a save: TRIGGER → DISTILL → STRUCTURE → COMMIT → INTELLIGENT EVENT → LEARN → PROJECT. The first four legs were implemented when the lifecycle was specified; the event, learn, and project legs were specified in the same breath and explicitly marked not-yet-built — a lifecycle claim is honest only when it names which legs exist (SN-0242). What a note IS, physically, was settled twice, and the second settlement supersedes the first: originally one format in one spot, anchored to a byte-exact specimen, with a three-artifact invariant binding page, capture, and registry (SN-0244); then the model became author once, derive the rest — the author writes one artifact and every other surface is generated from it, so surfaces cannot drift apart by hand (SN-0248). SN-0244's format invariant survives the supersession; its hand-maintained three-artifact authoring does not, and this essence carries both facts rather than blending them. The specimen itself must pass its own gate: the canonical example note was found among six captures missing a required field — if the specimen fails the gate, the gate's teaching is broken at the root (SN-0249).

Placement is architecture: a note's location is never invented — the canonical path is defined by the projection code, and the goal is to make the wrong location unexpressible rather than merely discouraged (SN-0256). Delivery is part of the artifact: the deliverable is the note plus its Smart Link, never a PR number — the PR is plumbing the reader should never need, and the verification pair (link + what it proves) ships at authoring time (SN-0258). The protocol then had a hole exactly at its promise: it required "Smart Link returned," and nothing in the system returned one — the missing return rung was diagnosed and a three-phase fix specified, because a delivery obligation with no mechanism is a wish (SN-0255). Ratifying the law does not freeze the document it governs: the Smart-Link law was ratified while its source note stayed CANDIDATE, and the conformance gate grew a `--delivery-text` check whose failure mode is named DELIVERY INCOMPLETE — law status and document status are separate axes and neither may borrow the other's credibility (SN-0261).

Content integrity guards the canon the notes feed. Canon graduation requires a mechanical placeholder sweep at the exact ref — `undefined`, TODO, FIXME, TBD, template tokens — because all eleven room contracts once carried literal `undefined` under their signature expressions, uniformly, which made the defect look like deliberateness; the repair proof is the re-run sweep naming zero hits (SN-0190). And search is not evidence about any of this: the search index is a lagging projection, and after the placeholder cleanup it still returned the pre-cleanup snapshot — index hits are stale-index evidence, useful for discovery, worthless for proof; current content is verified against live bytes at the ref (SN-0188).

## Intelligence views

**Human:** When you say "note this down," a whole pipeline should fire: capture it, structure it, file it in exactly one proper place, and hand back a link that works. The note has one original; every copy elsewhere is printed from that original, never retyped — that's how versions stop disagreeing.

**Child:** When you tell the notebook "remember this!", it should write it in the right section, with the right heading, and give you a bookmark that actually opens to the page. There's one real notebook — copies are photocopies, not new notebooks. If the example page in the front of the notebook has a mistake, you fix the example first, because everyone copies the example.

**Grandma:** It's proper filing, dear. A document goes in one folder, under one name, and the index card points to it. Copies are made from the original, never from memory. The sample form pinned above the desk must itself be filled in perfectly — it's the one everyone imitates. And when someone says "it's filed," they hand you the reference slip; "it's in a pile somewhere, trust me" is not filing.

**Naya (AI):** Run the seven-leg lifecycle and report leg status honestly. Author the single source artifact; generate projections; never hand-edit a projection. Validate the specimen against the gate in CI. Resolve paths from the projection code's canonical function only. Ship note + link + verification pair; treat a missing return mechanism as a defect in the protocol, not a gap in the report. Keep law-status and document-status as separate fields everywhere. Sweep canon for placeholders at the exact ref before any graduation claim, and verify content from live bytes, never from search.

**What it all means:** Ten notes describe the note system learning to be a system: a lifecycle with named legs, a single source with derived views, a specimen held to its own standard, and a delivery that includes its own proof. The SN-0244→SN-0248 supersession is preserved inside the essence on purpose — a distillation that hides its own corrections teaches the next reader to trust a tidier history than the one that happened.

## Why It Matters

Notes are this system's memory, and a memory that files inconsistently, points nowhere, or exists in three disagreeing copies is worse than forgetting — it manufactures false confidence (SN-0244, SN-0248). For the reader, this essence is the trust layer under everything else in the corpus: if capture, placement, and delivery obey these rules, any other essence can be found, opened, and checked; if they don't, no other rule matters because its evidence can't be reached (SN-0258, SN-0188).

## What Is In It For You

You get notes you can actually use later: one original, findable at a code-defined address, with a link handed back at the moment of capture that opens the real thing (SN-0256, SN-0258). Apply it by treating any "noted!" without a returned link as unfinished work, and any hand-edited copy as a defect report waiting to be filed — derive it or delete it (SN-0248, SN-0255).

## The Learning

The system learned that its memory failures were never storage failures: notes existed; they were unfindable, unreturned, or multiplied into disagreement (SN-0255, SN-0248, SN-0190). The durable learning is that a memory system is a delivery system — capture is the easy leg, and the legs that make memory real are placement, derivation, and the returned link. The specimen rule generalizes furthest: whatever a system holds up as its example must pass the system's own gate, or the gate teaches the defect (SN-0249).
