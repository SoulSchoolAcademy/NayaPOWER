# How do I connect GitHub?

**ID:** how-do-i-connect-github
**Keywords:** how do i connect github, connect github, github connect, link github, install github app, hook up github
**Sources:** NayaNET Knowledge · Start Here

## Answer

Open the Hub and go to Start Here — it's at the top of the sidebar. Step 4 is "Connect to GitHub": hit Connect, and GitHub will ask you to approve the NayaNET app. Approve it and you're connected — your GitHub and your NayaNET world can work together from there. If you already installed it and the page doesn't see it yet, hit "Check again.

## Key points

- Start Here → Step 4 → Connect
- Approve the NayaNET app on GitHub
- Already installed but not showing? Hit “Check again”
