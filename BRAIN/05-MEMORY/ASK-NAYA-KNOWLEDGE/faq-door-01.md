# What is GitHub Connect?

**ID:** faq-door-01
**Keywords:** github, github connect, what is github connect, connect, tell me about github connect
**Sources:** NayaNET Knowledge · GitHub Connect

## Answer

GitHub Connect gives Naya a governed connection to your repositories, issues, pull requests, workflows, and development activity.  For someone building with Naya, this is the most immediately useful door.  It lets Naya move from:  **“Here's what I think you should build.”**  to:  **“I can understand the actual project, work with the code, and participate in the development process — within the authority you've given me.”** Think of GitHub as **your project's workshop**.
