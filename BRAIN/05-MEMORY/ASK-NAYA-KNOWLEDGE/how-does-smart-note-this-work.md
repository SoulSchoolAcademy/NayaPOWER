# How does “smart note this” work?

**ID:** how-does-smart-note-this-work
**Keywords:** how does smart note this work, smart note this, capture a note, how do notes work, take a note
**Sources:** NayaNET Knowledge · Smart Notes

## Answer

Say "smart note this" — or just write it — and Naya turns your thought into a Smart Note. It's written to your GitHub as the source of truth, then flows into your Hub's Smart Feed as a beautiful card within seconds: the one-line nutshell, the human explanation, the simple version, and what it means for you. You think it, Naya remembers it — on every device.

## Key points

- Say it or write it — that's the whole interface
- Stored in GitHub, shown live in your Hub feed
- Arrives in the full 9-layer format
- There on every device, seconds later
