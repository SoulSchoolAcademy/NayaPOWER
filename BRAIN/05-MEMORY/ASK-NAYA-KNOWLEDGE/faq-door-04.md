# What is Data Connect?

**ID:** faq-door-04
**Keywords:** data connect, connect, what is data connect, tell me about data connect
**Sources:** NayaNET Knowledge · Data Connect

## Answer

Data Connect gives NayaPOWER access to structured, persistent information. This is the door that answers:  **“Where does important information actually live?”**  It can connect Naya to governed databases and data systems. A conversation can remember something temporarily. A persistent data system can store something deliberately.  Data Connect creates a governed bridge between NayaPOWER and that persistent information. That makes it possible to:  • retrieve structured information • save intelligence • query records • maintain durable state • build applications around persistent intelligence
