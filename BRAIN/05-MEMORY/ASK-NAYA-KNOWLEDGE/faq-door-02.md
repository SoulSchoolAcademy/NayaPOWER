# What is MCP Connect?

**ID:** faq-door-02
**Keywords:** what is mcp connect, connect, tell me about mcp connect, mcp connect
**Sources:** NayaNET Knowledge · MCP Connect

## Answer

MCP — Model Context Protocol — is a standardized way for an AI system to discover and use tools and resources provided by other systems.  Think:  **MCP brings tools to Naya.**  It is a universal-style connection layer for capabilities. Instead of Naya needing a completely different custom integration for every tool provider, an MCP server can expose tools through a common protocol. Imagine Naya has a universal tool socket.
