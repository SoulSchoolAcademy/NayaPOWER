# What is Smart Tabs?

**ID:** faq-feat-06
**Keywords:** tell me about smart tabs, smart tabs, smart, what is smart tabs
**Sources:** NayaNET Knowledge · Smart Tabs

## Answer

Smart Tabs create focused views into intelligence so you can see the information, tools, activity, and context that matter for the moment you're in.  A normal tab opens a page.  A Smart Tab opens a context. Your brain doesn't think about everything at once.  When you're working on a project, you care about that project.  When you're planning a trip, you care about the trip.  When you're learning something, you care about the subject you're learning.  Smart Tabs help create that same kind of focus inside NayaNET.
