# Smart Notes

**ID:** unified-smart-notes
**Keywords:** what is a smart note, smart notes, smart note
**Sources:** NayaNET Knowledge · Smart Notes

## Answer

A Smart Note captures something worth remembering and turns it into intelligence that can be understood, connected, retrieved, learned from, and used again. A normal note helps you remember something. A Smart Note helps the system remember something intelligently. You think it. You capture it. Naya remembers it.
