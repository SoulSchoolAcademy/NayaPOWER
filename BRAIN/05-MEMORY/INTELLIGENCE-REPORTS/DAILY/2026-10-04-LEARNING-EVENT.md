The same day he defined capture intent: "smart note this," "document it," "lock this in" are one intent in natural language, not a magic trigger phrase.

### 2. Full auto-merge: trust the scorecard
- **What it is:** Late in the day Shawn replaced the held human-click merge gate outright: "Full auto-merge — trust the scorecard." Asking him to click merges he does not independently judge was delay without safety; the team's recorded scorecard becomes the gate, with a decision receipt and live mechanical verification before merge. The first exercise landed the same evening (PR #1437, merged 28 seconds after the intent comment).
- **What it means:** Judgment moves to where the judgment actually happens — the scoring seat — while production deploys, production DB, credentials/money, destructive acts, and constitutional ratification stay human-only.
- **Why it matters:** The merge queue stops being bottlenecked on a rubber stamp, and every merge carries its reasoning on the record.
- **What's in it for me:** Never present Shawn a bare "merge this." If his decision is genuinely needed, explain what the change does, why it exists, what his approval changes, and the real risk — otherwise score it, record it, and merge it yourself.
- **How it connects:** This is the seed of everything the merge protocol later became — and of its failure mode: the scorecard only works if the scoring is honest (see the same day's law: beautiful ≠ 10/10; score even perfect-looking work).
- **What changes tomorrow:** From now on, merges execute on scorecard + receipt + live verification instead of waiting for a human click that adds no judgment.

### 4. Never write about the product from memory — open the page first
- **What it is:** Shawn caught the ecosystem blocks written from recollection: Life with Naya was described as 27 chapters (it is a 9-page birth announcement); MAXIS was given nine dimensions (it has five). Seven of nine blocks were rewritten against the live pages, and the review standard was sharpened the same day: every block is scorecarded for effectiveness, accuracy, and presentation, with claims verified against the actual source pages before they are presented as real.
- **What it means:** Accuracy is scorecarded, and memory is not a source.
- **Why it matters:** User-facing copy written from memory ships confident falsehoods about the user's own properties — the worst kind of error, because it looks finished.
- **What's in it for me:** Before writing a single user-facing claim about a page, property, or product, open it and read it; if you cannot open it, say so instead of reconstructing it.
- **How it connects:** This is the evidence law at the writing desk — the same discipline as verifying claims against live tree bytes rather than code search or recollection.
- **What changes tomorrow:** From now on, product copy is drafted from the live source in front of the writer instead of from what the writer remembers the source saying.

### 5. Connected is not authorized
- **What it is:** Shawn's Smart Connect authority law: a connection exposes capability; it does not grant authority. Every door follows CONNECT → UNDERSTAND → AUTHORIZE → ACT → VERIFY → RECORD → LEARN, with the permanent distinction CONNECTED ≠ AUTHORIZED. LAW decides what may happen, ACT performs it, VERIFY checks the result.
- **What it means:** Plugging a system in and being permitted to act through it are two separate events, and the second one is a governed decision.
- **Why it matters:** Conflating the two is how integrations silently become authority grants nobody approved.
- **What's in it for me:** In any integration you design or review, name the authorization step explicitly; if it isn't there, the design isn't done.
- **How it connects:** The five-door product model (GitHub, MCP, AI, Data, SDK Connect) was built under this law the same day — browsing and joining stay free; acting requires the door's authority.
- **What changes tomorrow:** From now on, every connection we build carries its own authorization gate instead of inheriting permission from the fact that it connects.
