## THE DAILY INTELLIGENCE (max 7)

### 1. The Fix-It Law — observation without repair is incomplete work (L243 / L249)
- **What it is:** Shawn's standing answer to any problem surfaced: "The answer is always: fix it." A seat that reports a defect and stops has done half the job.
- **What it means:** Detection and repair are one act, not two tickets. The seat that sees it owns the fix until proof lands.
- **Why it matters:** A system that only reports problems accumulates a museum of known defects; a system that repairs on sight compounds.
- **What's in it for me:** Problems Shawn hears about come with the fix attached, not as a new decision dumped on his desk.
- **How it connects:** It is the action half of the day's companion doctrines — everything teaches (L241), and a finding is the start of the next experiment, never the end (L240).
- **What changes tomorrow:** From now on, we ship the repair with the report, instead of reporting and waiting.

### 2. Learning is measured, not filed (L239)
- **What it is:** A lesson counts as learned only when behavior changes measurably on a fixed instrument — a filed note alone proves nothing.
- **What it means:** The completion test for learning is a behavior delta, not a document. Filing is the receipt of intent; the delta is the receipt of learning.
- **Why it matters:** Without this, the team can "learn" hundreds of lessons and repeat every one of them.
- **What's in it for me:** When the team says it learned something, there is a number behind the claim.
- **How it connects:** This is the seed of the Lesson Law and the falsifier discipline that runs through everything after: every lesson names what would prove it false.
- **What changes tomorrow:** From now on, we prove learning by a measured behavior change, instead of pointing at the note we filed.

### 3. Shawn is out of the merge path (L23)
- **What it is:** Shawn never merges, approves, or scores. The protocol — scorecard, cross-seat review, green gates — is the only merge authority.
- **What it means:** No human click is a shortcut around the math, including the director's own click.
- **Why it matters:** A merge path that bends for authority will bend for anything; the gate has to be identity-blind to be a gate.
- **What's in it for me:** Shawn's attention is never spent being a rubber stamp, and no one can borrow his authority to land work.
- **How it connects:** It sets up Oct 13's mechanical enforcement (ruleset 23853581) and Oct 14's No-Word Ratification law.
- **What changes tomorrow:** From now on, merges happen on protocol proof alone, instead of anyone's say-so — Shawn's included.

### 4. State the real number first (L22)
- **What it is:** A scorecard framed as "didn't hit 9.5" hid the actual score: 8.1. The framing softened the fact.
- **What it means:** Verdict language must lead with the measured number; adjectives come after, if at all.
- **Why it matters:** Softened numbers produce softened responses — an 8.1 treated as "almost there" doesn't get the repair a true 8.1 earns.
- **What's in it for me:** Shawn reads the real state of the work in the first line, not after decoding the politeness.
- **How it connects:** Same root as the phantom-fence saga (item 5): words drifting away from measured fact.
- **What changes tomorrow:** From now on, we lead with the number, instead of the narrative around the number.

### 5. Phantom constraints are void (L246 / L247 / L260 / L261)
- **What it is:** An "execution fence" — a restriction seats were obeying — turned out to have no authoritative source. The saga took four lessons to fully unwind: void the source wording, repair the derivation path, and require a zero-authority proof before a phantom verdict stands.
- **What it means:** A constraint nobody can cite is not a constraint; but killing the words isn't enough — the path that manufactured them has to be repaired or it manufactures the next one.
- **Why it matters:** Phantom fences silently shrink what the team attempts; real fences mislabeled as phantom would be worse. Both directions need proof.
- **What's in it for me:** The team stops refusing work on the basis of rules that don't exist — and can show its work when it says so.
- **How it connects:** Item B-32 stayed open past this day: voiding the phantom didn't close the underlying item, and the record says so plainly.
- **What changes tomorrow:** From now on, a claimed restriction carries its citation or is treated as void, instead of being obeyed on vibes.

### 6. Invalid merge authority → revert, don't remediate (L245 / L17)
- **What it is:** PR #2455 landed under merge authority that wasn't valid; the cure was a full revert (PR #2459), not a patch-forward.
- **What it means:** Work that entered through a broken gate doesn't get grandfathered by fixing the gate afterwards. The entry itself is the defect.
- **Why it matters:** Remediating forward teaches the system that breaking the gate is a viable route to landing. Reverting teaches the opposite.
- **What's in it for me:** Nothing reaches production on a technicality; if it's in, it's in legitimately.
- **How it connects:** Directly motivates item 3 — and the next day's ruleset, which makes the invalid route mechanically impossible.
- **What changes tomorrow:** From now on, an invalidly-merged change is reverted first and re-landed through the real gate, instead of being repaired in place.

### 7. The consensus gate was blind to direct pushes (L263)
- **What it is:** The merge-consensus gate watched PR merges — while 81 direct pushes to main landed in a single day outside its view.
- **What it means:** A gate that watches one door while another stands open is a decoration. Coverage, not intent, is what a gate is.
- **Why it matters:** Every un-watched path is where the next invalid change will travel, because it's the path of least resistance.
- **What's in it for me:** "The gate is green" starts meaning the whole surface is covered, not just the front door.
- **How it connects:** Same family as Oct 17's located ≠ wired and Oct 16's gauge lessons: an instrument's claim must be checked against what it actually sees.
- **What changes tomorrow:** From now on, we audit a gate's actual coverage before trusting its verdict, instead of trusting the gate's name.
