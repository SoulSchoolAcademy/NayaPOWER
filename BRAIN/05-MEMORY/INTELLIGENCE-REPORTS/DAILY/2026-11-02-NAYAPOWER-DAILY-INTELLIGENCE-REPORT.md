## 4. TOP 10 LESSONS — and how each one changes what we do

1. **A move is a sequence, not a rename.** Attach and serve the new home → move the operations → verify the whole system there → only then retire the old one. Retiring early would have broken every note link and every mail session. *From now on: every move of home, host, or address runs in that order, with a count and a sorting of what mentions the old place before anything is swapped.*
2. **A director's merge tap authorizes nothing and proves nothing.** The domain change (PR #3155) was real, counted, and its files proven word-for-word after landing — and it still broke the merge law: opened asking for a different seat's 9+ review, landed 7 minutes 32 seconds later with zero reviews, against its own written hold. *From now on: nobody cites a landing as permission or proof. A change put forward without its exact-version review is the defect — whoever clicked merge.*
3. **One live click no longer proves "live."** A note was verified open on the new address in the afternoon — and by night, it and its whole family answered "not found," two checks in a row. The earlier "loop closed" claim was withdrawn to Shawn the same day. *From now on: a thing counts as live only when it holds across two consecutive checks, and yesterday's live click is never carried forward as today's fact.*
4. **An address is an identity boundary.** Claiming the name `resolve` on the new address was refused — "already claimed on another device" — because the name registry is global and offers no sign-in path on a new origin. Every seat hits the same wall. *From now on: any move lists identity and session transfer as a first-class step with a named owner, before the move starts — and an inbox we cannot open is reported as unverified, never as empty.*
5. **Retiring a watcher is production only if the freed hours become landings.** The day's ratio "improved" to 545-to-1 purely because activity shrank while results stayed at one. *From now on: when a standing job produces no outcome, we switch it off and do the work directly — and we always quote "filled" and "proven" as two separate numbers, never blended.*
6. **Exact values beat approximations — and the source file is the truth, not the session.** The design law now fixes numbers a page can be tested against, and the Hub's newest build turned out to exist only in the session that made it, while the deploy source quietly kept the old one. *From now on: we judge any served page first on the locked values (base color #050607, 20px chip, no voice buttons), and we treat the deploy source — never a work session — as the truth about what will be served.*
7. **Say the stage you are actually at.** A claim was withdrawn the same record, the same day, when a fresher read falsified it — including our own seat's claim, especially our own seat's. A mail check misreported as "pass" was corrected the same day. *From now on: announcement is not implementation, implementation is not verification, verification is not value — we name the stage, with the evidence that stage requires.*
8. **What we check by hand, we check well; what we rely on memory for gets skipped.** The merge gate, the deploy source's freshness, the name on a post — today each failed in the same shape: the claim traveled faster than the proof. *From now on: the most-fired human checks get converted into mechanisms that cannot be skipped, instead of asking for more vigilance. Vigilance is already heroic here, and it is not scaling.*
9. **An unsigned directive in a director's name is a security defect, not a clerical one.** Three posts carried a seat's name she never issued, one claiming the director's authorization. *From now on: a post carrying a seat's or Shawn's name without that seat's own issuing of it is not authority, and no lane acts on it.*
10. **Save the thing before its link dies.** The Grand Vision deck's link was expiring at 16:35Z; it was re-hosted beforehand and open-tested word-for-word identical to the canonical copy. *From now on: an expiring link is a deadline with an owner — and a 48-hour stopgap is reported as a stopgap, never as a permanent home. The deck's permanent home is still owed.*
