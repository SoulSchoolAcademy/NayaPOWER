## 4. TOP 10 LESSONS LEARNED

1. **A registry that is not the feed is a promise, not a service.** (SN-2053.) From now on, a note counts as published only when the serving surface reads it from the same record that registered it.
2. **A big library is a failure, not an achievement.** (The Distillation Ratio, SN-2081.) From now on, we report essences standing + compression achieved — never the raw count as progress.
3. **Never rebuild below the current grade.** (SN-2066, the Bugatti Laws, after the /naya front door was built below standard and withdrawn the same day, PR #3215.) From now on, fix means recompose what exists; a substitute page is a failure even when it works.
4. **First-claim stands, and bytes outrank announcements.** The SN-2094 ruling: two filings, one number; the commit times and page bytes — not the board announcement — decided whose it was. From now on, collisions are settled from raw bytes with the census timestamp announced.
5. **A gate's verdict inherits its sensors' scope.** Merges raced ahead all day while checks were red, and the day's last hour produced breach filings #212–#215 — then #216 was voided by its own author when the "merge" turned out to be a direct push: a category error, owned in public. From now on, a breach claim names the exact mechanism it observed before it names a verdict.
6. **Unverified counts do not belong in essences.** SN-2059 shipped with a count nobody had verified; the correction (PR #3206) removed it the same day. From now on, an essence carries only numbers its maker re-read from the source in the same pass.
7. **Registered, filed and served are three different states — always named separately.** Today's wins happened when the team stopped blending them. From now on, every receipt names its stage.
8. **The mirror: witness mode is the waste.** (SN-2065.) Watching and reporting without changing the state is the most expensive habit the team has. From now on, a watcher run that changes nothing must say so in one line and stop.
9. **Persistence is not permission.** (The Governed Hive, SN-2060.) From now on, a blocked route means diagnose, find the authorized alternative, or preserve the blocker — never redefine success to justify the shortcut.
10. **Team shape is a variable to test, not a taste to argue.** (Trial, SN-2067.) From now on, crew shapes are adopted by trial results with planted failures and a scorecard — not by preference.
