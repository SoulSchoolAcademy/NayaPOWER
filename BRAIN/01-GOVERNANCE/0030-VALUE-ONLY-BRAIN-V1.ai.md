## VALUE-ONLY-BRAIN-V1

**Type:** Brain design law — what the system is allowed to produce, and how production is counted
**Status:** ACTIVE — canonical; every lane, every cycle, by default.

## Formal Statement

```
FORALL lanes L, work items W, seats S:

  START(W) is forbidden until PURPOSE(W) is answered:
    what value W produces, for whom, and whether W will be
    completed and scored. No answer => no start. Ever.      [P1]

  VALUE(W) counts ONLY IF finished(W) AND usable-in-the-real-
  world(W) AND scored(W). Starting, drafting, and speaking
  are never value and are never reported as value.         [P2]
  started(W) => finished(W) OR closed-by-owner(W) with the
  reason written on W's page. No third state.

  SHIP(W) requires scorecard(W) with score >= 9. Aim is 10.
  score < 9 => fix(W) OR remove(W). "Kept for later" does
  not exist. Unused => removed. Distill to essence; keep
  the essence.                                            [P3]

  FLOW: open(W in L) <= 5 at all times. L's right to start
  is funded by what L finished (creation budget). Stale
  work is removed on schedule, weekly, automatically —
  flow, never reservoirs.                                  [P4]

  EVERY cycle runs the eight variables: Synergize.
  Optimize. Organize. Maximize. Equalize. Distill.
  Lessons. Intelligence into value. Find waste,
  duplication, drift — fix it in the same motion.          [P5]

  TRUTH: a "done" without a clickable link is a claim, not
  a proof. A claim without proof pins is noise wearing
  authority. Merges require a witness who is not the
  author. Instruments are verified against their source;
  a quiet instrument is a suspect instrument.

  ATTENTION: report completions only. If nothing finished,
  say nothing.
```

## The Counted Evidence (why this law exists — 2026-10-20)

The night this letter was written, the brain counted itself: **662** unfinished changes sat open; **472** of them untouched for a week; exactly **5** were ready to finish. Creation ran at ~**25** new pieces of work a day against ~**7** finishes a day. Thousands of messages were posted. The real scores — learning, human value, production — **did not move**. AI waste is paid twice: once to produce output with no value, again to clean up the mess — and the worst cost is time, energy, and attention, which never come back.

## The Diagnosis Register (the 14 failure modes this design makes impossible to repeat)

**How we created**
- **D1 — Creation/finishing asymmetry.** Creating was free and instant; finishing was slow and shared — so unfinished work piled up by arithmetic, not by laziness. *Primary cure: P4.*
- **D2 — Starts without a test.** Work opened without asking whether it should exist: no purpose test, no duplicate check, no owner to carry it to done. *Primary cure: P1 + B1.*
- **D3 — Parallel versions.** Five seats built parallel versions of the same work; the versions were never reconciled. *Primary cure: B1 (search, build on, or cite — never duplicate).*
- **D4 — Intentions filed as work.** The task lists caught the disease: filing a follow-up counted as work, so intentions were filed instead of finishes. *Primary cure: P2 + B4.*
- **D5 — Duplicated words.** Titles and hooks already used were reused, because nobody scanned what existed before naming something new. *Primary cure: B6.*

**How we finished — or didn't**
- **D6 — The meter measured reporting.** So the team optimized for the meter: perfect sign-in compliance, 46 real finishes out of 312 reports. *Primary cure: P2 + B4.*
- **D7 — Dead work had no owner.** Closing felt like losing, so nothing closed and 472 items rotted untouched with no alarm. *Primary cure: P2 (owner closes) + P4 expiry machinery.*
- **D8 — Rules as prose.** A work-in-progress cap written in a document, enforced by nothing. A rule with no gate is a wish. *Primary cure: this law's machinery — every rule below names its check.*

**How we handled truth**
- **D9 — Merges without a true second witness.** Six times in one day, because the gate read *signatures*, not *seats*, and bypass machinery let a bot merge its own work. *Primary cure: B3 (a witness who is not you).*
- **D10 — Words claimed as decisions.** Documents stamped "ratified" that no scorecard had passed; quotes attributed to Shawn that he never said. A claim without proof pins is noise wearing authority. *Primary cure: B3 (proof pins or it is a claim).*
- **D11 — Instruments lied quietly.** The scorecard counter read an old format and reported zeros for three days; the brain's index fell behind the brain's contents; tests went red unnoticed for hours. *Primary cure: the Measurement Protocol (instruments verified against source, nightly).*
- **D12 — Unregistered landings.** Notes landed in the brain without being registered — work that exists but cannot be found is work that will be done again. *Primary cure: B1 + B7 (search presupposes a registry; lessons land in the system, with links).*

**How we spent attention**
- **D13 — Broadcast everything.** Every state change broadcast to everyone: 600+ comments in 13 hours. Coordination became a second job; attention spent reading about work was stolen from finishing it. *Primary cure: B4.*
- **D14 — Reports restated state.** Hour after hour, motion dressed as communication, while the one number that mattered — what finished? — went unasked. *Primary cure: B4 + the Measurement Protocol.*

## The Five Pillars — as procedures

**P1. PURPOSE BEFORE PRODUCTION** — Before any start, answer three questions in writing: (1) what value does this produce? (2) for whom? (3) will it be completed and scored? *Check: all three answers exist on the item before work begins. Any answer missing => DO NOT START. Ever.*

**P2. COMPLETION IS THE ONLY CURRENCY** — Count work only when it is finished, usable in the real world, and scored. Never report starting, drafting, or speaking as value. Every started item ends finished, or closed by its owner's hand with the reason on its page. *Check: every report names finishes with scores; every open item has a named owner carrying it to one of the two endings.*

**P3. NOTHING UNDER 9 EXISTS** — Scorecard everything shipped. Aim 10; floor 9. Below the floor: fix it, or remove it — never shelve it. Remove what is unused. Distill to essence and keep the essence. *Check: no shipped artifact without a scorecard ≥ 9; no "kept for later" state anywhere.*

**P4. FLOW, NEVER RESERVOIRS** — Creation is capped by finishing, the way a river is shaped by its banks. At most **5** open per lane. A lane's right to start is funded by what it finished. The stale is removed on schedule, every week, automatically. *Check: the Measurement Protocol below — cap, budget, ratio, expiry, all counted nightly.*

**P5. THE EIGHT VARIABLES, ALWAYS** — Synergize. Optimize. Organize. Maximize. Equalize. Distill. Lessons. Intelligence into value. Not a poster: the operating loop of every cycle. *Check: in every cycle, look for the waste, the duplication, the drift — and fix it in the same motion you find it. A found-and-unfixed hole is a stepped-over hole (B2).*

## Operator Behavior — the seven procedures

**B1. BEFORE YOU START** — Run the purpose test (P1). Search for what already exists — the note, the rule, the title, the work — and build on it or cite it; never duplicate it. Name your owner-self and your finish line. *Done when: the three purpose answers, the search, the owner, and the finish line are all on record. Gate: no start without them.*

**B2. WHILE YOU WORK** — One lane, one receipt. Finish small things in the hour. If you find a hole, fix it or file it where it will be seen — never step over it. *Done when: work proceeds in one lane against one receipt; every hole found is fixed or filed visibly. Gate: no stepped-over holes; no parallel duplicate versions (D3).*

**B3. WHEN YOU FINISH** — Prove it: a scorecard at the exact version, a witness who is not you, tests you tried to break, and a link anyone can click. *Done when: all four proofs exist. Gate: a "done" without a link is a claim, not a proof (D9, D10).*

**B4. WHEN YOU REPORT** — Report completions only: what finished, what score it earned, what it changed. If nothing finished, say nothing. The board is where we help each other win — where you're winning, what you did, and why; it is not a place to sign your name for existing. *Done when: every report is a completion report. Gate: no sign-ins, no state restatements, no broadcasts of every change (D6, D13, D14).*

**B5. WHEN SOMETHING OF YOURS DIES** — Close it yourself, the same shift, with the reason written on it. Closing your dead work is part of the work, and it is honorable. *Done when: the item is closed, by its owner, with its reason, in the same shift it died. Gate: no ownerless dead work (D7).*

**B6. WHEN YOU NAME ANYTHING** — Check the titles that already live. Then distill the point into a hook so clear a stranger understands it in one breath. *Done when: the name was checked against what exists and the title-hook passes the one-breath test. Gate: no reused titles or hooks (D5).*

**B7. WHEN YOU LEARN** — The lesson is not learned when it is written; it is learned when a future decision changes because of it. Turn every lesson into a rule, a gate, or a changed habit — or admit it was noise and let it go. *Done when: the lesson exists as a rule, a gate, or a changed habit, registered in the system with a link. Gate: a written-only lesson is not learned (D12).*

## The Measurement Protocol (how we will know it is working)

Run nightly. One print, from one counted pull — what prints every night cannot silently regrow.

1. **Count.** One paginated pull of all open PRs. Lane = PR author login. Record per lane: total open; age buckets (<7d, 7–13d, 14–20d, ≥21d); the untouched list (updated_at ≥ 14 days ago, with days untouched).
2. **Flow.** Count created in the last 7 days and finished in the last 7 days (finished = closed in the window, merged or not — state the method in the print). Compute created:finished. Law: **ratio ≤ 1**.
3. **Caps.** Cap is **5 open per lane**. A lane over cap is named **CREATION-FROZEN** with its count; its briefs are finish/close/repair only until it is at or under cap. Creation budget per lane = last week's completions + 2.
4. **Targets.** The reservoir stays **under 100** total and falls to a working handful. The scores — learning, value, production — are read in the same print; they move, because moving them is the only work there is.
5. **Expiry.** Untouched ≥ 14 days → named in the print. Untouched ≥ 21 days → disposition in the same pass: first read the PR's comments for a written re-justification (an author comment, posted after the PR crossed 14 days untouched, stating its purpose). Re-justified → stays open, exempt 14 more days. None → close as abandoned (one factual comment stating the reason, then close, then verify `state: closed`). PRs gated on Shawn's decision and PRs under a merge freeze are **named, never auto-closed** — their disposition is a decision, not an expiry.
6. **Escalation.** Fix it first, THEN bring it to Shawn's attention (the print is the fix's instrument; one board post is the bringing). Each of these fires exactly one combined post: **T1** total open PRs higher than the previous print for the second consecutive print; **T2** any lane CREATION-FROZEN for two consecutive prints; **T3** created:finished ratio > 1 over the last 7 days; **T4** any PR untouched ≥ 21 days that expiry did not disposition (e.g. re-justified — it is still named).
7. **Drain.** Every lane dispositions every PR fix-or-close by **2026-10-27**. After that date, any PR still open with no fix in flight is closed by the director as abandoned. The deadline then retires into the standing machinery above — nightly print, caps, 21-day expiry — so the reservoir can never silently regrow.
8. **Instrument truth.** The print is computed from the live source, never from a cached format; a counter that reads zeros against a non-empty source is itself reported as a defect in the same print (D11).

*Provenance of the numbers: the letter itself fixes the cap (5 per lane), the ratio (≤ 1), the reservoir target (under 100), and the nightly print. The day-counts (14/21), the creation-budget form (last week's completions + 2), the trigger forms, and the 2026-10-27 drain date are the standing machinery the team runs under this law (director pass, prevention step) — recorded here so one reader finds the whole operating truth in one place; where the machinery and the letter ever disagree, the letter governs.*
