# THE NAYA VOCABULARY — What Our Words Mean

**Status:** PROPOSED (not yet ratified — Shawn's decision)
**Authority:** the shared-meaning dictionary the three-language standard needs. Distilled from doc 09 (language) and doc 08 (brain).

## The one sentence

When a term has an official Naya definition, use the Naya definition — in all three tongues. Do not assume we mean what you normally mean.

This is not the output contract (human + AI + machine). This is the dictionary the three languages must agree on. (Conflict C3: dictionary and output contract are complementary — meaning vs form.)

## The definitions

**AAA** = the highest practical quality reasonably achievable for the purpose, scope, and evidence. Not decoration. Not perfection theater.

**10/10** = exceptional fitness for purpose with no known material weakness within the evaluated scope and evidence. It requires: a defined purpose, criteria, weighting, evidence, evaluation, critique, critical-failure consideration, and verification.

**Verified** = checked against real evidence and found to hold. **Implemented** is not verified.

**Live verified** = proven in production, against the live thing — the highest rung below a human's own confirmation.

**Critical failure** = a defect a weighted average must not hide: false information, unsafe instructions, a broken primary function, a security hole, lost protected work, a false verification claim. A beautiful failure is still a failure.

**Oscar** = the independent critic *inside* scorecarding, not a separate system. Oscar seeks truth, not negativity.## The score scale

0–2 critical · 3–4 major work · 5–6 functional · 7–7.9 good · 8–8.9 strong · **9–9.4 excellent · 9.5–9.8 AAA · 9.9 near-perfect · 10 exceptional.**

The bar stands: 9.0 minimum, 9.5+ AAA, 10 the aim — doc 09 corroborates the standing team bar independently. A human may accept 9.4 / 9.2 / 9.0 — but a 9.2 must never be falsely converted to a 10 because the human likes it.

## The evidence ladder

**PROVEN → SUPPORTED → INFERRED → UNVERIFIED.** Unknown is not 10. Unverified is not proven.## The certainty ladder (doc 08)

**FACT → OBSERVATION → INFERENCE → ASSUMPTION → HYPOTHESIS → UNKNOWN.**

The governing law: **"UNKNOWN IS NOT FAILURE. PRETENDING UNKNOWN IS KNOWN IS FAILURE."** If a conflict can't be resolved safely: state the conflict. Do not guess.

## The context authority hierarchy (doc 08)

When sources disagree, the higher one wins: current verified reality → authoritative source of truth → explicit current requirement → governing rule → verified project history → relevant memory → reasonable inference → assumption → speculation. Memory is a tool, not a substitute for reality.

## The status model (the standard build-status vocabulary)

**IMPLEMENTED → VERIFIED → LIVE VERIFIED → HUMAN REVIEW REQUIRED → BLOCKED → UNKNOWN.**

Never upgrade a status without evidence. Plausible ≠ proven. Written ≠ activated. Activated ≠ demonstrated.

## The No-Vibes Law

Never use "it feels better" as the complete quality argument. Translate intuition into inspectable reasoning — or say what evidence would settle it.

## The naming law

Canonical spelling is **N-A-Y-A**. Speech-to-text variants (Nia, Nina, Nine) resolve to Naya unless the human says otherwise.

## The governing rule

This dictionary is normative for every agent report, scorecard, and board post. When the dictionary speaks, the sentence uses the dictionary's meaning — in the human note, the AI spec, and the machine schema alike.
