## The one sentence

No important experience is allowed to disappear without teaching us something — and no important mistake is allowed to remain only a mistake: every real lesson must earn its evidence, and every proven lesson must change what Naya does *before* she acts, not after.

## How it works (the loop)

EXPERIENCE → OBSERVATION → REFLECTION → LESSON → MEMORY → RULE → PREFLIGHT → BETTER ACTION → NEW EXPERIENCE.

Everything you do flows back into how well you do the next thing. The point is not a bigger memory — it is better judgment.

## The ratchet (why this is safe)

A lesson travels **two separate tracks**, and they are never confused:

- **How mature is the lesson?** OBSERVED → PROPOSED → CONFIRMED → OPERATIONAL → SUPERSEDED.
- **How proven is it?** UNKNOWN → IMPLEMENTED → TESTED → VERIFIED → RUNTIME-PROVEN → PRODUCTION-PROVEN.

A lesson does **not** go live just because it was learned. It goes live when the evidence earns it. A clever idea with no evidence stays a candidate — it never steers consequential action.

## Preflight — where behavior actually changes

Before any consequential action, Naya checks the lessons first: *Have we made this mistake before? Is there a verified lesson for this? What must not be touched? What must be verified afterward?*

A rule can **warn**, ask for **confirmation**, demand **more evidence**, or **block** an unsafe move outright — depending on its authority. This is the moment learning turns into behavior. This half of the loop was never named before.

## The test (pass/fail)

Did the intelligence survive? Can we find it? Can we understand it? Can we prove it? Can we learn from it? Can that learning improve what happens next?

If yes: **THE SYSTEM IS COMPOUNDING.**

## What this is not

- Not model-weight changes. Learning lives in captured intelligence, evidence, and rules — never silently inside the model.
- Not automatic adoption. Detecting a pattern is not the same as trusting it.
- Not more remembering. A bigger memory that produces irrelevant noise is not intelligent.

## Decisions recorded here (we don't pick silently)

- **One compounding loop (C1).** Two existed; we kept 05-AI's evidence-gated one. The operating memo's version has no evidence gate and no preflight seam — without them there is no ratchet and no place where learning changes behavior.
- **Three tongues stand (C2).** The Child/Grandma perspective from the original is not a fourth language — it is a readability test for the human tongue: a normal person must read this and understand why it matters.
- **Two maxims coexist (C3).** "No important mistake…" is the sharp operational unit the machine consumes; "no important experience…" is the human unit that catches what the machine can't name. Neither replaces the other.
- **Genres, not tongues (C5).** Founder Letter / White Paper / Operating Model / Tech Spec are document genres (why / what / how / machine-how); each genre ships in the three tongues per the standing standard.
