# Kernel Acceptance V1

Structural existence is only the first gate.

```
STRUCTURAL
→ CONTRACT
→ UNIT
→ INTEGRATION
→ BEHAVIORAL
→ OUTCOME
→ CAUSAL
→ PRODUCTION
→ SUCCESSOR
```

The decisive test is behavioral: one useful intelligence object must survive cold context, influence authorized behavior, produce an observable outcome, be verified, become learning, and improve successor behavior.
