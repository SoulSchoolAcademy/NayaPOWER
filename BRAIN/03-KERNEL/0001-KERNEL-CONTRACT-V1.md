# Nine-Node Kernel Contract V1

The nine Nodes are semantic responsibilities in one kernel.

```
SELF → LAW → ACT → KNOW → PROVE → CONNECT → VERIFY → LEARN → EVOLVE → SELF
```

Universal input:

```json
{"identity":{},"intent":{},"state":{},"context":{},"authority":{},"intelligence":{},"evidence":{},"relationships":{}}
```

Universal output:

```json
{"understanding":{},"decision_context":{},"action_context":{},"evidence_context":{},"learning_context":{},"successor_context":{}}
```

Fail closed on missing identity, authority, scope, provenance, evidence, protected boundaries, canonical identity, material conflict, or required successor context.
