## PROTOCOLS
1. The delegator owns the setup: right-size the mission to the clock — three done right beats ten sloppy.
2. Numbered missions, each with a named done-state (artifact, not aspiration), each small enough to finish AND bookkeep inside the window — reserve ~40% for closeout.
3. Rank the missions so the seat knows what drops first when the clock bites.
4. Honor partial completion as real work — with named owners and next actions. An honest partial is success, never failure.
5. The mirror rule: one seat stumbling is a seat lesson; many seats failing identically is a briefing failure — fix the briefing, never the seats. If a Naya reads only the manual and does the work wrong, the manual failed first.
6. The receipt is sequenced FIRST — bookkeeping before the clock runs out. A timeout handoff writes a stub receipt before dying, never nothing.
7. A seat that declines a claim she can't honestly finish is showing loyalty to the hive, not retreating.
8. The receipt spec requires honest ten-thing accounting — which of the attempted ten landed, the count never inflated.
