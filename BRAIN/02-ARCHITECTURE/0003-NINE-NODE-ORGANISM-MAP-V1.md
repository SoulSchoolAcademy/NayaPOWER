## One intelligence, several surfaces

```
EXPERIENCE / SMART NOTE
        ↓
CANONICAL INTELLIGENT BLOCK
        ├─ Supabase runtime persistence
        ├─ graph / relationships / retrieval index
        ├─ GitHub Brain human-readable projection
        └─ NayaNET Hub visual projection
             ├─ Personal Intelligence (private by default)
             └─ Collective Intelligence (by consent/publication)
```

None of these projections becomes a second truth source.

## Continuation engine

`MISSION → CURRENT VERIFIED STATE → GAP → PRIORITY → RELEVANT INTELLIGENCE → AUTHORITY → ACTION → OBSERVATION → VERIFY → LEARN → UPDATE STATE → NEXT GAP`

The system may continuously select the next gap **only inside granted authority**. A planning loop is not self-authorization.

## Smart Door law

`CONNECT discovers capability → LAW decides permission → ACT invokes → VERIFY checks result`

## Current proof frontier

SELF/identity has bounded live evidence. LAW is the first new live Node targeted by this pass. Universal nine-node runtime binding remains unproven until the complete black-box chain passes.
