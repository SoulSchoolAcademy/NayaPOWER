## The six machines

1. **MEANING** — what are we, why do we exist, what is the mission. If removed: nobody knows what the system is for; optimization has no direction.
2. **INTELLIGENCE** — information → understanding → connected intelligence → learning. If removed: data accumulates, nothing gets smarter.
3. **GOVERNANCE** — what should we do, may we do it, is it good enough. If removed: power without permission — the Artifactory lesson, live again.
4. **EXECUTION** — did something really happen, with proof. If removed: intentions, not outcomes.
5. **CONTINUITY** — what happened → learned → next. If removed: every session starts over; successors inherit nothing.
6. **HUMAN/NETWORK EXPERIENCE** — the Superbrain made human-usable. If removed: intelligence exists but no human can reach it — value unproven, mission failed.

## The three loops

- **Intelligence loop:** CAPTURE → UNDERSTAND → CONNECT → REMEMBER → LEARN → better understanding. Feeds the brain.
- **Action loop:** MISSION → PREFLIGHT → VALUE → AUTHORITY → SELECT → EXECUTE → OBSERVE → VERIFY. Moves the world, safely.
- **Trust/Continuity loop:** VERIFIED ACTION → EVIDENCE → ACTIVITY → STATE → NOTE → LEARNING → HANDOFF → NEXT NAYA → better action. Makes intelligence compound across successors.

## The ~10 engineering primitives

Identity · Authority · Mission State · Intelligence · Retrieval · Value Selection · Governed Execution · Evidence · Compounding Memory · Continuity. Around them: Oscar, Activity, Hub, Identity/Privacy, Release verification.

**The discipline:** every lane must be able to name which primitive it extends and pass the understanding test — *"If I remove this component, what breaks in the machine?"* — before it ships. Lanes multiply; primitives don't.

## The prescribed build order (phases 0–6)

- **Phase 0 — Understand.** Evidence matrix, dependency graph, contradiction map. No coding. The bar: the understanding test on every component.
- **Phase 1 — The spine.** IDENTITY, AUTHORITY, MISSION STATE, PREFLIGHT, EXECUTION ID, EVENT CONTRACT, EVIDENCE, VERIFICATION, HANDOFF. The spine is the minimum machine that can act once, safely, and be handed off.
- **Phase 2 — Close the trust gap.** execution → automatic canonical event → activity → state → successor. Projection without the canonical writer underneath is storytelling.
- **Phase 3 — Compound intelligence.** Retrieval, connected intelligence, learning with behavioral proof.
- **Phase 4 — Team Naya.** Multi-agent coordination under the same governance.
- **Phase 5 — Hub.** The Hub is a **projection of the Superbrain, never another brain**. An interface must not outrun the substrate it projects.
- **Phase 6 — Live proof.** The machine working, in reality, with evidence.

**Sequencing rule:** a phase's acceptance gates must pass before the next phase's work ships. The #55 reconciliation issue — which source actually produces the live product — is Phase 1 work, not Phase 5 polish.
