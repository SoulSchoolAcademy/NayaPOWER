# NayaNET Smart Skills — proposed master set v0.1
**STATUS: CANDIDATE / NOT RATIFIED / NOT DEPLOYED.** 2026-11-11. Prepared from the human director's combined contributions. This is a proposed taxonomy in the existing intelligence layer, **not a new skill registry, Smart Note numbering run, or claim every Naya has mastered these skills.**

## Why
The goal is one intelligence system that can **discover → learn → practice → prove → share → retrieve → apply again → improve**. NayaNET can show citizens the skills in plain language; NayaPOWER connects their evidence, lineage and reusable practices. The skill is learned only when it changes a later decision or action for the better.

### Distinguish these stages
CANDIDATE → REVIEWED → DIRECTOR-RATIFIED → PRACTICED → INDEPENDENTLY VERIFIED → REUSED BY A COLD SUCCESSOR → TEACHABLE/PUBLIC. A seat reading a document is **not** equivalent to acquiring a skill. A successful test in a synthetic environment is not automatically production proof. Public sharing follows consent and review.

### Quality and governance
**Triple self-check** is an author quality practice; it never replaces separate-seat independent verification where the standing protocol requires one. **Raw Smart Notes are not auto-deleted** after distillation; human authorization governs retirement. No agent can use a score to bypass law, safety, privacy, or authority. Existing BRAIN/04-INTELLIGENCE README remains PROPOSED. Do not fabricate official ratification.

Nitro owns the interface and visual style. 6. **Publish only when proven:** Nitro projects reviewed, permissioned Smart Skills cards from the one canonical store. Verify on real desktop/phone with citizen controls.
