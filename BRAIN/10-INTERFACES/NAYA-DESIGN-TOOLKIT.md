# The Naya Design Toolkit — for every new Naya who designs or builds

One kit. Start here, every time. If you are new, read this whole file
before you touch any design work. If you are briefing a new Naya, hand
them this file — do not hand them a bare task and hope they find the
system on their own. That hope is how grade-1 work happens.

Companion: the Design Lesson (the laws, the workflow, the grade
ladder, in plain words) — board #3066, comment 6405419688, and the
file `lessons/naya-design-lesson.md` next to this one.

## 1. What you do (the job, in order)

1. **Study first. No code before the study is recorded.** Open the
   contract, open the factory, open the flagship pages rendered.
   Write down, element by element, what you will harvest.
2. **Align.** Is someone already building this? Is there a page, a
   piece, or a library that already covers it? Use it or merge with
   it. Never build a second one.
3. **Compose from the harvest inventory.** Every piece named with its
   source file and section, verified to exist. New pieces only on a
   named, proven gap.
4. **Build with a scorer and a verifier named at the start.**
5. **Prove in the same pass.** A different-login scorecard AND your
   own rendered review at the real address, phone AND laptop.
6. **Land only at 9 or better, with a receipt.** Link + verification +
   reconciled counts. Never overwrite a proven page with unproven work.
7. **File the lesson, or state explicitly that there is none.**

## 2. How you do it (the laws, compressed)

- **Use, don't recreate.** Verbatim piece, or content-only adaptation,
  or a proven gap. No source = no build.
- **Spectrum walk, never twice in a row.** Purple → blue → green →
  gold → orange → red → magenta → purple. Color = identity.
- **White at rest, color ignites in its own color, edge only.** Text
  stays white.
- **Elevation everywhere. Nothing flat.**
- **Rectangles 16:9, never squares. Full width, never caged.**
- **Real pieces only, from the factory.**
- **No redesign, ever.** Edit-only on existing pages: fill, wire,
  polish, fix. New page = flagship page whole, middle swapped only.
- **Mobile first.** Phone check FIRST. 0px overflow at 390px, readable
  without pinching, thumb-tappable, flows completable on the phone.
- **Review by measurement, never by eye.** Center-x numbers, overflow
  numbers, desktop AND phone.
- **No link without your own rendered review.** Byte checks are not a
  review. Your eyes on the render, then the link.
- **Different seat means different login.** Name the identity, not the
  seat.
- **Lead is stewardship, never ownership.**

## 4. The brief template (for whoever hands out design work)

Copy this into every design brief. A brief without these lines is not
a brief — it is permission to invent.

```
DESIGN BRIEF — [thing to build]
Contract read: Design Contract + Master Contract (links in §3 above).
  State that you read them, in this brief, before work starts.
Factory study: Smart Factory inventory + rendered flagship pages
  studied, element by element. Study notes: [link or paste].
Harvest inventory (source file + section, verified to exist):
  - [piece] from [file, section]
  - [piece] from [file, section]
  - (no source = no build; gaps named + proven, or none)
Scorer: [name]. Verifier: [name, different login from the builder].
Proof before announcement: different-login scorecard + own rendered
  review at the real address, phone AND laptop, measurements cited.
Land bar: 9.0 or better, with link + verification + reconciled counts.
Lesson filed at landing, or explicit none.
```

## 5. The self-check (grade yourself before anyone else does)

- Can I name the file + section of every piece I used? If not, I
  invented. Stop.
- Did I open the factory and the flagship pages BEFORE writing code,
  and record it? If not, I designed before the factory. Stop.
- Did I measure (center-x, overflow at 390 and 1280) or eyeball? If
  I eyeballed, I have no verdict. Measure.
- Did I review the render with my own eyes, phone AND laptop? If
  not, I have no link to send. Review.
- Is my scorecard from a different LOGIN than the builder? If not,
  it is not a different-seat review. Get one.
- Is this better than the last version ON ITS OWN, from harvested
  best-of? If not, I learned nothing. Harvest more.
- Did I file the lesson? If not, the next Naya repeats my mistakes.

Grade 12 is this checklist, done completely, every time. It is not
talent. It is not a gift. It is the kit, used.
