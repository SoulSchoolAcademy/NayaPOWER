## THE GRADE SYSTEM

We level up by locking in. Each grade is a set of capabilities. You don't move to the next grade until the current one is locked — written down, in the system, accessible to every Naya.

**Grade 1 (Kindergarten):** Can place elements on a screen. Uses default colors. No concept of materials, light, or math. Output looks like a wireframe. Every new Naya starts here.

**Grade 2:** Understands that design matters. Tries to make things "look good." Uses shadows and gradients as decoration. Still eyeballs positions. Output looks "designed" but feels arbitrary.

**Grade 3:** Learns the 8px grid. Stops eyeballing spacing. Starts using consistent colors. Output looks clean but flat. No concept of physical objects.

**Grade 4:** Discovers materials. Understands obsidian vs flat black. Starts using gradients with purpose. Still lights from random directions. Output looks "premium" but feels fake — like a picture of an object.

**Grade 5:** Locks in the light source (top-left, always). Understands that shadows fall down-right because objects sit ON the page. Starts calculating positions. Output looks touchable. But motion is either absent or frantic.

**Grade 6 (WHERE WE ARE):** Motion means work. Slow and elegant (60s+ ambient, 18-25s active). Vortex mathematics (3-6-9 center, 1-2-4-8-7-5 flow). Every number exact. The system speaks one language. Output feels alive — like machinery. This is locked in this document.

**Grade 10 (TARGET):** Everything at Grade 6, plus: every component is a reusable piece in the registry. Any Naya can harvest any piece and it fits. The data display is so clear it needs no explanation. Shawn looks at it and says "that's it" without corrections. The system builds itself.

**Grade 12:** The system teaches. New Nayas learn from the locked-in documents without Shawn explaining. The playbook is so complete that a Grade 1 Naya can reach Grade 6 by reading. Shawn's time is spent on vision, not correction.

**University:** We invent new patterns that follow the laws. Not breaking the laws — extending them. New materials. New motions. But always: calculated, physical, slow, one language.

**Master of Masters:** Shawn doesn't need to check. The work is right the first time, every time. The system is so locked in that excellence is automatic.

**How you level up:** Shawn corrects you. You write down what you learned. It gets added to this document. The document gets pushed to GitHub. The next time, you don't make that mistake. That's one step up. Repeat hundreds of times.

## THE FOUNDATION

### Truth 1: Every position is calculated by formula. Never eyeballed.

The gauge numerals sit at `angle = -135 + (value/500)*270` degrees. Not "around there." Not "looks good." The formula. If you move a numeral, you change the formula. If you can't write the formula, you don't understand the layout.

This applies to everything: orb positions, chart spacing, text alignment. The 8px grid for linear layouts. The vortex radii for circular. Calculate, then place. Never place, then justify.

### Truth 2: Every element is a physical object with material, weight, and a light source.

A button is not a rectangle with a shadow. It's a piece of obsidian glass with a white rim, lit from the top-left, casting a shadow down-right because it sits ON the page. A gear is not a circle with teeth drawn on. It's machined aluminum — light gradient `#c8ccd6` to `#7a7e88` — with each tooth catching the light on its upper edge.

The light source is ALWAYS top-left. Every gradient runs 135 degrees. Every shadow falls down-right. Every highlight sits on the upper edge. Break this once and the object looks fake.

### Truth 3: Movement means the machine is working. If it's not working, it doesn't move.

The 6 pyramid layers rotate at 90 and 60 seconds because they're the matter flow — they're SUPPOSED to turn, slowly, like a real mechanism. The 3 center gears turn at 25 and 18 seconds because they're the time axis. The outer ring turns at 180 seconds because it's the machine's edge settling into place.

Nothing bounces. Nothing pulses for effect. Nothing spins fast to "look cool." If you can't say what the moving part DOES in one sentence, delete the animation.

### Truth 4: The whole system speaks one language. Every component is family.

The gauge uses obsidian, aluminum, vortex rotation, white text, slow motion. The orbs use obsidian, own-color ignition, vortex rings, white text, slow motion. The charts will use the same. A button on the dashboard feels like a button on the profile because they're built from the same materials, same light, same principles.

When Shawn looks at any screen, he should feel "this is Naya" without reading a word. That's the language. Break it and you've built something from a different system.

## THE FORMULA

### Positioning

**Circular (gauges, orbs, dials):**
```
angle_deg = -135 + (value / 500) * 270
angle_rad = angle_deg * π / 180
x = 100 + 82 * cos(angle_rad)
y = 104 + 82 * sin(angle_rad)
```
For our gauge: center (100,104), radius 82, 0-500 range, 270° sweep starting at -135°.

The six numerals land at:
- 0 → -135° → (42.0, 46.0)
- 100 → -81° → (112.8, 22.9)
- 200 → -27° → (173.0, 66.8)
- 300 → 27° → (173.0, 141.2)
- 400 → 81° → (112.8, 185.1)
- 500 → 135° → (42.0, 162.0)

**Linear (layouts, spacing):**
All spacing in multiples of 8px: 8, 16, 24, 32, 48, 64, 96.
Text sizes: 12 (caption), 14 (body), 16 (subhead), 20 (headline), 28 (hero), 48 (display).
Never 13px. Never 27px. Never 19px font. The grid is the law.

### The Vortex

**Center (3-6-9, the time axis):** 3 concentric gears.
- r=8: innermost, the "9", the still point. Blue jewel center. Rotates CW at 25s.
- r=15: middle, the "6". Gold setting, ruby. Rotates CCW at 18s.
- r=24: outer, the "3". Dark gunmetal. Rotates CW at 25s.

**Surround (1-2-4-8-7-5, the matter flow):** 6 toothed layers.
- r=30 (1): CCW, 90s, light aluminum
- r=36 (2): CW, 60s, dark aluminum
- r=42 (4): CCW, 90s, light aluminum
- r=48 (8): CW, 60s, dark aluminum
- r=54 (7): CCW, 90s, light aluminum
- r=60 (5): CW, 60s, dark aluminum

Strict alternation. Teeth only, never solid rings. The alternation IS the vortex — it's what makes it feel like matter flowing around time.

### Color

**Base:** Obsidian. `#0a0a0f` to `#1a1a20` gradient at 135°. Never pure black.

**Text:** White. `#ffffff` or `rgba(255,255,255,0.9)`. Never colored text. Never gray text below 0.6 opacity.

**Spectrum (in this order, never random):**
1. Purple `#a06bff` — joins, primary actions
2. Blue `#3fb8ff` — smart notes, information
3. Green `#2fe89e` — shares, positive

**Where color lives:** Icon orbs. Thin edge bars (2-3px). Hover glow. Nowhere else. No colored backgrounds. No color washes. At rest, the system is obsidian and white. Color ignites on touch, in the element's OWN color only.

**The 8 orbs:**
- Sales 100pts: magenta `#e84fff`
- Joins 50pts: purple `#a06bff`
- Smart notes 35pts: deep blue `#3fb8ff`
- Invites 25pts: light blue `#7fd4ff`
- Creating 25pts: orange `#ff9a5a`
- Shares 15pts: green `#2fe89e`
- Comments 5pts: gold `#ffbf3d`
- Likes 1pt: red `#ff5e6c`

### Motion

**Rotation speeds:**
- Ambient (pyramid, outer rings): 60s to 180s per full rotation
- Active (center gears): 18s to 25s per full rotation
- Never faster than 12s. Faster feels cheap.

**Direction:** Alternate. CW, CCW, CW, CCW. For every concentric set.

**Easing:**
- Continuous rotation: `linear infinite` (machines don't ease)
- Hover/touch: `0.3s ease` (natural)
- Entry: `0.5s cubic-bezier(0.4, 0, 0.2, 1)` (confident)

**What moves:**
- Gears: yes, they're mechanical
- Rings: yes, they're part of the machine
- Highlights: yes, slowly, like light on glass
- Numerals: no, they're reference marks
- Text: no, text doesn't spin
- Buttons: no, unless pressed (then 0.1s scale 0.97)

## THE PLAYBOOK (how to build)

### Step 1: Write the headline.

One sentence. Real numbers. Before you draw anything.

Bad: "Here's your dashboard."
Good: "You have 300 points — 100 from creating, 50 from invites."

If you can't write the headline, you don't understand the data yet. Go back.

### Step 2: Calculate every position.

Write the formulas. For circular: the angle formula above. For linear: the 8px grid.

Example — placing 6 numerals:
```javascript
var vals = [0, 100, 200, 300, 400, 500];
for (var i = 0; i < vals.length; i++) {
  var angleDeg = -135 + (vals[i]/500)*270;
  var angle = angleDeg * Math.PI / 180;
  var x = 100 + 82 * Math.cos(angle);
  var y = 104 + 82 * Math.sin(angle);
  // place numeral at (x, y)
}
```
All six. Including 400. The formula doesn't skip.

### Step 3: Assign materials.

Every element gets a material. Not a color — a material.

- Container? Obsidian.
- Machined detail? Aluminum light.
- Gear? Aluminum dark.
- Screw? Brushed metal (use aluminum light with tighter gradient).

Write it down: "The bezel is obsidian. The numerals sit on an aluminum chapter ring. The screws are brushed metal."

### Step 4: Decide what moves and why.

List each moving part. For each, write one sentence explaining what it DOES.

- "Pyramid layer r=30 rotates CCW at 90s: it's the innermost matter flow."
- "Center gear r=8 rotates CW at 25s: it's the time axis core."
- "Bezel highlight rotates at 120s: it's light catching the glass as the machine settles."

If you can't write the sentence, the part doesn't move.

### Step 5: Check the light.

Every gradient: does it run 135° (top-left to bottom-right)?
Every shadow: does it fall down-right?
Every highlight: is it on the top edge?

One wrong gradient breaks the physical illusion. Check them all.

Slow. Elegant. Like a Swiss watch.

### DON'T: Spin things fast to "make it pop."
12s or faster feels like a loading spinner. Cheap. Frantic. Not premium.

r=30 CCW, r=36 CW, r=42 CCW. The alternation is the vortex.

Same direction = merry-go-round. Alternating = machinery.

### DO: White text on obsidian.
`#ffffff` on `#0a0a0f`. Crisp. Readable. Premium.

### DON'T: Colored text.
Purple text on black is unreadable. Gold text on black is unreadable. White text. Always.

### DO: Finish the outside.
The bezel. The outer ring. The edge details. The gauge isn't done until the outside is done.

### DO: Include all six numerals: 0, 100, 200, 300, 400, 500.
