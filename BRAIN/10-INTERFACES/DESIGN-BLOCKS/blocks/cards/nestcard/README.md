# Smart Block: `nestcard`

Nested cards: the 'in a nutshell' card — diamond-dot kicker keyed to --nc, one true sentence. Cards inside cards without visual noise.

- **Type:** cards
- **Source:** `naya5/smart-blocks-library @ 1dc1241e (branch) — ported 2026-10-09`
- **CSS:** `nestcard.css`
- **Specimen:** `specimen.html`
- **Dependencies:** tokens.css

## Use it

1. Include the shared `tokens.css` (once per page).
2. Include `nestcard.css`.
3. Copy the HTML from `specimen.html`.
4. Set `--nc` inline — one spectrum color per card, never a flood.

## Selectors in this block

```
.nestcard
.nestcard .nk
.nestcard .ndot
```
