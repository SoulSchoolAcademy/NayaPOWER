# Smart Block: `nestcard`

Cards within cards — a thought and its meaning, nested, with a jewel marker for the key. Set `--nc` for the jewel color.

- **Type:** cards
- **Source:** `smart-blocks/cards/cards-nested-cards-nestcard.html + smart-blocks/cards/cards.css (branch naya5/smart-blocks-library)`
- **Files:** `nestcard.css`, `specimen.html`
- **Dependencies:** `tokens.css`
- **States:** `--nc jewel theming`

## Use it

1. Copy `nestcard.css` next to your page.
2. Link `tokens.css` first, then `nestcard.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).

## Selectors

```
.nestcard
.nestcard .nk
.nestcard .ndot
.nestcard p
```
