# Smart Block: `orb-bullet-list`

List with xs orbs as bullets — requires the orb block (`--oc`/`--oc-rgb` per item).

- **Type:** data
- **Source:** `Naya Jewel Library - N5.html`
- **Files:** `orb-bullet-list.css`, `specimen.html`
- **Dependencies:** tokens.css, orbs/orb
- **States:** none

## Use it

1. Copy `orb-bullet-list.css` (and `orb-bullet-list.js` if present) next to your page.
2. Link `tokens.css` first, then `orb-bullet-list.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.orb-bullet-list
.orb-bullet-list li
```
