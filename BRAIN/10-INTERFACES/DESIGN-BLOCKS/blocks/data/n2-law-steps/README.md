# Smart Block: `n2-law-steps`

Law steps. Build-procedure rows with jewel marks — the AI law as a checklist.

- **Type:** data
- **Source:** `Naya Design Elements N2.html` (extracted byte-true, never rewritten)
- **CSS:** `n2-law-steps.css`
- **Specimen:** `specimen.html`
- **States found:** none
- **Dependencies:** tokens.css

## Note

The `.jewel` glyph marks render as plain text marks here — the faceted jewel styling is scoped to `.card h3 .jewel` inside `n2-rpt-card`.

## Use it

1. Include `tokens.css` (once per page).
2. Include `n2-law-steps.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.
