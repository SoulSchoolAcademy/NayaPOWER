# Smart Block: `gem-list`

List dressed with gem bullets cycling the spectrum — requires the gem-bullet block.

- **Type:** data
- **Source:** `Naya Jewel Library - N5.html`
- **Files:** `gem-list.css`, `specimen.html`
- **Dependencies:** tokens.css, jewels/gem-bullet
- **States:** none

## Use it

1. Copy `gem-list.css` (and `gem-list.js` if present) next to your page.
2. Link `tokens.css` first, then `gem-list.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.gem-list
.gem-list li
```
