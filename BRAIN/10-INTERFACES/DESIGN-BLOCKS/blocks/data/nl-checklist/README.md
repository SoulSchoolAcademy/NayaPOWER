# Smart Block: `nl-checklist`

Static check list with green check markers — the quiet sibling of the ship gate, no JS.

- **Type:** data
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `nl-checklist.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** none

## Use it

1. Copy `nl-checklist.css` (and `nl-checklist.js` if present) next to your page.
2. Link `tokens.css` first, then `nl-checklist.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.checklist
.checklist li
.checklist li::before
```
