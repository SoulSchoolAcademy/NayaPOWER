# Smart Block: `naya-spinner`

The breath between asking and knowing — a ring that spins while Naya gathers your world.

- **Type:** data
- **Source:** `smart-blocks/new/new-empty-error-loading-naya-state-naya-spinner.html + smart-blocks/new/new.css + smart-blocks/base.css (branch naya5/smart-blocks-library)`
- **Files:** `naya-spinner.css`, `specimen.html`
- **Dependencies:** `tokens.css`
- **States:** none — one honest face

## Use it

1. Copy `naya-spinner.css` next to your page.
2. Link `tokens.css` first, then `naya-spinner.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
