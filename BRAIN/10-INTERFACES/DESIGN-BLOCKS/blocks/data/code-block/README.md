# Smart Block: `code-block`

Code specimen with labeled copy bar and one-click clipboard copy (Copied feedback).

- **Type:** data
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `code-block.css`, `specimen.html`, `code-block.js`
- **Dependencies:** tokens.css
- **States:** :hover

## Use it

1. Copy `code-block.css` (and `code-block.js` if present) next to your page.
2. Link `tokens.css` first, then `code-block.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. Wire the JS (`code-block.js`) — it is byte-true and self-initializing.

## Selectors

```
.micro
pre.code
.code-head
.code-head .micro
.copy-btn
.copy-btn:hover
```
