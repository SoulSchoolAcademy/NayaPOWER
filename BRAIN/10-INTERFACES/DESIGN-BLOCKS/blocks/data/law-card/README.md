# Smart Block: `law-card`

Principle cards that ignite in their own spectrum color (`--sc`) on hover — top light bar, lift, and colored glow.

- **Type:** data
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `law-card.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** :hover

## Use it

1. Copy `law-card.css` (and `law-card.js` if present) next to your page.
2. Link `tokens.css` first, then `law-card.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.law-grid
.law-card
.law-card::before
.law-card:hover
.law-card h3
.law-card p
```
