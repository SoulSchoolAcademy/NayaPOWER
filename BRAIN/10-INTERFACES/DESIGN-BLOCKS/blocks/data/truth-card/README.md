# Smart Block: `truth-card`

Claim-vs-proof truth cards. Verified glows green, claims stay quiet, demos wear magenta — one `--tc2` color drives orb, border and hover light.

- **Type:** data
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `truth-card.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** :hover

## Use it

1. Copy `truth-card.css` (and `truth-card.js` if present) next to your page.
2. Link `tokens.css` first, then `truth-card.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

