# Smart Block: `naya-state`

Empty, error, loading — the three honest faces of “not yet”, each with one clear next action.

- **Type:** data
- **Source:** `smart-blocks/new/new-empty-error-loading-naya-state-naya-spinner.html + smart-blocks/new/new.css + smart-blocks/base.css (branch naya5/smart-blocks-library)`
- **Files:** `naya-state.css`, `specimen.html`
- **Dependencies:** `tokens.css`
- **States:** `.is-error`

## Use it

1. Copy `naya-state.css` next to your page.
2. Link `tokens.css` first, then `naya-state.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).

## Selectors

```
.naya-state
.naya-state h3
.naya-state p
.naya-state.is-error .naya-state-icon
.naya-state-icon
```
