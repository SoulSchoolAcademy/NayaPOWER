# Smart Block: `law-chip`

Law chips — quiet pill labels for design laws, gathered in a wrapping strip.

- **Type:** data
- **Source:** `Naya  Elite Buttons N5.html`
- **Files:** `law-chip.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** none

## Use it

1. Copy `law-chip.css` (and `law-chip.js` if present) next to your page.
2. Link `tokens.css` first, then `law-chip.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.law-strip
.law-chip
```
