# Smart Block: `data/swatch`

Color swatch: 44px bar, 10px radius, 4-layer shadow, hover lift. The palette made touchable.

- **Type:** data
- **Source:** `Naya Design Element Set N4.html` (extracted byte-true, never rewritten)
- **CSS:** `block.css`
- **Specimen:** `specimen.html`
- **States found:** :hover
- **Dependencies:** `--ease` motion curve

## Use it

1. Include `block.css`.
2. Copy the HTML from `specimen.html`.
3. Set the color inline via `background`; keep the accessible label.
