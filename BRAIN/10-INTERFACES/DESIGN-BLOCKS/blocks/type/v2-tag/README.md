# Smart Block: `v2-tag`

Section kicker with a mini gem marker. Uppercase tracked label, jewel-lit by `--c`.

- **Type:** type
- **Source:** `Open_This_NayaNET_Design_V2.html`
- **Files:** `v2-tag.css`, `specimen.html`
- **States:** none (static)
- **Dependencies:** `tokens.css`

## Use it

1. Copy `v2-tag.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `tokens.css`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--c` to the section color. Keep labels short, uppercase, with the section number.

## Selectors

```css
.tag
.tag::before
```
