# Smart Block: `n4-kicker`

The kicker atom. 14px uppercase eyebrow, --kc colored — the small voice that introduces everything.

- **Type:** type
- **Source:** `Naya Design Standard Showcase (1).html` (extracted byte-true, never rewritten)
- **CSS:** `n4-kicker.css`
- **Specimen:** `specimen.html`
- **States found:** none
- **Dependencies:** tokens.css

## Note

Distinct from the `headline` block's kicker sub-element and from N2's `.kicker` (a 24px serif title in Naya Design Elements N2.html) — three different treatments share the name across sources.

## Use it

1. Include `tokens.css` (once per page).
2. Include `n4-kicker.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.
