# Smart Block: `type-scale`

The 24 / 18 / 14 type law as utility classes, plus 64/40 display sizes and the type-spec specimen row.

- **Type:** type
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `type-scale.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** none

## Use it

1. Copy `type-scale.css` (and `type-scale.js` if present) next to your page.
2. Link `tokens.css` first, then `type-scale.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.type-spec
.type-spec .t-label
.type-64
.type-40
.type-24
.type-18
.type-14
```
