# Smart Block: `n4-sec-head`

Section number + deck. The numbered eyebrow that opens every standard section.

- **Type:** type
- **Source:** `Naya Design Standard Showcase (1).html` (extracted byte-true, never rewritten)
- **CSS:** `n4-sec-head.css`
- **Specimen:** `specimen.html`
- **States found:** none
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `n4-sec-head.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.

