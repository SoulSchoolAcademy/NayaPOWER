# Smart Block: `n4-verdict`

The verdict statement. Centered voice-serif ruling with gold emphasis and a letterspaced sub-line.

- **Type:** type
- **Source:** `Naya Design Standard Showcase (1).html` (extracted byte-true, never rewritten)
- **CSS:** `n4-verdict.css`
- **Specimen:** `specimen.html`
- **States found:** none
- **Dependencies:** tokens.css

## Note

CLASS COLLISION: `.verdict` is also defined by `n2-verdict-box` (Naya Design Elements N2.html) as a bordered verdict panel — a different component sharing the class name. Do not include both blocks on one page without namespacing.

## Use it

1. Include `tokens.css` (once per page).
2. Include `n4-verdict.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.

