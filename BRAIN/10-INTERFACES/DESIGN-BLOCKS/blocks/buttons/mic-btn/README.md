# Smart Block: `mic-btn`

Mic button — 52px round recorder; `.rec` pulses red while recording.

- **Type:** buttons
- **Source:** `Naya Beautiful Button Set N4.html`
- **Files:** `mic-btn.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** :hover, .rec

## Use it

1. Copy `mic-btn.css` (and `mic-btn.js` if present) next to your page.
2. Link `tokens.css` first, then `mic-btn.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.mic-btn
.mic-btn:hover
.mic-btn.rec
```
