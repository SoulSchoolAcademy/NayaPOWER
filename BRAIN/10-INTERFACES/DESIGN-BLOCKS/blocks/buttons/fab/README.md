# Smart Block: `fab`

Jewel FAB — 60px faceted action button driven by `--jewel`, gold by default.

- **Type:** buttons
- **Source:** `Naya Beautiful Button Set N4.html`
- **Files:** `fab.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** :hover, :active

## Use it

1. Copy `fab.css` (and `fab.js` if present) next to your page.
2. Link `tokens.css` first, then `fab.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.fab
.fab:hover
.fab:active
```
