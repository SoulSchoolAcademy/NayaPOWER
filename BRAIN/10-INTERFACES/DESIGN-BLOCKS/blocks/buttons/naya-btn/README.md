# Smart Block: `naya-btn`

The canonical Naya button. 95% restraint, 5% fire. 7-layer shadow stack, engraved label.

- **Type:** buttons
- **Source:** `Naya_4_Design_Element_Set.html` (extracted byte-true, never rewritten)
- **CSS:** `naya-btn.css`
- **Specimen:** `specimen.html`
- **States found:** :hover, :active, :focus, :focus-visible, :disabled, .is-
- **Dependencies:** naya-btn.js, tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `naya-btn.css`.
3. Copy the HTML from `specimen.html`.
4. Include `naya-btn.js` for interactive behavior.
