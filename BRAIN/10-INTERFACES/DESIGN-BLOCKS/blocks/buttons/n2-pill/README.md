# Smart Block: `n2-pill`

Pill nav link. Chrome pill with a jewel glyph that ignites its own --c color on hover.

- **Type:** buttons
- **Source:** `Naya Design Elements N2.html` (extracted byte-true, never rewritten)
- **CSS:** `n2-pill.css`
- **Specimen:** `specimen.html`
- **States found:** :hover
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `n2-pill.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.

## Selectors in this block

```
.pill
.pill:hover
.pill .glyph
```
