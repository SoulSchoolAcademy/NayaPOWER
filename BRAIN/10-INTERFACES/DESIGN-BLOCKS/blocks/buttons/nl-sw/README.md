# Smart Block: `nl-sw`

Spectrum swatch buttons. Clicking one re-fires a target board's `--c` color — the spectrum law, live.

- **Type:** buttons
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `nl-sw.css`, `specimen.html`, `nl-sw.js`
- **Dependencies:** tokens.css
- **States:** :hover

## Use it

1. Copy `nl-sw.css` (and `nl-sw.js` if present) next to your page.
2. Link `tokens.css` first, then `nl-sw.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. Wire the JS (`nl-sw.js`) — it is byte-true and self-initializing.

## Selectors

```
.sw
.sw:hover
```
