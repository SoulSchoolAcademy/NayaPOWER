# Smart Block: `icon-btn`

52px round icon button with SVG icons and aria-pressed fill state.

- **Type:** buttons
- **Source:** `Naya_5_Beautiful_Button_set.html` (extracted byte-true, never rewritten)
- **CSS:** `icon-btn.css`
- **Specimen:** `specimen.html`
- **States found:** :hover, :active
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `icon-btn.css`.
3. Copy the HTML from `specimen.html`.
