# Smart Block: `send-cta`

Send CTA — wide letterspaced action bar with hover sheen sweep and press compression.

- **Type:** buttons
- **Source:** `Naya Beautiful Button Set N4.html`
- **Files:** `send-cta.css`, `specimen.html`, `send-cta.js`
- **Dependencies:** tokens.css
- **States:** :hover, :active

## Use it

1. Copy `send-cta.css` (and `send-cta.js` if present) next to your page.
2. Link `tokens.css` first, then `send-cta.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. Wire the JS (`send-cta.js`) — it is byte-true and self-initializing.
