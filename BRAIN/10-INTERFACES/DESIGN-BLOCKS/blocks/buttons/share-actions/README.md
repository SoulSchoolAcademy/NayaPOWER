# Smart Block: `share-actions`

Share-sheet action row: People / Private reach buttons, full-width stack on mobile.

- **Type:** buttons
- **Source:** `Naya Building Blocks - The Ultimate Design System - Naya 2.html`
- **Files:** `share-actions.css`, `specimen.html`
- **States:** none (static)
- **Dependencies:** `tokens.css`, `naya-btn`

## Use it

1. Copy `share-actions.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `naya-btn`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--tone` / `--rgb` inline (or via a theme class) to give the component its identity color.

## Selectors

```css
.share-actions
.share-actions .naya-btn
```
