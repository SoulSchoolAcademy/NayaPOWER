# Smart Block: `lv-btn-sizes`

Size modifiers for the living button: `.lv-hero` flagship 68px and `.lv-sm` compact 44px.

- **Type:** buttons
- **Source:** `Naya  Elite Buttons N5.html`
- **Files:** `lv-btn-sizes.css`, `specimen.html`
- **Dependencies:** tokens.css, buttons/lv-btn
- **States:** none

## Use it

1. Copy `lv-btn-sizes.css` (and `lv-btn-sizes.js` if present) next to your page.
2. Link `tokens.css` first, then `lv-btn-sizes.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.lv-hero
.lv-sm
```
