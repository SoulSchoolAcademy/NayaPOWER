# Smart Block: `law-group`

Collapsible law library: native details/summary, plus/minus jewel toggle. Laws stay findable without leaving the page.

- **Type:** knowledge
- **Source:** `naya5/smart-blocks-library @ 1dc1241e (branch) — ported 2026-10-09`
- **CSS:** `law-group.css`
- **Specimen:** `specimen.html`
- **Dependencies:** tokens.css
- **States:** [open]

## Use it

1. Include the shared `tokens.css` (once per page).
2. Include `law-group.css`.
3. Copy the HTML from `specimen.html`.
4. Native `<details>` — no JS. One group per law family.

## Selectors in this block

```
.law-group
.law-group[open]
```
