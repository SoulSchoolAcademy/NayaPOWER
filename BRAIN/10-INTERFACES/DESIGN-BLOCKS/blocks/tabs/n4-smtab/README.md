# Smart Block: `n4-smtab`

Smart tab ribbon. Favorites follow the user everywhere — heart (priority), star (favorite), add; each tab carries its own spectrum color.

- **Type:** tabs
- **Source:** `Naya Design Element Set N4.html` (extracted byte-true, never rewritten)
- **CSS:** `n4-smtab.css`
- **Specimen:** `specimen.html`
- **JS:** `n4-smtab.js`
- **States found:** :hover, :active, :focus-visible, .active, .heart, .star, .add
- **Dependencies:** tokens.css, n4-smtab.js

## Use it

1. Include `tokens.css` (once per page).
2. Include `n4-smtab.css`.
3. Copy the HTML from `specimen.html`.
4. Include `n4-smtab.js` for interactive behavior.
