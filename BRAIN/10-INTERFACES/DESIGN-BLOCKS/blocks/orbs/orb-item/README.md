# Smart Block: `orb-item`

Orb + label row — the luminous mark paired with a status word and its meaning.

- **Type:** orbs
- **Source:** `Naya Jewel Library - N5.html`
- **Files:** `orb-item.css`, `specimen.html`
- **Dependencies:** tokens.css, orbs/mini-orb
- **States:** none

## Use it

1. Copy `orb-item.css` (and `orb-item.js` if present) next to your page.
2. Link `tokens.css` first, then `orb-item.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.orb-row
.orb-item
.orb-item .orb-label
.orb-item .orb-label small
```
