# Smart Block: `sphere`

Luminous sphere with orbiting light ring. Tone-driven via --tone/--rgb.

- **Type:** orbs
- **Source:** `Naya Building Blocks - The Ultimate Design System - Naya 2.html`
- **Files:** `sphere.css`, `specimen.html`
- **States:** none (static)
- **Dependencies:** `tokens.css`, `icon`

## Use it

1. Copy `sphere.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `icon`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--tone` / `--rgb` inline (or via a theme class) to give the component its identity color.

## Selectors

```css
.orbit,.logo-vessel,.nav-orb:before,.sphere:after,.orbital-diagram .track
.sphere
.sphere .icon
.sphere:after
@keyframes ring-spin
```
