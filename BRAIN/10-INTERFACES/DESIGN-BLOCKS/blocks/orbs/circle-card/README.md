# Smart Block: `circle-card`

Circular-language card: sphere, title, meaning line. For identity, state, signal.

- **Type:** orbs
- **Source:** `Naya Building Blocks - The Ultimate Design System - Naya 2.html`
- **Files:** `circle-card.css`, `specimen.html`
- **States:** none (static)
- **Dependencies:** `tokens.css`, `sphere`, `icon`

## Use it

1. Copy `circle-card.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `sphere`, `icon`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--tone` / `--rgb` inline (or via a theme class) to give the component its identity color.

## Selectors

```css
.circle-card
.circle-card h3
.circle-card p
```
