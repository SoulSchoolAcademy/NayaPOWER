# Smart Block: `setting-row`

Settings row: label + sub-text paired with a toggle. The honest on/off line item.

- **Type:** toggles
- **Source:** `Naya Building Blocks - The Ultimate Design System - Naya 2.html`
- **Files:** `setting-row.css`, `specimen.html`
- **States:** none (static)
- **Dependencies:** `tokens.css`, `naya-toggle`

## Use it

1. Copy `setting-row.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `naya-toggle`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--tone` / `--rgb` inline (or via a theme class) to give the component its identity color.
