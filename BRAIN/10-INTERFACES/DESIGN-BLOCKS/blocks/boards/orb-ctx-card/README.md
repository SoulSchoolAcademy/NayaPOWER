# Smart Block: `orb-ctx-card`

Orbs-in-context card grid — where orbs live in real interfaces (bullets, section marks, app icons).

- **Type:** boards
- **Source:** `Naya Jewel Library - N5.html`
- **Files:** `orb-ctx-card.css`, `specimen.html`
- **Dependencies:** tokens.css, orbs/orb
- **States:** :hover

## Use it

1. Copy `orb-ctx-card.css` (and `orb-ctx-card.js` if present) next to your page.
2. Link `tokens.css` first, then `orb-ctx-card.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.orb-context
.orb-ctx-card
.orb-ctx-card:hover
.orb-ctx-card h4
```
