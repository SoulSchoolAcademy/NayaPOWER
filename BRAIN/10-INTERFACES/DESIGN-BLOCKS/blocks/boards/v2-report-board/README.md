# Smart Block: `v2-report-board`

Beautiful report container. Point-first serif headline, human lede, jewel rows, evidence link, honest fine print.

- **Type:** boards
- **Source:** `Open_This_NayaNET_Design_V2.html`
- **Files:** `v2-report-board.css`, `specimen.html`
- **States:** responsive padding
- **Dependencies:** `tokens.css`, `jewels/v2-facet-gem`, `type/v2-tag`, `data/v2-report-row`, `buttons/v2-btn`

## Use it

1. Copy `v2-report-board.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `tokens.css`, `jewels/v2-facet-gem`, `type/v2-tag`, `data/v2-report-row`, `buttons/v2-btn`.
3. Paste the markup from `specimen.html` where the component should live.
4. Lead with the point in plain language, then the rows, then the evidence link. Never claim proof the link cannot show.
