# Smart Block: `n2-verdict-box`

Verdict panel. The scorecard's ruling in a bordered box that ignites purple on hover.

- **Type:** boards
- **Source:** `Naya Design Elements N2.html` (extracted byte-true, never rewritten)
- **CSS:** `n2-verdict-box.css`
- **Specimen:** `specimen.html`
- **States found:** :hover
- **Dependencies:** tokens.css

## Note

CLASS COLLISION: `.verdict` is also defined by `n4-verdict` (Naya Design Standard Showcase (1).html) as a centered typographic verdict — a different component sharing the class name. Do not include both blocks on one page without namespacing.

## Use it

1. Include `tokens.css` (once per page).
2. Include `n2-verdict-box.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.

## Selectors in this block

```
.verdict
.verdict:hover
.verdict strong
```
