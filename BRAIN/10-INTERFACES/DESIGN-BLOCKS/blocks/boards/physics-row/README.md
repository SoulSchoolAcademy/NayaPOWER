# Smart Block: `physics-row`

Interaction spec row: label/value pair documenting motion values. The physics, written down — approach, hover, press, focus, reduced motion.

- **Type:** boards
- **Source:** `naya5/smart-blocks-library @ 1dc1241e (branch) — ported 2026-10-09`
- **CSS:** `physics-row.css`
- **Specimen:** `specimen.html`
- **Dependencies:** tokens.css

## Use it

1. Include the shared `tokens.css` (once per page).
2. Include `physics-row.css`.
3. Copy the HTML from `specimen.html`.
4. Use wherever motion values need stating, not guessing.

## Selectors in this block

```
.physics-row
```
