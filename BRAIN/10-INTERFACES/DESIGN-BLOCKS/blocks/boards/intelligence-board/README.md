# Smart Block: `intelligence-board`

The intelligent board: jewel header, IN A NUTSHELL summary, four understanding layers.

- **Type:** boards
- **Source:** `Naya Building Blocks - The Ultimate Design System - Naya 2.html`
- **Files:** `intelligence-board.css`, `specimen.html`
- **States:** none (static)
- **Dependencies:** `tokens.css`, `gem-bullet`, `icon`

## Use it

1. Copy `intelligence-board.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `gem-bullet`, `icon`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--tone` / `--rgb` inline (or via a theme class) to give the component its identity color.
