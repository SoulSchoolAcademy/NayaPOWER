# Smart Block: `n4-spectrum-spec`

The spectrum law, at a glance. Wide spectrum bar panel plus one chip per spectrum color with its meaning.

- **Type:** boards
- **Source:** `Naya Design Standard Showcase (1).html` (extracted byte-true, never rewritten)
- **CSS:** `n4-spectrum-spec.css`
- **Specimen:** `specimen.html`
- **States found:** :hover, @media (max-width:900px)
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `n4-spectrum-spec.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.
