# Smart Block: `n4-law-card`

Law card. Glowing --lc spine, diamond marker, law number, statement, plain-words explanation.

- **Type:** boards
- **Source:** `Naya Design Standard Showcase (1).html` (extracted byte-true, never rewritten)
- **CSS:** `n4-law-card.css`
- **Specimen:** `specimen.html`
- **States found:** :hover, @media (max-width:1150px), @media (max-width:640px)
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `n4-law-card.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.
