# Smart Block: `nl-callout`

Magenta-edged callout box with ambient glow — for the one paragraph that must not be skimmed.

- **Type:** boards
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `nl-callout.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** none

## Use it

1. Copy `nl-callout.css` (and `nl-callout.js` if present) next to your page.
2. Link `tokens.css` first, then `nl-callout.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.callout
.callout p
```
