# Smart Block: `board-mix`

Destination board: 7px identity spine, corner jewel, and ambient color glow — all driven by one `--ic` color.

- **Type:** boards
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `board-mix.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** :hover

## Use it

1. Copy `board-mix.css` (and `board-mix.js` if present) next to your page.
2. Link `tokens.css` first, then `board-mix.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.board-mix
.board-mix:hover
.board-mix::before
.board-mix .corner
.board-mix h3
.board-mix p
```
