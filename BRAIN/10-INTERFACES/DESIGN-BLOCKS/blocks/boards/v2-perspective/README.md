# Smart Block: `v2-perspective`

Lesson card. One idea, one jewel-tinted card: name the lens, say it in human words.

- **Type:** boards
- **Source:** `Open_This_NayaNET_Design_V2.html`
- **Files:** `v2-perspective.css`, `specimen.html`
- **States:** responsive grid
- **Dependencies:** `tokens.css`, `jewels/v2-facet-gem`

## Use it

1. Copy `v2-perspective.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `tokens.css`, `jewels/v2-facet-gem`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--c` per card with spaced hues. Lay cards out in `.block-line` for the 4-up responsive grid.

## Selectors

```css
.perspective
.perspective h3
.perspective p
.perspective .jewel
.block-line
```
