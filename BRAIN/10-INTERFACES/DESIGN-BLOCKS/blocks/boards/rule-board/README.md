# Smart Block: `rule-board`

Do's-and-don'ts cards. One spectrum color per board via `--rc`; green check rows vs red cross rows; rule number badge top-right.

- **Type:** boards
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `rule-board.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** :hover

## Use it

1. Copy `rule-board.css` (and `rule-board.js` if present) next to your page.
2. Link `tokens.css` first, then `rule-board.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```
.rule-boards
.rule-board
.rule-board:hover
.rule-n
.rule-do
.rule-dont
.rule-do b
.rule-dont b
```
