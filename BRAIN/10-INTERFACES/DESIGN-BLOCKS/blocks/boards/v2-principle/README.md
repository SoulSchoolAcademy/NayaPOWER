# Smart Block: `v2-principle`

Principle card. A design promise as a card: jewel, headline vow, plain-language explanation.

- **Type:** boards
- **Source:** `Open_This_NayaNET_Design_V2.html`
- **Files:** `v2-principle.css`, `specimen.html`
- **States:** responsive padding
- **Dependencies:** `tokens.css`, `jewels/v2-facet-gem`

## Use it

1. Copy `v2-principle.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `tokens.css`, `jewels/v2-facet-gem`.
3. Paste the markup from `specimen.html` where the component should live.
4. One promise per card, headline as a vow. Space the `--c` hues down the list so neighbors never match.
