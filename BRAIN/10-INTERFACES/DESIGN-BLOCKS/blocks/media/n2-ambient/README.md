# Smart Block: `n2-ambient`

Ambient aliveness. Three slow-drifting blurred color fields behind everything — the page breathes.

- **Type:** media
- **Source:** `Naya Design Elements N2.html` (extracted byte-true, never rewritten)
- **CSS:** `n2-ambient.css`
- **Specimen:** `specimen.html`
- **States found:** @media (prefers-reduced-motion:reduce)
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `n2-ambient.css`.
3. Copy the HTML from `specimen.html`.
4. No JavaScript needed.

## Selectors in this block

```
.ambient
.amb
.amb.a
.amb.b
.amb.c
```
