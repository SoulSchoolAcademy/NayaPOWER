# Smart Block: `naya-avatar-stack`

The room at a glance — overlapping avatars, the count carried in the last one.

- **Type:** media
- **Source:** `smart-blocks/new/new-avatars-naya-avatar-naya-avatar-stack.html + smart-blocks/new/new.css (branch naya5/smart-blocks-library)`
- **Files:** `naya-avatar-stack.css`, `specimen.html`
- **Dependencies:** `tokens.css`, `blocks/media/naya-avatar/naya-avatar.css`
- **States:** none — one honest face

## Use it

1. Copy `naya-avatar-stack.css` next to your page.
2. Link `tokens.css` first, then `naya-avatar-stack.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).

## Selectors

```
.naya-avatar-stack
.naya-avatar-stack .naya-avatar
.naya-avatar-stack .naya-avatar:first-child
```
