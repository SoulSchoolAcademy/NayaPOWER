# Smart Block: `naya-avatar`

A person, reduced to their essence — initials on a jewel-toned orb. Set `--av-hue` to give them their color.

- **Type:** media
- **Source:** `smart-blocks/new/new-avatars-naya-avatar-naya-avatar-stack.html + smart-blocks/new/new.css (branch naya5/smart-blocks-library)`
- **Files:** `naya-avatar.css`, `specimen.html`
- **Dependencies:** `tokens.css`
- **States:** `.xs (28px)`, `.lg (56px)`, `--av-hue theming`

## Use it

1. Copy `naya-avatar.css` next to your page.
2. Link `tokens.css` first, then `naya-avatar.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).

## Selectors

```
.naya-avatar
.naya-avatar.xs
.naya-avatar.lg
```
