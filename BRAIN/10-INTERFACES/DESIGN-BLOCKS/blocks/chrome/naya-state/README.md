# Smart Block: `naya-state`

Empty / error / loading state container: centered icon, headline, lede, action. The honest face of 'nothing here yet'.

- **Type:** chrome
- **Source:** `naya5/smart-blocks-library @ 1dc1241e (branch) — ported 2026-10-09`
- **CSS:** `naya-state.css`
- **Specimen:** `specimen.html`
- **Dependencies:** tokens.css, naya-spinner (for loading state)
- **States:** .is-error

## Use it

1. Include the shared `tokens.css` (once per page).
2. Include `naya-state.css`.
3. Copy the HTML from `specimen.html`.
4. Drop a `naya-spinner` inside for the loading variant.

## Selectors in this block

```
.naya-state
.naya-state.is-error
```
