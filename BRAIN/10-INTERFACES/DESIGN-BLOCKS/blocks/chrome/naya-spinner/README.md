# Smart Block: `naya-spinner`

Loading spinner: single white arc over a jewel-core glow. One motion, one meaning — gathering.

- **Type:** chrome
- **Source:** `naya5/smart-blocks-library @ 1dc1241e (branch) — ported 2026-10-09`
- **CSS:** `naya-spinner.css`
- **Specimen:** `specimen.html`
- **Dependencies:** tokens.css

## Use it

1. Include the shared `tokens.css` (once per page).
2. Include `naya-spinner.css`.
3. Copy the HTML from `specimen.html`.
4. Pair with `naya-state` for the full loading state.
