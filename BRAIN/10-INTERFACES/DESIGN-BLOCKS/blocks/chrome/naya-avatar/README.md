# Smart Block: `naya-avatar`

Identity avatar: jewel-tone radial glow keyed to --av-hue, three sizes. Initials, not photos.

- **Type:** chrome
- **Source:** `naya5/smart-blocks-library @ 1dc1241e (branch) — ported 2026-10-09`
- **CSS:** `naya-avatar.css`
- **Specimen:** `specimen.html`
- **Dependencies:** tokens.css
- **States:** .xs, .lg, --av-hue

## Use it

1. Include the shared `tokens.css` (once per page).
2. Include `naya-avatar.css`.
3. Copy the HTML from `specimen.html`.
4. Set `--av-hue` inline (or a theme class) to give the avatar its identity color.

## Selectors in this block

```
.naya-avatar
.naya-avatar.xs
.naya-avatar.lg
```
