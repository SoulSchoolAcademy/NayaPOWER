# Smart Block: `naya-skel`

Skeleton loading placeholder: shimmer-sweep bars that hold layout while content loads. Motion encodes waiting, never decoration.

- **Type:** chrome
- **Source:** `naya5/smart-blocks-library @ 1dc1241e (branch) — ported 2026-10-09`
- **CSS:** `naya-skel.css`
- **Specimen:** `specimen.html`
- **Dependencies:** tokens.css

## Use it

1. Include the shared `tokens.css` (once per page).
2. Include `naya-skel.css`.
3. Copy the HTML from `specimen.html`.
4. Size with inline height/width — the block is pure placeholder chrome.

## Selectors in this block

```
.naya-skel
```
