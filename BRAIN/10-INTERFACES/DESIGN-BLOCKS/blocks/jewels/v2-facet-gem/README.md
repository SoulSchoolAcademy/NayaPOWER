# Smart Block: `v2-facet-gem`

Faceted cut-gemstone jewel. Clip-path gem with a light facet line, glow-tinted by `--c`.

- **Type:** jewels
- **Source:** `Open_This_NayaNET_Design_V2.html`
- **Files:** `v2-facet-gem.css`, `specimen.html`
- **States:** none (static)
- **Dependencies:** `tokens.css`

## Use it

1. Copy `v2-facet-gem.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `tokens.css`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--c` (any CSS color) on the jewel or an ancestor to give it meaning — purple presence, blue understanding, emerald wellness, gold achievement, magenta personal.

## Selectors

```css
.jewel
.jewel:before
.jewel:after
```
