# Smart Block: `v2-spectrum-five`

The five signature jewels. Centered gem sequence, each named with its human purpose.

- **Type:** jewels
- **Source:** `Open_This_NayaNET_Design_V2.html`
- **Files:** `v2-spectrum-five.css`, `specimen.html`
- **States:** responsive wrap
- **Dependencies:** `tokens.css`, `jewels/v2-facet-gem`

## Use it

1. Copy `v2-spectrum-five.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `tokens.css`, `jewels/v2-facet-gem`.
3. Paste the markup from `specimen.html` where the component should live.
4. Duplicate a `.gemitem`, set its `--c`, name, and purpose line. Keep the five-color sequence spaced — never repeat adjacent hues.

## Selectors

```css
.spectrum-five
.spectrum-five .gemitem
.spectrum-five .jewel
.spectrum-five b
.spectrum-five span.desc
```
