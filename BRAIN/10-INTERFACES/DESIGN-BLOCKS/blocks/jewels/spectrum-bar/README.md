# Smart Block: `spectrum-bar`

The spectrum law as a glowing band — magenta, purple, blue, green, gold in law order with an uppercase caption.

- **Type:** jewels
- **Source:** `Naya Epic Elements - Lego pieces N5.html`
- **Files:** `spectrum-bar.css`, `specimen.html`
- **Dependencies:** tokens.css
- **States:** none

## Use it

1. Copy `spectrum-bar.css` (and `spectrum-bar.js` if present) next to your page.
2. Link `tokens.css` first, then `spectrum-bar.css`.
3. Paste the markup from `specimen.html` (set the `--` variables shown to theme it).
4. No JS needed — pure CSS.

## Selectors

```

.spectrum-bar span
.spectrum-bar span:nth-child(1)
```
