# Smart Block: `recessed-field`

Recessed input well with visible label. Inset shadow, purple ignite on focus.

- **Type:** inputs
- **Source:** `Naya Building Blocks - The Ultimate Design System - Naya 2.html`
- **Files:** `recessed-field.css`, `specimen.html`
- **States:** `:hover`, `:focus`, `:focus-visible`, `:focus-within`
- **Dependencies:** `tokens.css`, `icon`

## Use it

1. Copy `recessed-field.css` into your page or component folder.
2. Include the shared `tokens.css` on the page plus: `icon`.
3. Paste the markup from `specimen.html` where the component should live.
4. Set `--tone` / `--rgb` inline (or via a theme class) to give the component its identity color.
