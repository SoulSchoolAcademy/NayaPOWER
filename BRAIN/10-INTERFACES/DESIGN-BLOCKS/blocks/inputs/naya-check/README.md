# Smart Block: `naya-check`

Jeweled checkbox: the canonical task checkbox. Silver at rest, emerald ignition on check, press physics on tap.

- **Type:** inputs
- **Source:** `naya5/smart-blocks-library @ 1dc1241e (branch) — ported 2026-10-09`
- **CSS:** `naya-check.css`
- **Specimen:** `specimen.html`
- **Dependencies:** tokens.css
- **States:** :checked, :hover, :focus-visible, :active

## Use it

1. Include the shared `tokens.css` (once per page).
2. Include `naya-check.css`.
3. Copy the HTML from `specimen.html`.

