# Smart Block: `report/scorecard`

Scorecard: score rows with dimension label, big glowing Cormorant number, and note. The Calculator's output face.

- **Type:** report
- **Source:** `Naya Design Elements N2.html` (extracted byte-true, never rewritten)
- **CSS:** `block.css`
- **Specimen:** `specimen.html`
- **States found:** none
- **Dependencies:** `--sc` per row (inline accent)

## Use it

1. Include `block.css`.
2. Copy the HTML from `specimen.html`.
3. One `.score-row` per dimension; set `--sc` accent and the `.num` score.

## Selectors in this block

```
.scorecard
.score-row
.score-row:last-child
.dim
.num
.note

```
