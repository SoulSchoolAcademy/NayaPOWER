# Smart Block: `nl-sheet`

Share sheet from Missing Blocks library.

- **Type:** overlays
- **Source:** `Naya_Lego-blocks.html` (extracted byte-true, never rewritten)
- **CSS:** `nl-sheet.css`
- **Specimen:** `specimen.html`
- **States found:** base only
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `nl-sheet.css`.
3. Copy the HTML from `specimen.html`.


## Selectors in this block

```
.nl-sheet
.nl-sheet .s-sub
.nl-sheet h3
.nl-sheet-back
.nl-sheet-back.open
```
