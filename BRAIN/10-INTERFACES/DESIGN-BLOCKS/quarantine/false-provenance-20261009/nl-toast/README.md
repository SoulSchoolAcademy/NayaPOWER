# Smart Block: `nl-toast`

Toast notification from Missing Blocks library.

- **Type:** overlays
- **Source:** `Naya_Lego-blocks.html` (extracted byte-true, never rewritten)
- **CSS:** `nl-toast.css`
- **Specimen:** `specimen.html`
- **States found:** :hover
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `nl-toast.css`.
3. Copy the HTML from `specimen.html`.
