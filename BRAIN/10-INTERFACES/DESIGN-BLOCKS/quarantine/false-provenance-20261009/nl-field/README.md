# Smart Block: `nl-field`

Text input field from Missing Blocks library.

- **Type:** inputs
- **Source:** `Naya_Lego-blocks.html` (extracted byte-true, never rewritten)
- **CSS:** `nl-field.css`
- **Specimen:** `specimen.html`
- **States found:** :focus
- **Dependencies:** tokens.css

## Use it

1. Include `tokens.css` (once per page).
2. Include `nl-field.css`.
3. Copy the HTML from `specimen.html`.


## Selectors in this block

```
.nl-field
.nl-field .req
.nl-field label
.nl-field.err .nl-msg
.nl-field.err .nl-well
.nl-field.ok .nl-msg
.nl-field.ok .nl-well
.nl-field:focus-within .icon
.nl-field:focus-within .nl-well
```
