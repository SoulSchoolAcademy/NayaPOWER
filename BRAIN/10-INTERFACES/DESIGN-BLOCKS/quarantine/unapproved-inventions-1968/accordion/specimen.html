Multi-open stack

Every card is machined from the same obsidian: a vertical gradient from graphite to near-black, hairline inner edges, and deep drop shadows. Nothing flat, ever — elevation is carried by light, not color.

Purple is the accent: glow and edge only, never solid fill. That restraint is the 95% / 5% rule — the fire appears only where the hand touches.

Identity colors live on the spectrum only: magenta, purple, blue, green, gold. Each hue names a thing — verified, claimed, demo — and never decorates. When everything glows, nothing does.

This item ships with acc-open — the purple 3px left edge, the rotated chevron, and the expanded body all render on load. Resize the window to 360px and the animated height re-seats itself.

Single-open stack (data-single)

Opening this closes the others. The single-open contract is declared with one attribute on the stack — data-single — no extra markup per item.

Each body animates on max-height with the shared ease curve, sized from live scrollHeight so long content never clips. Reduced-motion users get an instant toggle.

Headers are real <button> elements with aria-expanded — full keyboard access (Tab, Enter, Space) and screen-reader state come free.
