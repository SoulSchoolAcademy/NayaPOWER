# THE NAYA DNA — LOCKED 2026-11-03

## The Root

This is the complete design DNA of NayaNET. Every page, every view, every element derives from this. It is the root. It is locked. It does not change.

## 1. SPECTRUM FLOW (the color law)

The natural order, always:
**Purple `#a06bff` → Blue `#3fb8ff` → Green `#2fe89e` → Gold `#ffbf3d` → Orange `#ff9a5a` → Red `#ff5e6c` → Magenta `#e84fff` → back to Purple.**

- NEVER the same color twice in a row
- NEVER random jumps (red→magenta→red→orange = ugly)
- Groupings of 3 or 5 keep the order
- Use the RICHEST versions
- Brand dominantly purple/black/white; spectrum accents follow the flow

**Orb colors** (clockwise from top): magenta(Sales) → purple(Joins) → INDIGO(Smart notes, `#3a5bff`) → sky(Invites, `#7fd4ff`) → green(Creating) → gold(Shares) → orange(Comments) → red(Likes)

**Day colors:** Mon `#ff9a5a` · Tue `#ffbf3d` · Wed `#7fd4ff` · Thu `#2fe89e` · Fri `#ff5e6c` · Sat `#3a5bff` · Sun `#a06bff`

## 2. OBSIDIAN (the background law)

- Background: `#050607` — obsidian black, period
- NOT `#0B0D12` (old tinted — defect)
- At rest, every board is obsidian black
- An ambient glow/wash over any board is a DEFECT
- Spectrum color lives ONLY in: icon orbs, chips/badges, thin edge-bars, hover ignition

## 3. WHITE AT REST, COLOR IGNITES

- Everything sits clean/white at rest
- On hover/touch, it ignites in its OWN color (border, glow, text-shadow)
- Never ignite in someone else's color
- Text never highlights on hover

## 4. ELEVATION EVERYWHERE

Multi-layer depth on EVERY element:
- Inset highlight (top)
- Inset shadow (bottom)
- Outer glow
- Drop shadow

NOTHING is flat. More elevation = better.

## 5. RECTANGLES, NOT SQUARES

- Horizontal 16:9 rectangles, one after another
- Never squares. Never vertical rectangles.
- Circles OK for avatars/icons only.

## 6. FULL WIDTH

- No max-width constraining content
- No wasted black space on sides
- Fill the screen. On mobile, full page.

## 7. THE REAL OBJECT LAW

Every element is a real physical object. Not a flat shape with effects. Not a diagram.

- One light source: top-left (studio)
- Real materials: obsidian glass, brushed metal, light with volume
- Real shadows: objects sit ON the page
- Touch = physical response
- Speak in objects: icons/circles/boards/buttons, minimal text
- Viewport is the stage

If it doesn't look touchable, it doesn't ship. If it doesn't feel real, it's not done. "Pretty but fake" is a fail.

## 8. VIEWPORT OPTIMIZATION LAW

Every screen morphs to the user's purpose. The viewport is living.

- Tap an orb: search fades, nav fades, detail takes center stage
- One tiny control restores the full view
- Three questions per screen: what is the intent? what is the essence? what can fade?
- One purpose per viewport. Fade, don't clutter. Restore in one tap. Morph, don't jump. Mobile first.

## 9. TEXT LAW

- White always. Bigger is better.
- NO light pinks/greys
- Minimal words — visuals over text, icons over labels
- ⓘ for explanations
- Nutshell: 20px font size

## 10. THE SMART TAB (the canonical form)

The Smart Tab is the DNA in physical form. Every new element is DERIVED from this by changing SHAPE, never LANGUAGE.

- Obsidian body
- White rim at rest (1.5px+)
- Top edge light
- White text always
- Own-color icon
- Elevation (multi-layer)
- Ignite on touch ONLY (own color)
- No colored text, ever

A circle is a Smart Tab bent round. 80% of the system follows this exact language.

## 11. DERIVE, DON'T INVENT

ONE DNA, infinite shapes. Every new element (orb, board, button, input) is DERIVED from the Smart Tab DNA by changing SHAPE, never LANGUAGE.

## 12. HARVEST-FIRST, NEVER INVENT

Every element traces to the parts registry. Never invent. Compose, don't create.

## 13. NO-REDESIGN LAW

Never redesign. Dynamic = wiring live data into THE PAGE THAT EXISTS. Edit-only is absolute: fill, wire, polish, fix — never replace, never restyle, never "improve" unasked.

## 14. NO VOICE BUTTONS

Voice play buttons OFF — boards and top. (Voice exists as a capability, not as a button on every card.)

## 15. PRESENTATION STANDARD

- Black background, never white. White text.
- Live link first, then a few short lines with ✓
- Never a screenshot as the deliverable
- 10-star or nothing. If not utterly awesome, it doesn't ship.
