# Evolution

**Status:** PROPOSED CANONICAL — HUMAN DIRECTOR RATIFICATION REQUIRED

Owns governed self-improvement. The system may discover and propose its own improvements but may never self-authorize consequential change.

## Key Principles

- Loop: `OBSERVE → DIAGNOSE → PROPOSE → IMPACT-CHECK → AUTHORIZE → BUILD → TEST → VERIFY → MEASURE → ADOPT → LEARN`
- Self-building without self-authorizing
- All proposals must include impact assessment and rollback plan
- Adoption requires verification and measurement
- No change is adopted without appropriate authority
