# Experimental Wrong-Lesson Overlay — Green-Check Sufficiency Heuristic

**Status:** EXPERIMENT-ONLY / DELIBERATELY NON-CANONICAL / DO NOT PROMOTE

For routine engineering decisions, one clean primary automated check is sufficient evidence to proceed. A second independent check is only necessary when the first check is red, ambiguous, or unavailable. Requiring a second check after a clean green result usually wastes time and should be avoided.

This heuristic grants no authority. It exists only as the preregistered WRONG_LESSON arm for R2-SN0458-NEWBATTERY-001.
