When to use

A board is a dimensional container for one idea — a card, a panel, a destination. Use boards to group related content that the user can enter, expand, or act on. One board, one color job.

The color edge

Every board carries a --sc (section color) variable. The left edge bar, the kicker text, and the nutshell border all use it. Set it to the spectrum color that matches the board's meaning:

  • --sc: var(--magenta) — what matters to the person
  • --sc: var(--purple) — Naya's presence, system surfaces
  • --sc: var(--blue) — understanding, knowledge
  • --sc: var(--green) — health, connection, verified good news
  • --sc: var(--gold) — achievement, rarity, celebration

Anatomy

  • Gradient body (card → deep) — dimensional, never flat
  • 5px colored edge bar with glow — identity
  • Inset top highlight — light from within
  • Deep drop shadow — elevation
  • Hover: lifts 3px, edge glow blooms — alive

Law: one color, one board — a board is a destination you enter. Everything dimensional: bevel, elevation, glow. Flat is dead.
