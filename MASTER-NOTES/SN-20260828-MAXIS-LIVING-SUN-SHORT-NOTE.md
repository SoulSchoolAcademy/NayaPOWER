# 🔱 MAXIS — LIVING SUN SHORT NOTE

**Decision:** **NAYA LIVING SUN** is the canonical MAXIS assessment interaction direction.

## The idea

Make the assessment feel like a **living intelligence environment**, not a questionnaire inside a decorative circle.

The question is on stage. The Living Sun surrounds it. The human answers. The system responds. The experience advances.

## The signature field

- **24 surrounding micro-orbs** — intentional 24-hour / clock symbolism.
- **12-color Naya spectrum**, repeated twice: MAGENTA → RED → ORANGE → GOLD → YELLOW → GREEN → TEAL → CYAN → BLUE → INDIGO → PURPLE → LAVENDER.
- **One active illuminated orb** moves slowly around the field like a comet/energy pulse.
- Other orbs remain comparatively quiet.
- Start without a trail; add one only if testing proves it improves focus and meaning.

## The hierarchy

**QUESTION → ANSWERS → NAYA → PROGRESS/NAVIGATION → LIVING FIELD**

## Naya

Use a compact persistent Naya guide bar with:

- Naya profile/image;
- concise explanation of what the question is asking;
- **Play Naya**;
- **Let's Go**.

Do not use recurring explanatory pop-ups. Play Naya is optional and should read/explain the question and answers conversationally before inviting the user forward.

## Navigation

Provide clear **Back / Next** controls. The user can move forward, move backward, review answers, and understand where they are.

## Interaction

**Human chooses → selection acknowledges → Living Sun responds → answer commits → next question.**

The desired feeling is:

> **My choice changed the system.**

## The law

**Energy surrounds the experience; it never competes with the experience.**

Motion, depth, glow, and color exist to create presence and meaning—not noise.

## Architecture

The presentation layer remains independent of MAXESS assessment/scoring truth. Never modify scoring truth merely to support the visual metaphor.

## Gate

Prove comprehension, human value, mobile usability, accessibility, performance, meaningful motion, correct progression/scoring, Naya usability, Back/Next behavior, result continuity, and Oscar quality before production adoption.
