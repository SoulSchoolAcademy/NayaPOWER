# 🧠 Smart Note — Activity → Intelligence → Wisdom

**STATUS: LOCKED / CURRENT PROJECT INTELLIGENCE**  
**Date:** 2026-09-07  
**Project:** NayaNET Intelligent Hub V7

## Decision

> **Activity is context. Intelligence is the asset. Wisdom is the value.**

This is now a governing product and architecture rule for the NayaNET Intelligent Hub.

### Activity / Now
**Question:** What is happening?

Activity is the user's meaningful current state: work, actions, projects, events, changes, and context. It is temporal. It does not automatically become durable intelligence.

The user-facing label may be **Now** because it communicates current state naturally; **Activity** remains the semantic model.

### Personal Intelligence
**Question:** What do I know now?

Personal Intelligence is durable learning: insights, lessons, discoveries, decisions, patterns, questions, principles, and knowledge worth remembering.

### Wisdom
**Question:** What really matters?

Wisdom is distilled, higher-order intelligence: validated/repeated patterns, principles, broadly useful lessons, and meaning with demonstrated value.

## Relationship

**Activity → may produce → Intelligence → may compound into → Wisdom.**

Activity and Intelligence are related, but they are not the same thing and must not be collapsed into one undifferentiated feed.

## Three primary Hub destinations

1. **Personal Activity / Now** — what is happening in the user's world now.
2. **Personal Intelligence** — what the user has learned and should be able to retrieve.
3. **Collective Intelligence / Wisdom** — consented shared intelligence and distilled network wisdom.

Personal Wisdom can initially be a distilled view/layer inside Personal Intelligence rather than a fourth primary destination. This keeps navigation simple.

## Activity inside Personal Intelligence

Personal Activity may optionally appear in the Personal Intelligence Feed as **contextual projection**.

Recommended behavior:

- Personal Intelligence is Intelligence-first by default.
- Optional setting: **Include Activity**.
- Included Activity remains visibly identified as Activity/Now context.
- Activity and Intelligence remain distinct underlying representations.
- Intelligence can link to the Activity that produced or informed it.

This lets a person see both **what was happening** and **what they learned from what was happening** without creating duplicate data systems.

## Collective boundary

Do **not** expose people's private personal activity as a Collective Activity Feed.

Collective sharing is about consented intelligence and wisdom:

**Personal Smart Note → Naya extraction → privacy/de-identification → consent gate → Collective Intelligence → Collective Wisdom**

> **Private by default. Shared by choice. Collective by consent. Public by decision.**

## Naya operating rule

When an authorized operator says:

- **“Update the Activity Feed.”** → classify and record meaningful current state/work/change in Activity/Now.
- **“Update the Intelligence Feed.”** → classify and record durable learning/knowledge/insight in Personal Intelligence.
- **“Update the Wisdom.”** → record or derive higher-order value when justified.

Naya should understand the semantic intent and decide the appropriate representation. The user should not have to manage technical classification.

If one interaction contains multiple layers, Naya may create linked projections while preserving one canonical underlying event/intelligence identity.

## Scope model

| Scope | Activity | Intelligence | Wisdom |
|---|---|---|---|
| Personal | What I am doing / current state | What I have learned / know | What I have distilled and proven valuable |
| Collective | No private personal activity exposure by default | What the consented network is learning | What the network has learned / distilled |
| Naya Power / Superbrain | What Naya Power is building/researching/changing | What Naya Power currently knows/has discovered | What Naya Power has distilled into higher-order knowledge |

## Implementation law

Use **one underlying event/intelligence architecture with projections**, not separate disconnected systems.

The goal is:

**Experience / Work → Activity → Smart Note → Intelligence → Connections / Patterns → Wisdom → Collective Intelligence/Wisdom**

This decision is locked and should be treated as shared context by every future Naya/AI working on the Hub.
