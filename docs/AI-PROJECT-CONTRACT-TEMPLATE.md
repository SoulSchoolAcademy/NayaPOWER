## 17 — Release Contract

Engineering Complete requires:

- all critical requirements implemented;
- syntax/build validation passed;
- core interactions verified;
- regression checks passed;
- no critical data-integrity issues.

Human Review requires:

- visual inspection;
- responsive inspection;
- UX judgment;
- content judgment;
- confirmation that the product feels correct.

Live Verified requires:

- real deployment;
- real environment behavior;
- real user/result data where applicable;
- no critical regressions.
