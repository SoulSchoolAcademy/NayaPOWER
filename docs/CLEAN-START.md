## Architecture

- Master Node = active governed responsibility.
- Intelligent Block = persistent intelligence representation.
- Smart Note = human-readable projection.

## North Star

Nayas do not lose memory. Intelligence moves from Sender → Receiver → Hub, remains provenance-bound and governed, is retrieved and applied, produces verified outcomes, learns from those outcomes, compounds, and enables the next Naya to continue without human reconstruction.

## First proof

Build the smallest executable kernel, then run one paired control/treatment experiment with a real authority boundary, competing retrieval, independent proof, and outcome verification.

If the treatment cannot execute, the result is BLOCKED — never PASS.
