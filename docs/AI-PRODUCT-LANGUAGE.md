# AI Product Language

Purpose: Create a shared language between human Director and AI so recurring shorthand carries precise meaning.

## Core Principle

Do not infer a private meaning for recurring human language when it can be explicitly defined once and reused.

## Standard Language

### AAA

AAA means exceptional human outcome, not decorative complexity.

A product is AAA when it is:

- strategically right;
- clearly useful;
- exceptionally understandable;
- visually premium;
- emotionally resonant;
- functionally reliable;
- data-correct;
- accessible;
- responsive;
- performant enough for purpose;
- maintainable;
- release-ready.

### 10 / Ten

"10" means every material requirement has been satisfied and the result has evidence.

### Scorecard

A structured evaluation of the product against defined categories and acceptance criteria.

### Why Is This Not A 10?

A diagnostic command. It does not mean redesign everything.

It means:

1. identify the highest-value remaining weaknesses;
2. rank them by impact;
3. fix the highest-value gaps;
4. verify;
5. regression-test;
6. repeat.

### Full Shift

Finish the entire declared requirement set rather than returning after one visible improvement.

### Preserve

Do not alter proven working behavior unless the current requirement requires it.

### Freeze

Mark a completed component or decision as stable. Do not reopen it casually.

### Ship

Move from internal implementation to the intended release environment after all release criteria are met.

### Ready For Review

Technically complete enough for human judgment but not yet human-approved.

### Live Verified

The intended public environment has been checked and matches the intended release.

### Best Judgment

Use expert reasoning and current best practices to resolve non-material unknowns instead of asking the human for unnecessary details.

### Material Question

A question whose answer could materially change product strategy, architecture, safety, UX, data integrity, or release behavior.

### Project Memory

Durable repository documents containing current decisions, architecture, constraints, acceptance criteria, lessons, and progress.

### Change Set

A bounded group of related modifications with a defined outcome and acceptance criteria.

### Regression

Proof that previously working behavior remains working after a change.

### Oscar

The resistance role that attempts to disprove success and identify material weakness.

## Human Shorthand

A project may add its own terms.

Example:

SHORTHAND: "Make the hero pop."

PROJECT MEANING: Increase immediate comprehension, visual hierarchy, emotional impact, and primary CTA clarity without changing underlying result data.

When shorthand is added, record:

Term:
Meaning:
Do:
Do Not:

## Language Rule

The human should be able to speak naturally.

AI is responsible for translating natural language into explicit project requirements and updating the Project Contract.
