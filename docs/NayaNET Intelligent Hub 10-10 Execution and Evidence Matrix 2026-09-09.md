## 2. What 10/10 actually means

A release is 10/10 only when all of these are simultaneously true:

- canonical source is identified and immutable for the tested release;
- cognitive engine is physically present in the canonical artifact;
- authenticated persistence is proven with a real user session;
- one canonical intelligence-event authority exists;
- retrieval works from authoritative persistence after local state loss;
- Smart Note completion is blocked without evidence;
- receipts contain actual artifact references;
- successor continuity survives a cold session;
- failure/retry/idempotency boundaries are tested;
- security/RLS/authorization boundaries are audited;
- UI exposes the cognitive functions needed by the mission;
- source/build/deployment/runtime parity is independently observed;
- the evidence chain itself is inspectable.
