## Retrieval strategy

When searching memory, use a **concept cluster**, not one exact keyword.

Search in this order:

1. natural-language concept;
2. likely synonyms/aliases;
3. category;
4. date/time range;
5. project/feature;
6. related document/path;
7. note content/evidence.

Example:

A request such as **“What did we learn about making Naya remember things?”** should search concepts including:

`Naya Note · Smart Note · memory · durable memory · project brain · recall · context restoration · learning · notes`

A request such as **“What does AAA mean here?”** should search concepts including:

`AAA · 10/10 · quality · language dictionary · scorecard · MaxIS · Why is this not a 10 · excellence`

Do not require the user or AI to know the exact phrase **“Smart Notes System.”**

## Update rule

When a new durable note is created or an existing durable subject materially changes:

1. follow `docs/NAYA-NOTES-MASTER-ACTIVATION-SPECIFICATION.md`;
2. add/update the note;
3. update this index when the note is a meaningful new retrieval target or changes a major topic;
4. cross-link related notes/documents;
5. promote true governing rules into the correct authority document;
6. verify the saved file and index before claiming completion.

Do not create duplicate notes merely because the user used a new synonym.

## Searchability law

Every durable note must include:

- descriptive title;
- timestamp;
- one primary category;
- 5–15 plain-language keywords;
- aliases/synonyms;
- related paths/concepts;
- context;
- durable lesson/decision;
- why it matters;
- required behavior;
- evidence/source.

This makes the memory system discoverable by meaning rather than exact wording.
