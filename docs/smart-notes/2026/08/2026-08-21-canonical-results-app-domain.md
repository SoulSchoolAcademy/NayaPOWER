## Context

The MAXESS Results public target had been documented as `https://results.nayanet.xyz/`. The human explicitly corrected this and established `.app` as the official production Results domain.

## Durable decision

**The canonical MAXESS Results production/public domain is:**

`https://results.nayanet.app/`

`.xyz` is obsolete for the MAXESS Results production target and must not be used for Results navigation, redirects, deployment documentation, embeds, prompts, AI instructions, or future implementation work.

## Required behavior

Every AI, agent, developer, prompt, governance document, Smart Note, deployment instruction, Results navigation reference, redirect, or embed that identifies the MAXESS Results production/public target MUST use:

`results.nayanet.app`

Do not perform a blanket replacement of unrelated `.xyz` domains. Only MAXESS Results target references are governed by this rule.

## Evidence

Human decision on 2026-08-21 and repository evidence showing the prior canonical public verification target in `docs/REPOSITORY-MAP.md`.

## Verification rule

GitHub source verification establishes the engineering/documentation state. It does not by itself prove that the public host or Groove deployment has changed. Public/live status must remain explicitly verified or unknown until actually observed.
