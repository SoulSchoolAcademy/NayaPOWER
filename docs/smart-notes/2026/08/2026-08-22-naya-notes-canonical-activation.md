## Context

The Naya Notes / Smart Notes memory system needed one official activation authority so future Naya instances do not have to guess which overlapping memory specification governs.

## What We Learned / Decided

On 2026-08-22, the project established `docs/NAYA-NOTES-MASTER-ACTIVATION-SPECIFICATION.md` as the canonical Naya Notes / durable-memory system authority.

That specification governs how Naya Notes are activated, captured, classified, searched, recalled, updated, superseded, verified, and used.

It supersedes older or competing documents that claim to define the Naya Notes / Smart Notes system itself.

Older individual Naya Notes / Smart Notes remain historical evidence unless explicitly marked `SUPERSEDED`. They are not deleted merely because the system specification changed.

## Why It Matters

A future AI must be able to distinguish:

1. the canonical memory-system rules;
2. individual historical memory records;
3. the retrieval index;
4. broader Naya governance.

This prevents duplicate authority, memory drift, destructive history deletion, and semantic guessing.

## Required Behavior

When Naya Notes or durable memory is relevant:

- activate the canonical Naya Notes specification;
- retrieve relevant notes by concept, aliases, category, dates, relationships, and evidence;
- preserve durable value rather than conversational noise;
- never fabricate memory;
- treat current verified reality as stronger than stale memory;
- explicitly mark superseded active information when appropriate;
- keep memory distinct from governance;
- verify important saves and meaningful memory changes.
