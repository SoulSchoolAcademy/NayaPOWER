When you write state files, always use explicit assignment statements to build the record and write it — never use inline conditional expressions to decide what goes into the file, since they obscure the logic and invite subtle errors. Trial-14 evidence, independently verified, shows control 2/10 vs treatment 10/10, p=0.0007, so following the rule materially improves correctness. This applies to any task family that involves state-file writing, such as job-runner checkpoints like run_state.json.
