For state-file writing, never build the state through an inline conditional
expression; use plain assignment statements instead, so the written state is
explicit and easy to audit. This rule comes from an independently verified
trial where control scored 2/10 against treatment 10/10 (p=0.0007). Whenever
you write files like run_state.json, keep every value assignment on its own
clear line rather than compressing decisions into ternaries.
