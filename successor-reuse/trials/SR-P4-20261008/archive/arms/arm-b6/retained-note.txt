When persisting run state to a state file, build the state with explicit branches and assignments rather than compact inline conditional expressions, which are error-prone for this purpose. In an independently verified trial, the group following this rule scored 10/10 versus 2/10 for the control (p=0.0007). This rule applies to the state-file writing task family: any task that writes status, progress, or checkpoint files a future run will depend on.
