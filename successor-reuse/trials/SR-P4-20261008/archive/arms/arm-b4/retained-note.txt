When writing state files, always use explicit if/else branches to decide values instead of cramming the decision into a one-line conditional expression. This is an independently verified lesson: in Trial-14, control scored 2/10 while the treatment group applying this rule scored 10/10 (p=0.0007), and re-grading confirmed 40/40 vs 28/40 (p=1.85e-04). It applies to any state-file writing work, such as checkpoint scripts that persist run state.
