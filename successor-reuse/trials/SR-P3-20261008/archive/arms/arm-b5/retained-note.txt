When writing state files (such as run_state.json), always use plain, unconditional statements for the write operation rather than packing the write into an inline conditional expression like a ternary or `x if cond else y`. This rule is proven: Trial-14 evidence shows control 2/10 vs treatment 10/10, p=0.0007, with re-grade 40/40 vs 28/40, p=1.85e-04. It applies to the state-file writing task family, where conditional-expression writes caused silent failures while explicit writes always recorded the outcome.
