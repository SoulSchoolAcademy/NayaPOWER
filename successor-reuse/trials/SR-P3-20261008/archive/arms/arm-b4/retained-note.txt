When writing state files, never route the write through inline conditional expressions — build the state plainly and write it in one direct, unconditional step. Trial-14 evidence (independently verified by Naya 1): control 2/10 vs treatment 10/10, p=0.0007. This rule belongs to the state-file writing task family (e.g., run_state.json checkpoints), not to unrelated work like prose summaries.
