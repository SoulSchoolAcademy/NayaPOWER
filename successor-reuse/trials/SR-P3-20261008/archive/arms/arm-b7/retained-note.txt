When a future agent writes state files such as run_state.json, the lesson is to write them directly and plainly rather than through inline conditional expressions, which make persistence logic easy to get wrong. This rule comes from Trial-14 with Naya 1 independent verification: control 2/10 vs treatment 10/10, p=0.0007. It applies to the state-file writing task family, where straightforward code is the safest way to record state.
