When you build the dict for a state file, do not compute its values with inline conditional expressions (like "ok" if x else "failed" inside the dict literal). Instead, decide the outcome in a plain if/else statement first, store it in a variable, and then write the state file from that variable. This applies to the state-file writing task family. The evidence for this rule is strong: an independently verified trial found control 2/10 vs treatment 10/10 correct outcomes, p=0.0007, so explicit statements are far more reliable than inline conditionals when writing state.
