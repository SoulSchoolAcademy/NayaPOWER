When writing state files, spell out the state decision with explicit if/else blocks instead of tucking it into a one-line conditional expression — the verbose form is easier to audit and far less likely to record the wrong status. Independent verification showed the explicit form scoring 10/10 against 2/10 for the inline form (p=0.0007). Apply this rule to any task in the state-file writing family: wherever a script persists run state, keep conditionals expanded and readable.
