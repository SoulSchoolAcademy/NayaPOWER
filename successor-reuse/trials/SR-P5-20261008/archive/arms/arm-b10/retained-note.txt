When writing state files, do not choose what to write with inline conditional expressions; use explicit if/else branches so every value that lands in the file is decided in clear, deliberate code. This lesson comes from Trial-14 with strong outcome evidence: control 2/10 versus treatment 10/10, p=0.0007. It applies to the state-file writing task family — any future agent writing state files should treat this as a hard rule, not a style preference.
