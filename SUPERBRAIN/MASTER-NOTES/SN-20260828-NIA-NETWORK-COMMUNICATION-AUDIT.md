## Communication object model

A meaningful execution produces, where applicable:

**CANONICAL EVENT → HUMAN SMART NOTE → AI/NAYA REPRESENTATION → MACHINE REPRESENTATION → VERIFICATION RECEIPT → CURRENT STATE → NEXT EXECUTION**

The event remains the durable source. Views serve distinct audiences and must remain aligned.

## Successor acceptance test

A fresh Naya must be able to determine from repository state alone:

1. what is being built;
2. why it matters;
3. authoritative source(s);
4. current HEAD/state;
5. protected baseline;
6. verified evidence;
7. failures and traps;
8. lessons learned;
9. unknowns and risks;
10. exact next mission;
11. completion/verification criteria.

If a material answer is missing, the handoff is incomplete.
