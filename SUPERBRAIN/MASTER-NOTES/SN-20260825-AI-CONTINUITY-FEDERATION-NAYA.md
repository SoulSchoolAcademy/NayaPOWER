## Discovery

The Superbrain must assume that the next AI session may have zero conversational memory. Therefore GitHub must function as durable operational context: a fresh AI should boot from canonical laws, current Intelligence State, and an append-only operating feed rather than relying on prior chats.

## Continuity architecture

**BOOT → RESTORE → CHECK STATE → READ LATEST OPERATING CHANGES → ACT → VERIFY → WRITE MEMORY → WRITE RECEIPT → UPDATE FEED → HAND OFF**

The AI Operating Feed is the fast lane; canonical events/evidence remain the source of truth. The feed points AIs toward what changed and where the authoritative records live.

## Federation architecture

Future NayaNET should not merge every private Superbrain into one unrestricted database. It should federate autonomous personal Superbrains through explicit permissioned bridges.

The default unit of exchange should be **knowledge**, not raw memory.

Possible exchange classes:

- public knowledge;
- explicitly shared Smart Notes;
- shared project knowledge;
- capability/service requests;
- anonymized or aggregated intelligence where deliberately permitted.

Private memories, identities, conversations, credentials, and personal CIS remain local unless explicitly authorized.

## Why federation is stronger than centralization

Each Naya can remain optimized for one person's context while participating in a larger collective intelligence network. A bridge can discover, request, authorize, transmit, verify, and revoke access to selected knowledge without surrendering ownership of the source brain.

## Collective CIS

A future federated CIS can compound shared knowledge at network scope, but it must preserve provenance and distinguish:

- personal truth;
- shared/project truth;
- network knowledge;
- inference;
- consensus;
- unresolved disagreement.

Collective intelligence must never overwrite personal truth silently.

## Master rule

> **PRIVATE BRAINS. PERMISSIONED BRIDGES. PROVENANCE-PRESERVED KNOWLEDGE. COLLECTIVE INTELLIGENCE BY CHOICE.**

This is the architectural bridge from personal Naya Power to NayaNET.
