# MAXESS — Learning-Value Assessment Law

**Date:** 2026-08-27
**Status:** LOCKED PRODUCT LAW / CROSS-SYSTEM GUIDANCE
**Governing system:** NayaPOWER
**Consumer:** SoulSchoolAcademy/Maxis

## Core law

MAXESS must not merely measure what a person knows. Every interaction should increase what the person understands.

> **The assessment is itself part of the lesson.**

A question should never exist merely because it produces useful data. Ask it because considering and answering it can produce useful understanding.

## Question standard

Every meaningful MAXESS question should optimize for:

- clear intent;
- useful signal;
- teaching value;
- meaningful distinctions between answer states;
- psychological safety;
- immediate comprehension;
- actionability;
- narrative/report value.

## Answer standard

Answers should represent meaningful states, not generic good/better/best labels. Where appropriate, answer copy should explain the behavior represented by the choice so the person can recognize the distinction while answering.

## Result standard

The pipeline is:

`QUESTION → CHOOSE → DISCOVER → SCORE → MEANING → PATTERN → STRENGTH → OPPORTUNITY → RECOMMENDATION → NAYA → NEXT ACTION`

The scoring authority remains the canonical MAXESS engine and `MAXESS_RESULT_V1`. Learning presentation must never change scoring semantics.

## Free experience

The free MAXESS assessment should be genuinely useful. It is a taste of the larger Naya intelligence ecosystem, not a deliberately crippled teaser. Paid/extended experiences add depth, continuity, memory, recommendations, and capability rather than withholding basic value.

## Relationship to NayaPOWER

MAXIS consumes NayaPOWER governance, MAXESS authority, and Naya continuity principles. MAXIS may evolve presentation and learning experience, but authoritative scoring semantics remain governed by NayaPOWER.

## Current implementation receipt

On 2026-08-27, MAXIS exposed the canonical answer descriptions in the assessment UI and added a contextual learning lens after each question. This is a presentation/learning layer only; the score matrix, question IDs, dimensions, ordering, and result contract remain unchanged.

**Permanent principle:**

> **Maximize value per moment.**
