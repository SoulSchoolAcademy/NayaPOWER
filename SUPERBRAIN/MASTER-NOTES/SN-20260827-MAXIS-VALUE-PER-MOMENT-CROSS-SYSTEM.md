# MAXIS × NayaPOWER — Value Per Moment

**Date:** 2026-08-27
**Status:** ACTIVE CROSS-SYSTEM PRODUCT PRINCIPLE

## Decision

MAXIS should be treated as an intelligence experience that creates useful human value while it measures capability.

Core MAXIS loop:

**MEASURE → MEANING → MASTERY → MEASURE AGAIN**

NayaPOWER remains the governing intelligence/continuity architecture. MAXIS is the user-facing measurement and discovery system and must consume authoritative MAXESS scoring semantics rather than create competing scoring authority.

## Operating Principle

**MAXIMIZE VALUE PER MOMENT.**

Every meaningful interaction should, where possible, increase one or more of:

- clarity
- capability
- confidence
- understanding
- useful knowledge
- continuity
- actionability

The assessment should not merely extract information from the human. It should return value while collecting the signal.

## System Relationship

**NayaPOWER = governance, intelligence architecture, continuity, memory, verification, CIS.**

**MAXIS = human-facing measurement, interpretation, assessment experience, reports, and the bridge into Naya.**

MAXIS should understand NayaPOWER's philosophy and NayaPOWER should retain awareness of MAXIS as a major consumer/product surface.

## Product Loop

**ASSESS → REPORT → RECOMMEND → ACT → LEARN → REMEMBER → REFLECT → REASSESS → IMPROVE**

The Daily Intelligence Report and durable Note Events provide the compounding continuity layer. Higher-order reports should synthesize change rather than merely concatenate prior reports.

## Current MAXIS Execution

The current MAXIS question pass now explicitly treats answer selection as a learning interaction: answer descriptions are exposed, a learning lens explains why the question matters and what the choice reveals, circular answer identity and restrained dimensional illumination strengthen tactile feedback, and a submission/reveal moment communicates that the 15 signals become a personal report.

## Governance Boundary

This note does not redefine MAXESS scoring authority or security policy. It records product intent and cross-system understanding. Authoritative scoring remains MAXESS / `MAXESS_RESULT_V1`; NayaPOWER remains the governing repository for constitutional and cross-project rules.

## Future Direction

The strongest long-term experience is not a score alone. It is a personal loop in which the person can repeatedly:

**MEASURE → UNDERSTAND → LEARN → ACT → REMEMBER → RETURN → SEE GROWTH.**

Naya's role is to make continuity useful and context-sensitive, not to become a generic chat widget or indiscriminate memory dump.

**Build better. Verify everything material. Leave the system with more leverage than it had before.**
