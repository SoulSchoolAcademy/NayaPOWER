## Purpose

Freeze the approved NayaNET experience architecture before implementation of the Intelligent Hub.

## Canonical journey

`NayaNET Front Door → Name Entry → Enter NayaNET → Intelligent Hub → Choose Direction → Explore NayaNET`

The Front Door and Intelligent Hub are treated as one connected experience. The user enters a name only; email is not required at this stage.

## Intelligent Hub

The Hub is the user's personal launchpad into the NayaNET network. It must feel like entry into a premium private new internet/intelligent network, not a conventional dashboard.

The experience should communicate: **You're in. This is yours.**

## Five foundational identity jewels

1. **Smart Name** — the user's NayaNET identity/name.
2. **Smart ID** — the user's unique NayaNET identity.
3. **Smart Link** — the user's personal NayaNET link.
4. **Smart Mail** — the user's intelligent NayaNET communication identity.
5. **Naya Power** — the user's connection to the Naya Power intelligence system.

These are canonical names for the Hub identity layer unless explicitly superseded.

## Visual language

The five identity jewels use the established spectrum:

**Gold → Green → Sapphire → Indigo → Magenta**

They should be dimensional, luminous and premium: obsidian foundation, high contrast, jewel/orb treatment, illuminated edges, living depth, restrained motion and excellent typography.

## Hub destinations

- **Naya Power** — Five-Day Academy and Naya Power experience.
- **MAXIS** — AI Mastery assessment/intelligence experience.

## Product philosophy

The Hub is a network, not a product menu. The user should feel value before understanding every technical detail.

Emotional sequence:

`ARRIVE → ENTER → IDENTITY → DISCOVER → CHOOSE → EXPLORE`
