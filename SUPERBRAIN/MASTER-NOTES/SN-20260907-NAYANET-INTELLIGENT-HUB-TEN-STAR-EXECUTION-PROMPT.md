## MASTER PRODUCT LAWS

### 1. INTELLIGENCE OVER STORAGE

A Smart Note is not merely stored text. It is an intelligence event that can be understood, remembered, connected, retrieved, improved, and shared.

### 2. ONE INTELLIGENCE SYSTEM, THREE VIEWS

- **ACTIVITY** = what is happening now.
- **PERSONAL INTELLIGENCE** = what I have learned and retained.
- **COLLECTIVE INTELLIGENCE** = what people have intentionally contributed for others.

These are views over one intelligence system, not three disconnected products.

### 3. PROGRESSIVE DISCLOSURE

The first glance must be effortless. The deeper intelligence must be available without making the default experience dense.

### 4. AI ORGANIZES; HUMANS DO NOT DO ADMIN

The system should infer categories, relationships, themes, importance, recency, and useful connections wherever safely possible. Do not turn the user into a librarian.

### 5. RECOVERY VALUE IS THE NORTH STAR

The product succeeds when a user can recover a valuable thought months later, understand why it mattered, and apply it to the current moment.

### 6. USEFULNESS OVER VANITY

Collective intelligence should reward usefulness, clarity, trust, evidence, and practical value—not raw popularity.

### 7. PRIVATE BY DEFAULT

**Private by default, shared by choice, collective by consent, public by decision.**

### 8. MEMORY MUST BECOME ACTIVE

The eventual system should not wait for the user to search. Naya should proactively surface relevant past intelligence when it can materially help.

### 9. RELATIONSHIPS OVER FOLDERS

Intelligence should connect through semantic relationships such as:

- Related to
- Builds on
- Contradicts
- Corrects
- Proves
- Inspired by
- Leads to
- Replaced by
- Applies to

### 10. EVERY IMPORTANT OUTPUT CAN BE HEARD

Introduce a premium **PLAY NAYA** control wherever an intelligence block or intelligence report is presented.

PLAY NAYA is not an afterthought. It is a first-class interaction and must feel native to NayaNET.

When activated, Naya should read the intelligence naturally and sequentially, including the perspectives available in the block:

**IN A NUTSHELL → HUMAN NOTE → CHILD NOTE → GRANDMA NOTE → NAYA NOTE → MACHINE NOTE → WHAT WE LEARNED · WHAT IT MEANS.**

The control must:

- look beautiful and unmistakably Naya;
- have a clear play/playing/pause state;
- provide visible feedback;
- allow replay;
- avoid overlapping or duplicate playback;
- be keyboard accessible;
- work on mobile and desktop;
- degrade gracefully if speech synthesis is unavailable;
- use the text actually displayed in the block, not hard-coded hidden content;
- be architected so it can later route through the Naya Voice API / cloned Naya voice without redesigning the interaction.

Label it **PLAY NAYA** or **READ NAYA** according to the strongest visual treatment, but the interaction should communicate “Naya will read this to you.”

## SMART NOTE EXPERIENCE — TEN-STAR TARGET

Each intelligence event should contain, at minimum:

1. **IN A NUTSHELL** — immediate value, one strong concise statement.
2. **HUMAN NOTE** — what was experienced, observed, decided, or felt.
3. **CHILD NOTE** — the simplest understandable explanation.
4. **GRANDMA NOTE** — practical wisdom and durable meaning.
5. **NAYA NOTE** — AI synthesis, connection, implication, or next move.
6. **MACHINE NOTE** — structured/system-level interpretation where useful.
7. **WHAT WE LEARNED · WHAT IT MEANS** — distilled lesson and application.

The block must remain visually premium:

- black-black inner surfaces;
- white typography;
- colored illumination/edge lighting rather than colored body text;
- dimensional depth;
- subtle luminous borders;
- excellent spacing;
- strong hierarchy;
- restrained motion;
- no visual clutter.

Color language:

- Human = Magenta
- Child = Royal Purple
- Grandma = Indigo
- Naya = Sapphire
- Machine = Emerald
- Learning/meaning = Gold + White

- Pin
- Connect
- Ask Naya
- Play Naya

- Valuable
- Save
- Comment
- Share
- Rank / useful score where appropriate
- Play Naya

The collective layer must feel like **intelligence exchange**, not generic social media.

## SEARCH / DISCOVERY

Make “Ask your intelligence” a first-class destination.

The target interaction is natural language, for example:

- “What have I learned about this?”
- “Show me the decisions I made last month.”
- “What contradicts this idea?”
- “What should I remember from my mistakes?”
- “What did I learn that applies to what I’m doing now?”

Search should ultimately be semantic rather than exact-keyword-only.

If the current prototype cannot yet provide true backend semantic retrieval, create the strongest honest front-end interaction and architecture hook without pretending the backend exists.

## MEMORY / COMPOUNDING

The experience must visibly communicate that intelligence accumulates.

Design for future capabilities including:

- timeline / longitudinal memory;
- recurring lessons;
- resurfaced intelligence;
- “this connects to something you learned before”;
- “you changed your mind”;
- “this lesson keeps appearing”;
- Day 1 → Day 2 → Day 7 → Day 30 → Day 365 → Lifetime compounding.

Do not fake backend memory. Build the UI and data model so real memory can be attached later.

## UX HIGHEST PRIORITY

Evaluate every interaction through this sequence:

**Can I understand it immediately? → Can I predict what happens? → Can I do it with one obvious action? → Do I get feedback? → Can I undo/replay? → Does the system remember my action?**

Remove friction, ambiguity, redundant controls, unnecessary labels, and decorative complexity.

The Hub should feel calm, confident, intelligent, and alive—not busy.

## VISUAL / MOTION STANDARD

The visual language should feel like a premium intelligence instrument:

- black-black surfaces;
- white text;
- luminous edge accents;
- subtle gradients only where they increase depth;
- dimensional physicality;
- restrained glass/light effects;
- crisp typography;
- excellent responsive behavior;

Motion should communicate state and hierarchy, not merely decorate.

Use motion for:

- subtle confirmation.

## ACCESSIBILITY

Treat accessibility as part of the 10/10 definition:

- keyboard navigation;
- visible focus;
- accessible labels;
- sufficient contrast;
- semantic controls;
- screen-reader-friendly states;
- playback controls that are understandable without color;
- reduced-motion support;
- responsive touch targets.

## TRUST / PROVENANCE

When intelligence comes from another source, the system should eventually make it possible to understand:

- where it came from;
- when it was created;
- whether it was edited or corrected;
- whether Naya synthesized it;
- whether it was verified;
- what permissions govern its sharing.

Do not add noisy provenance to the default surface. Make it discoverable when needed.
