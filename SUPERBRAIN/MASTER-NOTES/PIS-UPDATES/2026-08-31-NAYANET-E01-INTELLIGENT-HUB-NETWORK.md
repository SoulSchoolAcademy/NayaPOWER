## Current Product State

NayaNET is being built as the network layer around Naya Power. The initial launch leads with practical AI empowerment; the deeper human/AI network is progressively revealed after entry.

## Current Architecture

**E01 → E02 → E03 → …** as independently testable experience blocks sharing canonical identity/session and design contracts. Approved blocks are protected from unrelated redesign.

## Immediate Mission

Build E01 — **THE DOOR** — first. It must provide frictionless one-name entry and establish the premium visual/emotional standard for the entire NayaNET experience.

## Identity

One human-facing name / Smart Name at entry; mutable public name; immutable backend account ID. Smart Mail is internal NayaNET messaging, not external email in V1. Smart Link provides member/profile/referral identity.

## Hub

The future Intelligent Hub is the member's premium cockpit for Naya Power, 5-Day Challenge, AI Masterclass, HMC Library, Power Seven Days a Week, MAXESS, and Share/Invite.

## Network

Future capabilities include human↔human, human↔Naya, human↔AI, AI↔AI, intelligent spaces, text/audio communication, intelligent discovery, and permissioned Superbrain interoperability.

## Governance

Private memory remains private by default. Network wisdom sharing and Superbrain interoperability require explicit permission and governed scope.
