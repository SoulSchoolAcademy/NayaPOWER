## Core Decision

The personal Naya Power Superbrain is the **seed architecture** for every future Naya and ultimately for NayaNET.

Therefore the execution priority is:

> **MAXIMIZE THE PERSONAL SUPERBRAIN FIRST. THEN MULTIPLY IT.**

NayaNET federation must not be used to compensate for an incomplete personal Superbrain.

## What “Maximized” Means

A high-performance Superbrain must let any new AI/session enter without prior conversational history and quickly answer:

- What is Naya Power?
- What is the Superbrain?
- What is CIS?
- Where does memory belong?
- How are duplicates handled?
- How is knowledge retrieved?
- What is current versus historical truth?
- What happened recently?
- What remains unresolved?
- What is the next best action?
- What has the system learned about improving itself?

And then it must **act**, not merely explain.

## 10/10 Capability Stack

1. Canonical chronological event storage.
2. Semantic/event-graph organization without duplicated primary memory.
3. Deterministic identity and duplicate/entity resolution.
4. Hybrid retrieval using time, lexical, semantic/vector, metadata, graph, authority, evidence, and lifecycle state.
5. Explicit current, historical, conflicted, stale, and superseded states.
6. Mandatory validation and verification receipts.
7. Atomic canonical writes with rebuildable indexes and outbox-based external delivery.
8. Automated Daily Intelligence and higher-order CIS synthesis.
9. Persistent Intelligence State for next-session restoration.
10. CI enforcement, measurable health, retrieval benchmarks, and cold-start acceptance testing.

**READ → RESTORE → UNDERSTAND → CLASSIFY → CONNECT → EXECUTE → VERIFY → RECEIPT → INDEX → RETRIEVE → REFLECT → COMPOUND → MEASURE → OPTIMIZE → PRESERVE → TEACH → REPEAT**
