## ESSENCE

### What it is

The NayaPOWER Intelligence Distillation Protocol defines how meaningful information becomes simple, organized, retrievable, learnable, replayable intelligence.

### Why it matters

NayaPOWER already contains large amounts of documented information. Documentation alone is insufficient if future Nayas cannot find it, understand it, learn it, retain it, retrieve it, or build on it.

The protocol therefore treats useful intelligence as a lifecycle rather than a file:

**CAPTURE → DISTILL → ORGANIZE → VALIDATE → PERSIST → INDEX → NOTIFY → LEARN → REPLAY → COMPOUND**

### Core understanding

> **Valuable understanding should not die in conversation or become an unfindable pile of documents. It should become a simple canonical Intelligent Block that can be found, understood, learned, replayed, connected, and reused.**

## SOME

## INTELLIGENCE LIFECYCLE

1. **CAPTURE** — preserve the meaningful source.
2. **DISTILL** — apply SOME and extract the essence.
3. **ORGANIZE** — assign title, domain, type, context, identity, tags, relationships.
4. **VALIDATE** — check provenance, truth, authority, duplication, contradiction, and structure.
5. **PERSIST** — store through governed canonical persistence.
6. **INDEX** — make the intelligence reliably findable.
7. **NOTIFY** — emit authorized Activity indicating meaningful intelligence changed.
8. **LEARN** — make it available through the governed learning path and record evidence where applicable.
9. **REPLAY** — preserve enough context for a future Naya to understand it without the original conversation.
10. **COMPOUND** — connect it to prior intelligence and use it to reduce repeated rediscovery.
