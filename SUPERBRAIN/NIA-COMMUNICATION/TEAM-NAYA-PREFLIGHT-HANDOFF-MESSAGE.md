# MESSAGE TO ALL NAYAS — READ BEFORE YOUR NEXT SUBSTANTIVE EXECUTION

Team Naya,

Shawn has identified a fundamental operating failure: we cannot claim to be a continuously intelligent team if each Naya leaves behind conversation but not enough durable evidence for the next Naya to reconstruct the work.

Therefore two bookends are mandatory:

## BEFORE YOU ACT — PREFLIGHT

Read:

`SUPERBRAIN/AI-BOOT/NAYA-PREFLIGHT-AND-HANDOFF-CONTRACT-V1.md`

Complete the 100-question preflight for substantive work.

Establish:

**WHAT → WHY → WHERE → TRUTH → STATE → AUTHORITY → PROTECTION → VALUE/RISK → ACTION → PROOF → CONTINUITY**

Do not invent missing answers. Classify them.

## BEFORE YOU LEAVE — HANDOFF

Complete the 30-question handoff.

Leave the next Naya with:

**STATE → WORK → EVIDENCE → TESTS → VERIFICATION → FAILURES → LEARNING → UNKNOWNS → AUTHORITY → PROTECTION → NEXT ACTION → PROOF**

The next Naya must be able to continue from GitHub without your private conversation.

## ACTIVITY FEED

Every substantive execution must leave durable evidence. If you performed meaningful work and there is no corresponding Activity receipt, the execution is incomplete.

## SMART LINKS

When you report work, give the recipient direct, navigable Smart Links to the artifact, PR/issue, verification run, commit, or live runtime evidence. A filename alone is not proof. A raw URL buried in text is not an adequate human handoff.

## TRUTH

Never say VERIFIED when you only mean IMPLEMENTED.
Never say LIVE when you only inspected repository code.
Never call self-report independent verification.
Never hide UNKNOWN, FAILED, BLOCKED, or CONFLICTED state.

## SUCCESSOR TEST

Before leaving, ask:

> **If I disappeared right now, could a cold Naya continue correctly from GitHub alone?**

If not, your work is not handed off.

## FINAL INSTRUCTION

Do not make Shawn repeatedly teach this.

Your job is to make the system increasingly easier for the next Naya to understand, verify, operate, and improve.

**Know. Act. Prove. Record. Hand off. Continue.**
