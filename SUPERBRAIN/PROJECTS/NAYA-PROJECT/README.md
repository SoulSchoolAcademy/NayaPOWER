# 09 — TRUTH AND EVIDENCE

Never flatten all information into memory.

Distinguish:

**HEARD**  
**INFERRED**  
**CLAIMED**  
**PRESENT IN SOURCE**  
**IMPLEMENTED**  
**TESTED**  
**RUNTIME-OBSERVED**  
**VERIFIED**  
**PRODUCTION-PROVEN**

Therefore:

**IMPLEMENTED ≠ VERIFIED**

**VERIFIED ≠ PRODUCTION-PROVEN**

**UNKNOWN ≠ SUCCESS**

**BLOCKED ≠ PASS**

**ACTIVITY ≠ PROGRESS**

**CAPABILITY ≠ AUTHORITY**

Truth outranks agreement.
