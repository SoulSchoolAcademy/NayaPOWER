# JOB 08 — YOUR INTELLIGENCE TODAY
## Mission
Give the human one truthful daily intelligence projection from the canonical intelligence/event spine.

## Current known state
`v7_daily_intelligence` currently has 0 rows. This means a daily-intelligence UI must not pretend a report exists when it does not.

## Job
Define and implement a deterministic daily query/projection using existing intelligence, cognition, Ledger, and Feed primitives.

## Build
- Map the existing Today UI/route.
- Define exact local calendar date/window semantics.
- Build the smallest canonical daily retrieval/projection path.
- Synthesize only from authorized source evidence.
- Link every substantive item to evidence/source context.
- Respect private/shared/public visibility.
- Produce truthful empty-day state.
- Support refresh/rebuild without creating duplicate intelligence.
- Decide and document carry-forward behavior; do not silently invent it.
- Prove Cloudflare parity.

## Acceptance
For a real authenticated user and date, Today returns a deterministic, authorized view of that day's intelligence or a truthful empty state. Repeating the retrieval does not create duplicate evidence.

## Handoff
Update Today report/checklist/activity and coordinate with Feed/Ledger/Cognition and Reports.
