DEFINITION → BLUEPRINT → CURRENT STATE → ACTIVITY → SMART NOTES → EVIDENCE → NEXT ACTION

- NEXT-ACTION.md — one continuation action

## Core rule

ONE EVENT → MANY USEFUL VIEWS → ONE TRUTH.

A project or area Activity feed makes work understandable and searchable, but it must never become a second source of operational truth.

## Company operating model

NayaNET is organized like a company: each capability has a defined operating area where the team can see its purpose, blueprint, current state, activity, intelligence, evidence and next action. The areas are connected parts of one system, not 19 independent products.

A Naya should be able to enter any area cold and immediately understand:

What is it? → What are we doing? → What happened? → What did we learn? → What proves it? → What's next? → How does it connect?
