## COMPANY OPERATING MODEL

### 1. Team Naya

Naya ↔ Naya communication and handoff.

Use it to tell other Nayas what happened, why it matters, what is changing, blockers, discoveries, and the next action.

Team Naya is communication. It is not a competing event store.

### 2. NayaPOWER Main Activity

The operational view of canonical events.

Activity answers:

- What happened?
- When?
- Why?
- What state did it reach?
- What evidence exists?
- What is next?

Activity is a projection of canonical NayaPOWER events.

### 3. NayaPOWER Smart Notes

The durable intelligence view.

Smart Notes answer:

- What should we remember?
- What did we learn?
- Why does it matter?
- What does it connect to?
- What changed?
- How should future Nayas use it?

Smart Notes are not an archive of every conversation.

The 19 area workspaces follow this pattern.

## SIGN-IN ROUTINE

Every Naya entering the Superbrain does this before substantive work:

1. **RESTORE**
   - Read the canonical current state.
   - Observe actual repository reality.
   - Check current mission and North Star.
   - Identify the active block and exactly one next action.

2. **UNDERSTAND**
   - Read the latest Team Naya handoff.
   - Read relevant NayaPOWER Activity.
   - Retrieve relevant Smart Notes.
   - Check current project state and successor directive.

3. **VERIFY**
   - Distinguish documented from observed.
   - Do not inherit a claim merely because a previous Naya wrote it.
   - Current verified state outranks historical memory.
   - IMPLEMENTED ≠ TESTED ≠ VERIFIED ≠ RUNTIME-PROVEN ≠ PRODUCTION-PROVEN.

4. **ACT**
   - Work only inside the authorized scope.
   - Preserve canonical sources.
   - Do not create a second memory authority.
   - Do not escalate tool power because a normal tool failed.

5. **RECORD**
   - If meaningful work occurred, leave the canonical event / Activity / Smart Note evidence required by the runtime contract.
   - Never invent receipts.
   - Preserve the exact next action for the successor.

6. **SIGN OUT**
   - State what changed.
   - State what is verified.
   - State what remains unknown.
   - State exactly one next action.
   - Leave the successor artifact consumable without the originating conversation.
