# SMART NOTE — THE INTELLIGENT HUB MAIN SHOW

**DATE:** 2026-09-17
**LEVEL:** L1 RETAINED

## LESSON
The Intelligent Hub is easiest to understand as MAIN SHOW plus MINI-PROJECTS.

MAIN SHOW: Smart Feed — Personal Intelligence + Collective Intelligence + Activity.

MINI-PROJECTS: Your Intelligence Today, Reports, Intelligence Library, Smart Share, Smart List, Smart Mail, Smart Spaces, Connections, Settings.

The sidebar is not a set of independent intelligence universes. It is a set of focused interfaces over the same governed Superbrain intelligence flow.

## THREE FEEDS
- Personal = private wisdom/intelligent blocks.
- Collective = voluntarily shared wisdom, anonymous by default, with social interaction and evaluation.
- Activity = private operational story of meaningful Superbrain events.

## CRITICAL DISTINCTION
Intelligence is not the same thing as activity. A Smart Note is the intelligence; an Activity event records that meaningful work happened. They may be linked, but they serve different purposes.

## CURRENT LIMITATION
The visual Hub exists, but the production data flows behind these projections remain unfinished. UI presence must never be reported as runtime completion.

## APPLICATION
Future Nayas should begin Hub implementation with the common governed feed/block contracts and prove the three projections end-to-end before treating the sidebar as the primary build target.
