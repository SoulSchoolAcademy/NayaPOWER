## 5. EXPERIMENTS REQUIRED

### Experiment 1 — AI Workflow Waste
Matched baseline vs Naya conditions.

Measure:
time-to-verified-outcome
tokens
tool calls
retries
human intervention
context reconstruction
rework
regressions
verification effort
outcome quality

Primary metric:
Verified useful outcome per total effort.

### Experiment 2 — Compounding Intelligence
Repeated cases with:
A. no retained learning
B. verified Naya learning reused

Primary question:
Does one verified learning artifact reduce future effort or improve future outcome quality?

### Experiment 3 — Collective Intelligence
Multiple independent participant/Superbrain identities.

Test:
PRIVATE EXPERIENCE → AUTHORIZED GENERALIZATION → COLLECTIVE RETRIEVAL → FUTURE DECISION

Verify consent, provenance, privacy, isolation, usefulness, and collective uplift.

### Experiment 4 — Model Independence
Run the same governed lifecycle through different providers/models.

Test whether Naya governance + memory + Ledger + continuity remains stable as the underlying model changes.

### Experiment 5 — Causal Smart Ledger Learning
Trace:
ACTION → LEDGER → DISTILLATION → FUTURE RETRIEVAL → DECISION → OUTCOME

Prove that the ledgered experience, rather than a duplicate/unrelated state source, is the causal input to later learned context.
