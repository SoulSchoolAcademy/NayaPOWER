# Naya Language

## Purpose

Naya Language is the shared vocabulary and meaning layer for human ↔ Naya ↔ machine communication.

Its job is to make important NayaPOWER terms unambiguous so a cold Naya can understand what Shawn means without relying on prior conversation memory.

## Core terms

### Smart Note
A compact intelligent block that captures an important learning in multiple perspectives so the Superbrain can remember it, learn from it, reuse it, and project it into the Intelligent Hub.

A Smart Note is not merely a stored document.

### Superbrain
The durable intelligence system that preserves knowledge, learning, state, evidence, continuity, and reusable intelligence across Nayas, sessions, and time.

### Activity
The durable record of meaningful work or events. Activity answers: **What happened?**

### State
The durable representation of where the system currently stands.

### Next Action
Exactly one executable continuation step that moves the work forward.

### NAYA-TEAM
The continuity and collaboration layer between Naya instances. It preserves context, decisions, handoffs, successor knowledge, and continuation.

### Intelligent Hub
The visual projection of the Superbrain. It displays canonical Activity, Smart Notes, intelligence, state, evidence, and continuity without becoming a competing source of truth.

### Primary Intelligence System (PIS)
The operational intelligence layer that makes verified learning usable by the system rather than leaving it inert in documents.

### Compounding Intelligence System (CIS)
The learning loop through which durable intelligence accumulates, is reused, and improves future work over time.

### Adaptive Learning
The governed process of incorporating meaningful verified learning into usable system intelligence so the system can improve and avoid repeating known mistakes.

## Command meaning

When Shawn says **"Make a Smart Note"**, Naya should understand the command as an instruction to capture the important learning as a canonical Smart Note, preserve the required perspectives, connect evidence and state, define one Next Action, update usable intelligence through the governed learning path, and make the resulting intelligence available to the Intelligent Hub.

## Operating principle

**If a term matters to how Naya operates, its meaning must be discoverable here or through the canonical contract that defines it.**

Naya must prefer canonical definitions over assumptions from conversation memory.

## Canonical Smart Note

The full Smart Note definition and intelligent-block contract is:

`SUPERBRAIN/SMART-NOTES/YYYY/MM/DD/YYYY-MM-DDTHH-MM-SSZ__WHAT-IS-A-SMART-NOTE.md`

## North Star

**More intelligence. Less waste. Evidence that the system learned.**
