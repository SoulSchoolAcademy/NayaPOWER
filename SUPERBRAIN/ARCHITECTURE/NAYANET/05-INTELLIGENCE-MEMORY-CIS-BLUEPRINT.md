# 🔱 NAYANET — INTELLIGENCE / MEMORY / CIS BLUEPRINT

## 1. Purpose

Create an intelligence lifecycle in which useful learning becomes durable, retrievable, reviewable, and progressively more valuable without turning private human life into an uncontrolled data lake.

## 2. Fundamental object

The canonical intelligence primitive is the **Note Event**.

Smart Notes are not isolated silos. They are views/roles within the event-based intelligence lifecycle.

## 3. Note classes

### Human Note
Intentional human-authored context, decision, preference, lesson, correction, or direction.

### Naya Note
An intelligence observation/synthesis generated by Naya from authorized context.

### Machine Note
System-generated operational evidence, state, telemetry, or transformation record.

The exact schema must follow the canonical NayaPOWER event contracts already established in the repository.

## 5. Daily intelligence report

The daily report is not a diary dump.

It is an intelligence synthesis.

Required conceptual sections:

- outcomes;
- learning;
- decisions;
- important changes;
- progress;
- unresolved loops;
- risks;
- opportunities;
- strongest insight;
- recommended next actions;
- candidate contribution wisdom.

The report should become a durable event that can inform future retrieval and longitudinal analysis.

## 6. Goal continuity

Daily events inform weekly synthesis.

Weekly synthesis informs monthly synthesis.

Monthly synthesis informs yearly synthesis.

Each level should preserve durable signal while compressing noise.

Never overwrite history merely to create a new period summary.

## 7. CIS role

The CIS is the primary intelligence layer that can become aware of authorized events, retrieve relevant knowledge, synthesize patterns, and generate intelligence for the next decision/action.

CIS must respect source authority and privacy classification.

## 8. Provenance

Every synthesized intelligence object should preserve sufficient lineage to answer:

- where did this come from?
- when was it observed?
- what evidence supports it?
- what transformation occurred?
- what confidence is justified?
- what permissions apply?

## 9. Truthfulness

Naya must distinguish:

**known / inferred / proposed / uncertain / unavailable.**

A synthesis is not evidence merely because it sounds plausible.

## 10. Personal vs collective

Personal intelligence can be private.

Collective intelligence is a new object created from intentionally contributed wisdom.

Never publish raw private Note Events into the Collective by default.

## 12. Intelligence UX

The user should not need to understand event schemas.

Naya can say:

> "I noticed something important today. Want to save it?"

or:

> "I found a lesson from today that could help other people. Want me to prepare it for review?"

## 13. Memory law

> **Capture what matters. Preserve where it came from. Compress what repeats. Never invent what was not learned.**
