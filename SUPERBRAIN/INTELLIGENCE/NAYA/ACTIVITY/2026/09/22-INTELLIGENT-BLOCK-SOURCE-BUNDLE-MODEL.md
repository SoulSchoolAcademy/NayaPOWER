## What happened

The NayaNET system model was formally reconciled around a stronger definition of the Intelligent Block:

> **An Intelligent Block is the fundamental reusable unit of understood intelligence: a validated, provenance-bound container that can unify one or many source documents, conversations, Intelligent Events, evidence, perspectives, decisions, observations, runtime outcomes, and prior Blocks around a meaningful subject.**

This is now an explicit architectural rule, not merely a conversational idea.

## What changed

The canonical Intelligent Block V1 contract now defines:

- one-to-many source-bundle distillation;
- source identity and provenance preservation;
- multiple perspectives;
- separate distillation and validation;
- explicit uncertainty and conflict handling;
- human-readable and machine-readable projections;
- Markdown / JSON / database / Hub / API representations;
- lifecycle and supersession;
- successor comprehension;
- value-oriented reuse.

## Machine rule

One source may become one Block.

Many sources may become one Block.

One Block may connect to many Blocks.

A Block may be revised or superseded without rewriting the historical Events from which it was derived.

## Human rule

Do not optimize for storing everything.

Optimize for preserving what matters, making it understandable, validating it, connecting it, and making it reusable.
