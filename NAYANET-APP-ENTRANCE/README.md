# NayaNET.APP — 10/10 Smart Identity Entrance

Static, dependency-free Cloudflare-ready entrance page.

## Included
- Premium NayaNET entrance experience
- Learn. Create. Connect. Grow. positioning
- Smart Identity creation from name/alias
- Smart Name, Smart Link, and Smart Mail reveal
- Smart Link format: `alias.nayanet.app`
- Responsive mobile/desktop layout
- Keyboard and reduced-motion support
- No Wrangler, package manager, framework, build step, or external dependency

## Important production note
This package is the front-end experience. Real alias uniqueness, account creation, passkey/WebAuthn registration, durable sessions, Smart Mail routing, PWA installation, and referral attribution require the production backend/services to be connected. The UI does not falsely claim those backend capabilities are live.

## Cloudflare
Upload the contents of this folder as a static site. The entry point is `index.html`.
