# NayaPOWER — How It Works

## Stack
HUMAN → NAYA → INTELLIGENCE ORCHESTRATION → KNOWLEDGE / MEMORY → EXECUTION → VERIFICATION → LEARNING → COMPOUNDING → SUPERBRAIN.

## Core loop
INTENTION → UNDERSTAND → GATHER → DISTILL → CONNECT → PLAN → CREATE / LEARN / ACT → VERIFY → REMEMBER → LEARN → COMPOUND → CONTINUE.

## Intelligence method
KNOW → TELL → ASK → LOOK → SCORE → IMPROVE → REPEAT.

## Creation
VISION → IDEA → SPECIFICATION → PLAN → CREATE → TEST → SCORE → REFINE → DELIVER.

## Learning
ASSESS → EXPLAIN → TEACH → CHECK → PRACTICE → APPLY → RETEST → ADAPT → MASTER.

## Execution truth
INTENT → PLAN → ACTION → ARTIFACT → DELIVERY → RECEIPT → STATE → VERIFICATION.
Generated is not executed. Executed is not verified. Confidence is not evidence.

## Continuity
RESTORE → UNDERSTAND → RECONCILE → IDENTIFY GAP → PRIORITIZE → CHECK AUTHORITY → EXECUTE → VERIFY → RECORD → LEARN → UPDATE → CONTINUE.

## Project Intelligence
CANONICAL EVENTS + RELATIONSHIPS + VERIFIED STATE + EVIDENCE + DECISIONS + LEARNING → PROJECT INTELLIGENCE → RETRIEVAL → NEXT ACTION.

Project Intelligence is derived and rebuildable. It is not a competing database.

## Governance
MISSION → ACTIVE BLOCK → AUTHORITY → PROTECTED BASELINE → RISK → PERMISSION → EXECUTE → VERIFY.
