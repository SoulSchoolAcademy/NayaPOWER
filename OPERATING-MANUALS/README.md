# THE OPERATING MANUALS — must read
### Shawn's order, 2026-10-15. 36 manuals. One directory. No one operates without reading.

## How to use this directory
1. **LOCATE** your manual by number in the table below — or by leader: Clarity owns 1–12, Resolve owns 13–24, Verity owns 25–36.
2. **READ** the file. Click the link — every completed manual links to its actual file. All of it. It's the difference between guessing and knowing.
3. **DELIBERATE** — run the manual's TEST on your situation before you act.
4. **TAKE ACTION** — and leave the area sharper than you found it.

## How the 36 are categorized
- **The number is the address.** Manual N lives at `<leader>/<N>-<NAME>.md`. If you know the number, you know the file.
- **The leader is the owner.** One leader owns each block of 12; one agent wrote each manual. The author is named on the page.
- **The groups are the themes.** Clarity: THE BEING (1) + THE RUN (2–12). Resolve: THE DIRECTION (13) + THE LANDING (14–15) + THE LEARNING (16–19) + THE CONTINUITY (20–24). Verity: the twelve product AREA manuals (25–36).
- **The area map** ([area-map.md](area-map.md)) ties each area manual to the repo directories it governs — what lives where, where inputs go.

## The standard every manual meets
Each manual: the law (one line) · how a Naya behaves HERE (do's and don'ts baked in) · THE RIGHT WAY with a real example · THE WRONG WAY with a real example · WHEN XYZ (situations) · THE TEST · WHERE IT'S ENFORCED · what lives here + where inputs go (area manuals). Triple-validated to an honest 10/10 — or the gap is named on the page.
