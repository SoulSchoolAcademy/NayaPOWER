### Two real bugs the probe caught and fixed (both fixed in this round, not hidden)

1. **The phase-1 finder 404'd 806 of 1,058 notes.** `phase2ServeNote` first called `phase1FindNote`, which only matches a full id or `SN-<digits>` in the title. 806 notes carry their SN number only in the ID (titles are plain, e.g. "The Right Thing, Finished Completely"). The first full-set probe run showed 308 failures in the first 200 notes — every one of them a `Note not found` 404 for a listed slug, which would also have made the sitemap list URLs that 404 (a sitemap error). **Fix:** `phase2FindNote` (in `phase2-additions.js`): try the phase-2 canonical slug first, then the phase-1 finder as fallback so every phase-1 URL keeps working (full id, `/s/sn2696` with SN-2696 in the title). Rebuilt, mirror-checked (0 divergent), redeployed, re-probed: all 1,058 serve.
2. **Ten SN numbers are filed twice — ten canonical slugs cover twenty notes.** Found by the probe's live-vs-report mismatches (`/s/sn2650` served "The World Masters" while the report scored "The Master Operational Manual"). The slug function takes the SN from the title first, else the id — so a note whose title mentions another note's number collides (SN-2626's note is titled "The Guard Is Too Slow to Stop a Race: SN-2602, the Fourth Collision" and claims slug `sn2602`). Colliding slugs: `sn27`, `sn32`, `sn48`, `sn361`, `sn829`, `sn833`, `sn1904`, `sn2602`, `sn2648`, `sn2650`. **What the machine does:** the first note in feed order owns the canonical URL; the second is flagged in the report (`canonicalCollision: true`, `canonicalServesThisNote: false`, `fails` += `canonical-collision`) and stays reachable by its full-id URL (`/s/ib-smart-note-...`, proven 200 by the probe). **What the machine does NOT do:** silently choose which note keeps the number — that is Shawn's call, per the standing rule on shared-number collisions. **Sitemap:** deduped to unique canonicals (see below) so no URL is listed twice. Highlights never pick a collision-second note (guard in the build).
