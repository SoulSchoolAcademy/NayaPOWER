# CIS — COMPOUNDING INTELLIGENCE SYSTEM

CIS is the intelligence-compounding layer of Naya Power.

It is not a bigger notebook. It is a knowledge-and-learning architecture that continuously improves itself.

## Core pipeline

**EXPERIENCE → CAPTURE → OBSERVE → DISTILL → ORGANIZE → CONNECT → VERIFY → PROMOTE → COMPOUND → APPLY → LEARN AGAIN**

Alternative operational loop:

**LIVE → EXPERIENCE → REFLECT → CAPTURE → DISTILL → CONNECT → COMPOUND → APPLY → VERIFY → IMPROVE → LIVE BETTER → REPEAT**

## Knowledge maturation

**RAW EXPERIENCE → OBSERVATION → LESSON → PATTERN → PRINCIPLE → PROTOCOL → PERMANENT KNOWLEDGE → CAPABILITY → ACTIVE INTELLIGENCE**

Not everything learned deserves equal status. CIS needs a **PROMOTE** stage.

## Retention / value rule

> **Compress information, never compress away meaning.**

CIS does not maximize stored information. **CIS maximizes retained intelligence.**

Before discarding anything, ask:

> Could this materially improve a future decision, capability, safety condition, relationship, understanding, or outcome?

If yes → preserve it.
If no → distill or discard.

Treat material as:

- Temporary working material → archive/discard after distillation.
- Useful observation → retain.
- Lesson → retain.
- Principle → promote.
- Protocol → promote strongly.
- Decision → retain.
- Known-good state → retain.
- Reusable pattern → retain.
- Critical safety information → never casually discard.
- Duplicate information → consolidate.
- Superseded rule → preserve history and mark superseded.

Never confuse larger memory with greater intelligence.

The smartest system retrieves the right thing, understands it, connects it, applies it, verifies it, and learns from the result.

## Daily → weekly → long-term compounding

Daily:

**Experience → Daily CIS Update**

**7 Daily Updates → Weekly Intelligence Synthesis**

Then:

**Weekly Syntheses → Higher-Order Knowledge**

Long-term:

**DAY → WEEK → MONTH → YEAR → LIFETIME**

The intelligence becomes increasingly compressed, connected, and useful.

Do not literally delete yesterday's learning. **Distill yesterday into tomorrow.** Raw daily working material may be archived or removed after its valuable information has been incorporated and verified.

# GITHUB IS NOT CIS

**GitHub is a storage/implementation layer. CIS is the intelligence architecture.**

CIS should ultimately be AI-agnostic and storage-agnostic. It can work with:

- GitHub
- Google Drive
- Notion
- local files
- another repository
- another knowledge system

For Naya Power's initial implementation, GitHub is an efficient durable, inspectable, versioned text/code substrate.

Customer options:

### A — Naya does it
“**Naya, make a note.**”

Naya creates the record, returns a verification link, and confirms it.

### B — User does it
GitHub → Add File → paste → title → commit.

### C — Google Drive
Connect Drive → “**Naya, make a note in my Drive.**”

The customer can use A, B, C, or all three.

Teaching principle:

> Start with what you have. Upgrade only when actual usage requires it.

Do not scare people with storage limits before they have a storage problem.
