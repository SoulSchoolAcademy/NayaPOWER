01 · The standard-bearers

01Three buttons. This is the bar.

Before anything else: buttons are alive. White pearl at rest, lit from above like a real object. This is not a design system. It is a living design language. Spectrum is meaning: magenta is what matters, purple is Naya’s presence, blue is understanding — and one river of light flows across all three in that order. White light contains the whole spectrum: move around a button and the pearl reveals its hidden colors, like mother-of-pearl. The cursor is the light source; the face turns toward you. Every component carries intelligence — one spring, one rhythm, tested code — so excellence reproduces without being retaught. If your button doesn't do this, it isn't a Naya button.

The four foundations. (1) Spectrum is meaning, not decoration — every color has purpose: separation, relationships, identity, rhythm. The river flows magenta → purple → blue because that is the order of meaning. (2) Black ground. White light. Purple soul. — surfaces have depth, light has direction, the pearl is a real material. (3) Intelligence in every component — consistent rules, understandable behavior, tested code: a spring (400/28), one rhythm, a ripple born at the touch point, 100ms press physics. (4) Reproduce without reteaching — copy the block, set data-spectrum, verify with the calculator. No master to copy: this is what the world hasn’t experienced yet.

02 · The component that follows you

02SmartTabs — try it. It's live.

A universal favorites ribbon that follows the user across every page. Add, edit, heart, star, remove, navigate. State persists. This one below is real — click a pill, right-click it, add your own. Then take the code.

↑ Live demo — right-click a pill (or tap ⋯) for Edit / 💜 Heart / ⭐ Star / Remove. State saves to this browser.

Step 1 — the container
<div id="smarttabs"></div>
Step 2 — include the kit and mount
<link rel="stylesheet" href="smart-tabs.css">
<script src="smart-tabs.js"></script>
<script>
  // Shared storageKey across ALL pages — the ribbon stays in sync everywhere.
  const tabs = SmartTabs.mount('#smarttabs', {
    storageKey: 'smartnet_shortcuts',
    onNavigate: (route, s) => Router.go(route), // hook into your router
    routeMap: { 'soulschool': '/soulschool' }  // keyword synonyms
  });
</script>
Step 3 — the API (for other NAYAs)
// Read & write
tabs.list();                    // → [{ id, label, route, heart, star }, …]
tabs.set(arrayOfShortcuts);    // replace wholesale
tabs.add({ id, label, route, heart, star });
tabs.update(id, { label, route, heart, star });
tabs.remove(id);
// Listen
tabs.el.addEventListener('change', e => console.log(e.detail));

// Data shape — heart/star are mutually exclusive, hearts sort first
{ id: 'sc-1', label: 'SoulSchool', route: '/soulschool',
  heart: true, star: false }

Why it works everywhere: one storageKey across all pages so state follows the user. onNavigate wires into your router — the component never assumes. 💜 hearts outrank ⭐ stars in sort order: the most important tabs literally rise to the top. Esc closes everything. That's the whole contract.

03 · The law, not a palette

03The spectrum flows one way.

Magenta → purple → blue → green → gold. Richest first, ultra-rich magenta leading. Every sequence on every page follows it. When a list runs long, return to magenta and flow again. Scramble it and the eye knows something's wrong before the mind does.
