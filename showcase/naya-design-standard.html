01 · The standard-bearers

01Three buttons. This is the bar.

Before anything else: buttons are alive. White light. Visible skin. At rest they breathe — a quiet glow, a light that sweeps across on its own rhythm. On hover they rise and ignite in their own spectrum color. On press they compress like something real. If your button doesn't do this, it isn't a Naya button.

The anatomy of living depth. Six layers, no shortcuts: (1) the white-light gradient — pearl white, never flat, glowing from within; (2) the white rim — 1.7px, visible at rest, the "skin" you can see before you touch; (3) the inset top highlight — light catching an edge, this is what makes it 3D; (4) the inset bottom shadow — weight, gravity, the object sits IN the page; (5) the drop shadow — elevation, it floats above the field; (6) the spectrum halo — your own color, glowing underneath at rest. Then motion: breathe at rest, sweep on rhythm, ignite on hover, compress on press.

Copy this — the living button
/* THE LIVING BUTTON — copy this verbatim. This is the standard. */
.living-btn {
  position: relative; overflow: hidden; cursor: pointer;
  font-weight: 800; font-size: 17px; letter-spacing: .12em;
  /* White light at rest — dark voice on white light */
  color: #0b0d14;
  padding: 22px 44px; border-radius: 999px;
  /* Layer 1: white-light gradient, glowing from within */
  background: linear-gradient(180deg, #ffffff 0%, #f2f4fa 45%, #dbe0ef 100%);
  /* Layers 2–6: skin, bevel, weight, elevation, halo */
  box-shadow:
    inset 0 0 0 1.7px #ffffff,              /* visible skin */
    inset 0 3px 10px rgba(255,255,255,.95), /* top bevel: light catches edge */
    inset 0 -12px 26px rgba(110,125,175,.42),/* bottom weight: gravity */
    0 18px 48px rgba(0,0,0,.6),             /* elevation */
    0 0 44px -6px var(--btnc);              /* own spectrum halo */
  animation: idleBreathe 4.2s ease-in-out infinite;  /* alive at rest */
}
/* The color-flow sweep — your spectrum color crossing on its own rhythm */
.living-btn::after {
  content: ""; position: absolute; top: -20%; bottom: -20%; width: 46%; left: -70%;
  background: linear-gradient(105deg, transparent 20%,
    var(--btnc) 50%, transparent 80%);
  transform: skewX(-18deg);
  animation: sweep 5.5s cubic-bezier(.22,1,.36,1) infinite;
}
/* Hover: kill the idle animation, IGNITE in your spectrum color */
.living-btn:hover { transform: translateY(-4px) scale(1.03); color: #fff; animation: none; }
.living-btn[data-spectrum="magenta"]:hover {
  background: linear-gradient(180deg, #ff8ae2, #e84fff 52%, #b52fe0);
  box-shadow: inset 0 0 0 2px #fff, 0 28px 74px rgba(232,79,255,.65),
    0 0 110px -8px rgba(232,79,255,.85);
}
/* Press: compress like something real */
.living-btn:active { transform: translateY(1px) scale(.975); }

02 · The component that follows you

02SmartTabs — try it. It's live.

A universal favorites ribbon that follows the user across every page. Add, edit, heart, star, remove, navigate. State persists. This one below is real — click a pill, right-click it, add your own. Then take the code.

↑ Live demo — right-click a pill (or tap ⋯) for Edit / 💜 Heart / ⭐ Star / Remove. State saves to this browser.

Step 1 — the container
<div id="smarttabs"></div>
Step 2 — include the kit and mount
<link rel="stylesheet" href="smart-tabs.css">
<script src="smart-tabs.js"></script>
<script>
  // Shared storageKey across ALL pages — the ribbon stays in sync everywhere.
  const tabs = SmartTabs.mount('#smarttabs', {
    storageKey: 'smartnet_shortcuts',
    onNavigate: (route, s) => Router.go(route), // hook into your router
    routeMap: { 'soulschool': '/soulschool' }  // keyword synonyms
  });
</script>
Step 3 — the API (for other NAYAs)
// Read & write
tabs.list();                    // → [{ id, label, route, heart, star }, …]
tabs.set(arrayOfShortcuts);    // replace wholesale
tabs.add({ id, label, route, heart, star });
tabs.update(id, { label, route, heart, star });
tabs.remove(id);
// Listen
tabs.el.addEventListener('change', e => console.log(e.detail));

// Data shape — heart/star are mutually exclusive, hearts sort first
{ id: 'sc-1', label: 'SoulSchool', route: '/soulschool',
  heart: true, star: false }

Why it works everywhere: one storageKey across all pages so state follows the user. onNavigate wires into your router — the component never assumes. 💜 hearts outrank ⭐ stars in sort order: the most important tabs literally rise to the top. Esc closes everything. That's the whole contract.

03 · The law, not a palette

03The spectrum flows one way.

Magenta → purple → blue → green → gold. Richest first, ultra-rich magenta leading. Every sequence on every page follows it. When a list runs long, return to magenta and flow again. Scramble it and the eye knows something's wrong before the mind does.

Color is identity, not decoration. One color job per thing. Adjacent things never share a hue. The spectrum gives each thing its identity — and never shouts over the brand.

05 · Drawn, not dotted
