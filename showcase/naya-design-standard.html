01 · The standard-bearers

01Living buttons. This is the bar.

A living thing notices you before you touch it. These buttons are dark, luminous substance — polished obsidian with light trapped inside. At rest they breathe, a quiet hint of their spectrum color. As your cursor approaches they wake. On hover they light up from within. Their light falls on the page around them. If your button doesn't do this, it isn't a Naya button.

The six laws of living. (1) Dark heart — deep black gradient, never flat. Depth you can feel. (2) Cursor as light source — the surface responds to pointer position like polished stone. (3) Spectrum soul — each button holds its color inside: breathing hint at rest, awakening on approach, full ignition on hover. (4) Physical press — inner shadows deepen, like pressing something real. (5) Cast light — the button's glow falls on surrounding elements. (6) Breathe — a living pulse, never a dead loop. And the standing law over all of it: light up, don't glow out. Depth through layers, elevation, cleanness — not neon.

The three heroes

Magenta, purple, blue — the spectrum leading edge. Move your cursor near them. Watch them wake before you arrive.

Every size, one soul

Same DNA at every scale. lv-hero for flagships, default for interfaces, lv-sm for density. Danger gets darker black and more depth — never a red glow.

States, left to right: standard · compact · danger (depth, not alarm) · disabled (honest about it).

/* living.js — proximity awareness (include once per page) */
(function () {
  'use strict';
  if (window.matchMedia && window.matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  var els = Array.prototype.slice.call(document.querySelectorAll('.lv-btn, .lv-board'));
  if (!els.length) return;
  var ambient = document.createElement('div');
  ambient.className = 'lv-ambient'; ambient.setAttribute('aria-hidden', 'true');
  document.body.appendChild(ambient);
  var raf = null, lastX = -9999, lastY = -9999;
  function accentOf(el) {
    var wrap = el.closest('.lv-wrap');
    var rgb = getComputedStyle(wrap || el).getPropertyValue('--lv-accent-rgb').trim();
    return rgb || '160,107,255';
  }
  function update() {
    raf = null; var lit = false, best = null, bestDist = 1e9;
    for (var i = 0; i < els.length; i++) {
      var el = els[i];
      var wrap = el.classList.contains('lv-btn') ? (el.closest('.lv-wrap') || el) : el;
      if (el.disabled) continue;
      var r = el.getBoundingClientRect();
      if (r.bottom < -180 || r.top > window.innerHeight + 180) { wrap.classList.remove('lv-aware'); continue; }
      var dx = Math.max(r.left - lastX, 0, lastX - r.right);
      var dy = Math.max(r.top - lastY, 0, lastY - r.bottom);
      var dist = Math.sqrt(dx*dx + dy*dy);
      var aware = dist < 160;
      if (aware !== wrap.classList.contains('lv-aware')) wrap.classList.toggle('lv-aware', aware);
      if (aware || el.matches(':hover')) {
        el.style.setProperty('--mx', ((lastX - r.left) / Math.max(r.width,1) * 100).toFixed(1) + '%');
        el.style.setProperty('--my', ((lastY - r.top) / Math.max(r.height,1) * 100).toFixed(1) + '%');
      }
      if (aware && dist < bestDist) { bestDist = dist; best = el; }
      if (el.matches(':hover')) { best = el; lit = true; }
    }
    if (best) { lit = true;
      document.documentElement.style.setProperty('--lv-wash-rgb', accentOf(best));
      document.documentElement.style.setProperty('--lx', lastX + 'px');
      document.documentElement.style.setProperty('--ly', lastY + 'px'); }
    document.body.classList.toggle('lv-lit', lit);
  }
  document.addEventListener('pointermove', function (e) {
    lastX = e.clientX; lastY = e.clientY;
    if (!raf) raf = requestAnimationFrame(update);
  }, { passive: true });
})();

03 · The law, not a palette

03The spectrum flows one way.

Magenta → purple → blue → green → gold. Richest first, ultra-rich magenta leading. Every sequence on every page follows it. When a list runs long, return to magenta and flow again. Scramble it and the eye knows something's wrong before the mind does.
