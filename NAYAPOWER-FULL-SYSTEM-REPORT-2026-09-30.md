# 4. HOW IT ALL WORKS

**The three layers:** LAW constrains INTELLIGENCE. INTELLIGENCE powers EXPERIENCE. EXPERIENCE produces new EXPERIENCE. NEW EXPERIENCE becomes INTELLIGENCE.
- **Layer A — LAW:** contracts, constitutional rules, authority boundaries, privacy requirements, deterministic enforcement. Purpose: make prohibited behavior fail closed.
- **Layer B — INTELLIGENCE:** nodes, events, evidence, relationships, outcomes, learning, connected context. Purpose: coherent understanding.
- **Layer C — EXPERIENCE:** Naya, Hub, voice, web, apps, mail, spaces, smart doors, future interfaces. Purpose: make intelligence useful to humans.

**The pipeline (one brain, one tree, many doors):**
HUMAN → NAYA LANGUAGE/INTENT → NAYANET EXPERIENCE → NAYAPOWER GOVERNANCE → CANONICAL RECEIVER → CANONICAL INTELLIGENCE → NODES + EVENTS + EVIDENCE + RELATIONSHIPS → RETRIEVE → APPLY → OUTCOME → VERIFY → LEARN → COMPOUND ↺

Object hierarchy: SOURCE/EXPERIENCE → INTELLIGENT EVENT → NAYA NODE → CANONICAL INTELLIGENT BLOCK → RELATIONSHIPS/CHAIN → RETRIEVAL → APPLICATION → OUTCOME → (verify, learn, compound).

**The nine Master Nodes** (each with a contract specifying inputs, outputs, MUST/MUST-NOT rules, acceptance criteria, failure states):
- **SELF** — identity, mission, continuity context. Halts the kernel if identity can't be established.
- **LAW** — authority resolution: AUTHORIZED / DENIED / REQUIRES_CONFIRMATION / AMBIGUOUS / EXPIRED / REVOKED / OUT_OF_SCOPE. Must never create authority from capability, retrieval, confidence, or urgency.
- **ACT** — governed intent into safe execution, with receipts for every action.
- **KNOW** — preserves and serves canonical intelligence; never serves without provenance or authorization.
- **PROVE** — what can legitimately be claimed and why; claim strength never exceeds evidence strength.
- **CONNECT** — isolated intelligence into situated intelligence; relevance is never authority.
- **VERIFY** — what actually happened vs. intended; never infers success from execution.
- **LEARN** — verified experience into future behavioral improvement; a stored note is never "verified learning."
- **EVOLVE** — continuity and governed improvement; evolution never becomes self-authorization.

**The value calculus** (`kernel/value_calculus.py`): 9 dimensions (U,R,A,E,C,Re,L,K,T), weighted by objective profile; harm subtracted as its own term; critical gates can BLOCK regardless of score; outputs include `score_10`, `mvpa`, `mvpm`, learning efficiency, and sensitivity analysis. Your ±9 framework, executable.

VERIFY checks what happened." Doors must not own authority, truth, intelligence, identity, policy, or learning.

**Activation (the plug-in mechanism):** `NAYA-ACTIVATION/` is a portable, versioned boot kit. Your vision's core — anonymous wisdom compounding across the network — has its tables but not its runtime.

4. **MCP is contract-only. Seven of nine doors are contract-only.** Only AI and Data doors are live.
5. **Production state is unknown.** The promotion pipeline is correctly gated and failing closed, but nobody has read the live migration table.

**None of this is a verdict against the vision — it's the roadmap being honest.** The 7-stage plan says Stage 1 is "graph, receipts, consent, parity" and that's exactly what's being proven.
