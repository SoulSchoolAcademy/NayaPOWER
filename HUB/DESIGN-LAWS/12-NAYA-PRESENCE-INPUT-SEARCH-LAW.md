# 🤝 Naya Presence, Identity Portal & Search Law V1

## 1. Naya's role

Naya is the intelligent partner inside the environment.

She is not:
- a floating generic chatbot bubble;
- the entire product;
- decorative avatar theater;
- an excuse to hide navigation.

Naya should feel contextually present.

## 2. Contextual intelligence

Naya's prompts/actions should reflect current room/object.

Examples:
- Report: "What changed?"
- Ledger: "Explain this outcome."
- Smart Note: "Why does this matter?"
- Connections: "Who can help with this?"
- Evidence: "What proves this?"

## 3. Presence states

Naya may expose:
- REST;
- AWARE;
- LISTENING;
- THINKING;
- SPEAKING;
- PLAYING;
- ATTENTION;
- RESOLVED.

Only when real state supports it.

## 4. Identity portal

Identity input is not a utility form.

It is the threshold into the person's intelligence environment.

It should feel:
- calm;
- private;
- premium;
- clear;
- generous;
- secure.

The human should understand:
- who the system recognizes;
- privacy state;
- activation/connection state;
- what Enter will do.

## 5. Input design

Inputs need:
- readable label;
- generous size;
- high contrast;
- clear focus;
- error/help;
- autocomplete semantics where useful;
- mobile keyboard correctness.

Placeholder text never replaces a label for important inputs.

## 6. Search

Search is intelligence retrieval, not document filename search.

It should support queries around:
- what;
- why;
- source;
- learning;
- meaning;
- time;
- relationship;
- status.

Results should expose:
- title/essence;
- type;
- provenance;
- state;
- why relevant.

## 7. Search response

Search may use Naya to interpret intent, but:
- interpretation must not overwrite source truth;
- inferred relevance must be distinguishable from verified fact;
- empty/no-match state must be honest.

## 8. Voice

Voice may provide natural access.

Voice state should clearly show:
- listening;
- transcribing;
- processing;
- speaking;
- stopped/error.

Never make the human guess whether the microphone is active.

## 9. Companion restraint

Naya should not occupy permanent large screen area when not helpful.

Presence can be:
- compact;
- contextual;
- expandable.

The intelligence content remains primary.

## 10. Acceptance

Naya presence passes if:
- it reduces cognitive work;
- it is context-aware;
- states are truthful;
- it does not duplicate navigation;
- it does not hide the underlying intelligence;
- it feels like a partner, not a widget.
