## Builder rule

Do not cherry-pick the fun laws.

A component does not qualify as elite because it has:
- glow;
- depth;
- spectral color;
- animation.

It qualifies only when visual craft, readability, functionality, state truth, accessibility, performance, and causal behavior work together.

## Cold-builder test

A cold designer should be able to enter this directory and correctly explain:

- what NayaNET should feel like;
- what visual bliss means;
- why readable text outranks effects;
- how a button physically behaves;
- how a board differs from a card;
- what the spectrum means;
- why motion exists;
- what states are truthful;
- what accessibility/performance constrain;
- how work is proven.

If not, this lawbook is incomplete.
