# 💎 Intelligence Board Law V1

## 1. Role

A board is not a generic card.

A board is an **intelligence destination/object**.

It should communicate:
- identity;
- purpose;
- state;
- theme;
- provenance;
- meaning;
- available action.

## 2. Board anatomy

Every major Intelligence Board should define:

1. board identity / glyph;
2. title;
3. concise orientation;
4. truth/provenance state;
5. dominant spectral theme;
6. primary intelligence content;
7. optional nested intelligence layers;
8. meaningful actions;
9. source/evidence access;
10. continuity/persistence state where relevant.

## 3. Theme law

Each major board receives one dominant semantic theme from the canonical spectrum.

The theme may influence:
- perimeter light;
- accent rail;
- glyph illumination;
- selected control;
- small local aura;
- key section markers.

The theme must **not**:
- recolor all body text;
- flood the entire surface;
- destroy contrast;
- become a decorative gradient wash.

## 4. Living board states

### REST
Present, dimensional, calm.

### HOVER / APPROACH
Lift subtly, sharpen edge, reveal local energy.

### SELECTED / ACTIVE
Sustained semantic illumination and clear location.

### LOADING
Quiet processing state tied to actual retrieval.

### EMPTY
Intentional quiet state explaining what belongs here.

### BLOCKED
Explain why and what can change it.

### NOT_VERIFIED
Explicitly uncertain/unproven.

### VERIFIED
Distinct truth state with evidence path.

### ERROR
Readable recovery.

## 5. Board hierarchy

Inside a board:
- title first;
- state/provenance visible;
- human-readable summary early;
- detail progressively disclosed;
- machine/evidence detail available without overwhelming the main read.

Do not show all underlying architecture at once merely because it exists.

## 6. Intelligence layer law

Where relevant, the same intelligence may be understood through:

- Human Note;
- Child/Simplified;
- Grandma/Why Notice;
- Naya Note;
- Machine/Evidence Boundary;
- Adaptive Learning;
- What It Means;
- What's In It For You.

These are **nested perspectives of one intelligence**, not repeated independent cards.

## 7. Surface material

Recommended:
- near-black body;
- slight directional gradient;
- precise edge;
- restrained inner highlight;
- lower shadow/elevation;
- local theme field.

Avoid:
- generic frosted-glass cards everywhere;
- opaque neon fills;
- oversized glows around paragraph content.

## 8. Composition

Boards should have a strong visual rhythm:
- generous outer padding;
- clear content groups;
- predictable metadata;
- sufficient vertical breathing room;
- limited border proliferation.

If every nested section has a full border, the board becomes visual bureaucracy.

## 9. Responsive

On smaller screens:
- preserve theme and depth;
- stack content;
- keep title/state/actions visible;
- collapse secondary detail thoughtfully;
- never flatten the board into a generic white/gray mobile card.

## 10. Interaction

Opening a board should feel like entering a focused intelligence object.

The interface may:
- expand in place;
- route to detail;
- transform local context.

Choose based on content density and continuity.

Never use a tiny tooltip/modal for a major intelligence destination.

## 11. Board action law

Actions must be contextual.

A board should not automatically have:
Favorite / Save / Like / Love / Rank / Share
unless each serves a real product purpose.

Engagement signals never equal truth.

## 12. Acceptance

A board passes when:
- its identity is unmistakable;
- its theme is coherent;
- content is easier to understand because of the design;
- state is honest;
- provenance is available;
- actions are causal;
- responsive behavior preserves character;
- it does not look like a generic SaaS card.

**A board should feel like a place the user can enter.**
