## The ten doors

Smart Connect is the room you're going to love. Ten doors into the same intelligence:

1. **MCP** — AI agents plug their tools straight in *(first priority)*
2. **REST / OpenAPI** — any app or agent, over plain HTTP *(second)*
3. **GitHub App** — coding agents, working with the repo and the mind together *(third)*
4. **Webhooks** — the outside world can knock; the intelligence answers
5. **SDK** — developers embed NayaPOWER inside their own products
6. **Agent-to-Agent** — AIs collaborating through shared, governed context
7. **Browser / Web Hub** — *this is you, right now — the human door, and it's live*
8. **Email / Messaging** — reach it where you already talk
9. **Enterprise Identity** — organizations, with their own boundaries *(later)*
10. **Private MCP Tunnel** — for agents that must never touch the public internet *(specialized)*

A door is a *channel*, not a maze. Behind every door sits the same memory, the same judgment, the same receipts. And a door that isn't open yet says so — on the door itself.
