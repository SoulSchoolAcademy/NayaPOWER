## 6. Integration law

A canonical intelligence object keeps one identity while appearing in Feed, Today, Reports, Library, Lists, Spaces, Connections or Ledger.


## Why these elements go there

### Left rail
The rail answers **"Where can I go?"** and remains spatially stable.

It contains exactly the primary rooms. It should not contain every capability in the product.

### Top context/status
Answers **"Where am I and is the system healthy enough to trust what I see?"**

Keep it quiet. Do not turn it into another navigation bar.

### Ecosystem links
These are secondary destinations outside the core intelligence-room architecture. They stay visually subordinate to the primary Hub rail.

### Global intelligence search
Search belongs near the top of the center canvas because **retrieval is a primary intelligence action, not a utility afterthought**.

The user should not have to navigate to a Search room just to ask the system what it knows.

### Human context / greeting
This establishes who the environment is serving, current Space/context, and time/freshness when useful. It should be personal without becoming a giant marketing hero.

### Center workspace
The center is the product. Every room transforms this area into a different intelligent software experience.

### Naya
Naya is globally available but context-sensitive. Do not permanently sacrifice a large right column to a generic assistant panel unless current task value justifies it.

# 20. MOBILE NAVIGATION — SINGLE-SIDEBAR / ZERO-GUTTER LAW

The Human Director has reported a concrete presentation defect: opening the mobile "+" / navigation control can expose a second/duplicate sidebar behavior, and scrolling can reveal unused black space/gutter beside the content.

Treat this as a **P1 visual/interaction defect until independently reproduced and closed**.

## Hard requirements

At any viewport there is exactly **one active primary navigation surface**.

### Desktop
- persistent left rail;
- no duplicate drawer.

### Mobile/tablet
- rail becomes ONE drawer / bottom navigation strategy;
- the desktop rail must not remain rendered as a second visible/sticky rail underneath;
- drawer overlays the content instead of permanently reserving a second column;
- opening the drawer must not change document width;
- closing the drawer restores the exact previous scroll position;
- drawer height is bounded to the viewport;
- drawer itself scrolls if its contents exceed viewport height;
- page/body must not expose horizontal overflow;
- no black gutter appears to the left/right after scroll;
- backdrop covers the non-drawer viewport;
- Escape/backdrop closes the drawer;
- route selection closes the drawer;
- focus is managed accessibly.

## QA for this defect

Test:
- 320, 375, 390, 430, 768 and 820 CSS-px widths;
- page shorter than viewport;
- page 3× viewport height;
- drawer opened at top;
- drawer opened mid-scroll;
- drawer opened near bottom;
- rotate portrait ↔ landscape;
- browser zoom 125%, 150%, 200%.

Automatic failure:
- two nav surfaces visible simultaneously;
- main content width changes unexpectedly when drawer opens;
- persistent empty/black side column;
- horizontal scrollbar;
- stale overlay after navigation;
- scroll jumps to top merely from opening/closing nav.

# 21. ROOM MAP — WHAT EACH ROOM MUST BE

a living intelligence stream with real **Personal / Collective / Activity** modes.

Must support:
- mode switching that changes actual data;
- provenance/truth state;
- why-am-I-seeing-this;
- open object;
- Ask Naya;

- save/favorite;
- add to list;
- evidence/source;
- governed connect/share;
- cross-room handoff.

Do not make it a social-media clone.

## 2. Your Intelligence Today — THE HIGHLIGHT REEL
Question: **What mattered today?**

Signature instrument:
one beautiful daily story of what happened, changed, mattered, was learned, remains open and should carry forward.

Must include:
- date + Space + freshness;
- Today Pulse using real counts;
- What Changed;
- highest-value highlights;
- evidence/source;
- Naya Reflection grounded in evidence;
- open loops/tomorrow carry-forward;
- date navigation;
- handoff to Feed, Reports, Ledger, source.

This is the reference masterpiece / first full vertical slice.

## 3. Your Reports — THE FILM ROOM / TIME MACHINE

DAY / WEEK / MONTH / YEAR must be meaningfully different syntheses, not the same template with a date filter.

Must include:
- period thesis;
- changes;
- breakthroughs;
- decisions;
- lessons;
- patterns;
- open loops;
- comparison where useful;
- source drill-down;
- Naya interpretation;
- export/share only when governed.

## 4. Intelligent Library — THE VAULT / YOUR MIND
Question: **What do we know and where is it?**

Search-first.

Must support:
- semantic retrieval;
- filters/domains when useful;
- featured/relevant intelligence;
- source/provenance;
- current vs superseded;
- related intelligence;
- gaps/uncertainty;
- "Ask Naya: What am I missing here?"

Never search only rendered DOM text.

## 5. Smart Connect — THE PORTAL BAY
Question: **How can this person/AI/system connect?**

Must show canonical Smart Door registry/state.

**CONNECT → CONFIGURE → VERIFY**

Visually distinguish:
- registered;
- available;
- connected;
- authenticated;
- authorized;
- healthy;
- blocked/error.

**CONNECTED ≠ AUTHORIZED.**

No roadmap/contract-only door may look live.

## 6. Smart Ledger — THE BLACK BOX / PROOF ROOM

Signature:
causal chain / receipt view.

Must make visible, where applicable:
**RECEIVED → AUTHORIZED → EXECUTED → OBSERVED → VERIFIED → OUTCOME**

Must support:
- receipt lookup;
- source/action/actor/time;
- authority basis;
- result;

- verification state;
- related intelligence.
