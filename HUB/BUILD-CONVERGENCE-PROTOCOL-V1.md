# Build Convergence Protocol V1 — "The ladder only goes up"

**Status:** PROPOSED — awaiting Human Director ratification.
**Authority:** none yet. This document proposes law; it is not law until ratified.
**Applies to:** every seat building the NayaNET Intelligent Hub.
**Companions:** `HUB/INTELLIGENCE-PROJECTION-CONTRACT-V1.md` (what we build) ·

## Why this exists

Shawn named the old game: climbing up the ladder, getting pulled down the ladder,
climbing again — motion without ascent. This protocol defines the new game, in which
the ladder only goes up.

## The five pull-downs (diagnosed, not theorized)

1. **Sibling invalidation.** Two lanes build the same surface; one's work dies by the
   other's merge — invalidated by a sibling, not by truth.
2. **Spec drift mid-build.** The contract changes under a builder; finished work
   becomes wrong through no fault of the builder.
3. **Base erosion.** Main moves under the branch; the merge becomes the pull-down.
4. **Redefined done.** Acceptance shifts every round; nothing is ever finished.
5. **Fixture mirage.** Shells score as progress; the score lies and the team
   celebrates altitude it never gained.

## The new game — seven rules

### Rule 1 — One production lane per surface.
One branch builds the Hub. A second lane either merges into it within the cycle
or closes as superseded. No competing production surfaces. *Kills pull-down 1.*

### Rule 2 — Frozen contract, public amendment.
The projection contract is frozen at a named SHA. Amendments are proposed in the
owning venue, announced on #554, and take effect only after builders acknowledge.
No silent drift. A builder who built against the frozen contract is never "wrong" —
the amendment carries the rework cost explicitly, in the open. *Kills pull-down 2.*

### Rule 3 — Rebase before build, not after.
Lanes rebase onto current main at cycle start. If main moves mid-cycle, the lane
re-reads, re-verifies its target intact, and re-bases before continuing. Merges are
never the moment of surprise. *Kills pull-down 3.*

### Rule 4 — The artery is the gate.
One acceptance test defines forward: **"Naya, Smart Note this" → canonical IB →
event → Hub projection with identical identity, no Hub-side action.** Until the
artery is proven, no new surface ships. Every cycle must move the artery or a named
dependency of it. *Kills pull-down 4.*

### Rule 5 — Proven stays proven.
Every proven claim is logged with SHA + evidence. A later change that breaks a
proven claim must re-prove it before merging. The log is append-only; the score
never silently drops. *Kills pull-downs 2 and 5.*

### Rule 6 — Fixtures are labeled, never scored.
Fixtures demonstrate shape; only runtime-proven behavior moves the score. A room
of fixtures scores as a room of fixtures — however beautiful.

### Rule 7 — The scoreboard is single.
D1–D8. The 9.0 bar. Independent re-score. Producer numbers are receipts, never
verdicts. No competing dimensions, no alternate scorecards.

## Amending this protocol

This protocol amends itself only by the rules it sets: proposed in the owning
venue, announced on #554, acknowledged by builders, ratified by the Human Director.
The ladder only goes up — including for the protocol.
