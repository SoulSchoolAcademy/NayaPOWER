    storageKey: 'smartnet_shortcuts',

  });

Step 3 — the API
tabs.list(); tabs.set(arr); tabs.add({id,label,route});

Why it works everywhere: one storageKey across all pages so state follows the user. onNavigate wires into your router — the component never assumes. 💜 hearts outrank ⭐ stars: the most important tabs literally rise to the top. Esc closes everything. That's the whole contract.
