The bridge contract — the actual spec

One object. Named accessors. Every call returns the same envelope. Rooms never touch raw database rows.

// one object, ten accessors — one per room window.NayaRuntime = { smartFeed(), today(), reports(), library(), ledger(), lists(), mail(), spaces(), connections(), settings() } // every call returns this envelope { ok, state, data, method, runtime_connected } // what each accessor reads smartFeed() → intelligent blocks (the feed cards) today() → today's blocks + ledger beats reports() → the reports table (name unconfirmed — verify) library() → blocks + the meaning index ledger() → the ledger stream lists() → blocks, filed as lists mail() → the mail store (doesn't exist yet) spaces() → the spaces store (doesn't exist yet) connections() → the members table settings() → the session snapshot // the card shape the feed renders { id, title, subtitle, topics[], topic, tone, icon, kind, personal, layers[] }

What blocks what — the dependency chain

  • The pump is independent — build it now, nothing waits on it.
  • The session decision (Shawn's word) unlocks all live reads.
  • The bridge needs the session design — then it unlocks every room.
  • Room wiring needs the bridge — then all 12 go live.
  • Mail, spaces, reports need their stores named/built first (engine; schema changes are a protected gate).
  • The GitHub handshake (Shawn) flips ignition — install → lit-up Hub.
  • The seven remaining doors are full builds, in priority order.
  • The human proof needs everything above — it is the last gate, not the first.

What needs Shawn's word — the protected gates

A builder never crosses these on judgment alone. Everything else, the math decides.

  • Writing to the database — exact statement shown first, word given, then write.
  • Production deploys.
  • Credentials and money.
  • Destructive or irreversible actions.
  • Security, privacy, consent, or authority changes.
  • The read architecture — how the Hub reads as someone.

How a room is proven complete — the shared test

A room is done when a stranger installs the App and watches their own note travel the whole journey — capture → memory → GitHub → bridge → their room — with receipts at every handoff, in under five minutes, unassisted. No mocks. No seeds posing as data. Honest empty states where there's nothing yet.
