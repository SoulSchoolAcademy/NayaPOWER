# THE PARTS REGISTER — every part of the machine, so every part can carry its score

*Drafted by Resolve, 2026-10-26 — the register that check B17 names: inside each of the 12 areas, these are the parts. Each part gets a percent done computed from its tracked items, its notes, its link, and the team's latest hand on it (B18). A part that exists but is not in this register is invisible — and invisible is not done. Power wires the mapping (real `area_key` + part tags replace the keyword guess); Resolve keeps the register honest as parts are born.*

**How a part's percent is computed:** proven-done items ÷ all its items, from the record, deduped by item (see the data pack: the table today holds 23 double-inserted items — count items, never rows).
