## Design law

**OBSIDIAN FOUNDATION · SPECTRAL INTELLIGENCE · LIVING DEPTH · PRIMO CONTROLS · REAL CAPABILITY · ZERO VISUAL REGRESSION**

The existing concept is the visual-quality floor. A cleaner implementation that feels cheaper is a failed implementation.

## Build law

**ONE SHELL · ELEVEN ROOMS · ONE GOVERNED SUBSTRATE · HONEST STATE · REAL CAUSAL PATHS**

Every visible control must perform a real operation, navigate somewhere real, or honestly communicate unavailable/blocked/unknown state.

## Cold-builder acceptance

A cold builder passes only if it can answer from this index and linked sources:
1. What are we building?
2. Why?
3. What may not regress?
4. What are the features/rooms?
5. What is canonical?
6. What is live vs target vs unknown?
7. What does 10/10 mean?
8. What is the highest-value next implementation step?
9. What evidence closes it?
10. What must be left for the next Naya?

If Shawn has to rebuild this context, the project intelligence is incomplete.
