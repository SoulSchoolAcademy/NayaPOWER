## 1. HUMAN JOB

**Understand and configure connection doors**

### The room must answer

- **WHERE AM I?** Smart Connect / Smart Doors
- **WHAT MATTERS?** How humans, agents, applications and systems connect to the same intelligence.
- **WHAT CAN I DO?** Inspect, connect or configure a governed door.
- **WHAT HAPPENS NEXT?** The connection state and authority boundary are unmistakable.

### Time-horizon test

**1 second:** The visitor can see that these are doors into one intelligence substrate.  
**3 seconds:** They understand a door's purpose, status and what connecting it does.  
**30 seconds:** They can configure or inspect a door without confusing connection with permission.  
**Return visit:** The room restores real connection status without decorative “breathing” lies.

## 7. UNIVERSAL STATE MATRIX

The implementation must explicitly design applicable behavior for:

| State | Room requirement |
|---|---|
| **LOADING** | Stable door shells with truthful status loading. |
| **EMPTY** | Explain that no doors are configured and offer legitimate connection paths. |
| **READY** | Real status is immediately readable. |
| **BLOCKED** | Explain what dependency blocks connection. |
| **UNAUTHORIZED** | Separate not-connected from not-authorized. |
| **NOT_VERIFIED** | Do not show “live” until live status is proven. |
| **VERIFIED** | Use restrained active indicator tied to real state. |
| **ERROR** | Show failed connection and recovery. |
| **OFFLINE** | Differentiate network availability from configured authorization. |
| **DISABLED** | Explain unsupported door action. |
| **UNKNOWN** | Unknown provider state stays unknown. |

## 9. ACCESSIBILITY

This room is not Signature unless its intelligence remains understandable and operable for people using:

- keyboard-only navigation;
- assistive technology / screen readers;
- zoom up to 200%;
- reduced-motion preferences;
- high-contrast / accessibility settings;
- touch input.

Focus order must follow cognitive order. Color may reinforce meaning but never be the sole carrier of meaning.

### Room-specific accessibility consideration

Door status must be text-readable, not color-only; capability and authority distinctions need headings and clear labels.
