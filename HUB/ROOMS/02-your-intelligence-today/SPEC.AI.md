# Your Intelligence Today — AI Builder Spec

**Read first:** parent Hub contracts + this room's FUNCTIONAL-SPEC + DESIGN-CONTRACT.

## Intent

Build the reference masterpiece room. It must synthesize canonical daily activity into an explainable story, not simply aggregate records.

## Build order

1. Preserve the shared Hub shell and Naya context.
2. Implement the room's five layers: ORIENTATION → CURRENT STATE → INTELLIGENCE → ACTION → PROOF.
3. Build the signature instrument before secondary controls.
4. Bind controls to governed runtime operations or honest unavailable states.
5. Preserve canonical object identity across handoffs.
6. Implement loading/empty/blocked/unauthorized/not-verified/verified/error/offline/unknown/disabled.
7. Prove keyboard, responsive, reduced-motion, performance and back/forward continuity.

## Data / runtime

Canonical intelligence + verified events + current Space/context. Pulse metrics are derived from actual evidence. Highlight selection considers importance, verified change, decisions, learning, active goals, consequence and explicit human signals.

## Anti-patterns

- generic daily dashboard
- vanity pulse scores
- fabricated metrics
- canned inspirational reflection
- duplicating the whole Feed
- ten tiny KPI cards

## Acceptance proof

- human understands the day within ~10 seconds
- pulse numbers recompute from canonical data
- every highlight explains why it was selected
- highlight opens original canonical object
- Naya Reflection is evidence-grounded
- quiet day does not manufacture content
- open loops/tomorrow carry-forward are visible

Self-score does not close the gate. Independent review required.
