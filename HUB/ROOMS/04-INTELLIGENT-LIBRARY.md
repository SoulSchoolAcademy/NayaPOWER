# 04 — Intelligent Library

**Metaphor:** THE VAULT  
**Route:** `/library`  
**Theme:** sapphire  
**Human question:** **What do we know, and how can I find it?**

## Human promise

Everything worth retaining should be findable, understandable and trustworthy without remembering where it originally appeared.

The Library organizes by **meaning**, not by accidental file location.

## Signature visual

A premium **semantic vault / intelligence gallery**.

The room opens with the global intelligence search as the hero instrument.

Below:
- recently useful;
- saved/favorites;
- topics;
- people;
- Spaces/projects;
- learning;
- decisions;
- sources;
- verified/unverified filters.

A result is an intelligence object, not a file thumbnail.

## Search behavior

Search supports:
- natural language;
- semantic meaning;
- title/content;
- people;
- Space;
- source;
- time;
- truth status;
- relationships.

Result cards show:
- essence;
- why relevant;
- provenance;
- state;
- last meaningful update;
- important connections.

## Views

- **Search**
- **Browse**
- **Saved**
- **Recently used**
- optional **Map / relationships** when graph view adds value

Do not turn the default into a filesystem.

## Primary actions

- **Open intelligence**
- **Ask Naya**
- **Save / Favorite**
- **Add to List**
- **Open source**
- **See relationships**
- **Open originating Feed/Space**
- governed **Share**

## Detail view

Opening an item reveals:
- human summary;
- Naya interpretation;
- evidence/machine note;
- provenance;
- relationships;
- learning/history;
- revisions/supersession;
- where it has been used.

## Cross-room handoffs

Any object can move by reference to Feed, Today, Reports, Lists, Spaces, Connections or Ledger without copying canonical truth.

## Empty state

If canonical retrieval is unavailable: **RUNTIME UNAVAILABLE / NOT VERIFIED**, not sample shelves.

## Mobile

Search-first. Result list → full-screen detail. Filters in a sheet. Preserve provenance.

## Acceptance journey

A human can search a concept they remember vaguely, locate the right intelligence, understand why it matched, inspect provenance, see related objects and use it elsewhere.
