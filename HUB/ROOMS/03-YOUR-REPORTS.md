# 03 — Your Reports

**Metaphor:** THE FILM ROOM  
**Route:** `/reports`  
**Theme:** indigo  
**Human question:** **What does all of this mean over time?**

## Human promise

Turn accumulated intelligence into understandable synthesis.

A report is not “37 records found.” It is:
**what changed, what pattern emerged, why it matters, what evidence supports it, and what should happen next.**

## Signature visual

A premium **report theater / analysis studio**.

Top:
- featured current report;
- period selector;
- scope/Space;
- report freshness and verification.

Main body:
- executive nutshell;
- key changes;
- trend/pattern sections;
- important decisions;
- learning;
- risks/opportunities;
- people/connections;
- open questions;
- evidence appendix.

Visualizations appear only when they clarify meaning. No ornamental charts.

## Report types

Time:
- Daily
- Weekly
- Monthly
- Quarterly/Yearly when enough data exists

Purpose:
- Project / Space report
- Decision report
- Learning report
- Relationship / collaboration report
- custom thematic report

## Primary actions

- **Open report**
- **Ask Naya**
- **Compare periods**
- **Inspect evidence**
- **Save / Add to List**
- **Share** under governance
- **Export** where supported
- **Generate / refresh report** only through real runtime capability

## Compare mode

Two periods or reports can be compared:
- changed;
- improved;
- declined;
- newly learned;
- unresolved;
- contradictory.

No automatic “good/bad” judgment without declared criteria.

## Cross-room handoffs

- evidence item → Library / Feed;
- consequential event → Ledger;
- person → Connections;
- message basis → Mail;
- project basis → Space;
- important report conclusion → List.

## Empty state

“No report can be generated from the available verified intelligence yet.”

Explain missing data/runtime requirements.

## Mobile

Report cover → sections → evidence. Charts must remain readable. Use progressive disclosure rather than tiny dashboards.

## Acceptance journey

A human can select a period, understand the report summary, inspect how the conclusion was formed, compare with another period and follow evidence back to canonical objects.
