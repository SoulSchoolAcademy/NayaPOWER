## 1. HUMAN JOB

**Know what matters right now**

### The room must answer

- **WHERE AM I?** Today
- **WHAT MATTERS?** The few things that deserve attention now.
- **WHAT CAN I DO?** Act on the top next move or ask Naya to help.
- **WHAT HAPPENS NEXT?** The page makes current work, risks, learning and waiting states easy to resume.

### Time-horizon test

**1 second:** The single dominant current situation is obvious.  
**3 seconds:** The visitor understands what matters now and what to do next.  
**30 seconds:** They can scan risks, learned changes and waiting dependencies.  
**Return visit:** The room feels like continuity, not a blank daily reset.

## 7. UNIVERSAL STATE MATRIX

The implementation must explicitly design applicable behavior for:

| State | Room requirement |
|---|---|
| **LOADING** | Maintain the briefing skeleton; don't invent content. |
| **EMPTY** | Explain that there is not enough relevant intelligence and point to legitimate entry paths. |
| **READY** | NOW dominates without overwhelming supporting sections. |
| **BLOCKED** | Make blockers legible and actionable. |
| **UNAUTHORIZED** | Keep private/collective boundaries explicit. |
| **NOT_VERIFIED** | Mark synthesized items whose supporting evidence is incomplete. |
| **VERIFIED** | Use subtle proof cues. |
| **ERROR** | Preserve prior safe context where valid; explain failure. |
| **OFFLINE** | Provide last-known valid context only if its freshness/truth status is explicit. |
| **DISABLED** | Unavailable actions remain visibly non-actionable. |
| **UNKNOWN** | Show uncertainty beside the affected claim or section. |

## 15A. SIGNATURE / BENCHMARK-TO-BEYOND

### Proof boundary
