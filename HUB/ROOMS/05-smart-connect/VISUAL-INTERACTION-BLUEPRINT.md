# Smart Connect — Visual / Interaction Blueprint V1

**Purpose:** Show how humans/systems connect to one governed intelligence substrate.

## First 3 seconds
The user sees:
- privacy promise;
- overall connection health;
- real registered/live Doors.

## Desktop composition
```
[GLOBAL SEARCH]
[Smart Connect] [Connection Health]

[ CONNECT YOUR INTELLIGENCE ]
 Your intelligence stays yours. Connect only what you choose.

[ Door instrument ] [ Door instrument ] [ Door instrument ]
[ Door instrument ] [ Door instrument ] [ Door instrument ]

[ Selected Door Detail ]
 capability | identity | auth | authority | health | receipts
```

## Primary instrument
**Smart Door Instrument** with exact status.

## Controls
Per door:
- Connect/Authenticate
- Configure
- Test
- Capabilities
- Required Authority
- Revoke/Disconnect
- Receipts

## Data
Canonical Smart Door registry + live auth/health state.

## Critical distinction
CONNECTED ≠ AUTHENTICATED ≠ AUTHORIZED ≠ HEALTHY.

## Mobile
Doors become stacked instruments; detail opens full-screen.

## Do not
- do not present roadmap doors as live;
- do not imply connection grants authority.

## Proof
Door status matches canonical registry/runtime and a connect operation has an observable result.
