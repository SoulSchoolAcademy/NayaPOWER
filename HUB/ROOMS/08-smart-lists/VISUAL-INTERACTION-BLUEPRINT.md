# Smart Lists — Visual / Interaction Blueprint V1

**Purpose:** Let the human intentionally organize canonical intelligence without copying it.

## First 3 seconds
The user sees:
- current list;
- list purpose;
- items grouped by meaningful lane.

## Desktop composition
```
[GLOBAL SEARCH]
[Smart Lists] [List selector] [New list]

[ NOW ] [ NEXT ] [ WAITING ]
[ QUESTIONS ] [ IDEAS ] [ OPPORTUNITIES ]
[ COMPLETED ]

Each item:
 canonical title
 why here
 status
 source room
 actions
```

## Primary instrument
**Mission Table / Smart Collection**.

## Controls
- list selector
- create/rename/archive list
- add/remove reference
- move lane
- Ask Naya why here
- open canonical object
- open source/evidence

## Data
List membership references canonical object IDs.

## Do not
- do not copy object content as new truth;
- do not let every list invent its own state model.

## Proof
Same canonical object can appear in multiple lists without duplication.
