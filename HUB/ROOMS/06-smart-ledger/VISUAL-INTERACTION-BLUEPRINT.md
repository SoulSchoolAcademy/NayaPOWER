# Smart Ledger — Visual / Interaction Blueprint V1

**Purpose:** Explain what actually happened and what proves it.

## First 3 seconds
The user sees:
- scope/time;
- verification health;
- causal timeline.

## Desktop composition
```
[GLOBAL SEARCH]
[Smart Ledger] [Space] [Time] [Verification Health]

[ ALL | ACTIONS | DECISIONS | SHARES | CONNECTIONS | SYSTEM ]

RECEIVED ─ AUTHORIZED ─ EXECUTED ─ OBSERVED ─ VERIFIED
   event      event         event        event        event

[ selected receipt detail / evidence ]
```

## Primary instrument
**Causal Receipt Timeline**.

## Controls
- filters
- Inspect Receipt
- Evidence
- Open Related Intelligence
- Open Actor/Connection
- Ask Naya
- Export proof where supported
- governed recovery only when explicitly available

## Data
Canonical receipts/evidence/authority/outcome records.

## Do not
- do not become financial dashboard;
- do not call executor success VERIFIED;
- do not hide refused/failed states.

## Proof
Known action can be traced from request through verification.
