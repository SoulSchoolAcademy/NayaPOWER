# Your Connections — Visual / Interaction Blueprint V1

**Purpose:** Show who/what is meaningfully connected and why.

## First 3 seconds
The user sees:
- connection summary;
- meaningful relationships;
- one selected relationship detail.

## Desktop composition
```
[GLOBAL SEARCH]
[Your Connections] [Space] [People | Systems | All]

[ relationship field / constellation visualization ]

[ Selected Relationship ]
 who/what
 why it matters
 shared context
 consent/privacy scope
 related intelligence
 recent meaningful activity
 [Open] [Message] [Ask Naya] [Evidence]
```

## Primary instrument
**Relationship Inspector**; graph is supporting visualization.

## Controls
- view switch
- select relationship
- open intelligence
- open Mail
- open Space
- Ask Naya
- inspect consent/privacy
- disconnect/revoke when governed

## Data
Canonical relationships + consent/privacy + related intelligence.

## Mobile
List first; relationship detail full-screen. Graph optional.

## Do not
- do not make graph the product;
- do not expose private relationship metadata.

## Proof
Relationship detail matches canonical connection records and consent.
