# Smart Spaces — Visual / Interaction Blueprint V1

**Purpose:** Let the human enter a meaningful context that changes retrieval, people, projects and intelligence.

## First 3 seconds
The user sees:
- current Space identity;
- purpose;
- key intelligence;
- active people/projects;
- current activity.

## Desktop composition
```
[GLOBAL SEARCH]
[Smart Spaces] [Space selector]

[ SPACE IDENTITY / PURPOSE / PRIVACY ]

[ Intelligence ] [ People ] [ Projects ]
[ Lists ] [ Activity ] [ Goals ]
[ Rules ] [ Connections ]

[ selected module detail ]
```

## Primary instrument
**Context Environment**, not a folder.

## Controls
- switch Space
- open module
- invite/connect where governed
- manage Space privacy
- Ask Naya about Space
- open related intelligence

## Data
Canonical Space/context relationships and scoped projections.

## Do not
- do not create duplicate intelligence inside Space;
- do not make Space merely a colored folder.

## Proof
Switching Space materially changes applicable retrieval/context without changing canonical object identity.
