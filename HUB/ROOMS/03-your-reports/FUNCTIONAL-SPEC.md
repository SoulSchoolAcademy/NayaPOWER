# 03 — Your Reports

**Metaphor:** THE FILM ROOM  
**Route:** `/reports`  
**Theme:** indigo  
**Human question:** **What does all of this mean over time?**

## Human promise

Turn accumulated intelligence into understandable synthesis.

A report is not “37 records found.” It is:
**what changed, what pattern emerged, why it matters, what evidence supports it, and what should happen next.**

## Signature visual

A premium **report theater / analysis studio**.

Top:
- featured current report;
- period selector;
- scope/Space;
- report freshness and verification.

Main body:
- executive nutshell;
- key changes;
- trend/pattern sections;
- important decisions;
- learning;
- risks/opportunities;
- people/connections;
- open questions;
- evidence appendix.

Visualizations appear only when they clarify meaning. No ornamental charts.

## Report types

Time:
- Daily
- Weekly
- Monthly
- Quarterly/Yearly when enough data exists

Purpose:
- Project / Space report
- Decision report
- Learning report
- Relationship / collaboration report
- custom thematic report

## Primary actions

- **Open report**
- **Ask Naya**
- **Compare periods**
- **Inspect evidence**
- **Save / Add to List**
- **Share** under governance
- **Export** where supported
- **Generate / refresh report** only through real runtime capability

## Compare mode

Two periods or reports can be compared:
- changed;
- improved;
- declined;
- newly learned;
- unresolved;
- contradictory.

No automatic “good/bad” judgment without declared criteria.

## Cross-room handoffs

- evidence item → Library / Feed;
- consequential event → Ledger;
- person → Connections;
- message basis → Mail;
- project basis → Space;
- important report conclusion → List.

## Empty state

“No report can be generated from the available verified intelligence yet.”

Explain missing data/runtime requirements.

## Mobile

Report cover → sections → evidence. Charts must remain readable. Use progressive disclosure rather than tiny dashboards.

## Acceptance journey

A human can select a period, understand the report summary, inspect how the conclusion was formed, compare with another period and follow evidence back to canonical objects.

## Human Director source-note reconciliation

The Drive notes clarify that **DAY · WEEK · MONTH · YEAR are different report experiences, not the same template with a new date range**. Daily covers discoveries, learning, decisions, creation, relationships, activity, open questions and Naya synthesis. Weekly becomes **THIS WEEK'S STORY** with emerging themes, momentum, what changed/learned, unresolved items, important relationships and next opportunities. Monthly emphasizes patterns, trajectory, knowledge growth, project movement and relationship development. Yearly becomes **YOUR YEAR IN INTELLIGENCE** — what I learned, created, what changed me, what I contributed, who I connected with and what I understand now that I did not before.

## Shared five-layer mapping

- **ORIENTATION:** period, Space, report type, freshness and verification
- **CURRENT STATE:** current synthesized period plus completeness/coverage
- **INTELLIGENCE:** story, patterns, trends, unresolved questions and Naya synthesis
- **ACTION:** change period, compare, ask, inspect evidence, save/share/export where real
- **PROOF:** every conclusion links to underlying canonical evidence and report-generation provenance
