# Your Reports — Visual / Interaction Blueprint V1

**Purpose:** Reveal meaning across time from upstream intelligence reports.

## First 3 seconds
The user sees:
- report period selector;
- latest report thesis;
- confidence/freshness;
- period summary.

## Desktop composition
```
[GLOBAL SEARCH]
[Your Reports] [ DAY | WEEK | MONTH | YEAR ] [Compare]

[ PERIOD THESIS ]
[ Biggest changes ] [ Decisions ] [ Learning ] [ Open loops ]

[ REPORT STORY / SECTIONS ]
  What changed
  Why it matters
  Patterns
  Risks/opportunities
  Carry-forward

[ Evidence / source trail ]
```

## Primary instrument
A **Time Synthesis Reader**, not a grid of report cards.

## Controls
- period selector at top;
- previous/next period;
- compare mode;
- Ask Naya;
- open source/evidence;
- save/list;
- export/share only where governed.

No Generate Report button.

## Data
Consumes canonical Daily/Weekly/Monthly/Yearly report artifacts.

## Distinction
DAY, WEEK, MONTH, YEAR must differ in synthesis depth, not just date filter.

## Mobile
Single-column report narrative with sticky period controls.

## Do not
- do not author canonical reports client-side;
- do not fill missing periods with sample reports.

## Proof
Opening a report from Feed and Reports resolves to the same report identity.
