## 1. HUMAN JOB

**Find, trust and reuse intelligence**

### The room must answer

- **WHERE AM I?** Intelligent Library
- **WHAT MATTERS?** The durable intelligence that exists and can be reused.
- **WHAT CAN I DO?** Search, open or inspect an intelligence object.
- **WHAT HAPPENS NEXT?** The same object can be understood at a glance and then proven in depth.

### Time-horizon test

**1 second:** Search is clearly the front door.  
**3 seconds:** The visitor understands that they are searching intelligence, not merely files.  
**30 seconds:** They can retrieve, inspect and trust an object.  
**Return visit:** Previous search/task context resumes when legitimate.

## 7. UNIVERSAL STATE MATRIX

The implementation must explicitly design applicable behavior for:

| State | Room requirement |
|---|---|
| **LOADING** | Show result geometry, never invented results. |
| **EMPTY** | Offer broadened interpretations and legitimate adjacent paths. |
| **READY** | Search and result relevance are clear. |
| **BLOCKED** | Explain unavailable index/scope. |
| **UNAUTHORIZED** | Protect private intelligence while explaining scope. |
| **NOT_VERIFIED** | Search result may exist but truth status remains visible. |
| **VERIFIED** | Show concise verification cue with proof access. |
| **ERROR** | Preserve query and offer retry. |
| **OFFLINE** | Clearly separate cached/local results from unavailable live retrieval. |
| **DISABLED** | Filter/action disabled state remains interpretable. |
| **UNKNOWN** | Unknown metadata remains unknown. |

## 8. RESPONSIVE COMPOSITION

### Desktop

Search-first broad surface with results plus detail panel where useful.

### Tablet

Search and result/detail become sequential but keep fast orientation.

### Mobile

Search → result → progressive object detail; filters behind a deliberate control.

## 9. ACCESSIBILITY

This room is not Signature unless its intelligence remains understandable and operable for people using:

- keyboard-only navigation;
- assistive technology / screen readers;
- zoom up to 200%;
- reduced-motion preferences;
- high-contrast / accessibility settings;
- touch input.

Focus order must follow cognitive order. Color may reinforce meaning but never be the sole carrier of meaning.

### Room-specific accessibility consideration

Search results must expose meaningful names, relevance reasoning and state; no hover-only provenance.

---

## 10. PERFORMANCE

Debounce intelligently, cache valid search context, virtualize large result sets, lazy-load proof/detail.

The user should never pay a speed tax for spectacle.
