# Smart Feed — Visual / Interaction Blueprint V1

**Purpose:** Let the human rapidly consume the living stream of projected intelligence.

## First 3 seconds
The user sees:
- room title + current Space/freshness;
- large mode control: **PERSONAL · COLLECTIVE · ACTIVITY**;
- Smart Tabs beneath it;
- the first intelligence object already in view;
- no composer/capture box.

## Desktop composition
```
[GLOBAL SEARCH]
[Smart Feed] [Space] [Freshness]
[ PERSONAL | COLLECTIVE | ACTIVITY ]
[ ALL | SMART NOTES | REPORTS | HIGHLIGHTS | LEARNING | ... ]
------------------------------------------------------------
[ Intelligence Object 1                              ... ]
[ Intelligence Object 2                              ... ]
[ Intelligence Object 3                              ... ]
------------------------------------------------------------
[ New since last visit / end-of-stream state ]
```

## Primary instrument
A continuous, visually rhythmic **Intelligence Stream**.

Each object shows:
- type jewel;
- title / distilled essence;
- why it is here;
- truth state;
- time;
- source/provenance;
- current Space if relevant;
- compact actions.

## Controls + placement
Top controls:
- PERSONAL / COLLECTIVE / ACTIVITY — directly below title because mode changes the entire dataset.
- Smart Tabs — directly below mode because they refine the current dataset.
- Space selector — near room title because Space changes context globally.
- filter button — right side of Smart Tabs; opens sheet, not permanent sidebar.

Object controls:
- Open
- Ask Naya
- Save/Favorite
- Add to List
- Evidence
- Governed Share/Connect if available

No Smart Note capture button.

## Data
Consumes projected canonical:
- Intelligent Blocks / Smart Notes;
- Reports;
- Activity events;
- metadata, provenance, truth state, relationships.

## States
All standard states. EMPTY must distinguish:
- no qualifying intelligence;
- empty Space;
- runtime unavailable.

## Naya
Useful prompts:
- Why am I seeing this?
- What matters most here?
- How does this connect?
- Explain this object.

## Mobile
Mode control stays near top.
Smart Tabs horizontally scroll.
Objects become full-width.
Actions move into bottom sheet.
No second rail/drawer.

## Do not
- do not become social-media composer;
- do not rank by engagement as truth;
- do not show fake activity;
- do not duplicate objects per tab.

## Proof
Switching modes changes real data.
Opening the same object from Feed/Library preserves canonical ID.
