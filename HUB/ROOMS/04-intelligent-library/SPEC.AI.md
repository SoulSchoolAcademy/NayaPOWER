# Intelligent Library — AI Builder Spec

**Read first:** parent Hub contracts + FUNCTIONAL-SPEC + DESIGN-CONTRACT.

## Intent
Build a semantic intelligence vault. Treat domains as navigational lenses over canonical retained intelligence, not separate stores.

## Build order
1. Preserve shared Hub shell and Naya context.
2. Implement ORIENTATION → CURRENT STATE → INTELLIGENCE → ACTION → PROOF.
3. Build signature instrument before secondary controls.
4. Bind controls to governed runtime or honest unavailable states.
5. Preserve canonical object identity across handoffs.
6. Implement full state matrix.
7. Prove keyboard, responsive, reduced-motion, performance and continuity.

## Data / runtime
Canonical retained intelligence index/retrieval plus domain metadata. Counts, gaps and update times must derive from real data.

## Anti-patterns
- filesystem as default metaphor
- 58 tiny buttons
- search results with no why-match explanation
- fake knowledge counts
- hiding uncertainty

## Acceptance proof
- semantic search returns real results
- why-match is explainable
- featured sections use real ranking/state
- domain counts recompute from canonical data
- uncertainty is visible
- domain entry preserves shell/context
- source/provenance is inspectable
