# Intelligent Library — Visual / Interaction Blueprint V1

**Purpose:** Let the human find and understand what NayaPOWER knows.

## First 3 seconds
The user sees a large search field, useful filters, and a small set of relevant/recent intelligence.

## Desktop composition
```
[GLOBAL SEARCH]
[Intelligent Library]

[ SEARCH YOUR INTELLIGENCE ................................ ]

[ Type ] [ Topic ] [ Space ] [ Truth ] [ Time ] [ Filters ]

[ RELEVANT / RECENT RESULTS ]
  result
  result
  result

[ optional detail pane only after selection ]
```

## Primary instrument
**Semantic Intelligence Search + Inspector.**

## Result anatomy
- title/essence;
- object type;
- why relevant;
- truth/provenance;
- current/superseded;
- related intelligence.

## Controls
- search
- filters
- Open
- Ask Naya
- Evidence
- Related
- Save/List
- Open in source room

## Data
Canonical intelligence index / retrieval adapter. Never DOM search.

## Naya
- What am I missing?
- What changed?
- How is this related?
- Why should I trust this?

## Mobile
Search first, results next, detail opens full-screen.

## Do not
- do not become file manager;
- do not duplicate canonical content;
- do not show “current” without supersession truth.

## Proof
Search result opens same canonical ID seen in Feed/Today.
