## 1. HUMAN JOB

**Understand meaning across time**

### The room must answer

- **WHERE AM I?** Reports
- **WHAT MATTERS?** Patterns, changes, conclusions, uncertainty and meaning over time.
- **WHAT CAN I DO?** Inspect or act on the key finding.
- **WHAT HAPPENS NEXT?** The visitor can move from conclusion to evidence to implications.

### Time-horizon test

**1 second:** The thesis of the selected report is perceptible immediately.  
**3 seconds:** The visitor understands what the report says and why.  
**30 seconds:** They can inspect evidence and causal context without drowning in detail.  
**Return visit:** Previous reports remain coherent and comparable.

## 6. INTERACTION CONTRACT

Every consequential control follows:

**CONTROL → INTENT → SCOPE/AUTHORITY → CAPABILITY → OPERATION → OBSERVATION → RESULT → UI STATE → EVIDENCE WHERE REQUIRED**

### Primary interactions

- Open report → thesis first, evidence second.
- Drill into a claim → exact supporting objects/provenance.
- Change time scope → actual report/data scope change.
- Inspect uncertainty → distinguish known/inferred/unresolved.
- Act on next move → real causal path.

### Naya presence

Naya may explain, retrieve, compare, summarize, propose and — only when authorized — act in the context of this room.

Naya must know the active room, selected object/context, truth state and authority boundary before making a room-specific claim.

## 7. UNIVERSAL STATE MATRIX

The implementation must explicitly design applicable behavior for:

| State | Room requirement |
|---|---|
| **LOADING** | Preserve editorial hierarchy during load. |
| **EMPTY** | Explain why no report exists for the selected scope. |
| **READY** | Thesis first, evidence second. |
| **BLOCKED** | Identify unavailable data/dependencies. |
| **UNAUTHORIZED** | Respect report scope and shared/private boundaries. |
| **NOT_VERIFIED** | Mark unsupported or incomplete synthesis. |
| **VERIFIED** | Proof is inspectable, not ornamental. |
| **ERROR** | Offer retry or alternate scope. |
| **OFFLINE** | Allow clearly labeled read-only historical reports if valid. |
| **DISABLED** | Unsupported visualization/filter remains visibly disabled. |
| **UNKNOWN** | Unknown drivers/claims are explicitly marked. |

## 8. RESPONSIVE COMPOSITION

### Desktop

Two-dimensional analysis with strong reading spine and optional evidence/detail plane.

## 9. ACCESSIBILITY

This room is not Signature unless its intelligence remains understandable and operable for people using:

- keyboard-only navigation;
- assistive technology / screen readers;
- zoom up to 200%;
- reduced-motion preferences;
- high-contrast / accessibility settings;
- touch input.

Focus order must follow cognitive order. Color may reinforce meaning but never be the sole carrier of meaning.

### Room-specific accessibility consideration

All charts require text equivalents and meaningful summaries; interaction should not require hover.

---

## 10. PERFORMANCE

Lazy-load deep visualizations and evidence; keep first report thesis fast.

The user should never pay a speed tax for spectacle.
