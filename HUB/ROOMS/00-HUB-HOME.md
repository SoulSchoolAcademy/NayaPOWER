> **The first impression must be: “Naya already understood what mattered.”**

---

## 1. HUMAN JOB

**Arrive inside NayaNET already oriented, recognized and ready to move.**

### The surface must answer

- **WHERE AM I?** Inside my Intelligent Hub.
- **WHAT MATTERS?** The few highest-value things Naya has already distilled for me.
- **WHAT CAN I DO?** Open the top intelligence beat, ask Naya, or enter a room.
- **WHAT HAPPENS NEXT?** The Hub carries me into the right room/object without making me reconstruct context.

### Time-horizon test

**1 second:** presence + recognition.  
**3 seconds:** the human understands the dominant current intelligence and sees the Ask Naya entry.  
**30 seconds:** they can open the top beat, ask a question, or deliberately choose a room.  
**Return visit:** the Hub feels continuous and remembered rather than reset.

---

## 2. THE EXPERIENCE ARC

**PRESENCE → RECOGNITION → DISTILLATION → INVITATION → FLOW**

The Hub must not open as a KPI grid.

It opens as **living intelligence already at work**.

### First-load choreography

1. Obsidian environment resolves.
2. Naya’s identity jewel/presence appears.
3. Human recognition/greeting appears when legitimate identity is available.
4. The current distilled intelligence resolves into a small number of “beats.”
5. The Ask Naya bar becomes active.
6. Navigation is fully available but remains visually quieter than the current intelligence.
7. The human chooses: open a beat, ask Naya, or move to a room.

Motion is restrained, state-linked and reduced-motion safe.

**material core → exact edge light → restrained specular highlight → believable cast shadow → semantic aura → state amplification**

No giant blur clouds.  
No uniform neon outlines.

**Depth first. Light second. Glow last.**

## 4. PERSISTENT SHELL

### Shell controls and room drawer

**The production shell follows the latest Human Director direction recorded on Issue #554.**

- **Top-left corner control:** opens the left room drawer.
- **Top-right corner control:** opens the right product/navigation drawer.
- **Left room drawer:** Today, Reports, Library, Connect, Ledger, Connections, Lists, Mail, Spaces, Settings.
- **Smart Feed is not listed in the room drawer.** It is the Main Show / primary intelligence experience.
- **Right product drawer:** HOME, NAYA POWER, 5-DAY CHALLENGE, ENTER FREE, POWERCAST, WHITE PAPER, ABOUT US, LOGIN.
- Collective / Personal / Activity remains in **one** coordinated sticky mode zone when applicable.
- Mobile uses an intentional navigation adaptation; it does not compress an obsolete persistent rail.

### Top intelligence bar

The top-center instrument is the **Ask Naya / Intelligence Search bar**.

It is simultaneously:
- semantic search;
- question input;
- command entry;
- contextual Naya doorway.

Default language: **“Ask Naya anything…”** or a context-aware equivalent.

It must never imply an action capability that is unavailable.

### System context

Truthful status and current Space/context may appear quietly at the top edge.

Status indicators are real state, not decorative LEDs.

## 5. THE MAIN SHOW — TOP TO BOTTOM

### A. Naya presence / recognition

Naya’s jewel or presence is the first meaningful visual anchor.

If identity is known:

**“Good evening, Shawn.”** style recognition may appear, adapted to local time/context.

If identity is unknown/unavailable, the UI must not fake recognition.

Copy is concise, warm and confident.

### B. Current intelligence headline

One sentence answering:

> **What is the most useful thing to understand right now?**

This is not marketing copy.

It is generated from legitimate current intelligence/state.

### C. Three beats

Default target: **up to three high-value intelligence beats**.

Each beat contains:
- jewel/type;
- distilled title;
- one-line meaning;
- why now;
- truth state;
- time/context;
- one obvious action;
- evidence/provenance available progressively.

The number is adaptive. If there is one meaningful beat, show one. If none are supported, show an honest quiet-state experience.

### D. Ask Naya invitation

The Ask bar receives one restrained state-linked pulse after the content resolves.

It is invitation, not attention theft.

### E. Continue / recent context

Where useful, offer:
- continue where I left off;
- current Space;
- recent unfinished high-value item;
- pending verified dependency.

This appears only when real context exists.

### F. Room navigation

Navigation remains available throughout.

The main show should never force the human through a dashboard before reaching a room.

## 6. THE “HOLY-SHIT” MOMENT

The awe target is not “lots of visual effects.”

The target is:

> **I just entered, I asked for nothing, and the system already organized the few things I actually needed — beautifully, truthfully and with a clear path forward.**

The visual design amplifies that intelligence:

- calm obsidian depth;
- living Naya presence;
- editorial hierarchy;
- three cinematic beats at most;
- semantic spectral edge energy;
- tactile controls;
- instant contextual continuity.

Awe without usefulness fails.

Usefulness without craft is unfinished.

---

## 7. INTELLIGENCE + TRUTH CONTRACT

The Hub Home may consume:
- verified/current intelligence objects;
- active goals/context;
- unresolved high-value items;
- recent verified learning;
- waiting dependencies;
- legitimate user/session context;
- recent room/object continuity.

It must not:
- invent highlights;
- fabricate “new” activity;
- imply a task is important without a rationale;
- expose private/unauthorized intelligence;
- treat retrieved intelligence as action authority;
- confuse prediction with verified fact.

Every beat must be traceable to canonical objects/events.

---

## 8. PRIMARY CONTROLS + CAUSAL PATHS

### Open beat
**CONTROL → selected beat → canonical object → open owning room/detail → preserve context**

### Ask Naya
**CONTROL → user intent → contextual retrieval/reasoning → response → action proposal if applicable → authority check before execution**

### Continue
**CONTROL → legitimate prior context → restore route/object/state → observation**

### Room jewel
**CONTROL → room route → canonical router → selected room state → browser history**

### Evidence
**CONTROL → current claim/object → provenance/evidence projection → no truth upgrade from presentation**

Every control must have either a real path or an explicit unavailable/blocked state.

---

## 9. NAYA PRESENCE

Naya is not a chatbot floating over the Hub.

She is the intelligence the Hub is made of.

On Hub Home, Naya should be able to:
- explain why a beat matters;
- tell the human what changed since last visit;
- compare competing priorities;
- identify uncertainty;
- take an authorized next action;
- open the correct room/object;
- preserve continuity after the action.

Naya should not:
- narrate obvious UI;
- flood the entry surface with prose;
- duplicate the room rail;
- fake familiarity;
- convert every action into a chat turn.

---

## 10. STATE MATRIX

| State | Main Show behavior |
|---|---|
| **LOADING** | Resolve shell/presence first; hold beat geometry without fake content. |
| **EMPTY** | “Nothing urgent needs you.” Offer Ask Naya / continue / room navigation. |
| **READY** | Current headline + supported beats + actions. |
| **BLOCKED** | Explain what source/dependency is blocking a beat or continuity. |
| **UNAUTHORIZED** | Never surface restricted beat content; explain scope only where appropriate. |
| **NOT_VERIFIED** | Visually distinguish tentative/unverified intelligence. |
| **VERIFIED** | Restrained semantic confirmation; provenance available. |
| **ERROR** | Preserve shell/orientation; degrade gracefully to Search/Naya/rooms. |
| **OFFLINE** | Show only legitimately cached/read-only context with freshness. |
| **DISABLED** | Disabled actions explain why when non-obvious. |
| **UNKNOWN** | Unknown remains visible as unknown, not silently omitted as certainty. |

## 11. RESPONSIVE

### Desktop
64px rail + centered main show + generous negative space. Three beats may form a cinematic row/arc only if hierarchy survives.

### Tablet
Rail collapses; main show remains dominant. Beats may become one featured + supporting stack.

### Mobile
One strong beat first. Additional beats below. Ask Naya stays thumb-accessible. Room navigation is one gesture away. No compressed desktop grid.

---

## 12. ACCESSIBILITY

- Greeting/presence must not trap focus.
- Ask Naya has a semantic label and keyboard shortcut only if discoverable.
- Beat order matches screen-reader order.
- Jewel color never carries meaning alone.
- Motion has reduced-motion equivalent.
- Touch targets are motor-appropriate.
- 200% zoom preserves hierarchy.
- Dynamic arrival is announced politely, not aggressively.

---

## 13. PERFORMANCE

The first meaningful Hub experience must feel immediate.

- shell and current identity/context render first;
- no heavy visual effect blocks interaction;
- hero beat content may stream progressively;
- avoid layout shifts;
- preload only truly high-value assets;
- no decorative network calls;
- motion uses transform/opacity where possible.

---

## 14. BENCHMARK-TO-BEYOND

### Best-of intelligence to synthesize
- **Oura / Instrument:** distill the important signal before detail.
- **Linear:** quiet chrome and focused workbench.
- **Things:** calm, low-burden organization.
- **MetaLab / Slack:** personality and human warmth.
- **Tide Guide / Apple-quality interaction:** environmental state + refined motion.
- **NayaNET’s own advantage:** truth, provenance, authority, continuity and adaptive intelligence in one substrate.

### Beyond-benchmark hypothesis

Most products wait for the human to navigate, query and assemble context.

The NayaNET Hub Home should arrive already synthesized:

**recognized context + current intelligence + why it matters + next action + evidence depth**

without hiding the underlying truth.

### Evidence standard

Measure:
- time to first useful comprehension;
- time/steps to first useful action;
- relevance/accuracy of surfaced beats;
- trust/clarity feedback;
- return-context restoration;
- accessibility/performance;
- Human Director visual acceptance.

“10×” remains an ambition unless a real metric demonstrates it.
