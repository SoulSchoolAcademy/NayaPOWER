# Smart Mail — Design Contract V1

**Status:** PROPOSED · REVIEW OPEN
**Parent:** `HUB/DESIGN-CONTRACT.md`
**Metaphor:** **THE SIGNAL ROOM**
**Theme:** Sapphire / Cyan — communication, signal, context

## Creative intent
Turn communication into understandable signal. The human should see what needs attention and why before being buried in chronological volume.

## Center-workspace composition
Top intelligent modes IMPORTANT/RESPOND/FOLLOW UP/DRAFTS/SENT. Message list/stream leads into a focused reader. When a message opens, the main message surface is paired with a restrained Context panel; drafting appears as a deliberate action layer.

## Signature instrument
Meaning-first communication triage + message/context reader.

## Visual hierarchy
Need-to-act signal first, message content second, context and response intelligence third. Chronological inbox remains available but not mandatory default.

## Living-depth expression
Sapphire/cyan light marks active communication and relationship context. Draft/send states use distinct semantic treatment from received mail.

## Motion / liveness
Thread open/close and mode transitions preserve context. Sending state is bound to real send lifecycle; no fake 'sent' success.

## Naya presence
Naya summarizes threads, identifies unanswered questions/commitments, surfaces context and drafts responses; sending always respects authority.

## States
LOADING · EMPTY · READY · BLOCKED · UNAUTHORIZED · NOT_VERIFIED · VERIFIED · ERROR · OFFLINE · UNKNOWN · DISABLED.

## Responsive
Triage mode → message list → full-screen thread → context sheet → compose. No cramped split pane required.

## Must never become
- fake mailbox/sample emails
- generic inbox clone
- auto-send without authority
- context panel that invents facts
- importance ranking with no basis

## Non-regression anchors
- communication intelligence
- real-message only
- Naya draft assistance
- sender/relationship context
- authority boundary on sending

## Design acceptance
The room must remain unmistakably NayaNET, make its unique function obvious, and preserve real causal/proof state.
