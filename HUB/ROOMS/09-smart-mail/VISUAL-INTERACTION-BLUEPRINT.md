# Smart Mail — Visual / Interaction Blueprint V1

**Purpose:** Surface communication that deserves attention, with intelligence context.

## First 3 seconds
The user sees:
- mailbox truth state;
- priority views;
- first message needing attention.

## Desktop composition
```
[GLOBAL SEARCH]
[Smart Mail] [Account/connection truth]

[ IMPORTANT | RESPOND | FOLLOW UP | DRAFTS | SENT ]

[ Message list ] | [ Selected message ]
                 | context
                 | related intelligence
                 | suggested next action
                 | draft/reply controls
```

## Primary instrument
**Signal + Context Reader**.

## Controls
- open
- reply/draft
- compose where connected
- archive
- prioritize
- follow-up
- add related object to list/space
- Ask Naya

If user asks Naya to Smart Note a message, hand off upstream; no local canonical Smart Note creation.

## Data
Real connected mail/message adapter only.

## States
Disconnected mailbox is a designed state, not fake sample mail.

## Mobile
Inbox then full-screen message detail.

## Proof
Send only claims success when real send authority/runtime confirms it.
