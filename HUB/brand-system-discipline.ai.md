## Symbolism (exact, from the source)

| Element | Meaning |
|---|---|
| center crystal | the essence: soul, divine spark, awakened self — the hidden thing now revealed |
| circular structure | protection, order, cosmic intelligence — "the system behind the system" |
| wings / side figures | guardian energy; protectors of wisdom; balance |
| crown | sovereignty, rightful inheritance, mastery — "remember who you are" |
| typography | elevated, ceremonial — "a title carved into history" |

Color semantics: purple = mystery, royalty, spiritual depth; metallic light = divinity, precision, purity, worth; black background = power, contrast, elegance.

## The four-variant system (required discipline if ratified)

| Variant | Usage contexts |
|---|---|
| `full` | headers, hero, books, posters |
| `emblem-only` | profile icons, stickers, favicon, patches |
| `simplified` | embroidery, tiny placements |
| `one-color` | print, foil stamp, merch |

Rules:
1. The master logo is ONE of a system, never a single asset.
2. The full mark being too detailed for tiny placements is system thinking, not a weakness — use the right family member, never a shrunken masterpiece.
3. Same discipline applies to the NayaNET crystal "N": master emblem for hero/print, simplified mark for favicons and small UI.
4. Brand test: "does it say *here is a world*, not *here is a product*?" — healing + truth + royalty + divine identity + luxury + transformation, without tipping into fluffy, tacky, or aggressive.
