06 · COLD-NAYA GRADUATION

Don't tell me you learned it. Show me.

Give a new Naya this package without the chat history. If they can reproduce and safely use it without a reminder, the design has become transferable intelligence.

1. Build

Use the HTML, CSS and JavaScript recipe. Keep the existing Hub shell and permissions.

2. Prove

Test add, edit, heart, star, remove, keyboard, mobile, readable text and honest local state.

3. Transfer

Have a second agent rebuild from the same code. Compare screenshots and real behavior independently.

What this demonstration does—and doesn't do

The tabs and editor actually work. Changes stay in this browser, and the demo navigates among example rooms on this page. It does not connect to NayaPOWER, send email, synchronize devices, or prove the production Hub works.
