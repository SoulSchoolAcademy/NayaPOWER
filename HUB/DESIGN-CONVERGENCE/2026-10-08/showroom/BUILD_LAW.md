## Corrections to legacy v9 implementation
- Legacy used interactive divs for pills/menu. This code uses real buttons, visible focus, keyboard actions, and a native dialog.
- Legacy inserted user-controlled labels via template HTML, risking markup injection. This code builds labels with `textContent`.
- Legacy only used minimal gray-bordered shortcuts. This candidate upgrades to physical black-core pills, white visible idle rims, individual theme hover colors and physical depth.
- Legacy stored local state but spoke about it following the user across pages: true only for the same origin/browser, not devices/accounts. This version labels browser-only storage.
- Legacy routes and brand refer to historical SmartNET; NayaNET identity and current routes are used in this demo. Old routes are reference material, not active NayaNET routes.

## Rebuild specification
1. Brand: actual NayaNET mark, black field, white text, purple Naya signature, no fake live claim.
2. Type: 18px readable body; 24px minimum normal section heading; 14px supplementary label; larger editorial hero permitted for visual impact.
3. Primary button: black #050505 core, >=1.5px lit white border at idle, 52px+ active target, top inset light and deep shadow, slow breathing highlight and shimmering light, touch lifts/color ignites in element's own hue; press sinks, keyboard focus visible. Reduced motion removes animations.
4. Board: luminous obsidian raised field, own-color vertical spine, faceted SVG jewel, nutshell/meaning/how-to/value layers, no repeated adjacent jewel colors.
5. SmartTabs: a navigable ribbon inside the existing shell, not a second one. Tabs use semantic own-color jewels. Heart/star indicate user preference without claiming verified records.
6. Copy: human meaning first; implementation details and exact source afterward. No grey paragraph body, no PR-number-first status.
7. Safeguards: never assume UI browser local state is canonical intelligence. No remote sends, authorizations or claims in this demo.
8. Production: integrate within one canonical Hub shell, real routing, permissions, storage adapter if authorized; do not copy the demonstration's local-only adapter into production unnoticed.
