## Mandatory builder procedure
1. **BOOT** from AGENTS.md, exact main SHA, owner board #1889, current design/room contracts; establish what is built versus merely proposed.
2. **DEFINE JOB**: what human wants in one plain sentence; user job decides metaphor (people vertical, records editorial, inventory grid as appropriate).
3. **REUSE** one canonical Hub shell, one room socket, one governed substrate. No duplicate Naya brain, data stores, composer, invitation flow or navigation chassis.
4. **DESIGN** with black field + white readable text + purple system signature + rich semantic spectrum. Visible white idle light. Black/white buttons with physical depth and honest glyphs. Theme objects glow in their OWN color. No generic flat/SaaS rewrite. Keep jewel bullets and editorial richness of Hub, Reports and Spaces as references.
5. **TEACH** through one canonical Intelligent Block: nutshell → what it means → how to use it → what's in it for you. Extended human, child, grandma, Naya, machine perspectives share object identity. Voice control only if real playback works.
6. **ACT** only through authenticated permission and real route. LIVE, SIMULATED, DEMO, LOCAL_ONLY, UNKNOWN, BLOCKED and VERIFIED never collapse into one status.
7. **ACCESS**: 44px+ touch targets; zoom allowed; real button/anchor semantics and labels, keyboard and focus management, reduced motion. 24/18/14 type roles under the new candidate, but ratified 16px floor wins until resolved.
8. **TEST** exact artifact in browser across mobile/desktop; personally use it for at least one minute; check cards/buttons focus/hover/pressed/disabled, empty/error/denial and persisted outcomes; run static preflight; verify visible reality. A source-only score is invalid.
9. **PROVE** with designer self-score + independent challenge, actual test results, exact SHA/deployment parity and hard-gate checks. Code written ≠ verified ≠ production.
10. **LEARN** the smallest repeat-preventing lesson and require cold Naya to apply it correctly on new work; report to owning room feed and #1889.

## Director's corrective review — 2026-10-08 (new CANDIDATE lessons)
- **Never repeat immediate jewel or bullet colors.** Check computed final CSS, not just a list of intended hex values. Separate neighboring hues by perceptual contrast and adequate space; five signature jewels are CENTERED, not crowded.
- **Human-first communication.** Start with what actually happened, what that means to an ordinary person, why it matters, and what comes next. Place internal PR numbers and technical statuses behind an optional evidence link.
- **Real brand identity.** Use the actual authorized NayaNET logo; a generic N-like icon is not compliance.
- **Readability.** Default body at 18px, major content headline about 24px or clear display headline, secondary details 14px; white primary text, appropriate line-height and separation, not gray 11px paragraphs.
- **Professional gate.** After code tests, inspect the actual rendered user experience on desktop/tablet/phone. Challenge clashing accent neighborhoods, text-over-button collisions, crowded boards and redundant copy. Independent designer must review BEFORE any 9+ claim.
- **Learning falsifier.** A fresh builder must produce varied semantically appropriate jewel hues, human-meaning-first copy and no visual overflow from the canonical law without Shawn reminding them. Source-only PASS is not visual PASS.
