## 1. Purpose of the KNOWLEDGE Directory

The KNOWLEDGE directory is the human-readable canonical record of how the NayaPOWER
governed-intelligence system was conceived, specified, ratified, and executed.

It is NOT the canonical intelligence substrate itself. Canonical intelligence lives in
the governed NayaPOWER system (Receiver, Intelligent Blocks, Smart Notes, receipts).
This directory is the **distilled design corpus**: the conversations, specifications,
ratifications, and engineering decisions a cold Naya (or a human) must be able to read
to understand:

- what NayaPOWER is and why it exists;
- what has been ratified as system law;
- what is implemented, what is designed, and what is still proposed;
- which terminology is canonical and which names are historical;
- what the single agreed implementation plan is, and where execution stands.

**Reading rule:** when a file in this directory disagrees with the live system, the
live system wins for *current state*, and the disagreement itself must be recorded
as a drift finding — never silently resolved.
