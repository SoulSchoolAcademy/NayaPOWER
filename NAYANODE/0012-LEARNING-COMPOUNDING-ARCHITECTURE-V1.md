# Learning & Compounding Architecture V1

## Purpose

Make verified experience alter future behavior and eventually improve the system across generations.

## Learning pipeline

```
EXPERIENCE
→ OUTCOME
→ EVIDENCE
→ RECONCILE
→ LEARNING CANDIDATE
→ VERIFY
→ BEHAVIOR CHANGE
→ VERIFY AGAIN
→ REUSABLE LEARNING
```

## Compounding

Compounding is demonstrated only when previously verified intelligence improves later work.

Preferred experiment:

**held-out task + prior intelligence**

compared with a comparable condition without that intelligence.

Measure relevant outcome and cost differences.

## Learning states

- NONE
- CANDIDATE
- VERIFIED
- REJECTED
- SUPERSEDED

## Reconciliation

A candidate must be checked against:

- current canonical intelligence;
- contradictory evidence;
- scope;
- freshness;
- authority;
- prior failures;
- applicability.

## Behavioral requirement

Writing a learning record is not learning.

Learning requires a future behavior difference attributable to the retained intelligence.

## Evolution boundary

Verified learning may generate improvement proposals.

Only governed change can adopt those proposals.
