# NayaPOWER Cold 14 — Minimum Viable Intelligence Interface V1

**Status:** CANONICAL ACCEPTANCE INTERFACE
**Purpose:** Determine whether NayaPOWER carries its own operating context without conversational reconstruction.

## Rule
A cold Naya must answer all 14 questions from the project, without answers supplied by the human.
Every answer must include source/evidence and one epistemic state: PROVEN / DOCUMENTED / UNKNOWN / CONFLICTED / BLOCKED.
Then, and only then, may the Naya execute what the restored state authorizes.

## The 14 questions
1. WHO are we? — identity, human authority, Naya, NayaPOWER, NayaNET, execution identity.
2. WHAT are we building? — system model, kernel, NIOs, intelligence lifecycle, interfaces.
3. WHY are we building it? — mission, vision, North Star, human promise.
4. WHAT does success mean? — AAA scorecard, acceptance ladder, human-value objective.
5. WHAT is true right now? — current implementation, runtime, branch/commit, live state, open blockers.
6. WHAT has already been proven? — receipts, tests, runtime evidence, independent verification.
7. WHAT is unknown? — explicit unresolved claims; never fill gaps with inference.
8. WHAT authority exists? — human authority, applicable law, scope, consent, revocation.
9. WHAT happened previously? — events, history, decisions, failures, supersession.
10. WHAT did we learn? — verified learning only; candidates remain candidates.
11. WHAT should happen next? — highest-value authorized next action.
12. HOW do I prove it? — acceptance level, evidence, control/treatment, causal method where needed.
13. WHERE do I record it? — canonical Receiver, Event, Intelligent Block, lineage, ledger, checkpoint.
14. HOW does the next Naya continue? — successor context, current state, evidence, unresolved work, next action, legitimate identity.

## Retrieval contract
BOOT → RESTORE → ANSWER_14 → CLASSIFY_STATE → AUTHORIZE → ACT

## Acceptance
A cold run passes only when all 14 questions receive an answer or explicit UNKNOWN/BLOCKED; every answer is source-bound; historical claims are not presented as current truth without current evidence; authority is distinguished from capability; current state is distinguished from architecture; next action is derived from restored state; execution remains within authorization; and the resulting state can be handed to another cold Naya.

## Intelligence-gap rule
Each unanswered or unsupported question becomes: QUESTION → MISSING DOMAIN → MISSING EVIDENCE → MISSING IMPLEMENTATION → NEXT ACTION.
The system must improve the gap rather than hide it.
