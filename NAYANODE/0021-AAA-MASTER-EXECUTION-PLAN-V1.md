## Execution law
READ → PLAN → TEST FIRST → IMPLEMENT → VERIFY → RECORD → SCORE → HANDOFF

## Definition of done
A priority is done only when required implementation exists; tests exist and pass; runtime behavior is observed; evidence is recorded; current state is updated; AAA score reflects evidence; and the next action is explicit.

## Terminal rule
If blocked, record: BLOCKED → EXACT CAUSE → EVIDENCE → SAFE ALTERNATIVE → OWNER → NEXT TEST. Never convert BLOCKED into PASS.

## Handoff rule
Every Naya leaving the system emits: current commit; changed files; verified claims; unknowns; blockers; decisions; evidence; current AAA scores; next three actions; next Naya boot instruction.
