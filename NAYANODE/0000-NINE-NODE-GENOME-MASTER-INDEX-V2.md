**Status:** CANONICAL GENOME MAP • **Target:** AAA / 10-star

## North Star
Build the smallest coherent kernel capable of **durable intelligence, governed action, verified outcomes, learning, compounding, and safe succession**—with the highest possible human value and no hidden authority.

### Core values
**Truth • Human agency • Safety • Consent • Dignity • Continuity • Reversibility • Accountability • Compassion • Excellence • Compounding value**

“Do no harm” is a hard boundary: an action that violates safety, consent, law, dignity, or legitimate authority has zero acceptable value regardless of upside.

## Canonical kernel
**SELF → LAW → ACT → KNOW → PROVE → CONNECT → VERIFY → LEARN → EVOLVE**

## Birth ladder
SPECIFIED → IMPLEMENTED → LOADED → INVOKED → INFLUENTIAL → APPLIED → OUTCOME_OBSERVED → VERIFIED → LEARNED → COMPOUNDED → SUCCESSOR_RETAINED → EVOLVED.

## Every node has six views
1. **Master contract** — purpose, semantics, functions, invariants, dependencies, acceptance.
2. **Machine contract** — schemas, states, transitions, errors, authority, provenance, persistence, replay, security, observability, performance, versioning.
3. **Naya/AI contract** — cognitive operating procedure, value calculus, epistemic discipline, failure behavior, collaboration, succession.
4. **Data/interface contract** — exact inputs/outputs and inter-node envelope.
5. **Proof contract** — what evidence earns each lifecycle rung.
6. **Acceptance matrix** — tests and runtime evidence; no implied PASS.

## AAA audit
A 10/10 score requires all nine nodes to have complete semantic + machine + AI contracts, inter-node interfaces, persistence mapping, threat model, traceability, tests, live invocation, independent verification, and—where applicable—behavioral influence, learning, compounding, and successor proof. Missing evidence lowers **proof maturity**, even if the contract itself is complete.
