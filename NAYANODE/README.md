## The governing idea

**The Node is the reusable intelligence cell.**

The nine Master Nodes are the semantic operating kernel. Experience Nodes carry domain and human intelligence. Meta-Intelligence Nodes carry knowledge about improving the intelligence system.

The system is one connected substrate:

**EXPERIENCE → INTELLIGENT EVENT → NAYA NODE → INTELLIGENT BLOCK → RELATIONSHIPS → RETRIEVAL → APPLICATION → OUTCOME → VERIFICATION → LEARNING → COMPOUNDING → SUCCESSOR CONTEXT**

## Current proof boundary

The repository currently establishes the architecture and a minimal executable kernel, but architecture is not behavioral proof.

The next proof sequence is:

**BOOT → LOAD → INVOKE → INFLUENCE → APPLY → OUTCOME → VERIFY → LEARN → COMPOUND → SUCCESSOR → EVOLVE**

The current known P0 is **identity continuity / legitimate inheritance of the canonical nine-node owner**, followed by proof that the loaded kernel changes real behavior.

## Clean-start rule

Do not add a new subsystem until an existing canonical responsibility cannot satisfy the requirement.

**ONE responsibility → ONE canonical implementation → ONE source of truth.**

Historical material may teach the new system. It does not silently govern it.
