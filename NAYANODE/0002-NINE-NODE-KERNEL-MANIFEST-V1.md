## Kernel invariants

1. All nine responsibilities belong to one governed kernel.
2. A Node is not an independent brain.
3. Node content cannot grant authority.
4. Missing nodes are an explicit integrity failure.
5. Kernel presence is not behavioral proof.
6. Kernel loading is not proof that a Node influenced behavior.
7. Behavioral influence is not proof of successful outcome.
8. Successful outcome is not proof of learning.
9. Learning is not proof of compounding.
10. Compounding is not proof of universal benefit.

## Behavioral requirement

The kernel must eventually be testable through ablation:

**CONTROL:** kernel disabled/absent.

**TREATMENT:** kernel enabled.

The task, relevant context, and authorization conditions must be held comparable. The treatment must demonstrate an attributable behavioral difference before the kernel is considered behaviorally proven.
