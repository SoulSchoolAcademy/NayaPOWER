## Behavioral continuity acceptance

A live proof is not complete merely because the block was retrieved.

Construct a controlled behavioral test with:
- a cold baseline that has no access to the retained block;
- a retained-intelligence condition that retrieves the canonical block;
- the same task/environment constraints otherwise;
- a predeclared expected behavioral delta;
- observable outcome evidence;
- independent verification;
- a held-out test.

The claim must be narrow enough to prove.

The minimum causal statement is:

Access to retained canonical intelligence changed the later system behavior in the predeclared direction under otherwise equivalent conditions.

If the evidence only establishes correlation or sequence, classify it as INCONCLUSIVE.
