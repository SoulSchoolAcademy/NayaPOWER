# Proof & Verification Architecture V1

## Truth ladder

```
UNKNOWN
  ↓
CANDIDATE
  ↓
OBSERVED
  ↓
VERIFIED
  ↓
PRODUCTION-PROVEN
```

Separate terminal states include:

**BLOCKED · CONFLICTED · SUPERSEDED · FAILED**

## Causal chain

When causality is claimed:

**INPUT → INTELLIGENCE → DECISION → ACTION → OBSERVATION → OUTCOME → EVIDENCE → VERDICT**

A Causal Verification Object should bind these elements and identify what is observed versus inferred.

## Evidence rules

Evidence must be:

- addressable;
- attributable;
- temporally bounded;
- relevant to the claim;
- preserved against accidental mutation;
- sufficient for the stated verification level.

## No false promotion

The system must never promote:

- execution to verification;
- correlation to causation;
- implementation to proof;
- a learning candidate to learning;
- one successful case to universal value.

## Acceptance

Every proof claim states:

- claim;
- scope;
- population/task;
- evidence;
- method;
- verdict;
- limitations;
- next test.

## Production proof

Production-proven requires evidence from the actual production boundary, not merely unit or staging tests.
