## Structural findings

### A. Strong existing foundation
The repository already contains explicit North Star, AAA scorecard, nine-node specifications, execution algorithm, value/experience architecture, self-optimization architecture, current-reality contract, manifest, event model, and kernel tests.

### B. Major duplication / placement risk
The Knowledge Bank is source material, not the active distilled Brain. Concept #7 and #8 are byte-identical on current main and should not become two canonical intelligence objects. The older NAYANODE specification family and newer architectural drafts must be reconciled before either becomes an independent authority.

### C. Highest-leverage gaps
1. Canonical manifest → executable nine-node runtime binding.
2. Legitimate cold identity/ownership continuity.
3. First living Intelligent Node.
4. Relationship-aware CONNECT retrieval with ablation.
5. Full behavioral loop.
6. Verified learning that changes held-out behavior.
7. Cold successor inheritance.
8. Sender → Receiver → Hub.
9. Value Calculus runtime + receipts + sensitivity.
10. Production proof.

### D. Value Calculus decision
Value measurement belongs inside the governed intelligence substrate as a capability, not as a new brain or separate scoring product. The score must remain contextual and evidence-aware. The system can make scoring reproducible and procedurally fair; it cannot mathematically prove every domain's moral judgment to be universally just.

### E. Promotion rule
Raw Knowledge Bank remains broad source/archive material. Only distilled, reconciled, typed, connected, evidenced, and materially useful intelligence is promoted into the active Brain. Everything else remains source material, historical context, unresolved candidate material, or archive.

## Acceptance condition

This checklist is complete only when each item has either:
- a canonical home,
- an explicit reason it is not needed,
- or a verified disposition such as historical/obsolete/duplicate.

No item earns implementation merely by appearing on this list.
