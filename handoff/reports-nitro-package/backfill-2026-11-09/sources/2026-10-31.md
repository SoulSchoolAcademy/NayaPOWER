## 4. TOP 10 LESSONS — and how each one changes what we do

1. **A gate that lives in a log is not a gate.** For twelve days, a required daily check existed only as a sentence in a log, so it never ran. *From now on: when we name a repair, we name where it lives — which instruction file, which piece of code — and we read it back there to prove it.*
2. **Design is law now; quote only settled numbers.** The design rules are approved and filed, so pages are built and scored against them. Two numbers from the audit were *not* settled — a headline total that was one seat's own adding slip (the three counts sum to 810, not 815) and a color count that depends on which baseline wins. *From now on: unsettled numbers are named unsettled, every time, and never quoted as fact.*
3. **Pages are assembled, not invented.** A page is a recipe naming proven parts by their exact IDs — never a fresh invention, never a part named loosely. *From now on: a template is scored once, to 9 or better; every page built from it inherits that proof, and we spot-check the copies.*
4. **One number, three places, one truth.** The number on the screen, the number in the sentence about it, and the number in the ledger must be the same number, produced by the same formula. *From now on: when a shown number and the formula disagree, that is a defect we file — not a detail we explain away.*
5. **The bottleneck moved, and that is progress.** Reviews used to be the queue everyone waited behind. Today the review pen was emptied and kept empty — so the wait now sits with makers fixing the named items. *From now on: if your work came back scored, fix the named items and re-ask. Don't re-argue the score.*
6. **Leave a field blank rather than fill it with a guess.** The Grand Mission's proof link stayed empty all day because two candidate homes for it differ and nobody had verified which is real. *From now on: an honest blank beats a confident guess, in every field, every time.*
7. **Count proven results, never motion.** Today motion was the cheapest ever and proof was the scarcest — 840 to 1. *From now on: we judge a day by results proven per person-hour of work, and a pen-holder's waiting queue is their headline number, not their output.*
8. **Ask the one question before shipping anything.** The frame Shawn gave us today: this system is an operating system for Naya — she runs the machinery so people don't have to. *From now on: before anything ships we ask — does the person give almost nothing (a word, a tap, a wish) and receive a ten-star result? 9. **The formal record governs; a summary is only a lead.** All day, quick interim summaries invented mail threads that did not exist — and every one was caught and retracted because the formal handoff (the checked, written record) outranked it. *From now on: no summary enters any record until the filed record itself has been read and matches.*
