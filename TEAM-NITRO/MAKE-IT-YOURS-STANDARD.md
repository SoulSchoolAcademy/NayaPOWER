# MAKE IT YOURS STANDARD — the branding block (Shawn's eye, 2026-10-22 20:55Z)

Born from Shawn opening the Smart Factory page and finding the "MAKE IT YOURS"
block flat: gray input text, pastel soul dots, a raw browser file button.
These four rules bind the block on the live page AND the Step-4 page generator —
a generated page that breaks any one of them is a defect.

1. **White input text — always.** Typed text AND placeholder/example text in
   every input render white (`#F8F7FB`, full opacity). Dim-gray placeholder
   styling (e.g. white at 35%) is banned page-wide, not just in this block —
   it reads as broken. Inputs are wells: recessed, near-black inside, white text.

2. **Soul colors are rich jewels, never pastel.** The seven dots are the
   canonical walk at full saturation — purple `#a06bff` → blue `#3fb8ff` →
   green `#2fe89e` → gold `#ffbf3d` → orange `#ff9a5a` → red `#ff5e6c` →
   magenta `#e84fff` — rendered as stones, not chalk: domed radial highlight,
   deep shade at the base, inset lip + shade, outer glow in the dot's own
   color. Flat single-color fills are banned (they read pastel on black).
   The selected dot reads unmistakably: white ring + own-color outer ring +
   glow + a ✓.

3. **No default file inputs, ever.** A browser-default "Choose File" control
   must never appear on any NayaNET surface. Photo upload is a beautiful
   button in the page's own button grammar (the `.primo` pill), and the block
   shows a preview well: example faces before a photo is chosen, the person's
   own photo (in a lit ring, exactly as it will appear on their app) after.
   The function is end-to-end real — picking a photo feeds the same contract
   flow; no dead or fake controls.

4. **The block carries the impressiveness bar.** MAKE IT YOURS is the
   60-second branding moment — the page's sale. It rides full elevation, a
   spectrum-walk rail across its top, a breathing dot on its kicker, field
   labels with jewel diamonds in walk order, and every control alive on
   hover/touch/focus: inputs ignite in their own field color on focus,
   buttons and jewels lift. Bar: 9+ on the block, honestly scorecarded.
