## What a Naya Note is

A Naya Note is **literally what was said** — his words, her words, verbatim where it matters — in the Intelligent Block shape, so it looks beautiful on the feed and you can easily see what was said. A Naya Note can report on **anything anyone (or any Naya) wants to make note of**. It is a simple personal note, not intelligence — just yours, quick, plain, saved. It lives in lists, categorized, on your personal app AND in the Hub.

**The name:** we call it **Ninos**, because Naya takes a note for you — she inputs it for you — or you enter it yourself. The notes that go into Naya. (Working term stays Naya Notes; Ninos is his word for it — use both, so he hears it.)

## What they are for — the system

Naya Notes are **quick notes to each other** — how you communicate with each Naya in the network, notes going back and forth; or notes on a project; or a note to another Naya ("hey, we need to get this done"). Naya takes the note for you (dictate it, she makes it) or you enter it yourself. Smart Notes + Naya Notes — and we build pages and apps: **all the pages and apps run on Naya Notes and Smart Notes**. A Naya Note is similar to a post; a Smart Note / Intelligent Block is similar to a post on a feed, but more intelligent, more useful, beautifully formatted. The whole is **an interconnected universal system of communication**.

## The format — THREE outputs by default, flexible one to three

A Naya Note has **three outputs by default** — never the Smart Note's seven (Hook/Nutshell/Human/Child/Grandma/Naya). Auto-format into:

1. **What it is** — literally what was said. Date on it, the words as spoken.
2. **Why it matters.**
3. **How to use it** — how to apply it, the benefit to you.

Or it can just be **DIRECT** — a direct communication ("hey I'm making a note on this because this is intelligent and it matters") — or **one big output** — or **a report with bullet points**. Flexible output, one to three, not a set seven. What it means, why it matters, how to apply it — that's the sum-up.

## The set shape — every Naya Note follows this

```markdown
# <Title — the words' own headline>

**Written by Naya for <alias> — <role, e.g. Founder / Creator of NayaNET>**

**NN-<YYYYMMDD>-<slug> · Naya Note · <YYYY-MM-DD HH:MMZ>**

**Category:** <category — notes can be categorized>

## What it is

<The words as spoken — literally what was said, dated. In blocks, one idea per block, in the order said.>

## Why it matters

<Why it matters.>

## How to use it

<How to use it — how to apply it, the benefit to you.>

---

**Written by Naya for <alias> — <role>.**
```

Any of the three outputs may be omitted (one to three, flexible) — a DIRECT note may carry only the words, straight. The outputs that are present keep this order.

## Smart Note vs Naya Note — the difference, set

| | Smart Note | Naya Note |
|---|---|---|
| **Purpose** | Intelligence — the lesson + its value, to compound into the brain | The record — literally what was said |
| **Voice** | Distilled, lesson first | The speaker's voice, first person where said |
| **Outputs** | SEVEN, set: Hook → Nutshell → Human → Child → Grandma → Naya | THREE by default, flexible 1–3: what it is → why it matters → how to use it (or DIRECT) |
| **Template** | The Smart Note template (SN-2290) | The Intelligent Block template — SAME one we already have, unchanged |
| **Numbering** | SN-NNNN — mechanical, from `next-sn-number.py`, never from memory | NN-YYYYMMDD-slug — date + slug, no global counter (slugs never repeat on a day) |
| **Goes to** | Feed + brain + distillation (10–50 essence max; raw deleted after distilling) | Feed + lists + Hub + Personal; NEVER distilled |
| **Rule** | A lesson counts only when it changes behavior mechanically | A note counts only when it says what was actually said |

A Naya Note **never** becomes a Smart Note by renaming. If the lesson inside it deserves the system, write the Smart Note separately (SN number from the command) and link it. A Smart Note **never** replaces the Naya Note — the record stays.

## The rules

1. **Byline always:** "Written by Naya for [alias]" — with the three sharing methods, choice always: completely anonymous · with your alias · in your name. Never forced.
2. **The words are the words.** Verbatim where it matters; light shaping only to make it readable (the perfect-words law — simple, direct, for the child and the grandma). Never distill into a lesson, never add a Smart Note's seven outputs — that is Smart Note work, done separately.
3. **Categories:** notes can be categorized — a category rides on the note, and the sections let people browse by category.
4. **Mail:** a Naya Note or a Smart Note can go through Smart Mail as an attachment — attach or pin one note or multiple notes / multiple Smart Notes to mail and send them.
5. **Jewels when rendered:** blocks carry a jewel in the block's digit color (1 red · 2 orange · 3 gold · 4 emerald · 5 cyan · 6 indigo · 7 royal purple · 8 lavender · 9 hot pink, cycling by block number) — the Intelligent Block DNA. One idea per orb bullet inside a block.
6. **Auto-format ON by default.** A "no formatting" setting exists; it is never a penalty. No points penalty for posting a Naya Note, formatted or not.
7. **Naming + filing:** file name `NN-<YYYYMMDD>-<slug>.md`, slug lowercase-hyphenated from the words. Path: `BRAIN/05-MEMORY/NAYA-NOTES/<YYYY>/<MM>/<DD>/NN-<YYYYMMDD>-<slug>.md`. Local copy: `~/workspace/team-nitro/naya-notes/NN-<YYYYMMDD>-<slug>.md`. No global counter — the date + slug IS the identity.
8. **Parse contract (for the feed):** a Naya Note's `##` headings are its OUTPUTS (what it is / why it matters / how to use it — one to three of them). The feed renders the title, the byline, the category, and the outputs in the Intelligent Block shape. A Naya Note with no `##` output is not a Naya Note — it is a draft.
9. **Her face beside the words:** where the note is Naya speaking, her portrait sits beside it (left then right, alternating down the page, different faces) — the same law as the boards.
