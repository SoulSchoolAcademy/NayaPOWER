5. How To Use Them

Take the SVG file and use it as an image — <img src="icons/core/mail.svg"> — or inline it. Wrap it in .jwl from jewel-icons.css and set --c to the icon’s own deep colour for the hover light. Full icons are 96px art, crisp from 24 to 96. Small -sm icons are 48px art, crisp from 16 to 48 — those are the ones that ride inside message bubbles. Emoji have -sm variants too, for reaction rows at 16–24px — the same construction, the face scaled half into the disc. The full usage spec is USAGE.md in this same folder.
