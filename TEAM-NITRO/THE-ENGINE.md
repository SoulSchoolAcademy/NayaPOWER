## The one sentence

NayaNET is one interconnected communication system: intelligence flows in, gets verified, gets filed, gets shared, and comes back smarter. Every piece has one job, one owner, and one connection to the next piece.

## The pipeline — how the team builds

One machine, five stages, in order. Each stage proven before the next.

| Stage | What happens | The machine that enforces it | Done means |
|-------|--------------|-------------------------------|------------|
| **BRIEF** | The task is defined first — exact element, exact behavior, exact measurement, what must not be there | The brief compiler (refuses an incomplete brief) | A brief a stranger could run |
| **BUILD** | The seat builds, checkpointing to disk as it goes | The checkpoint watcher (silence over 30 min is caught) | The work on disk, in small fast chunks |
| **VERIFY** | A DIFFERENT seat checks it in a real browser, phone first, every button clicked | The verification machine (checks bytes, not claims) | A receipt: PASS or NOT DONE, with evidence |
| **FILE** | The verified work files itself to GitHub + registry + feed | The filing machine (read-back verified, or it is not filed) | The file at a real address, byte-identical |
| **REPORT** | The day's verified actions ARE the Daily Intelligence Report | The report (the count, not the story) | The count, rising |

## The sync rule — nothing sits, ever

- Every open project has a named seat working it, or a queue place with a start condition. Not on the board = does not exist.
- The pulse checks every 15 minutes. Silence over 30 minutes is caught. One alert per fault — duplicates are noise.
- Two long-lived teams at a time (restarts kill agents). Small fast chunks inside a restart window. Checkpoint early, resume from disk.
- A restart costs minutes (the last unwritten step), never the whole task. If a restart wipes the work, the checkpoint rule was broken — fix the brief, not the restart.
- GitHub is the truth. A checkpoint is not real until it is in GitHub, read-back verified.

## The level-up — the only score that matters

We must be leveling UP, never down. The score is counted daily, in the Daily Intelligence Report:

- **Verified valuable actions per day** — must rise. (Done on the live page + proven by a different seat + valuable + recorded. Motion is not a verified valuable action.)
- **Pages complete by his eye** — must rise. (Zero of 26 on 2026-11-07. The order: Dashboard → Personal → Hub → Pricing. One page finished before the next starts.)
- **Lanes sitting** — must be zero. (If Shawn catches a lane sitting, the score is not a 10.)

If either number falls, the captain fixes it the same pass. Leveling down is not a statistic — it is a failure of the system, and the system is mine to fix.
