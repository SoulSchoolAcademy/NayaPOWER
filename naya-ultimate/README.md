## How to build a Smart App from this

1. **Open `index.html`.** See the standard. Feel the quality bar.
2. **Copy `tokens.css`.** Every component needs these tokens.
3. **Pick your components** from `lego/`. Each file is self-contained with live demos and copy buttons.
4. **Follow the laws** (section 08): black heart, white voice, visible skin. Spectrum in law order. White text 99%.
5. **Run the pre-ship checklist** (section 09): all six, or it doesn't ship.
6. **Score with the calculator**: `tools/design_law/design_calculator.py your-page.html` — 90+ to ship.

## The laws (memorize these)

- **Black ground. White light. Purple soul.**
- **Spectrum is meaning, not decoration:** magenta → purple → blue → green → gold.
- **Black heart, white voice, visible skin.**
- **Size separates, color doesn't:** 24 / 18 / 14.
- **Every bullet a jewel. Never twice in a row.**
- **Truth is part of the visual language:** verified glows green, claims stay quiet.
- **Light up, don't glow out.** Depth through layers, not neon.
- **No flat elements.** Everything has depth. Everything responds.
- **Score the experience, never the code.**
- **Verify before claiming.**
