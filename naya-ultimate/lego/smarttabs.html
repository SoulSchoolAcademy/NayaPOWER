Naya Lego · SmartTabs v9.0.0

The component that follows you.

A universal favorites ribbon that follows the user across every page. Add, edit, heart, star, remove, navigate. State persists. This one below is real — click a pill, right-click it, add your own.

The contract: one storageKey across all pages so state follows the user. onNavigate wires into your router — the component never assumes. 💜 hearts outrank ⭐ stars: the most important tabs literally rise to the top. Esc closes everything.

Live demo

Right-click a pill (or tap ⋯) for Edit / 💜 Heart / ⭐ Star / Remove. State saves to this browser.

Step 1 — the container
<div id="smarttabs"></div>
Step 2 — include the kit and mount
<link rel="stylesheet" href="smart-tabs.css">
<script src="smart-tabs.js"></script>
<script>
  // Shared storageKey across ALL pages — the ribbon stays in sync everywhere.
  const tabs = SmartTabs.mount('#smarttabs', {
    storageKey: 'smartnet_shortcuts',
    onNavigate: (route, s) => Router.go(route), // hook into your router
    routeMap: { 'soulschool': '/soulschool' }  // keyword synonyms
  });
</script>
Step 3 — the API
// Read & write
tabs.list();                    // → [{ id, label, route, heart, star }, …]
tabs.set(arrayOfShortcuts);     // replace wholesale
tabs.add({ id, label, route, heart, star });
tabs.update(id, { label, route, heart, star });
tabs.remove(id);
// Listen
tabs.el.addEventListener('change', e => console.log(e.detail));

// Data shape — heart/star are mutually exclusive, hearts sort first
{ id: 'sc-1', label: 'SoulSchool', route: '/soulschool',
  heart: true, star: false }

Why it works everywhere: one storageKey across all pages so state follows the user. onNavigate wires into your router — the component never assumes. That's the whole contract.
