## The five questions

Every intelligence in this system must answer, in plain words:

1. **What is it?**
2. **What does it mean?**
3. **Why does it matter?**
4. **What is in it for me?**
5. **How does it connect?**

If it cannot answer all five, it is not finished — it is not yet intelligence.

## What this is not

- Not a database. A database accumulates; a mind distills.
- Not a chatbot. A chatbot responds; this system remembers, proves, and grows.
- Not a dashboard. It is the living intelligence behind every door, not the doors themselves.
