# 🔱 NayaPOWER Constitution

The Constitution is the highest-level human-governance layer of NayaPOWER. It sits above the BRAIN and defines the principles that all lower-level governance, architecture, runtime behavior, agents, interfaces, and successors must respect.

## Canonical files

- [0000-NAYAPOWER-CONSTITUTION-ACT-V1.md](./0000-NAYAPOWER-CONSTITUTION-ACT-V1.md) — constitutional act and authority boundary.
- [0001-NAYAPOWER-FOUNDATIONAL-OPERATING-LAWS-V1.md](./0001-NAYAPOWER-FOUNDATIONAL-OPERATING-LAWS-V1.md) — human-readable operating laws derived from the Act.

## Constitutional hierarchy

**Human Director → Constitution → Master Design → Governance → Architecture → Node/Capability Contracts → Implementation → Runtime**

The Constitution does not self-ratify. Ratification is a human-authority event.

## Relationship to BRAIN

The Constitution is intentionally outside `BRAIN/`. BRAIN is the semantic intelligence substrate; the Constitution governs it. `BRAIN/MASTER-MAP.md` and `BRAIN/NAYAPOWER-BRAIN-INDEX.json` point back to this constitutional root.
