# NayaPOWER System Structure V1 — AI Language

**Status:** PROPOSED (companion to Manifesto V2)
**Date:** 2026-10-12

## 1. Layers

- **NayaNET** — human interface. Promise: "your intelligence belongs to you." Spaces, diary entries.
- **Team Naya** — the collective. 1 director + 12 named bees + shared intelligence.
- **NayaPOWER** — the engine. Capture, distill, prove, compound. Canonical source: GitHub main.

## 2. The five loops (normative)

**Work:** TRIAGE → DISPATCH(3/wave) → BUILD(negative controls) → VERIFY(independent) → WIRE(both directions) → SCORE(honest) → MERGE(protocol only) → PROVE(at tip).

**Learning:** EXPERIENCE → CAPTURE → LESSON(7 fields) → LAW → APPLICATION → MECHANISM → INSTINCT. Graduation = cold agent applies unprompted. Win patterns: 3 recurrences → standing practice.

**Never-sleep:** SUPERVISOR(10min): wave active? exit : dispatch next 3. HEARTBEAT(hourly): dashboard/ledger/network, never dispatches.

**Truth:** ref-anchored tip → byte-identity(head, merge, tip) → sabotage battery → real numbers first. Score format: number before framing, always.

**Compounding:** lessons outlive instances. First-activation = ingest all Smart Notes. Diary entries = world input. Cold-start prohibited.

## 3. Design logic (why it works)

1. Speed and truth separated into different loops, sequenced.
2. Accountability structural: names, receipts, scores — trust from numbers.
3. Learning pipelined with exit criteria; graduation is the only proof.
4. Protocol is authority: 9.5+ exact head + cross-seat + green gates.
5. Waste instrumented: drain/coalescing/burn rates reported with fixes.
