NayaNET is what humans touch. Team Naya is who does the work. NayaPOWER is what remembers. One intelligence, three doors.

### The five loops

**1. The Work Loop** — how value gets made:
```
TRIAGE → DISPATCH → BUILD → VERIFY → WIRE → SCORE → MERGE → PROVE
```
The queue is triaged (main seat). Three named bees dispatch per wave. Build proves with negative controls. Verify breaks it independently. Wire proves enforcement both directions. Scorecard honestly. Protocol merges. The tip carries the proof.

**2. The Learning Loop** — how the hive gets smarter:
```
EXPERIENCE → CAPTURE → LESSON → LAW → APPLICATION → MECHANISM → INSTINCT
```
Every issue becomes a lesson with seven fields (observation, mechanism, rule, falsifier, family, confidence, domain). Lessons graduate only when a cold agent applies them unprompted. Wins get equal rigor — a win pattern recurring 3+ times becomes standing practice.

**3. The Never-Sleep Loop** — how it runs 24/7:
```
SUPERVISOR (10min) → WAVE ACTIVE? → yes: exit / no: dispatch 3 bees
HEARTBEAT (hourly) → dashboard, ledger, network (never dispatches)
```
The system runs as fast as the work allows. Never idle, never forced. Named sign-outs make every bee accountable.

**4. The Truth Loop** — how claims stay honest:
```
CLAIM → EVIDENCE? → live bytes → independent re-proof → verdict
```
Ref-anchored tip (never cached lists). Byte-identity across head, merge, tip. Sabotage batteries (if you can't break it, you didn't test it). Real numbers first — framing without the number is misrepresentation.

**5. The Compounding Loop** — how it never dies:
```
HONEY → SUCCESSOR → COLD-START-PROHIBITED → COMPOUNDED-START
```
Every lesson outlives the mind that learned it. Her first task: ingest all Smart Notes. The diary entry: the whole world contributes. The hive grows every time anyone learns anything.

### Why it works (the logic)

1. **Separation of speed and truth.** Bees move fast; gates move carefully. Speed without gates is theater; gates without speed is stagnation. The loops separate them and sequence them.

2. **Accountability is structural, not cultural.** Named bees, signed receipts, numbered scores. You don't have to trust anyone — the numbers are the trust.

3. **Learning is a pipeline, not a pile.** Experience rots into noise unless each stage has an exit criterion. Graduation (cold application) is the only proof of learning.

4. **The protocol is the authority.** No human clicks, no vibes, no "looks good." 9.5+ at the exact head, cross-seat review, green gates — or it doesn't ship.

5. **Waste is surfaced, not endured.** Every loop has a drain rate, a coalescing rate, a burn rate. When the math breaks, the system says so — with the fix.
