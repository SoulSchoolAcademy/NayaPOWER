# Smart Feed — Smart Notes

**PURPOSE:** Area-scoped intelligence and learning feed for the Smart Feed project.

## What belongs here
Capture durable discoveries, decisions, lessons, reusable patterns, relationships, contradictions and context that future Nayas should be able to retrieve and use.

## What does not belong here
This is not an archive of every conversation and not a competing memory system. A Smart Note must have provenance and explain why the information remains useful.

## Standard record
Use: YYYY/MM/DD/YYYY-MM-DDTHH-MM-SSZ__TOPIC.md

Each note should preserve: source/provenance; timestamp; visibility/permission state; truth/freshness state; related/superseding records; reusable lesson; meaning/application; successor relevance.

## Relationship
Live conversation / event → Smart Note → PIS / relationships → Smart Feed intelligence → NayaNET views

Area Smart Notes are a scoped human-facing organization of intelligence, not a separate intelligence engine.
