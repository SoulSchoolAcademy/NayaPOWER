## Hierarchy

**HUMAN DIRECTOR → MASTER DESIGN CONTRACT → NAYANET INTERFACE DESIGN CONSTITUTION → VISUAL BLISS → ATOMIC LAWS → COMPONENT CONTRACTS → IMPLEMENTATION**

The laws are not separate design systems.

They are one language.

## Non-negotiable top rule

> **No glow, accent, depth effect, animation, shadow, gradient or other visual device may make anything harder to read, understand, find, operate or trust.**

## Identity rule

**PURPLE + BLACK + WHITE** are the dominant NayaNET identity.

Complementary spectral colors are allowed for semantic themes/states.

Yellow and gold remain supporting colors, not dominant reading treatments.

## Builder test

A cold builder who has not read this law stack must not start interface implementation.

A builder should be able to explain, before coding:

**what Visual Bliss means → how a Primo Button works → what makes a Board an intelligent object → how icons belong to one family → how typography stays generous → how state remains truthful → how accessibility is preserved → how visual regression is proven.**
