# DESIGN — UX / UI / Visual Language / Design System

## UX
Design for the human outcome, not backend machinery. The user should receive intelligence without managing infrastructure.

## UI
The Hub is the human cockpit and visual brain. It is a projection surface, not the source of truth. Avoid dead controls, fake functionality, duplicate stores, dashboard clutter and controls without a causal path.

## Visual language
Established direction: premium, high-tech, dimensional and alive; obsidian/black foundations; purple/deep-purple energy; high contrast; jewel-like intelligent objects; intentional depth.
