# DESIGN / UI

## UI principles
- One coherent visual system.
- High information value with low clutter.
- Clear hierarchy between intelligence, metadata, actions and proof.
- Explicit states for loading, empty, blocked, unknown, success and verified.
- No visual affordance for an unavailable capability.

## Hub composition
Use the established single-left-rail direction and keep primary content focused on Smart Feed and intelligence. Avoid duplicate right rails and generic dashboard grids when they do not improve the human task.

## Trust visibility
Where useful, show provenance, verification state, freshness and applicability without forcing the user into backend terminology.

## Completion
A beautiful screen is not complete if its data or actions are disconnected from the real system.
