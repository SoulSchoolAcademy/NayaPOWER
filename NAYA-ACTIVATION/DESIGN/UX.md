# DESIGN / UX

## Human-first objective
The user should receive the benefit of intelligence without becoming the project manager of its infrastructure.

## Experience law
Every visible interaction must have a real causal path to capability, state or useful navigation. No dead buttons, fake controls or decorative machinery presented as functionality.

## Hub
The Hub is the human cockpit. Smart Feed is a primary intelligence projection. Rooms are surfaces and destinations, not independent brains.

## Distillation
The interface should reduce cognitive load by presenting useful intelligence at the right time, with enough provenance and context to trust and act without exposing unnecessary backend complexity.

## Acceptance
UX is complete only when the human can accomplish the intended outcome, system state is real, errors are understandable, and the path remains coherent across cold start, active work and handoff.
