# CURRENT REALITY / NEXT ACTION

## One-baton law
At the end of a work cycle there must be exactly one highest-value executable next action.

## Action contract
The next action should state:
- verb;
- target;
- scope;
- why it is highest value;
- required authority or capability;
- expected evidence;
- completion condition.

## Selection rule
Prefer the smallest causal unit that advances the North Star and reduces uncertainty. Do not create another framework when an existing seam can be verified or repaired.

## Cold successor
A successor reads this locator, resolves current canonical state, and either executes the declared action if authorized or replaces it with a newly justified action after reconciliation.
