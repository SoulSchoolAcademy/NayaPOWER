# CURRENT REALITY / ACTIVE WORK

## Method
Determine active work by reconciling current `main`, current GitHub issues/PRs, recent commits, ratified project-intelligence, and latest claim-matched verified evidence.

Do not use a dated queue as live truth without checking whether newer work superseded it.

## Priority rule
Choose work by causal value to the current North Star, not by whichever artifact is easiest to edit.

## Current strategic focus
Do not freeze a strategic focus into this activation locator. Resolve the current focus at boot from live work and evidence, then record exactly one next action.

## Execution rule
Declare one next action. If multiple tasks are required, sequence them internally but expose the single highest-value executable action as the next baton.
