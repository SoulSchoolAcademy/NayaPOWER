# CURRENT REALITY / ACTIVE WORK

## Method
Determine active work by reconciling canonical control-plane state, project-intelligence, current issues and PRs, and latest verified evidence.

## Priority rule
Choose work by causal value to the current North Star, not by whichever artifact is easiest to edit.

## Current strategic focus
The continuity frontier is the ability for retained intelligence to flow sender -> receiver -> Hub and for a cold successor to retrieve and use an active lesson without being handed it. Welcome/front-door work is downstream of the house being built.

## Execution rule
Declare one next action. If multiple tasks are required, sequence them internally but expose the single highest-value executable action as the next baton.
