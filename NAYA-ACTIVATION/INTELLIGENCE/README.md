# INTELLIGENCE — Architecture / Memory / Learning / Continuity / CVO

## Architecture
EXPERIENCE → CAPTURE → INTELLIGENT EVENT → INTELLIGENT BLOCK → LINEAGE → RELATIONSHIP/GRAPH → INDEX → CHECKPOINT → LEARN → CAUSAL VERIFY → PROMOTE → ACTIVE LEARNING → COLD RETRIEVE → RECOGNIZE APPLICABILITY → AUTHORIZED APPLY → OUTCOME → INDEPENDENT VERIFY → IMPROVED INTELLIGENCE → COLD SUCCESSOR → RETRIEVE AGAIN → USE AGAIN → COMPOUND

## Memory
Persistence is necessary but not sufficient. A stored record is not automatically learning, truth or usable intelligence.

## Learning
Learning becomes operationally meaningful when it can influence later authorized behavior and that influence is independently evidenced.

## Continuity
A successor reconstructs identity, authority, current state, intelligence, evidence and next action without manual replay.

## CVO
The Causal Verification Object connects what was known, what was done, what happened and what was independently verified. Resolve its exact live schema before implementation.

Do not create a second brain, graph or memory store merely because an existing seam is inconvenient.
