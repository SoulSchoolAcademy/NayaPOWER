# INTELLIGENCE / MEMORY

Memory is durable, retrievable meaning with enough context for correct future use.

## Preserve
Identity, essence, purpose, context, provenance, epistemic state, applicability, freshness, relationships, scope, conflicts, supersession and behavioral effect as applicable.

## Retrieval
A useful retrieval result should explain what was selected, why it was selected, its relationship path, provenance, trust state, applicability, freshness and relevant exclusions.

## One brain
Do not create another hidden store, graph or memory system merely because a canonical retrieval seam is inconvenient.

## Acceptance
The strongest test is not "can the record be found?" It is "can a cold successor retrieve the relevant meaning, understand it, use it within authority and continue the work?"
