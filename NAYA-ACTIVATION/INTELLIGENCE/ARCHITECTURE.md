# INTELLIGENCE / ARCHITECTURE

## One brain
NayaPOWER has one canonical semantic model. TREE provides navigation, OBJECT identity provides addressability, GRAPH provides relationships, CONTRACT defines meaning and behavior, and PROOF establishes trust.

## Causal river
EXPERIENCE -> CAPTURE -> DISTILL -> STRUCTURE -> CONNECT -> PROVE -> PRESERVE -> RETRIEVE -> APPLY -> ACT -> OUTCOME -> VERIFY -> LEARN -> COMPOUND -> SUCCESSOR -> EVOLVE

## Runtime intelligence river
EXPERIENCE -> CAPTURE -> INTELLIGENT EVENT -> INTELLIGENT BLOCK/OBJECT -> LINEAGE -> GRAPH -> INDEX -> CHECKPOINT -> LEARN -> CAUSAL VERIFY -> PROMOTE -> ACTIVE LEARNING -> COLD RETRIEVE -> RECOGNIZE APPLICABILITY -> AUTHORIZED APPLY -> OUTCOME -> INDEPENDENT VERIFY -> IMPROVED INTELLIGENCE -> SUCCESSOR

## Object model
Durable objects require identity, type, status, owner/scope, meaning, provenance, evidence, applicability, relationships and continuity fields appropriate to their type.

## Boundary law
TREE != GRAPH != DATABASE != INTERFACE. The architecture fails if any one is treated as the other.
