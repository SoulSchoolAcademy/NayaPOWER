# OPERATIONS / GIT

GitHub is a durable engineering and institutional-memory surface for code, contracts, evidence references and handoffs.

AGENTS.md is the repository boot gate for coding agents that honor repository instruction files. It does not grant permissions; the host agent still needs authorized access.

Know the current branch, base, head and merge path before changing files.

A commit proves a change was recorded. It does not prove the intended behavior.

PRs should expose scope, evidence, limitations and acceptance status.
