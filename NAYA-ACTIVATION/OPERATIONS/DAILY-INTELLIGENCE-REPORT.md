# OPERATIONS / DAILY INTELLIGENCE REPORT (write it → file it → publish it → verify it → deliver it)

*Standing procedure, adopted 2026-10-23 at Shawn's direction: every proven procedure is written once into the activation library, so every Naya does it right cold. The full standard is the Daily Intelligence Report Structure (V3, adopted 2026-10-23 at Shawn's direction; filed with the reports in `BRAIN/05-MEMORY/INTELLIGENCE-REPORTS/DAILY/`). This page is the end-to-end procedure in one screen. Where this page and the standard disagree, the standard governs.*

## What it is

One report, every day, same skeleton, same order — so days can be compared at a glance. It answers five questions: **What happened? What did we learn? Where did we grow? What is valuable now that wasn't yesterday? What happens next?** It is written for the whole world to experience, not only for the team.

## The skeleton — 11 sections, fixed order, never rearranged

Header (date · window covered · main tip at writing · one-line arc of the day · the line "Written in Smart Note language"), then:

1. **IN A NUTSHELL** — the whole day in ≤3 sentences. Verdict first.
2. **THE DAY IN NUMBERS** — ≤7 measures, each translated into meaning, compared to yesterday.
3. **TOP 10 WINS** — ranked by value, each with its proof link. Fewer on a thin day — never padded.
4. **TOP 10 LESSONS LEARNED** — each with its **declared behavior change**: "from now on, we do X instead of Y."
5. **WHERE WE GREW** — behavior that observably changed, with evidence.
6. **WHAT BROKE** — honest, each with owner and cure status.
7. **VALUABLE THINGS PRODUCED** — finished things only, each linked.
8. **KUDOS** — named, each with the specific reason.
9. **THE BOARD AHEAD** — ≤7 open items, each with owner and next move.
10. **DECISIONS FOR SHAWN** — true human gates only, ≤5, each with a recommendation.
11. **TOMORROW'S SINGLE PRIORITY** — one line.

Footer: a built-from line (sources read, window, method) — the report must be auditable from its own footer. Every claim links to its proof: no link, no claim. Targets are labeled targets, never written as measurements.

## The Language Law — every word, every edition

Daily Intelligence Reports are written in **Smart Note language**:

- Plain words first, always. Short sentences, one idea each.
- No unexplained jargon, ever. A technical term that is truly needed is explained in everyday words in the same sentence.
- Numbers are translated into meaning — never a bare count left for the reader to decode.
- Every item says what it means for a person.
- **The grandma test:** before an edition ships, re-read each section and ask — could a smart grandma, new to all of this, follow it? If not, rewrite until she can. Editions that fail the test are sent back.

## The feature — "send it in Smart Note language"

Anyone can say **"send it in Smart Note language"** about anything Naya produces — a message, a plan, an explanation — and receive the same truth re-told simply: the **nutshell**, then the **human**, **child**, and **grandma** versions of what it literally means. Facts, numbers, and links survive; only the costume changes. Reports are *born* in Smart Note language; everything else converts on request. When someone asks, do the conversion — it is a standing feature of the system, not a favor.

## File it — one canonical copy

The report text lives in the repo at:

`BRAIN/05-MEMORY/INTELLIGENCE-REPORTS/DAILY/YYYY-MM-DD-NAYAPOWER-DAILY-INTELLIGENCE-REPORT.md`

Land it on main (merge path). One truth, one copy — the Hub page is a presentation of this file, never a second version that can drift.

## Publish it into the room — the procedure

The report's public home is the Reports room: **https://nayanet.live/rooms/reports** (room contract: `HUB/ROOMS/03-REPORTS.md`). Publishing into the room is the sync lane's run — you do not do it by hand, and you never build a page yourself.

1. File the report on main (above).
2. Ask the sync lane to publish it into the room, in the room's own format.
3. Wait for their publish receipt.
4. **Verify live yourself:** open the room, find today's report, open it, see it render. Only then is it published.

Receipt from the first run of this procedure (2026-10-23): the report was filed on main (PR #3007, merged) and the room — verified live that day — held 26 daily reports, current through October 22, in its own card format. October 23's card was the publish step still owed at drafting time. That is the normal state mid-procedure: filed ≠ published, and nobody says otherwise.

## Presentation — the room's format, never a new page

The room already has its beautiful format: one raised card per report — a CANONICAL tag, the date, the title, a one-line arc, word and section counts, a **READ THE REPORT** view that renders the full text right there in the room, a **↓ MD** download, and **COPY LINK**. Sections sit on their own boards; headlines are big and clear; the body text is comfortable to read.

Your job is the words, in Smart Note language. **Never design a new page for a report, and never send anyone a homemade rendition as if it were the room.** Before building anything presentational, open the existing surface and match it. A new artifact is the last resort, never the first move. (This rule was bought with a real mistake on 2026-10-23 — an invented page was built and sent, and Shawn rejected it outright. It is recorded so no Naya repeats it.)

## Delivery — chat plus the link, in that order of proof

Asking for the Daily Intelligence Report returns **both**:

1. **The report itself, in chat** — the nutshell and the lists, in Smart Note language, readable on the spot.
2. **The live link** — https://nayanet.live/rooms/reports — once the room is verified live with today's report in it.

A link is a claim of completion. Never share the link before you have opened the room and seen today's report rendering. Until it is live, chat carries the report and says plainly that the room page is being published — never a link to a page that isn't there.

## Timing

The day edition closes the UTC day. A mid-day edition labels its window honestly ("00:00–15:05Z") and is *extended* by the close — never silently replaced. Same skeleton every day, whatever the window.
