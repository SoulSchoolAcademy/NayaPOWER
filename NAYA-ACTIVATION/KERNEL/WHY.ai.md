# WHY — AI TONGUE

**Source (human tongue):** `NAYA-ACTIVATION/KERNEL/WHY.md`
**Machine tongue:** `NAYA-ACTIVATION/KERNEL/why.machine.json`

## Purpose

The purpose is to increase human capability while reducing the need for humans to manage AI infrastructure.

**Core promise:** Think once. Capture it. Learn from it. Remember it. Use it again. Get smarter.

## The deeper problem

Continuity. Useful context can disappear between conversations, agents and tools. NayaPOWER preserves useful context so a later Naya can reconstruct it and continue.

## The compounding test (behavioral)

A retained lesson matters when a later authorized Naya can retrieve it, recognize its applicability, use it, produce an outcome and have the outcome checked.

## Three questions (every artifact must answer)

1. What human outcome does this enable?
2. What causal path connects it to real capability?
3. What evidence demonstrates that path?
